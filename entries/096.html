パソコンの電源を入れると勝手にアプリが開く。起動を速くするスタートアップの整理方法

    AIの見立て

    起動時に開くアプリは、設定から選んで止めることができる。必要なものだけ残せば、立ち上がりは速くなる場合がほとんど

    起動時に開くアプリは、設定から選んで止めることができます。止めるといっても、アプリそのものを消すわけではありません。起動時に開かないようにするだけなので、使いたいときはいつでも自分で開けます。

    ボトルネックは3つです。1つ目は、何が起動時に開いているのか分からないことです。2つ目は、止めてよいものと、止めてはいけないものの区別がつかないことです。3つ目は、設定の場所を知らないことです。

    一覧を開いて、必要なものだけを残します。そうすれば、立ち上がりは速くなる場合がほとんどです。

    この記事は、2026年11月時点の Microsoft と Apple の公式情報をもとにしています。手順や画面の名前は、OS のバージョンで変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    電源を入れると、頼んでいないアプリが次々に開く
    チャット、音楽、会議のアプリが、起動時に開く設定になっている状態。自分で設定した覚えがなくても、インストールしたときにそうなるアプリがある。
    落ち着いて使えるようになるまで、何分もかかる
    起動時に開くアプリが多いほど、立ち上がりに時間がかかる。開いたアプリで画面もいっぱいになる。
    何が起動しているのか分からない
    起動時に開くアプリの一覧を、まだ見ていない。一覧を見る画面は、Windows にも Mac にも、もともと用意されている。
    大切なものを止めてしまうのが不安で、そのままにしている
    この不安には理由がある。セキュリティソフトや、キーボード・音などのソフトを止めると、困ることがある。一方で、起動時に開かないようにしても、アプリそのものは消えない。止めたあとで、元に戻すこともできる。
    毎朝パソコンを開くのが憂うつ
    起動のたびに待たされ、勝手に開いたアプリを閉じる手間が、毎日くり返されている。

    起動時にアプリが開く仕組み

    仕組みを知ると、どこを見ればよいかが分かります。

    パソコンを起動すると、「起動時に開く」設定のアプリが自動で立ち上がる
    Windows では、サインインしたときに、スタートアップに登録されたアプリが自動で起動します。Mac では、ログインしたときに、ログイン項目に入っているアプリが開きます。
    インストールしたときに、起動時に開く設定になるアプリがある
    チャットや音楽、会議のアプリには、インストールしただけで起動時に開く設定になるものがあります。自分で設定した覚えがなくても、一覧に入っていることがあります。
    起動時に開くアプリが多いほど、立ち上がりに時間がかかる
    Microsoft の案内では、起動時に自動で動くアプリは、起動の速さとパソコン全体の動きの両方に影響することがあります。開くアプリが多いと、画面もアプリでいっぱいになります。
    Windows では、一覧を見てオン・オフを切り替えられる
    「スタート」→「設定」→「アプリ」→「スタートアップ」と進むと、起動時に開くアプリの一覧が出ます。アプリごとのスイッチをオフにすると、起動時に開かなくなります。タスクマネージャーの「スタートアップ アプリ」でも、同じ一覧を見て、「無効にする」で止められます。タスクマネージャーには、各アプリが起動にどれだけ影響しているかも表示されます。
    Mac では、ログイン項目から外せる
    アップルメニュー →「システム設定」→「一般」→「ログイン項目と機能拡張」と進みます。macOS Ventura と Sonoma では、「ログイン項目」という名前です。一覧で項目を選び、一覧の下にある「削除」ボタンを押すと、ログイン時に開かなくなります。
    起動時に開かないようにしても、アプリは消えない
    スイッチをオフにしたり、ログイン項目から外したりしても、アプリそのものはパソコンに残ります。使いたいときは、いつもどおり自分で開けます。もう一度オンにする（Mac では一覧に追加する）と、元に戻ります。
    前回開いていたアプリを、再起動のあとに開き直す設定もある
    Windows 11 では、「設定」→「アカウント」→「サインイン オプション」に「再起動可能なアプリを自動的に保存し、サインイン時に再起動する」という項目があります。Mac では、システム終了や再起動のときに出る画面に「再ログイン時にウインドウを再度開く」があります。これがオンだと、前回開いていたアプリがまた開くことがあります。

    原因の切り分け方

    アプリが開くタイミングと、起動の遅さの様子によって、見る場所が変わります。

    電源を入れた直後に、たくさんのアプリが開く
    スタートアップ（Mac ではログイン項目）の設定が原因のことが多いです。開くアプリが、一覧に入っているかを確かめます。
    前回開いていたアプリが、再起動のあとにまた開く
    Windows では「再起動可能なアプリを自動的に保存し、サインイン時に再起動する」、Mac では「再ログイン時にウインドウを再度開く」が原因のことがあります。
    一覧にないアプリが開く
    Microsoft の案内では、一覧に出ないアプリは、エクスプローラーのスタートアップ フォルダーから設定されていることがあります。アプリ自身の設定に、起動時に開く項目があることもあります。
    Mac で、ログイン項目が原因かどうかを確かめたい
    Apple の案内では、Shift キーを押したまま「ログイン」ボタンをクリックし、Dock が表示されたら離すと、ログイン項目を開かずにログインできます。この方法で速く立ち上がるなら、ログイン項目が原因と考えられます。
    開くアプリが少ないのに、起動が遅い
    スタートアップ以外の原因も考えられます。たとえば、パソコン本体の空き容量が残りわずかなことや、長く使っていることによる別の原因です。

    落とし穴

    次のことに気をつけないと、パソコンが守られなくなったり、動かなくなったりします。

    セキュリティソフトを止める
    パソコンが、ウイルスなどから守られなくなることがあります。セキュリティソフトは、オンのまま残します。
    キーボードや音など、パソコンを動かすのに必要なソフトを止める
    パソコンのメーカーが入れたソフトには、キーボードの特別なキーや、音、画面の明るさの調整などに使うものがあります。止めると、その機能が動かなくなることがあります。
    名前の分からないものを、そのまま止める
    止めてよいのかを判断できません。止める前に、名前で検索して、何のソフトかを確かめます。検索しても分からないものは、止めずに残します。
    一度にたくさん止める
    何かが動かなくなったとき、どれが原因か分からなくなります。1〜2個ずつ止めて、再起動して確かめます。
    「起動を速くする」とうたう無料のソフトを入れる
    広告が多いものや、個人情報を集めるものがあります。パソコンにもともとある設定で整理するのが安全です。
    アプリを消す（アンインストールする）
    アプリを消すのと、起動時に開かないようにするのは別の操作です。消すと、アプリの中のデータがなくなる場合があります。まずは起動時の設定だけを変えます。
    Mac の「バックグラウンドでの実行」をまとめてオフにする
    Apple の案内では、「アプリにバックグラウンドでの実行を許可する」でオンにしたアプリは、開いていない間も、アップデートの確認やデータの同期などができます。オフにすると、こうした動きが止まることがあります。名前の分からないものや、セキュリティソフトのものは、オンのまま残します。
    レジストリを書き換える
    Microsoft の案内にも、レジストリを変更すると意図しない結果が生じる可能性があると書かれています。この記事の手順では、レジストリは触りません。

    公式情報で確かめたこと

    次のことを、Microsoft と Apple の公式サポート情報で確かめました。OS のバージョンによって、手順や画面の名前が違うことがあります。

    Windows のスタートアップ（Microsoft「Windows でスタートアップ アプリケーションを構成する」）
    対象は Windows 11 と Windows 10 です。「スタート」→「設定」→「アプリ」→「スタートアップ」で、アプリのトグルをオンにすると起動時に実行され、オフにすると実行されなくなります。「スタート」を右クリックして「タスク マネージャー」を選び、「スタートアップ アプリ」タブでアプリを選ぶと、「有効にする」か「無効にする」を選べます。タスク マネージャーには、各アプリが起動に与える影響が表示されます。一覧にないアプリは、エクスプローラーのスタートアップ フォルダー（shell:startup）から設定できます。フォルダーからショートカットを削除すると、起動時に開かなくなります。レジストリを変更すると、意図しない結果が生じる可能性があると書かれています。
    タスクマネージャーを開くキー（Microsoft「Windows のキーボード ショートカット」）
    Ctrl＋Shift＋Esc で、タスク マネージャーが開きます。
    再起動のあとにアプリがまた開く設定（Microsoft「Microsoft Edge が自動的に起動されないようにする」）
    「スタート」→「設定」→「アカウント」→「サインイン オプション」で、「再起動可能なアプリを自動的に保存し、サインイン時に再起動する」をオフにする手順が案内されています。
    Mac のログイン項目（Apple「Macでログインするときに項目を自動的に開く」）
    最新の macOS では、アップルメニュー →「システム設定」→ サイドバーの「一般」→「ログイン項目と機能拡張」と進みます。macOS Sonoma の版では「ログイン項目」です。macOS Monterey の版では、「システム環境設定」→「ユーザとグループ」→「ログイン項目」です。開かせたくない項目を選び、一覧の下の「削除」ボタンを押します。「アプリにバックグラウンドでの実行を許可する」でオンにしたアプリは、開いていない間も、アップデートの確認やデータの同期などができます。Shift キーを押したまま「ログイン」ボタンをクリックし、Dock が表示されたら離すと、項目を開かずにログインできます。
    Mac の再起動のあとにウインドウがまた開く設定（Apple「Macをシステム終了する/再起動する」）
    アップルメニュー →「システム終了」または「再起動」を選んだときに、「再ログイン時にウインドウを再度開く」の選択を解除すると、前回開いていたアプリのウインドウは開き直しません。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. 電源を入れると、頼んでいないアプリが次々に開く
    2. 何が開いているのか分からず、止めてよいものの区別もつかない
    3. 大切なものを止めるのが怖いので、設定を開かずにそのままにする
    4. 翌朝も同じアプリが開き、使えるようになるまで待たされる

    4のあと、また1に戻ります。

    この流れは、2と3のところで止められます。2では、起動時に開くアプリの一覧を開いて、名前を確かめます。3では、名前が分かって、毎回開く必要のないものだけを止めます。起動時に開かないようにするだけなので、アプリは消えず、いつでも元に戻せます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • パソコン本体の性能（買い替えるまで変わらない）
    • セキュリティソフトや、パソコンを動かすのに必要なソフト（止めないほうがよい）
    • アプリが、インストールのときに起動時に開く設定になること
    • OS のバージョンによる、設定の名前や場所の違い

    変えやすいこと

    • 起動時に開くアプリのオン・オフ
    • 前回開いていたアプリを、再起動のあとに開き直す設定
    • 名前の分からないものを、検索して確かめること
    • 新しくアプリを入れたときに、一覧を確かめる習慣

    次の行動プランは3段階です。今日は、一覧を確かめて、1〜2個だけ止めます。1週間で、毎日使うアプリだけを残します。1か月後には、起動時に開くアプリがまた増えていないかを見直します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は、2026年11月時点の Microsoft と Apple の公式情報をもとにした例です。設定の名前や場所は、Windows と Mac、OS のバージョンで変わることがあります。分からないところは、Microsoft や Apple、メーカーの公式サイト・公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：15〜20分（再起動の時間を含む）

      • 起動時に開くアプリの一覧を開く

        • Windows 11：「スタート」→「設定」→「アプリ」→「スタートアップ」と進みます。または、Ctrl＋Shift＋Esc を同時に押してタスクマネージャーを開き、左側の「スタートアップ アプリ」を選びます。
        • Windows 10：「設定」→「アプリ」→「スタートアップ」と進みます。タスクマネージャーでは、上の「スタートアップ」タブです。
        • Mac：アップルメニュー →「システム設定」→「一般」→「ログイン項目と機能拡張」と進みます。macOS Ventura と Sonoma では「ログイン項目」です。それより前の macOS では、「システム環境設定」→「ユーザとグループ」→「ログイン項目」です。

        毎朝勝手に開くアプリが、一覧に入っているかを確かめます。タスクマネージャーでは、各アプリが起動にどれだけ影響しているかも表示されます。影響が大きいと表示されたものが、見直す候補です。

      • 名前が分かって、毎回開く必要のないものを1〜2個だけ止める

        たとえば、音楽のアプリ、ゲームのランチャー、使っていないチャットアプリです。

        • Windows：「設定」の一覧では、アプリのスイッチをオフにします。タスクマネージャーでは、アプリを選んで「無効にする」をクリックします。
        • Mac：一覧で項目を選び、一覧の下にある「削除」ボタンを押します。

        セキュリティソフトと、名前の分からないものは、触らずに残します。

        止めても、アプリは消えません。使いたいときは、いつもどおり自分で開けます。

      • パソコンを再起動して、変わったかを確かめる

        再起動して、止めたアプリが開かないことと、立ち上がりが速くなったかを確かめます。

        困ったことが起きたら、元に戻します。Windows では、同じ画面でスイッチをオンにするか、「有効にする」を選びます。Mac では、一覧の下の追加ボタンを押し、アプリを選んで「追加」をクリックします。

    2. 1週間の行動

      目安：1日5分ほど。設定を変えたら、そのつど再起動して確かめます

      • 毎日使うアプリだけを残す

        一覧を見直して、毎日必ず使うアプリだけをオンのまま残します。それ以外は、1〜2個ずつオフにします。再起動のたびに、困ることがないかを確かめます。

        名前の分からないものは、オフにする前に、名前で検索して何のソフトかを確かめます。セキュリティソフトや、パソコンのメーカーが入れたキーボード・音などのソフトだと分かったら、オンのまま残します。検索しても分からないものも、残します。

      • 前回開いていたアプリが、再起動のあとにまた開くなら、その設定をオフにする

        • Windows 11：「スタート」→「設定」→「アカウント」→「サインイン オプション」と進み、「再起動可能なアプリを自動的に保存し、サインイン時に再起動する」をオフにします。Windows 10 では、項目の名前が違うことがあります。
        • Mac：アップルメニュー →「システム終了」または「再起動」を選びます。出てきた画面で、「再ログイン時にウインドウを再度開く」のチェックを外してから進みます。

      • 一覧にないアプリが開くなら、アプリの設定を確かめる

        そのアプリの設定を開き、「起動時に開く」「自動で起動する」のような項目がないかを確かめます。項目の名前は、アプリによって違います。

        Windows では、スタートアップ フォルダーにショートカットが入っていることもあります。「スタート」を右クリックして「ファイル名を指定して実行」を選び、shell:startup と入力して「OK」を押すと、フォルダーが開きます。開かせたくないアプリのショートカットを削除すると、起動時に開かなくなります。ショートカットを消しても、アプリそのものは消えません。ショートカット以外のファイルは消さないでください。

      • 立ち上がりと画面が変わったかを確かめる

        電源を入れてから使えるようになるまでの時間を、スマホの時計などで計ります。最初の日と比べると、変化が分かりやすくなります。

        止めたアプリを、使いたいときに自分で開けるかも確かめます。

    3. 1か月の見直し

      目安：月に1回、10分ほど

      • 新しくアプリを入れたら、一覧を確かめる

        インストールしたあと、起動時に開く設定になっていないかを一覧で確かめます。インストールの画面に「起動時に開く」のようなチェックがあれば、外しておきます。

      • 起動がまた遅くなったら、一覧を見直す

        月に1回、一覧を開いて、知らないうちに増えたアプリがないかを確かめます。今日と同じ手順で、必要のないものを止めます。

      • それでも遅いときは、容量やパソコン本体を見直す

        起動時に開くアプリを減らしても遅いときは、ほかの原因を考えます。

        • 空き容量がいつも残りわずかなら、容量を整理します。Windows では「設定」→「システム」→「ストレージ」、Mac ではアップルメニュー →「システム設定」→「一般」→「ストレージ」で、空き容量を確かめられます。
        • 何をしても起動が遅い場合や、長く使っているパソコンの場合は、買い替えも考えます。

    1か月たったら、止めたままにしたアプリと、元に戻したアプリをメモしておきます。新しいアプリを入れたときや、パソコンを買い替えたときに、このメモを見ながら同じ整理ができます。手順の名前や設定の場所は、Windows と Mac、OS のバージョンで変わることがあります。分からないところは、Microsoft や Apple、メーカーの公式サイト・公式ヘルプで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。専門的な助言ではありません。

    セキュリティソフトや、キーボード・音などパソコンを動かすのに必要なソフトは、止めないでください。止めると、パソコンが守られなくなったり、動かなくなったりすることがあります。

    よく分からない名前のものは、止める前に名前で検索して、何のソフトかを確かめてください。

    アプリを消すのと、起動時に開かないようにするのは別の操作です。消すと、データがなくなる場合があります。まずは起動時の設定だけを変えてください。

    手順や条件は変わることがあります。この記事は、2026年11月時点の公式情報をもとにしています。最新の情報は、Microsoft や Apple、メーカーの公式サイト・公式ヘルプで確かめてください。
