お悩み No.003 ・ 2026年11月22日公開

奥の部屋だけ Wi-Fi が届かない、家中快適にするには

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    リビングでは快適で、離れた部屋だけがつながりにくいという症状は、ルーターから部屋までの距離や、間にある壁や床が原因のときによく見られます。この種類の原因は、ルーターの置き場所を変えたり、電波を届ける機器を足したりすると、改善することが多いものです。家の構造を変えなくても、試せることがあります。

    ただし、朝と夜で調子が変わる点は、距離や壁だけでは説明しにくい症状です。ほかの電波との干渉や回線の混雑が重なっている可能性もあるため、確かめながら原因を絞り込みます。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    場所
    リビングは快適だが、奥の部屋と2階の部屋では電波が弱く、つながりにくい。
    仕事部屋
    仕事用の机を置いた部屋が、Wi-Fi が届かないためにほとんど使えていない。
    対策
    ルーターを買い替えるべきか、中継器を置くべきかが分からない。原因もよく分からない。
    時間帯
    朝はつながりにくく、夜は大丈夫なことがある。日によって調子が変わる。
    制約
    家の構造は変えられない。

    つながりにくさの原因の候補

    Wi-Fi がつながりにくくなる原因は1つとは限らず、いくつかが重なっていることもあります。症状だけでは原因を決められないので、考えられる候補を分けて挙げます。それぞれに確かめ方を添えました。

    置き場所と高さ
    Wi-Fi の電波は、ルーターを中心にして周りへ広がります。ルーターが家の端や床の上、棚の中、テレビの裏にあると、離れた部屋に届く電波が弱くなります。確かめ方：ルーターがどこに、どの高さで置かれているかを見ます。周りを家具や家電で囲まれていないかも確かめます。
    壁・床・水回り
    電波は、壁や床を通り抜けるたびに弱くなります。コンクリートの壁や金属、鏡は電波を通しにくく、水は電波を吸収します。ルーターと部屋の間に浴室やキッチン、水槽があると、電波が届きにくくなることがあります。2階の部屋に届くには、床も通り抜ける必要があります。確かめ方：ルーターからつながりにくい部屋までの間に、壁や床がいくつあるか、水回りがないかを確かめます。
    周波数帯
    家庭用の Wi-Fi には、主に 2.4GHz と 5GHz の2種類の電波があります。2.4GHz は壁や床を通りやすく、遠くまで届きやすい性質があります。その代わり、ほかの機器の電波と干渉しやすく、速度は 5GHz より出にくくなります。5GHz は速度を出しやすく干渉も受けにくい一方、壁や床で弱まりやすい性質があります。確かめ方：スマホの Wi-Fi 設定で、つないでいるネットワークの名前を見ます。名前の見分け方は、行動プランで説明します。
    電波の干渉
    電子レンジは、使っている間、2.4GHz に近い周波数の電波を出します。Bluetooth の機器や近所の家の Wi-Fi も、同じ周波数帯を使います。電子レンジを使う時間や、近所や家族がネットを使う時間によって、つながりやすさが変わることがあります。「朝はつながりにくい」という症状にも当てはまる可能性があります。確かめ方：つながりにくかった時刻と、そのときに電子レンジを使っていたかを記録します。
    ルーターの性能
    ルーターの規格が古いと、新しい規格のものより速度が出にくいことがあります。長く使っているルーターは、ファームウェア（本体のソフト）の更新が終わっていることもあります。確かめ方：ルーター本体に貼られたシールで型番を確かめ、メーカーのサイトで、対応している規格と更新の状況を調べます。
    回線
    家に引き込んでいるインターネット回線や、プロバイダの設備が混雑していると、Wi-Fi の電波が強くても遅くなります。確かめ方：ルーターのすぐそばと、つながりにくい部屋で、同じ時間に速度を測ります。ルーターのそばでも遅い場合は、回線の問題の可能性があります。

    このほか、5GHz の一部のチャンネルでは、ルーターが気象レーダーなどの電波を検知すると、自動でチャンネルを切り替えます。切り替えの間、1分ほど 5GHz につながらなくなることがあります。また、スマホやパソコンが古い規格にしか対応していない場合も、速度が出にくくなります。

    ボトルネック

    AIは、ルーターからつながりにくい部屋までの距離と、その間にある壁や床が、いちばん大きなボトルネックだと考えます。リビングでは快適に使えているので、回線とルーター本体は、少なくともリビングで使う分には動いていると考えられるためです。

    ただし、これだけが原因だと決めつけず、費用がかからず元に戻しやすいものから順に試していきます。

    1. ルーターの置き場所と高さを変える（無料で、すぐに試せる）
    2. 周波数帯を選び直し、ルーターを再起動する（操作だけで試せて、元にも戻せる）
    3. 中継器やメッシュ Wi-Fi を足す（費用がかかるので、1と2で足りないときに考える）
    4. 有線LANでつなぐ（ケーブルを通せる場所なら、いちばん安定しやすい）

    1つ試すごとに、つながりにくい部屋の状態を確かめると、どれが効いたのかが分かります。3と4は、どちらを先にしても構いません。仕事用の机のように使う場所が決まっていて、ケーブルを通せるなら、有線LANを先に試す方法もあります。

    原因の切り分け方

    どの候補が当てはまるかは、ルーターのそばと、つながりにくい部屋で、同じ時間に速度を比べると絞り込めます。

    奥だけ遅い
    ルーターのそばでは速く、奥の部屋や2階の部屋だけが遅い。電波が届いていないことが主な原因と考えられます。置き場所、周波数帯、中継器などで改善を目指します。
    そばでも遅い
    ルーターのすぐそばでも遅い。回線やプロバイダの設備、ルーター本体の不調が考えられます。この場合は中継器を足しても改善しにくいので、ルーターの再起動や、プロバイダへの相談を先に考えます。
    時間で変わる
    同じ部屋でも、時間帯によって速さが大きく変わる。電子レンジなどの干渉や、回線の混雑が重なっている可能性があります。つながりにくい時刻と、そのときの家の様子を記録して、共通点を探します。

    買い替えが必要かどうかの見分け方

    ルーターの買い替えが必要かどうかは、次のどちらに当てはまるかで判断できます。

    まだ買い替えなくてよい場合

    • 置き場所を変えたり、2.4GHz に切り替えたりしたら、つながるようになった
    • ルーターが Wi-Fi 5（IEEE 802.11ac）以降に対応していて、ルーターのそばでは十分に速い（中継器やメッシュ Wi-Fi、有線LANを足せば足りる可能性があります）
    • ルーターのそばでも遅いが、原因が回線やプロバイダの側にあると分かった（ルーターを替えても改善しにくい）

    買い替えを考えてよい場合

    • ルーターが Wi-Fi 4（IEEE 802.11n）以前の規格にしか対応していない
    • メーカーによるファームウェアの更新が終わっている
    • 再起動してもすぐに不安定になる、本体が熱くなりすぎるなど、ルーター自体の不調が続く

    ルーターを新しくしても、1台で届く範囲には限りがあります。遠い部屋に届かない主な原因が距離や壁なら、買い替えだけでは解決しないこともあります。その場合は、中継器やメッシュ Wi-Fi、有線LANと組み合わせて考えます。プロバイダから借りているルーターなら、買う前に、新しい機種と交換できないかをプロバイダに確かめます。

    次の行動プランは、無料で試せることから順に並べています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるものを試してください。1つ変えるごとに、つながりにくい部屋の状態を確かめると、どれが効いたのかが分かります。

    画面や設定の名前は、スマホやルーターの機種によって違うことがあります。分からないときは、機器の取扱説明書やメーカーのサイトで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分〜1時間

      • つながりにくい部屋で、今の状態を確かめる

        スマホを持ってリビング、奥の部屋、2階の部屋を回り、画面上の Wi-Fi アイコンの本数をメモします。本数が少ないほど、電波が弱い状態です。

        確かめた時刻と、つないでいる Wi-Fi の名前もメモしておきます。あとで置き場所や設定を変えたときに、効果を比べるためです。

      • ルーターを、家の中心に近い開けた場所へ移す

        電波はルーターを中心に広がるので、家の中心に近いほど、家全体に届きやすくなります。高さは、腰から胸くらいが目安です。

        • 避けたい場所は、テレビの裏、棚や戸棚の中、床の上、水槽の近くです。電子レンジや金属製のラックの近くも避けます。
        • 2階の部屋に届けたいときは、1階の中でも、その部屋の真下に近い場所に置くと届きやすくなることがあります。
        • アンテナが外に出ている機種は、まっすぐ上に向けるのが基本です。2階に届きにくい場合は、1本を横に倒すと改善することがあります。
        • 光回線の機器（ONU）の近くから動かせない場合は、ONU とルーターの間を長い LAN ケーブルでつなぐと、ルーターだけを移せます。
        • 動かす前に、ケーブルがどこに挿さっているかをスマホで撮っておくと、元に戻すときに困りません。

      • ルーターを再起動する

        長く動かし続けたルーターは、再起動すると調子が戻ることがあります。

        • ルーターの電源ケーブルを抜きます。ONU が別にある場合は、ONU の電源も抜きます。ONU とルーターが1台にまとまっている場合は、その1台の電源を抜きます。
        • 1分ほど待ってから、ONU の電源を先に入れます。ランプの点滅がおさまるまで数分待ち、そのあとでルーターの電源を入れます。
        • 本体の「RESET」や「初期化」のボタンは押さないでください。設定が消えて、インターネットにつながらなくなることがあります。

      • 2.4GHz と 5GHz を切り替えて、どちらが届くかを比べる

        多くのルーターは、2.4GHz と 5GHz で、別々の名前（SSID）の Wi-Fi を出しています。名前とパスワード（暗号化キー）は、ルーター本体のシールに書かれています。

        • 名前の一部に「G」や「2G」が付くものが 2.4GHz、「A」や「5G」が付くものが 5GHz であることが多いです。付け方はメーカーによって違います。ここでの「5G」は、スマホの通信規格の 5G とは別のものです。
        • つながりにくい部屋で、スマホの Wi-Fi 設定からもう一方の名前を選んでつなぎます。アイコンの本数や、動画や Web ページの表示の速さを比べます。
        • 遠い部屋では、壁や床を通りやすい 2.4GHz のほうがつながりやすいことが多いです。届くほうが分かったら、その部屋で使うパソコンも同じ名前につなぎます。
        • Wi-Fi の名前が1つしか見つからない場合は、ルーターが2つの周波数帯を自動で切り替えている（バンドステアリング）ことがあります。この場合は、今日は切り替えを試さずに次へ進んで構いません。

    2. 1週間の行動

      目安：1日10〜15分ほど。数日に分けて進めます

      • 部屋ごとの電波の強さと速度を測って記録する

        アイコンの本数より細かく、電波の強さを数字で確かめます。使っている機器に合わせて、次のどれかの方法で測ります。

        • Android：「設定」→「ネットワークとインターネット」→「インターネット」で、つないでいる Wi-Fi の歯車のマークを押すと、「信号強度」が表示されます。機種によって、項目の名前や場所が違います。
        • iPhone：Apple の無料アプリ「AirMac ユーティリティ」を入れ、iPhone の「設定」→「AirMac ユーティリティ」で「Wi-Fi スキャナ」をオンにします。アプリで「Wi-Fi スキャン」を実行すると、電波の強さが数字（dBm）で表示されます。
        • Windows のパソコン：スタートメニューで「ターミナル」または「コマンド プロンプト」を検索して開きます。netsh wlan show interfaces と入力して Enter を押すと、「シグナル」の欄に電波の強さが % で表示されます。
        • 速度：ブラウザで Fast.com を開くか、Google で「スピードテスト」と検索すると、無料で測れます。

        部屋ごとに、日時、つないでいる周波数帯、電波の強さ、速度をメモします。dBm の数字は、0 に近いほど電波が強いことを表します。-60 dBm 前後より強ければ十分で、-70 dBm を下回ると不安定になりやすい、という目安がよく挙げられます。

      • ルーターのそばと、つながりにくい部屋で、同じ時間に速度を比べる

        検証の「原因の切り分け方」で書いたとおり、2か所の速度を比べると、原因が電波の届き方にあるのか、回線にあるのかを絞り込めます。家族に協力してもらうか、続けて測ります。

        • 朝と夜の両方で測ります。朝につながりにくいときは、電子レンジを使っていたか、家族が動画やゲームを使っていたかもメモします。
        • 電子レンジを使っているときだけ遅い場合は、5GHz につなぐか、ルーターと電子レンジを離します。
        • ルーターのそばでも同じ時間帯に遅い場合は、回線やプロバイダの設備が混雑している可能性があります。

      • ルーターの型番と規格を確かめる

        ルーター本体のシールで型番を確かめ、メーカーのサイトで型番を検索します。確かめるのは次の2点です。

        • 対応している Wi-Fi の規格（Wi-Fi 4、Wi-Fi 5、Wi-Fi 6 など。IEEE 802.11n、11ac、11ax と書かれていることもあります）
        • ファームウェアの更新が続いているか。ルーターの設定画面やメーカーのアプリで、最新のファームウェアになっているかも確かめます。

        結果を検証の「買い替えが必要かどうかの見分け方」と照らし合わせて、買い替えが必要かを判断します。

      • 改善が足りなければ、中継器かメッシュ Wi-Fi を検討する

        置き場所と周波数帯を見直しても足りない場合は、電波を届ける機器を足します。主な方法は2つです。

        • 中継器：ルーターの電波を受け取り、もう一度送り出す機器です。比較的手軽に足せる方法で、つながりにくい部屋が1つのときに向いています。ただし、ルーターと直接つなぐより速度が落ちることがあります。
        • メッシュ Wi-Fi：複数の機器を組み合わせて、家全体を1つの Wi-Fi にまとめる方法です。部屋を移動すると、つながる機器が自動で切り替わります。2階建てで、つながりにくい部屋が複数あるときに向いています。中継器より費用がかかることが多いです。
        • 今のルーターが「メッシュ対応」や「EasyMesh 対応」なら、対応する機器を足すだけで済むことがあります。同じメーカーどうしでないと使えない機能もあるので、買う前にメーカーのサイトで対応する機種を確かめます。
        • 中継器は、つながりにくい部屋の中ではなく、ルーターとその部屋の中間あたりで、電波がまだ十分に強い場所に置きます。廊下や階段の近くが候補になります。

      • 古いルーターを中継器として使えないか確かめる

        以前使っていたルーターが家に残っている場合は、中継器として使える機種もあります。

        • 本体の裏のスイッチや設定画面で、「中継機」「WB」などのモードを選べるかを、取扱説明書やメーカーのサイトで確かめます。
        • 「AP（アクセスポイント）」モードにして今のルーターと LAN ケーブルでつなぎ、離れた部屋に置く方法もあります。ケーブルを通せるなら、無線で中継するより安定しやすくなります。
        • 2台目をルーターのモードのままつなぐと、つながりにくくなることがあります。必ずモードを切り替えてから使います。
        • 古い機種は対応する規格が古く、速度が出にくいことがあります。ファームウェアの更新が終わった機種は、安全のため使わないほうがよい場合もあります。

      • LAN ケーブルでつなげる場所は、有線にする

        仕事用の机のように使う場所が決まっていて、ケーブルを通せるなら、有線LANがいちばん安定しやすい方法です。電波の強さや干渉の影響を受けません。

        • ルーターの「LAN」と書かれた差し込み口とパソコンを、LAN ケーブルでつなぎます。1Gbps までの回線なら、「CAT5e」以上と書かれたケーブルが目安です。
        • 壁に LAN の差し込み口（情報コンセントなど）がある家では、それを使える場合があります。
        • 部屋をまたいでケーブルを通すときは、薄くて平たいタイプのケーブルを壁際に沿わせると、じゃまになりにくくなります。ドアに挟んだり、踏み続けたりしないように気をつけます。
        • LAN の差し込み口がないノートパソコンは、USB 接続の LAN アダプターを使うとつなげます。
        • ケーブルを通せない場合は、家の電気のコンセントを通してネットにつなぐ「PLC アダプター」という方法もあります。ただし、家の配線によって速度が変わります。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • 最初の記録と比べる

        1週間の行動と同じ方法で、部屋ごとの電波の強さと速度を測り直して比べます。仕事用の机で、Web 会議やファイルのやりとりが困らずにできるかも確かめます。

      • まだ弱い部屋があれば、中継器の置き場所を調整する

        中継器を置いても弱い場合は、置き場所が合っていない可能性があります。

        • 中継器とルーターの間の電波が弱いと、中継器から先も遅くなります。多くの中継器には、ルーターとのつながり具合を示すランプがあります。ランプで弱いと分かる場合は、中継器をルーターに少し近づけます。
        • 床の上や家具の裏は避け、腰から胸くらいの高さの開けた場所に置きます。
        • いくつかの場所で試し、1週間の行動と同じ方法で測って、いちばんよい場所を選びます。

      • メッシュ Wi-Fi の追加を検討する

        中継器の置き場所を変えても足りない場合や、つながりにくい部屋が複数ある場合は、メッシュ Wi-Fi の機器を足すことを検討します。すでにメッシュ Wi-Fi を使っていて、まだ弱い部屋がある場合は、機器を1台足すか、機器を置く間隔を見直します。

      • ルーターのそばでも遅いときは、回線業者に相談する

        ルーターのそばでも遅い状態が続く場合は、契約しているプロバイダや回線業者に相談します。1週間の行動でつけた記録（日時、場所、速度）を見せると、状況を伝えやすくなります。

        • 回線や設備に不具合がないかを、調べてもらえることがあります。
        • 借りているルーターや ONU が古い場合は、新しい機種と交換できるかを聞きます。
        • 混雑しにくい接続方式（IPv6 IPoE など）に対応しているかも聞けます。混雑する時間帯に遅くなる場合に、改善することがあります。

      • ルーターの買い替えを判断する

        ここまで試しても改善が足りず、検証の「買い替えを考えてよい場合」に当てはまるなら、ルーターの買い替えを検討します。家全体に届けたい場合は、メッシュ Wi-Fi に対応した機種を選ぶと、あとから機器を足して範囲を広げられます。

    1か月たって、仕事用の机でも困らずに使えるようになっていれば、それ以上の機器は必要ありません。ルーターや中継器の周りに物を置かないようにすると、今の状態を保ちやすくなります。
