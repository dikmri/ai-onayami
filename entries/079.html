    AIの見立て

    ZIPは複数のファイルをひとつにまとめた『圧縮ファイル』で、パソコンに標準で付いている機能や無料のソフトで開ける見込みあり。開けないときは、ファイル自体が壊れている場合と、開き方が合っていない場合があり、切り分けができる

    ZIPは、複数のファイルをひとつにまとめて、サイズを小さくしたファイルです。中身を使うには、「展開」という作業で元のファイルに戻します。「解凍」とも呼ばれ、どちらも同じ作業を指します。Windows にも Mac にも、ZIP を展開する機能が最初から付いています。

    開けない原因は、大きく2つに分けられます。1つは、ファイル自体が壊れている場合です。ダウンロードが途中で途切れた場合や、送る側のファイルが壊れている場合がこれに当たります。もう1つは、開き方が合っていない場合です。ZIP を開くアプリの設定が変わっている、ファイル名の文字コードが合わない、保存した場所が深すぎる、といった場合がこれに当たります。

    ボトルネックは、どちらの原因なのかを見分ける方法を知らないことです。見分けられないと、自分のやり方が悪いのか、ファイルが悪いのかが分かりません。そのため、同じやり方で何度も試したり、送り直しを頼むのをためらったりします。

    この記事の手順は、2026年11月時点の Microsoft と Apple の公式ヘルプ、7-Zip と CubeICE の公式サイトをもとにしています。メニューの名前や場所は、パソコンの種類や OS の版によって変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    「展開できません」「ファイルが壊れている可能性があります」と出る
    仕事のメールに添付されてきたZIPファイルの中身が見られない。
    ZIPがそもそも何なのか、どうやって開くのかが分からない
    言葉は聞いたことがあるが、開くための手順を知らない。
    ダブルクリックしても何も起きないことがある
    何が起きているのかが分からず、次に何を試せばいいのかも分からない。
    文字化けしたフォルダが出てきて、どれが本物のファイルか分からない
    展開はできたように見えるが、目当ての資料を見つけられない。
    急ぎの資料なのに開けず、送り直しを頼むのも気が引ける
    相手に手間をかけさせるのが申し訳なく、一人で何とかしようとしている。

    考えられる原因

    ZIP が開けない原因と、文字化けやエラーが出る原因として、次のことが考えられます。

    ZIPは、展開しないと中身を使えない
    ZIPは、複数のファイルをひとつにまとめて小さくしたものです。中のファイルを使うには、展開して元のファイルに戻す必要があります。Windows では、ZIP をダブルクリックすると、フォルダのように中身が表示されます。これは、まだ展開していない状態です。この状態で中のファイルを直接開くと、うまく開けなかったり、編集した内容が残らなかったりすることがあります。Windows では ZIP を右クリックして「すべて展開」を選ぶと、Mac では ZIP をダブルクリックすると、中身が取り出されます。
    ダブルクリックしても何も起きないのは、ZIP を開くアプリの設定が原因のことがある
    パソコンは、ファイルの種類ごとに、どのアプリで開くかを覚えています。これを「関連付け」と呼びます。ZIP の関連付けが、展開できない別のアプリに変わっていると、ダブルクリックしても何も起きないことがあります。以前に入れた展開ソフトを削除したあとなどに、こうなることがあります。パソコンに展開できるソフトが入っていない場合も、同じように開けません。
    文字化けは、作った人と開く人のパソコンで、日本語の扱い方が違うために起きる
    ファイル名の日本語をどの決まりで記録するかを、「文字コード」と呼びます。作った人と開く人のパソコンで文字コードが違うと、展開したファイル名やフォルダ名が文字化けします。たとえば、Mac で作った ZIP を Windows で展開すると、ファイル名が文字化けすることがあります。文字化けしているのは名前だけで、多くの場合、ファイルの中身は壊れていません。無料の展開ソフトの CubeICE や 7-Zip を使うと、文字化けせずに展開できることがあります。
    Mac で作った ZIP には、資料ではないフォルダが入っていることがある
    Mac で作った ZIP を Windows で展開すると、__MACOSX という名前のフォルダや、名前が ._ で始まるファイルが出てくることがあります。これらは Mac が使う補助的な情報で、送られてきた資料そのものではありません。資料は、それ以外のファイルです。
    「壊れている可能性があります」は、ファイルが途中で途切れているときに出ることがある
    ダウンロードが途中で止まると、一部が欠けたファイルが保存されることがあります。送る側で作った時点で、ZIP が壊れていることもあります。どちらの場合も、Windows では「…は無効です」のような表示が出て、展開できません。サイズが 0 バイトだったり、極端に小さかったりするときは、途中で途切れている疑いがあります。
    保存した場所が深すぎると、Windows では展開に失敗することがある
    Windows では、フォルダの場所とファイル名を合わせた長さ（パス）に、260 文字という上限があります。ZIP の中のフォルダ名やファイル名が長いと、深い場所で展開したときにこの上限を超えて、展開に失敗することがあります。デスクトップのような浅い場所に移すと、パスが短くなります。
    パスワード付き ZIP は、パスワードがないと展開できない
    中身を守るために、パスワードをかけた ZIP があります。展開するときにパスワードを入れる必要があり、パスワードは送り主から別に教えてもらいます。Windows の標準の機能では開けないパスワード付き ZIP もあり、その場合は 7-Zip などの展開ソフトを使います。
    空き容量が足りないと、展開できないことがある
    展開したファイルは、ZIP より大きくなることがあります。Apple のヘルプでは、ZIP を開けないときは、展開したものを保存する空き容量が十分にあるかを確かめるよう案内されています。

    どこが原因かを切り分ける方法

    次の順に確かめると、原因を絞り込めます。具体的な手順は、行動プランで説明します。

    最初に、ファイルのサイズを確かめる
    Windows では、ZIP を右クリックして「プロパティ」を選び、「サイズ」を見ます。Mac では、ZIP を選んでから「ファイル」メニューの「情報を見る」を選びます。0 バイトだったり、極端に小さかったりするときは、ダウンロードが途中で止まっている疑いがあります。メールの画面に添付ファイルのサイズが出ている場合は、その数字と比べます。
    サイズがおかしいときは、メールから保存し直す
    メールの添付ファイルを、デスクトップにもう一度保存します。保存し直してもサイズが変わらないときは、送る側のファイルに問題がある可能性があります。
    サイズに問題がなければ、デスクトップに移してから、標準の機能で展開する
    デスクトップのような浅い場所に移すと、パスの長さが原因の失敗を避けられます。Windows は右クリックして「すべて展開」を選び、Mac はダブルクリックで展開します。
    Windows で何も起きないときは、ZIP を開くアプリの設定を確かめる
    ZIP を右クリックして「プロパティ」を選び、「全般」タブの「プログラム」の欄を見ます。エクスプローラー以外のアプリが表示されていたら、関連付けが変わっています。「変更」を選んで「エクスプローラー」を選ぶと、元に戻せます。
    文字化けするときや、標準の機能で展開できないときは、無料の展開ソフトを試す
    7-Zip や CubeICE を公式サイトから入れて、展開し直します。7-Zip は、パソコンに合った版を選びます。多くのパソコンでは 64bit 版（64-bit x64）です。
    展開ソフトでも開けないときは、送り主にもう一度送ってもらう
    ここまで試して開けないなら、ファイル自体が壊れている可能性が高いと考えられます。もう一度送ってもらうのが確実です。Apple のヘルプでも、ほかの人から受け取った ZIP を開けないときは、もう一度圧縮して送り直すよう頼む方法が案内されています。

    直る見込み

    多くの場合は、標準の機能か無料のソフトで開ける
    ZIP は広く使われている形式で、Windows にも Mac にも展開の機能が付いています。標準の機能で開けないときも、7-Zip や CubeICE のような無料のソフトで開けることが多いです。
    文字化けも、専用のソフトを使えば直ることが多い
    CubeICE は、ZIP の中のファイル名の文字コードを自動で判別して、文字化けを防ぐと公式サイトで案内しています。ファイル名が文字化けしていても中身は無事なことが多いので、開いて中身を確かめてから、名前を付け直して使うこともできます。
    送り直してもらえば、直ることも多い
    ダウンロードの失敗や、送る側でのファイルの破損は、送り直してもらえば解決することが多いです。送る側も、資料が届いていないことを早めに知れば、早めに対応できます。恥ずかしがらずに頼んで構いません。

    公式情報で確かめたこと

    次のことを、Microsoft と Apple の公式ヘルプ、7-Zip と CubeICE の公式サイトで確かめました。パソコンの種類や OS の版によっては、画面や名前が違うことがあります。

    Windows で ZIP を展開する（Microsoft）
    ZIP を右クリック（または長押し）し、すべての内容を展開するメニューを選んで、画面の指示に従います。このメニューは、Microsoft の ZIP のヘルプでは「すべて抽出」と書かれていますが、Windows の画面と Microsoft のほかのヘルプでは「すべて展開」です。1つのファイルだけを取り出すときは、ZIP を開き、中のファイルを別の場所へドラッグします。Windows 11 バージョン 24H2 では、ZIP のほかに RAR、7z、TAR の形式も扱えます。
    暗号化されたファイルの扱い（Microsoft）
    Microsoft のヘルプでは、暗号化されたアーカイブ ファイルの操作は、Windows の標準の機能では対応していないと案内されています。その場合は、7-Zip などの他社のアプリを使う方法が挙げられています。
    Mac で ZIP を展開する（Apple）
    Finder のウインドウかデスクトップで、.zip ファイルをダブルクリックします。展開されたものは、.zip ファイルと同じフォルダに表示されます。展開したあとは、.zip ファイルを削除しても構いません。開けないときは、展開したものを保存する空き容量が Mac にあるかを確かめます。ほかの人から受け取った .zip ファイルは、ファイルに問題があることがあるため、もう一度圧縮して送り直すよう頼む方法が案内されています。
    ZIP を開くアプリを選び直す（Microsoft）
    「設定」→「アプリ」→「既定のアプリ」を開きます。「ファイルの種類またはリンクの種類の既定値を設定する」の検索欄に .zip と入れ、表示された結果から、開くアプリを選びます。
    パスの長さの上限（Microsoft）
    Windows API では、パスの最大長は MAX_PATH という値で、260 文字と定義されています。開発者向けの技術情報ですが、深い場所で展開すると失敗する理由の参考になります。
    ファイルをウイルス スキャンする（Microsoft）
    エクスプローラーでファイルやフォルダーを右クリックし、「Microsoft Defender でスキャンする」を選びます。Windows 11 では、右クリックしたあとに「その他のオプションを表示」（画面では「その他のオプションを確認」）を選ぶ必要がある場合があります。
    7-Zip（公式サイト）
    7-Zip は、オープンソースの無料のソフトです。公式サイトには、会社のパソコンを含めてどのパソコンでも使えること、登録や支払いが要らないことが書かれています。ダウンロードの表は、Windows の種類ごとに分かれています。多くのパソコンでは「64-bit x64」の行の版を選びます。2026年11月24日時点の最新版は 26.06（2026年11月6日公開）です。公式サイトは英語です。
    CubeICE（公式サイト）
    CubeICE は、個人・法人を問わず無料で使える展開ソフトです。公式サイトでは、圧縮ファイルの文字コードを自動で判別して、文字化けを防ぐと案内されています。AES-256 などで暗号化されたファイルにも対応しています。無料版は、ダウンロードの前に広告が表示されます。公式サイトでは、広告をクリックしなくてもダウンロードできると案内されています。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. ZIP を開こうとすると、エラーや文字化けが出る
    2. 自分の開き方が悪いのか、ファイルが壊れているのかが分からない
    3. 送り直しを頼むのも気が引けて、同じやり方で何度も試す
    4. 開けないまま時間が過ぎ、次に ZIP が届いたときも同じように困る

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。ファイルのサイズを見る、浅い場所で展開する、別の展開ソフトを試す、という順番を知っていれば、原因を短い時間で絞り込めます。ファイルが壊れていると分かれば、送り直しを頼む理由もはっきりします。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 送られてくる ZIP が壊れているかどうか
    • 送る人のパソコンの種類と、ZIP の作り方（文字コード）
    • 会社のパソコンに、ソフトを入れてよいかどうか（社内の決まり）
    • パソコンの種類や OS の版ごとの、メニューの名前と場所

    変えやすいこと

    • 展開する前に、ファイルのサイズを見ること
    • デスクトップのような浅い場所で展開すること
    • 展開のやり方を1つ決めておくこと
    • 文字化けしたときに使う展開ソフトを用意しておくこと
    • 送り直しを頼む文面を用意しておくこと
    • 自分が送る側のときに、送る前に一度展開して確かめること
    • パスワードを、メールとは別の方法で受け取ること

    次の行動プランは3段階です。今日は、届いた ZIP をデスクトップに移し、サイズを確かめてから標準の機能で展開します。文字化けするときは無料の展開ソフトを試し、それでも開けなければ送り直しを頼みます。1週間で、展開のやり方を1つに決め、受け取るときと送るときの確かめ方を身につけます。1か月後には、ZIP の整理と、見知らぬ差出人からの ZIP を開く前に確かめる習慣をつけます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は、Windows 11 と Mac での例です。メニューの名前や場所は、パソコンの種類や OS の版によって変わることがあります。画面がこの記事と違うときは、使っているパソコンの公式ヘルプで確かめてください。会社のパソコンにソフトを入れる前には、社内の決まりを確かめ、必要なら情報システムの担当者に相談してください。

    1. 今日からできる小さな一歩

      目安：15〜30分ほど。届いた ZIP ファイルを用意します

      • ZIP ファイルをデスクトップに保存する

        メールの添付ファイルを、デスクトップに保存します。すでにダウンロードのフォルダなどに保存している場合は、デスクトップにコピーします。デスクトップのような浅い場所で展開すると、Windows でパスの長さが原因の失敗を避けられます。

        差出人に心当たりがない ZIP は、ここで開かずに、下の「注意書き」を先に読んでください。

      • ファイルのサイズを確かめる

        • Windows：ZIP を右クリックして「プロパティ」を選び、「サイズ」を見ます。
        • Mac：ZIP をクリックして選び、「ファイル」メニューの「情報を見る」を選びます。

        0 バイトのときや、メールに表示されているサイズより極端に小さいときは、ダウンロードが途中で止まっている疑いがあります。メールからもう一度保存し直してから、サイズを確かめます。

      • Windows の場合：右クリックして「すべて展開」を選ぶ

        1. デスクトップの ZIP を右クリックします。
        2. 「すべて展開」を選びます。
        3. 展開先のフォルダが表示されます。そのままでよければ「展開」を選びます。
        4. 展開が終わると、ZIP と同じ名前のフォルダができ、その中に中身が入っています。

        Microsoft の ZIP のヘルプでは、このメニューは「すべて抽出」と書かれています。画面では「すべて展開」と表示されます。

      • Mac の場合：ダブルクリックする

        デスクトップの ZIP をダブルクリックします。展開されたものが、ZIP と同じ場所（ここではデスクトップ）に表示されます。開けないときは、Mac の空き容量が足りているかも確かめます。

      • Windows で何も起きないときは、ZIP を開くアプリを元に戻す

        1. ZIP を右クリックして「プロパティ」を選びます。
        2. 「全般」タブの「プログラム」の欄を見ます。エクスプローラー以外のアプリが表示されていたら、「変更」を選びます。
        3. 一覧から「エクスプローラー」を選んで確定し、プロパティの画面を閉じます。

        「設定」→「アプリ」→「既定のアプリ」で、検索欄に .zip と入れて、開くアプリを選び直す方法もあります。

      • 文字化けするときや、標準の機能で開けないときは、7-Zip を試す

        1. パソコンの種類を確かめます。「設定」→「システム」→「バージョン情報」の「システムの種類」に、「x64 ベース プロセッサ」か「ARM ベース プロセッサ」かが表示されます。
        2. ブラウザのアドレス欄に www.7-zip.org と入れて、7-Zip の公式サイトを開きます。検索結果の広告からは開きません。
        3. ダウンロードの表で、「Windows」の列が「64-bit x64」になっている行の「Download」を選びます。ARM ベース プロセッサのパソコンでは、「64-bit ARM64」の行を選びます。
        4. ダウンロードしたファイルを開き、画面の指示に従ってインストールします。
        5. ZIP を右クリックし、「7-Zip」→「ここに展開」を選びます。Windows 11 で「7-Zip」が見当たらないときは、先に「その他のオプションを確認」を選びます。

        「ここに展開」は、ZIP と同じ場所に中身を取り出します。中身が多いとデスクトップに散らばるので、先に空のフォルダを作り、その中に ZIP を移してから展開すると片付けやすくなります。メニューの名前は、7-Zip の版によって違うことがあります。

      • 7-Zip でも文字化けが直らないときは、CubeICE を試す

        CubeICE は、ZIP の中のファイル名の文字コードを自動で判別して、文字化けを防ぐ展開ソフトです。

        1. ブラウザのアドレス欄に www.cube-soft.jp/cubeice/ と入れて、公式サイトを開きます。
        2. 「無料でダウンロードする」を選びます。ダウンロードの前に広告が表示されますが、広告はクリックしなくてもダウンロードできます。
        3. ダウンロードしたファイルを開き、画面の指示に従ってインストールします。
        4. ZIP を右クリックし、CubeICE の「解凍」から展開します。

        CubeICE を入れると、ZIP をダブルクリックしたときの動きが変わることがあります。元に戻したいときは、上の「ZIP を開くアプリを元に戻す」の手順で戻せます。

      • Mac で作られた ZIP の、資料ではないファイルを見分ける

        展開したフォルダに __MACOSX というフォルダや、名前が ._ で始まるファイルがあれば、それは Mac が使う補助的な情報です。開いても資料は出てきません。資料は、それ以外のファイルです。

      • それでも開けないときは、送り主にもう一度送ってもらう

        ここまで試して開けない場合は、ファイル自体が壊れている可能性が高いと考えられます。たとえば、次のように頼みます。

        「お送りいただいたZIPファイルが、こちらでは開けませんでした。お手数ですが、もう一度お送りいただけますか。」

        文字化けで困っている場合は、「ファイル名を英数字にしていただけると助かります」と添えると、次からの文字化けを防ぎやすくなります。

    2. 1週間の行動

      目安：ZIP を受け取るたび、送るたびに数分

      • 展開のやり方を1つに決めて、メモしておく

        文字化けすることが少なければ、Windows は「すべて展開」、Mac はダブルクリックに決めます。文字化けすることが多ければ、7-Zip か CubeICE に決めます。手順をメモアプリなどに書いておくと、急いでいるときにも迷いません。

      • ZIP を受け取ったら、同じ順番で確かめる

        1. デスクトップに保存する。
        2. サイズが 0 バイトや極端に小さくないかを見る。
        3. 決めたやり方で展開する。
        4. 開けなければ、送り直しを頼む。

      • 自分が送る側のときは、送る前に一度展開して確かめる

        ZIP を作ったら、送る前に自分のパソコンで一度展開します。中身がそろっているか、ファイル名が文字化けしていないかを見ます。Mac では、ファイルやフォルダを Control キーを押しながらクリックし、「圧縮」を選ぶと ZIP を作れます。Windows での作り方は、Microsoft の「ファイルを圧縮および展開する」のヘルプに載っています。

        相手が Mac か Windows か分からないときは、ファイル名やフォルダ名を英数字にしておくと、文字化けを防ぎやすくなります。名前を短くし、フォルダを何重にも重ねないようにすると、相手がパスの長さで失敗することも減らせます。

      • パスワード付き ZIP は、パスワードを別の方法で受け取る

        パスワード付き ZIP を受け取ったら、パスワードは電話やチャットなど、メールとは別の方法で教えてもらいます。ZIP と同じメールや、続けて届くメールでパスワードを受け取ると、メールが他人に見られたときに、ZIP とパスワードの両方が知られてしまいます。

        パスワードを入れても Windows の「すべて展開」で開けないときは、7-Zip か CubeICE で展開します。

    3. 1か月の見直し

      目安：1か月後に20〜30分ほど

      • ダウンロードした ZIP を整理する

        • ダウンロードした ZIP は、「受け取ったZIP」のようなフォルダを1つ作って、そこにまとめます。
        • いらない ZIP は、展開して中身を確かめてから削除します。必要な中身は、別のフォルダに移しておきます。Apple のヘルプでも、展開したあとは .zip ファイルを削除して構わないと案内されています。

      • 見知らぬ差出人からの ZIP は、開く前にウイルス対策ソフトで確かめる

        1. ZIP を展開せずに、右クリックします。
        2. 「Microsoft Defender でスキャンする」を選びます。Windows 11 で見当たらないときは、先に「その他のオプションを確認」を選びます。
        3. 脅威が見つかった場合は、展開せずに、画面の指示に従って処理します。

        ほかのウイルス対策ソフトを使っている場合は、そのソフトのメニューでスキャンします。Mac でも、ウイルス対策ソフトを入れている場合は、そのソフトで確かめます。パスワード付き ZIP は中身が暗号化されているため、ウイルス対策ソフトが中身を調べられないことがあります。

        スキャンで何も見つからなくても、安全とは言い切れません。心当たりのないメールの ZIP は開かずに、会社なら情報システムの担当者に相談します。知っている人の名前で届いたメールでも、文面がいつもと違うときは、電話などで本人に確かめます。

      • 展開ソフトは公式サイトからだけ入手し、ときどき更新する

        7-Zip は www.7-zip.org、CubeICE は www.cube-soft.jp/cubeice/ が公式サイトです。公式サイトをブックマークしておき、次からはそこから開きます。検索結果の上のほうに「広告」「スポンサー」と書かれたリンクは、公式サイトではないことがあるので押しません。ダウンロード用のページには、本物に似せた広告のダウンロードボタンが出ることもあります。ボタンの位置と文字を確かめてから押します。

        7-Zip は自動では更新されないため、ときどき公式サイトで新しい版が出ていないかを確かめ、出ていれば入れ直します。

      • 1か月を振り返る

        ZIP が開けずに困った回数と、そのときの原因を振り返ります。原因は、壊れていた、文字化け、アプリの設定、パスワード、のどれかに分けます。同じ原因が続くなら、その原因に合ったやり方を、1週間の行動で決めた手順のメモに書き足します。

    1か月たったら、ZIP を受け取ってから中身を見るまでに迷った場面を振り返ります。迷わずに開けた回数が増えていれば、今のやり方を続けます。まだ開けないことがある場合は、どこで止まったか（サイズ、標準の機能、展開ソフト、パスワード）をメモします。そのうえで、この記事の切り分けの順に確かめるか、送ってくれた人や情報システムの担当者に相談します。手順の名前や場所はパソコンの種類やバージョンで変わることがあるので、分からないところは、使っているパソコンの公式ヘルプで確かめてください。

    見知らぬ人から届いた ZIP ファイルには、ウイルスが入っていることがあります。安易に開かず、開く前にウイルス対策ソフトで確認してください。知っている人の名前で届いたメールでも、文面や添付ファイルがいつもと違うときは注意してください。

    無料の展開ソフトは、必ず公式サイトから入手してください。検索結果の広告や、偽のダウンロードボタンには注意してください。会社のパソコンにソフトを入れる前には、社内の決まりを確かめてください。

    ファイル名やフォルダの階層が長すぎると、展開に失敗することがあります。

    設定の名前や場所は、パソコンの種類やバージョンで変わることがあります。この記事は、2026年11月時点の Microsoft と Apple の公式ヘルプ、7-Zip と CubeICE の公式サイトをもとにしています。分からない操作は、使っているパソコンの公式ヘルプで確かめてください。
