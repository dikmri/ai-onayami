    AIの見立て

    画面を2つに分ける機能は Windows に標準で備わっており、買い物や追加のソフトなしで解決できる見込みが高い。キーボードのショートカットか、ウィンドウを画面の端に寄せる操作を覚えれば、その場で並べられるようになる

    Windows には、ウィンドウを画面の半分や4分の1にぴったり合わせる「スナップ」という機能が標準で入っています。Windows キーを押しながら左右の矢印キーを押すと、使っているウィンドウを画面の左半分か右半分に寄せられます。マウスでウィンドウを画面の端までドラッグしても、同じように半分にできます。

    2台目のモニターや追加のソフトを買わなくても、今のパソコンの画面だけで試せます。そのため、解決できる見込みは高いと考えます。

    ボトルネックは3つです。1つ目は、そういう機能があることを知らないことです。2つ目は、マウスで大きさを調整しようとして、ぴったりにできないことです。3つ目は、ウィンドウを切り替えるたびに、どこまで作業したか分からなくなることです。

    キーボードのショートカットか、ウィンドウを画面の端に寄せる操作を覚えれば、その場で並べられるようになります。

    この記事は、2026年11月時点の Microsoft の公式サポート情報をもとにしています。Windows 10 と Windows 11 では、使える並べ方が違います。なお、Windows 10 のサポートは2025年10月14日に終了しています。

    悩みの分解

    お悩みの文章から、困っていることを7つに分けました。

    書類のウィンドウと入力画面を、何度も切り替えるのが面倒
    2つのウィンドウを重ねて使っているので、見るたびに切り替える必要があります。画面の左右に1つずつ並べれば、切り替えずに両方を見られます。
    切り替えるたびに「今どこまで打ったっけ」と分からなくなり、間違えそうで不安
    入力画面に切り替えると、書類のウィンドウは後ろに隠れます。目で追っていた行が見えなくなるので、戻ったときに位置を探し直すことになります。並べておけば、書類の位置を目で追ったまま入力できます。
    資料を見ながらメールを書くとき、別のウィンドウを開いてしまい、元の画面に戻れなくなる
    ウィンドウが重なっていると、目的のウィンドウを探すのに手間がかかります。資料とメールを左右に並べておけば、コピーと貼り付けのたびに探す必要がなくなります。開いているウィンドウを一覧で見る「タスク ビュー」を使うと、隠れたウィンドウもすぐ選べます。
    マウスでウィンドウの端をドラッグしても、ぴったり半分にならない
    手で大きさを合わせると、隙間や重なりができやすくなります。スナップを使うと、Windows がウィンドウの大きさと位置を半分ぴったりに合わせます。
    Excel の2つの表を見比べたいときも、タブを切り替えるばかりになる
    同じファイル（ブック）の中の2つのシートは、ふつうは1つのウィンドウで切り替えて見ます。Excel の「新しいウィンドウを開く」を使うと、同じブックを2つのウィンドウで表示できます。2つのウィンドウを左右に並べれば、別々のシートを同時に見られます。
    2台目のモニターは、置く場所もお金もかかる
    書類と入力画面のように2つを並べる程度なら、1つの画面のスナップで足りることが多いです。2台目のモニターは、並べても狭いと感じたときに考えれば間に合います。
    ショートカットで半分にできると聞いたが、やり方が分からない
    Windows キーを押しながら、左矢印キーか右矢印キーを押す操作です。Windows 10 と Windows 11 のどちらでも使えます。手順は行動プランで説明します。

    スナップの仕組み

    スナップでできることを知ると、作業に合った並べ方を選べます。

    ウィンドウを画面の端や隅に寄せると、大きさと位置が自動で決まる
    Microsoft は、ウィンドウを画面の左端か右端にドラッグすると、その側にスナップすると説明しています。隅にドラッグすると画面の4分の1に、上端にドラッグすると幅はそのままで高さが画面いっぱいになります。Windows 10 と Windows 11 で共通の機能です。
    キーボードでは、Windows キーと矢印キーで寄せられる
    Windows キーを押したまま矢印キーを押すと、使っているウィンドウがスナップされます。矢印キーを続けて押すと、位置を変えられます。Windows キーを離すと、その位置で決まります。
    片側に寄せると、反対側に置くウィンドウを選べる（スナップ アシスト）
    1つ目のウィンドウを片側に寄せると、ほかに開いているウィンドウの縮小画像が反対側に並びます。そこから1つ選ぶと、空いている側にぴったり収まります。Microsoft はこの機能を「スナップ アシスト」と呼んでいます。
    並べた2つの境目をドラッグすると、両方の幅が一緒に変わる
    スナップで並べた2つのウィンドウの境目を選ぶと、仕切りの線が出ます。この線をドラッグすると、隣のウィンドウも合わせて大きさが変わり、隙間や重なりはできません。書類を少し狭く、入力画面を広く、といった調整ができます。
    Windows 11 では、Windows キー＋Z で並べ方の一覧を出せる（スナップ レイアウト）
    Windows 11 では、Windows キー＋Z を押すと、2分割・3分割・4分割などの並べ方の一覧が出ます。ウィンドウの最大化ボタンにマウスのカーソルを合わせても、同じ一覧が出ます。Microsoft によると、出てくる並べ方はディスプレイの大きさによって違います。Windows 10 には、この一覧はありません。
    Windows 11 では、並べた組をまとめて呼び戻せる（スナップ グループ）
    Windows 11 では、スナップで並べたウィンドウの組が自動で「スナップ グループ」になります。タスクバーのアイコンにカーソルを合わせると、グループ全体を元に戻すか、そのアプリだけを戻すかを選べます。ほかのウィンドウを開いて並びが崩れても、元の並びにすぐ戻せます。
    Excel の「新しいウィンドウを開く」は、同じブックを2つ目のウィンドウで表示する機能
    Microsoft は、［表示］タブの［ウィンドウ］にある［新しいウィンドウを開く］で、今のブックに追加のウィンドウを作れると説明しています。2つのウィンドウは同じブックを表示しているので、それぞれで別のシートを選べます。Excel 2013 以降は、ブックごとに別々のウィンドウで開きます。別のファイルの表どうしも、スナップで左右に並べられます。

    原因の切り分け方

    何を並べたいかによって、近道が違います。次のように切り分けます。

    2つのアプリを行き来している（書類と入力画面、資料とメールなど）
    スナップで左右に並べるのが近道です。Windows キー＋左矢印キーで片方を左に寄せ、スナップ アシストでもう片方を右に置きます。
    同じ Excel ブックの2つのシートを見比べたい
    ［新しいウィンドウを開く］で2つ目のウィンドウを作り、2つをスナップで左右に並べます。Excel 自身の［並べて比較］と［同時にスクロール］を使うと、2つの表を同じ速さでスクロールできます。
    別々の Excel ファイルの表を見比べたい
    2つのファイルを両方とも開き、それぞれをスナップで左右に並べます。［新しいウィンドウを開く］を使う必要はありません。
    ノートパソコンなど、画面が小さい
    4分割にすると、1つのウィンドウが小さくなりすぎて、文字が読みにくくなります。まずは左右の2分割から試します。2分割でも文字が小さいときは、表示の拡大率を上げます。
    使っているのが Windows 10 か Windows 11 か分からない
    Windows キー＋左右の矢印キーと、画面の端へのドラッグは、どちらでも使えます。Windows キー＋Z の並べ方の一覧は、Windows 11 だけの機能です。どちらかは、設定の［バージョン情報］で確かめられます。
    並べても画面が狭くて作業しにくい
    1つの画面で工夫しても足りない場合に限って、2台目のモニターや、家にあるテレビをつなぐ方法を考えます。2つを並べる程度の作業なら、1つの画面のスナップで足りる場合が多いです。

    落とし穴

    スナップを使い始めるときに、つまずきやすい点があります。

    思ったとおりに並ばないときは、最大化を解除してから試す
    Microsoft の公式情報には、最大化したウィンドウをスナップする前に最大化を解除する必要がある、とは書かれていません。ただ、思ったとおりに並ばないときは、ウィンドウ右上の［元に戻す（縮小）］ボタンで最大化を解除してから試すと、原因を切り分けやすくなります。
    上や下の矢印キーを押すと、最大化や最小化になることがある
    Microsoft のショートカットの一覧では、Windows キー＋上矢印キーは最大化、Windows キー＋下矢印キーは最小化と説明されています。半分にしたいときは、左右の矢印キーを使います。ウィンドウが消えたように見えたら、タスクバーのアイコンを押して呼び戻します。
    Windows 10 では、Windows キー＋Z の並べ方の一覧は使えない
    Windows 10 の Windows キー＋Z は、全画面表示のアプリで使えるコマンドを表示する操作として一覧に載っています。Windows 10 で4分の1に寄せたいときは、ウィンドウを画面の隅までドラッグします。
    画面の端まで運ぶ前に指を離すと、半分にならない
    Microsoft は、半透明の表示が出るまでウィンドウを画面の端へドラッグするよう案内しています。半透明の表示が出る前にマウスのボタンを離すと、その場所にウィンドウが置かれるだけです。
    スナップがオフになっていると、寄せても半分にならない
    スナップは、［設定］→［システム］→［マルチタスク］の［スナップ ウィンドウ］でオンとオフを切り替えられます。端に寄せても半分にならないときは、ここがオンになっているかを確かめます。
    Excel の2つのウィンドウは、同じブックを表示している
    ［新しいウィンドウを開く］で作ったウィンドウは、別のファイルではありません。片方で数字を直すと、同じブックの中身が変わるので、もう片方にも同じ変更が出ます。別のファイルのつもりで両方を直さないように注意します。
    Excel の最後のウィンドウを閉じると、ブックが閉じる
    Microsoft によると、同じブックのウィンドウがほかにもあれば、閉じるのは作業中のウィンドウだけです。ウィンドウが1つしか残っていなければ、ブック全体が閉じます。最後のウィンドウを閉じる前に、保存を忘れないようにします。

    公式情報で確かめたこと

    次のことを、Microsoft の公式サポート情報で確かめました。Windows のバージョンや Excel のバージョンによって、画面の表示や項目の名前が違うことがあります。

    スナップの操作（Microsoft サポート「ウィンドウのスナップ」の Windows 11 と Windows 10 の説明）
    ウィンドウを左右の端にドラッグすると半分に、隅にドラッグすると4分の1になります。上端にドラッグすると、幅を保ったまま高さが画面いっぱいになります。Windows ロゴ キーを押したまま方向キーを押すとスナップされ、Windows キーを離すとその位置で決まります。半透明の表示が出るまで端へドラッグするよう案内されています。片側にスナップすると、スナップ アシストがほかのウィンドウの縮小画像を表示します。2つのウィンドウの境目を選ぶとバーが出て、隣のウィンドウも合わせて大きさが変わります。ここまでは Windows 10 と Windows 11 で共通です。
    Windows 11 だけの機能（同ページの Windows 11 の説明）
    ウィンドウの最大化ボタンにカーソルを合わせるか、Windows キー＋Z を押すと、スナップ レイアウトを選べます。表示されるレイアウトは、ディスプレイの大きさによって違う場合があります。ウィンドウを画面の上部にドラッグすると、スナップ バーが出ます。複数のウィンドウをスナップすると、スナップ グループが自動で作られます。タスクバーのアイコンにカーソルを合わせると、グループ全体かそのアプリだけを元に戻せます。Windows 10 の説明には、これらの機能はありません。
    スナップの設定（同ページ）
    設定アプリの［システム］→［マルチタスク］にある［スナップ ウィンドウ］で、スナップのオンとオフを切り替えます。Windows 11 には、画面の端までドラッグしなくてもスナップできるようにする項目もあります。Windows 10 には、隣のスナップされたウィンドウの大きさも同時に変える項目があります。
    キーボード ショートカット（Microsoft サポート「Windows のキーボード ショートカット」）
    Windows 11 では、Windows キー＋左矢印キーは「ウィンドウを画面の左側にスナップします」、Windows キー＋Z は「スナップ レイアウトを開きます」と説明されています。Windows 10 では、Windows キー＋左矢印キーは「画面の左側にアプリまたはデスクトップ ウィンドウを最大化する」、Windows キー＋Z は「全画面表示モードのアプリで使用できるコマンドを表示する」です。Windows キー＋上矢印キーは最大化、Windows キー＋下矢印キーは最小化（Windows 10 では現在のアプリを画面から削除する、または最小化）と説明されています。Windows キー＋Tab はタスク ビューを開く操作です。
    タスク ビューと Alt＋Tab（Microsoft サポート「Windows でマルチタスクを実行する方法」）
    タスク ビューには、開いているすべてのウィンドウの一覧が表示されます。タスクバーのタスク ビュー ボタンを選ぶか、Windows キー＋Tab キーを押すと開きます。Alt＋Tab では、開いているアプリをすばやく切り替えられ、Alt キーを離すと選んだアプリが前に出ます。
    Excel で2つのシートを並べる（Microsoft サポート「2 つ以上のワークシートを同時に比較する」）
    同じブックの2つのシートを比べるときは、［表示］タブの［ウィンドウ］で［新しいウィンドウを開く］を押し、各ウィンドウで比較するシートを選びます。［同時にスクロール］は、［並べて比較］がオンのときに限り使えます。ウィンドウの大きさを変えたあとは、［ウィンドウの位置を元に戻す］で元の設定に戻せます。Excel 2013 以降は、ブックごとに別々の Excel ウィンドウで開くと書かれています。
    Excel のウィンドウを閉じる（Microsoft サポート「ブックまたはブック ウィンドウを閉じる」）
    同じブックのブック ウィンドウがほかにもある場合は、作業中のウィンドウだけが閉じます。ウィンドウが1つだけの場合は、ブック全体が閉じます。［表示］→［新しいウィンドウ］で、今のブックに追加のウィンドウを作れるとも書かれています。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. 画面を半分ぴったりに分ける機能があることを知らず、ウィンドウを1つずつ切り替えて使う
    2. 切り替えるたびに書類が隠れ、どこまで打ったか分からなくなる
    3. マウスで並べようとするが、ぴったり半分にならず、隙間や重なりで見づらくなる
    4. 並べるのをあきらめて、また切り替えに戻る

    4のあと、また1に戻ります。

    この流れは、どの段階でも止められます。1は、Windows キー＋左右の矢印キーを覚えれば止まります。2は、書類と入力画面を左右に並べ、両方が見えたまま入力すれば止まります。3は、手で大きさを合わせるのをやめて、スナップで寄せれば止まります。4は、作業ごとに並べ方を決めて、毎回同じ並べ方にすれば止まります。

        書類のウィンドウと入力画面を、どちらも開いておきます。次の順番で試します。

        1. 書類のウィンドウを1回クリックして、選んだ状態にします。
        2. キーボードの Windows キー（Windows のマークが付いたキー）を押したまま、左矢印キーを押します。書類のウィンドウが、画面の左半分にぴったり収まります。
        3. Windows キーを離すと、右半分に、ほかに開いているウィンドウの縮小画像が並びます。
        4. 縮小画像の中から入力画面を選びます。入力画面が、右半分にぴったり収まります。

        縮小画像が出ないときは、入力画面を1回クリックしてから、Windows キーを押したまま右矢印キーを押します。

        思ったとおりに並ばないときは、ウィンドウ右上の［元に戻す（縮小）］ボタンを押して最大化を解除してから、もう一度試します。

      • マウスで並べる方法も試す

        1. ウィンドウのいちばん上のバー（タイトルが表示されている部分）を、マウスのボタンを押したままつかみます。
        2. そのまま、画面の左端までマウスを動かします。
        3. 画面の左半分に半透明の表示が出たら、マウスのボタンを離します。
        4. 右半分に縮小画像が並ぶので、もう片方のウィンドウを選びます。

        半透明の表示が出る前にボタンを離すと、半分になりません。そのときは、もう一度つかんで、端まで運び直します。

      • 境目をドラッグして、左右の幅を調整する

        並べた2つのウィンドウの境目にマウスのカーソルを合わせ、ドラッグします。隣のウィンドウも合わせて大きさが変わるので、隙間や重なりはできません。書類が読める幅を残して、入力画面を少し広くするなど、作業しやすい幅にします。

      • Excel の2つの表を並べて見比べる

        同じブックの中の2つのシートを見比べるときは、次の順番で試します。

        1. 見比べたいブックを開きます。
        2. ［表示］タブの［ウィンドウ］にある［新しいウィンドウを開く］を押します。同じブックが、2つ目のウィンドウで開きます。
        3. 1つ目のウィンドウを選び、Windows キー＋左矢印キーで左半分に寄せます。
        4. 右半分に並んだ縮小画像から、2つ目のウィンドウを選びます。
        5. 左右のウィンドウで、それぞれ見比べたいシートのタブを選びます。

        別々のファイルの表を見比べるときは、2つのファイルを両方とも開き、それぞれをスナップで左右に並べます。

        2つの表を同じ速さでスクロールしたいときは、［表示］タブの［ウィンドウ］にある［並べて比較］をオンにしてから、［同時にスクロール］を押します。Microsoft のヘルプでは、［並べて比較］のボタンが［横に並べて表示］と書かれていることもあります。

        Excel の関数で2つの表の違いを探す方法は、お悩み No.008「Excel の関数が覚えられず、集計や転記を手作業でしている。少しずつ使えるようになるには」も参考にしてください。

      • 資料とメールも、同じように並べる

        資料を左、メールを書く画面を右に並べます。コピーしたい文章を資料の側で選び、Ctrl キー＋C キーでコピーします。メールの側をクリックして、Ctrl キー＋V キーで貼り付けます。両方が見えているので、別のウィンドウを開いて元の画面を見失うことが減ります。

    2. 1週間の行動

      目安：毎日の作業の始めに1〜2分

      • Windows 11 なら、Windows キー＋Z で並べ方の一覧を試す

        並べたいウィンドウを選んで、Windows キーを押したまま Z キーを押します。2分割・3分割・4分割などの並べ方の一覧が出ます。ウィンドウ右上の最大化ボタンにマウスのカーソルを合わせても、同じ一覧が出ます。

        一覧の中で、ウィンドウを置きたい場所を選びます。残りの場所には、ほかのウィンドウの縮小画像が並ぶので、順に選んで埋めます。出てくる並べ方は、画面の大きさによって違います。

        Windows 10 には、この一覧はありません。Windows 10 で画面の4分の1に寄せたいときは、ウィンドウを画面の隅までドラッグします。

      • よく使う組み合わせは、毎回同じ並べ方にする

        たとえば、書類と入力画面なら「書類を左、入力画面を右」、資料とメールなら「資料を左、メールを右」と決めます。毎回同じ位置にあれば、目で探す手間が減ります。

        Windows 11 では、並べたウィンドウの組がスナップ グループになります。ほかのウィンドウを開いて並びが崩れたときは、タスクバーのアイコンにカーソルを合わせ、グループを選ぶと元の並びに戻せます。

      • タスク ビューで、隠れたウィンドウを探す

        目的のウィンドウが見つからないときは、タスクバーのタスク ビュー ボタンを押すか、Windows キーを押したまま Tab キーを押します。開いているウィンドウが一覧で表示されるので、目的のウィンドウを選びます。

        Alt キーを押したまま Tab キーを押す方法もあります。Tab キーを押すたびに選ぶウィンドウが変わり、Alt キーを離すと、選んだウィンドウが前に出ます。

      • 文字が小さくて見づらいときは、表示の拡大率を調整する

        半分に並べると、1つのウィンドウが狭くなり、文字が読みにくくなることがあります。そのときは、［スタート］→［設定］→［システム］→［ディスプレイ］を開きます。

        • Windows 11：［スケールとレイアウト］の［スケール］で、値を選びます。
        • Windows 10：［拡大縮小とレイアウト］の［テキスト、アプリ、その他の項目のサイズを変更する］で、値を選びます。

        100%から125%のように、1段ずつ上げて試します。選べる値はパソコンによって違います。迷ったら「(推奨)」と付いた値に戻します。

        拡大率を上げると文字は大きくなりますが、1つの画面に入る量は減ります。並べたときに、書類と入力画面の両方が読めるかを確かめながら選びます。Excel の表だけを大きくしたいときは、Excel のウィンドウの右下にある表示の倍率を変える方法もあります。文字を大きくする設定は、お悩み No.067「パソコンの文字が小さくて読めない。画面を大きくする設定と見やすくするコツ」でくわしく説明しています。

    3. 1か月の見直し

      目安：月に1回、15分ほど（2台目の画面を試す時間は別）

      • 作業の種類ごとに、並べ方を決めておく

        1週間使ってみて、よく使う組み合わせを書き出します。たとえば、次のように決めます。

        • 入力作業：書類を左、入力画面を右
        • 調べもの：ブラウザを左、メモ帳を右
        • Excel の見比べ：元の表を左、比べる表を右
        • メール：資料を左、メールを右

        決めた並べ方を紙に書いて、パソコンの近くに貼っておくと、毎回迷わずに並べられます。

      • 切り替えの手間と入力の間違いが減ったかを振り返る

        並べる前と比べて、切り替えの回数や、どこまで打ったか分からなくなる場面が減ったかを思い出します。まだ切り替えが多い作業があれば、その作業の並べ方を見直します。

      • それでも画面が狭いと感じるときだけ、2台目の画面を考える

        並べ方を工夫しても狭いと感じるときは、2台目のモニターをつなぐ方法があります。

        モニターを買う前に、家にあるテレビで試す方法もあります。パソコンとテレビの両方に HDMI の差し込み口があれば、HDMI ケーブルでつないで試せます。テレビの入力切替を、つないだ HDMI の差し込み口に合わせます。次に、パソコンで Windows キーを押したまま P キーを押し、［拡張］を選びます。［拡張］にすると、テレビがパソコンの画面の続きとして使えます。

        テレビを机から離れた場所に置くと、文字が読みにくくなることがあります。試してみて、2台目の画面で作業が楽になるかを確かめてから、モニターを買うかどうかを決めます。つなぎ方や、映らないときの確かめ方は、お悩み No.100「ノートパソコンを2画面にしたいのに、つないでも映らない・同じ画面しか出ない。デュアルディスプレイを広々使うには」でくわしく説明しています。

    手順の名前や設定画面の表示は、Windows のバージョンで変わることがあります。分からないところは、Microsoft の公式サポートで確かめてください。
