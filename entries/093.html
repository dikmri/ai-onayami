お悩み No.093 ・ 2026年11月24日公開

パソコンが勝手にスリープから復帰する。夜中に起動する原因と止め方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    勝手なスリープ解除の多くは設定で止められる。まず powercfg /lastwake で何が起こしたのか確かめ、スリープ解除タイマーとネットワークアダプターの電源管理を見直すのが近道

    勝手なスリープ解除の多くは、設定で止められます。壊れているわけではないことがほとんどです。設定を1つずつ確かめれば、直せる場合が多いです。

    ボトルネックは3つです。1つ目は、何がパソコンを起こしたのか分からないことです。2つ目は、電源まわりの設定の場所を知らないことです。3つ目は、スリープから戻らないときの対処を知らないことです。

    原因は、いくつかに絞れます。Windows Update などのメンテナンス、ネットワークアダプターの電源管理、キーボードやマウス、タイマーによる自動起動です。

    この記事は、2026年11月時点の Microsoft の公式情報をもとにしています。手順や画面の名前は、Windows のバージョンやメーカーで変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    スリープにして寝たのに、朝には起動している
    夜のあいだに、何かがスリープを解除している。ファンの音がしたり、画面がついたりしている。
    深夜に突然ファンが回りだして、目が覚める
    起きる時刻が毎晩同じか、ばらばらかが、原因を絞る手がかりになる。まだ確かめていない。
    スリープから戻すと、画面が真っ黒のまま動かない
    パソコン本体は動いていて、画面の表示だけが戻っていない可能性がある。モニターの側の問題の可能性もある。
    電源ボタンの長押しで、強制終了するしかない
    強制終了を繰り返すと、保存していない作業が消えたり、ファイルが壊れたりするおそれがある。
    触れていないのに起きるので、壊れかけているのか心配
    故障より先に、設定で起きている可能性を確かめる段階にある。
    Windows Update やタイマーが原因と聞いたが、どこを直せばよいか分からない
    原因の調べ方と、電源まわりの設定の場所を知らない。

    勝手に起きる仕組み

    仕組みを知ると、どこを直せばよいかが分かります。

    スリープは、少ない電力で待機する状態
    Microsoft の案内では、スリープは電力をほとんど使わず、パソコンから離れたときの状態にすぐ戻れる仕組みです。待機している間も、決まった信号を受けると、パソコンは起き上がります。
    スリープ解除タイマーは、決まった時刻にパソコンを起こす
    Windows には、予約した時刻にパソコンを起こす「スリープ解除タイマー」があります。Windows Update やアプリの更新、予約されたタスクがこれを使うことがあります。Microsoft の技術文書では、Windows Update のメンテナンスのためにパソコンが午前3時に起きた例が説明されています。
    自動メンテナンスは、使っていない時間に更新や点検をする
    Windows は、パソコンを使っていない時間に、ソフトウェアの更新やセキュリティのスキャンなどの「自動メンテナンス」を毎日行います。メンテナンスの設定には、「スケジュールされたメンテナンスによるコンピューターのスリープ解除を許可する」という項目があります。ここにチェックが入っていると、メンテナンスの時刻にパソコンが起きることがあります。
    ネットワークアダプターは、通信が来るとパソコンを起こすことがある
    ネットワークアダプターは、Wi-Fi や有線 LAN の通信を受け持つ部品です。Microsoft の技術文書では、「Wake on LAN」は、ネットワーク アダプターが決まった信号を受けると、パソコンを低電力の状態から起こす機能と説明されています。デバイス マネージャーの「電源の管理」タブで、起こしてよいかを設定します。「電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする」には、初期設定でチェックが入っている場合があります。
    キーボード、マウス、USB 機器も、パソコンを起こす
    Microsoft の案内では、機種によっては、キーを押したりマウスをクリックしたりするとスリープが解除されます。机の振動でマウスが少し動いただけでも、起きることがあります。
    スリープ中もネットにつながったままの機種がある
    ノートパソコンを中心に、「モダン スタンバイ」という方式でスリープする機種があります。Microsoft の技術文書では、この方式のパソコンは、電源につながっている間は、スリープ中でも更新などのメンテナンスを行うことがあります。どちらの方式かは、powercfg /a で確かめられます。結果の「利用可能」の側に「スタンバイ (S0 低電力アイドル)」があれば、モダン スタンバイの機種です。
    画面が真っ黒になるのは、画面の表示がうまく戻っていない場合がある
    画面の表示を担当する部分（グラフィックス）とそのドライバーが、スリープからうまく戻っていない場合があります。Microsoft の案内では、画面が真っ黒のときは、まず Windows ロゴ キー + Ctrl + Shift + B を押して、グラフィックス ドライバーをリセットします。うまくいくと、ビープ音が鳴るか、画面が一瞬ちらつきます。

    原因の切り分け方

    起き方によって、確かめることが変わります。どの場合も、まず powercfg /lastwake で、最後にパソコンを起こしたものを確かめます。

    毎晩ほぼ同じ時刻に起きる
    Windows Update やメンテナンスのタイマーが原因のことが多いです。powercfg /waketimers で、予約されている自動起動を確かめます。スリープ解除タイマーと、自動メンテナンスのスリープ解除の設定を見直します。
    夜中に、ばらばらの時刻に起きる
    ネットワークからの信号や、USB 機器の信号が原因のことが多いです。powercfg /devicequery wake_armed で、パソコンを起こせる機器の一覧を確かめます。一覧にネットワークアダプターがあれば、その電源の管理の設定を見直します。
    マウスを少し動かしたり、机が揺れたりすると起きる
    キーボードやマウスの「このデバイスで、コンピューターのスタンバイ状態を解除できるようにする」が原因のことが多いです。
    スリープから戻すと、画面が真っ黒になる
    画面の表示まわりの問題です。電源ボタンを長押しする前に、Windows ロゴ キー + Ctrl + Shift + B を試します。何度も起きる場合は、グラフィックス ドライバーの更新と、ネットワークアダプターの電源管理の設定を確かめます。
    電源ランプはついているのに、画面だけが暗い
    モニターの電源、ケーブルの差し込み、モニターの入力切替も確かめます。デスクトップパソコンでは、モニターの側が原因のこともあります。
    ノートパソコンを電源につないでいる夜だけ、ファンが回る
    モダン スタンバイの機種では、電源につないだスリープ中に、更新などのメンテナンスが行われることがあります。powercfg /a で方式を確かめます。

    落とし穴

    次のことに気をつけないと、パソコンや作業中のファイルに負担がかかります。

    勝手に起きたまま、放っておく
    ファンが回り続け、電気代がかかります。パソコンが熱くなることもあります。
    電源ボタンの長押しを、毎回の対処にする
    強制終了すると、保存していない作業が消えたり、ファイルが壊れたりすることがあります。長押しは、ほかの方法で戻らないときの最後の手段にします。
    変更前の状態を控えずに、設定を変える
    元に戻せなくなります。設定を変える前に、画面の写真を撮るか、メモに残します。
    Windows の設定だけで直ると思い込む
    メーカー製パソコンでは、メーカー独自の電源管理ソフトが別に動いていることがあります。この場合、Windows の設定だけでは直らないことがあります。
    キーボードとマウスの両方で、スリープ解除を止める
    キーやマウスでは、スリープから戻せなくなります。その場合は、電源ボタンを短く押して戻します。長押しすると強制終了になるため、押す長さに気をつけます。
    ノートパソコンを、スリープのままカバンに入れる
    カバンの中で勝手に起きると、熱がこもります。カバンに入れる前に電源を切るか、スリープの設定を確かめます。

    公式情報で確かめたこと

    次のことを、Microsoft の公式サポート情報と技術文書で確かめました。画面の文言は、日本語版 Windows 11 の表示で確かめました。技術文書の一部は、Windows 8 や Windows 10 を対象に書かれています。手順や画面の名前は、Windows のバージョンやメーカーで違うことがあります。

    原因を調べるコマンド（Microsoft Learn「Powercfg のコマンドライン オプション」）
    powercfg /lastwake は、最後のスリープからシステムを起こしたものの情報を表示します。powercfg /waketimers は、有効なスリープ解除タイマーの一覧を表示します。スリープ解除タイマーは、期限が来ると、パソコンをスリープ状態や休止状態から起こします。powercfg /devicequery wake_armed は、今パソコンを起こせるように設定されている機器の一覧を表示します。powercfg /devicedisablewake "機器の名前" で、その機器がパソコンを起こせないようにできます。日本語版 Windows 11 で試したところ、/waketimers は管理者として開いたターミナルでないと動きませんでした。
    スリープとは何か（Microsoft サポート「PC をシャットダウン、スリープ、休止状態にする」）
    スリープでは、電力がほとんど使われず、パソコンから離れたときの状態にすぐ戻れます。ほとんどのパソコンでは、電源ボタンを押すとスリープから戻ります。機種によっては、キーを押す、マウスのボタンをクリックする、ノートパソコンのカバーを開く、といった操作でも戻ります。
    勝手に起きる原因の例（Microsoft Learn「デスクトップがスリープ状態または休止状態から予期せず起動する」）
    Windows 8 のデスクトップパソコンが、毎日午前3時にスリープから起きた例が説明されています。原因は、Windows Update などの定期的なメンテナンスと、電源接続時に有効になっていた「スリープ解除タイマーの許可」です。対処として、メンテナンスの設定で、スケジュールされた時刻にパソコンを起こす項目のチェックを外すよう書かれています。
    自動メンテナンスとスリープ解除タイマーの場所（Microsoft Learn「自動メンテナンス」）
    自動メンテナンスの設定は、「コントロール パネル」→「システムとセキュリティ」→「セキュリティとメンテナンス」→「自動メンテナンス」で変えられます。スリープ解除タイマーは、「コントロール パネル」→「ハードウェアとサウンド」→「電源オプション」→「プラン設定の変更」→「詳細な電源設定の変更」→「スリープ」→「スリープ解除タイマーの許可」にあります。パソコンのスリープ解除は、BIOS の設定にも左右されます。
    ネットワークからのスリープ解除（Microsoft Learn「Wake on LAN の動作」）
    Wake on LAN は、ネットワーク アダプターが決まった信号を受けると、パソコンを低電力の状態から起こす機能です。Windows 10 では、Wake on LAN は、スリープからか、利用者が自分で休止状態にした場合にだけ対応します。シャットダウンした状態からは対応しません。ただし一部の機種では、Windows と関係なく、BIOS などの設定でシャットダウン状態から起きることがあります。
    スリープ中もネットにつながる方式（Microsoft Learn「モダン スタンバイと S3」）
    モダン スタンバイのパソコンは、スリープ中もネットワークの接続を保てます。電源につながっている間は、スリープ中でもメンテナンスに入り、更新などを行うことがあります。
    Windows Update のアクティブ時間（Microsoft サポート「アクティブ時間で PC を最新の状態に保つ」）
    アクティブ時間は、ふだんパソコンを使う時間帯を Windows に伝える設定です。Windows は、更新のための再起動を、アクティブ時間の外で行います。Windows 11 では、「設定」→「Windows Update」→「詳細オプション」→「アクティブ時間」で設定します。
    画面が真っ黒のとき（Microsoft サポート「Windows の空白画面のトラブルシューティング」）
    外部モニターを使っている場合は、モニターがつながっていて電源が入っているかを確かめます。Windows ロゴ キー + Ctrl + Shift + B を押すと、グラフィックス ドライバーがリセットされます。直らない場合は、デバイス マネージャーの「ディスプレイ アダプター」から、ドライバーを更新します。更新のあとに問題が起き始めた場合は、「ドライバーのロールバック」を選びます。
    デバイス マネージャーの「電源の管理」タブの文言（日本語版 Windows 11 の表示）
    「電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする」「このデバイスで、コンピューターのスタンバイ状態を解除できるようにする」「Magic Packet でのみ、コンピューターのスタンバイ状態を解除できるようにする」の3つです。機器によっては、一部の項目が表示されません。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. 何がパソコンを起こしたのか確かめないまま、スリープにする
    2. タイマーや機器の設定がそのままなので、夜中にまた起きる
    3. 戻そうとすると画面が真っ黒になり、電源ボタンの長押しで強制終了する
    4. 「壊れかけているのでは」と不安になるが、原因が分からないまま同じ使い方を続ける

    4のあと、また1に戻ります。

    この流れは、1と2のところで止められます。1では、powercfg /lastwake で、パソコンを起こしたものを確かめます。2では、分かった原因に合わせて、スリープ解除タイマーや機器の設定を変えます。

    もう一つのボトルネックは、画面が真っ黒になったときの対処を知らないことです。電源ボタンを長押しする前に、Windows ロゴ キー + Ctrl + Shift + B を試すと、強制終了の回数を減らせます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • Windows Update の更新そのもの（更新は必要）
    • パソコンがどちらの方式でスリープするか（機種で決まる）
    • メーカー独自の電源管理ソフトの動き
    • グラフィックスの部品とドライバーの相性
    • Windows のバージョンやメーカーによる、設定の名前や場所の違い

    変えやすいこと

    • 何がパソコンを起こしたのかを調べること
    • スリープ解除タイマーの設定
    • 自動メンテナンスのスリープ解除の設定
    • ネットワークアダプター、キーボード、マウスの電源の管理の設定
    • Windows Update のアクティブ時間
    • 画面が真っ黒になったときの戻し方
    • 夜にスリープにするか、電源を切るか

    次の行動プランは3段階です。今日は、何がパソコンを起こしたのかをコマンドで調べます。1週間で、スリープ解除タイマーと機器の設定を見直します。1か月後には、勝手に起きる回数が減ったかを確かめ、残った原因に対処します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は、2026年11月時点の Microsoft の公式情報と、日本語版 Windows 11 の画面をもとにした例です。画面やボタンの名前、設定の場所は、Windows のバージョンやメーカーで変わることがあります。分からないところは、Microsoft やメーカーの公式サイト・公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：15分ほど

      • 管理者としてターミナルを開く

        • Windows 11：スタートボタンを右クリックし、「ターミナル (管理者)」を選びます。
        • Windows 10：スタートボタンを右クリックし、「Windows PowerShell (管理者)」を選びます。機種によっては「コマンド プロンプト (管理者)」と表示されます。

        「このアプリがデバイスに変更を加えることを許可しますか?」と出たら、「はい」を選びます。次の3つのコマンドは、状態を表示するだけで、設定は変えません。

      • 何がパソコンを起こしたのかを確かめる

        powercfg /lastwake と入力して、Enter キーを押します。最後にパソコンをスリープから起こしたものが表示されます。

        • 機器の名前が出たら、その機器がパソコンを起こしています。
        • タイマーやタスクの名前が出たら、予約された自動起動が原因です。
        • 「スリープ状態の解除履歴カウント - 0」と出たら、記録が残っていません。次に勝手に起きた朝に、もう一度実行します。

      • 予約されている自動起動を確かめる

        powercfg /waketimers と入力します。パソコンを起こす予約が入っていれば、その時刻と、予約したプログラムやタスクの名前が表示されます。このコマンドは、管理者として開いたターミナルでないと動きません。

      • パソコンを起こせる機器の一覧を確かめる

        powercfg /devicequery wake_armed と入力します。今パソコンを起こせるように設定されている機器が表示されます。「HID キーボード デバイス」のようなキーボードやマウス、Wi-Fi や有線 LAN のネットワークアダプターの名前が並びます。

        3つのコマンドの結果は、画面の写真を撮るか、メモに残します。1週間後と1か月後に見比べます。

      • 寝る前の使い方を変える

        スリープにする前に、使っていないアプリを閉じます。夜にパソコンを使わないなら、今夜は電源を切ります。スリープにするなら、ノートパソコンのカバーを閉じる前に、スリープの設定を確かめます。

      • 画面が真っ黒になったら、長押しの前に試す

        1. Windows ロゴ キー + Ctrl + Shift + B を押します。ビープ音が鳴るか、画面がちらつけば、画面の表示がリセットされています。
        2. 外部モニターなら、モニターの電源、ケーブルの差し込み、入力切替を確かめます。
        3. それでも戻らないときに限って、電源ボタンを長押しして強制終了します。

    2. 1週間の行動

      目安：設定の見直しに30〜40分、記録は毎朝1分

      • 変える前の状態を控える

        この先の設定を変える前に、それぞれの画面の写真を撮ります。うまくいかないときに、元に戻せます。

      • スリープ解除タイマーを止める

        1. タスクバーの検索欄で「コントロール パネル」と入力して開きます。
        2. 「ハードウェアとサウンド」→「電源オプション」と進みます。
        3. 使っている電源プランの「プラン設定の変更」を選び、「詳細な電源設定の変更」を選びます。
        4. 「スリープ」→「スリープ解除タイマーの許可」を開き、「無効」にします。ノートパソコンでは、「バッテリ駆動」と「電源に接続」の両方を変えます。
        5. 「OK」を押します。

        選べるのは「無効」「有効」「重要なスリープ解除タイマーのみ」の3つです。この項目は「設定」アプリにはありません。項目が見つからないときは、Microsoft やメーカーの公式ヘルプで確かめます。

      • メンテナンスでパソコンを起こさないようにする

        1. 「コントロール パネル」→「システムとセキュリティ」→「セキュリティとメンテナンス」と進みます。
        2. 「メンテナンス」を開き、「自動メンテナンス」の「メンテナンス設定の変更」を選びます。
        3. 「スケジュールされたメンテナンスによるコンピューターのスリープ解除を許可する」のチェックを外し、「OK」を押します。

        同じ画面で、メンテナンスを行う時刻も確かめられます。チェックを外しても、パソコンを使っていない時間にメンテナンスは行われます。

      • ネットワークアダプターの電源の管理を確かめる

        1. スタートボタンを右クリックし、「デバイス マネージャー」を選びます。
        2. 「ネットワーク アダプター」を開き、使っている Wi-Fi や有線 LAN の機器を右クリックして、「プロパティ」を選びます。
        3. 「電源の管理」タブで、「このデバイスで、コンピューターのスタンバイ状態を解除できるようにする」のチェックを外します。
        4. 「OK」を押します。

        Wake on LAN を使ってパソコンを遠くから起こしている人は、チェックを外す代わりに、「Magic Packet でのみ、コンピューターのスタンバイ状態を解除できるようにする」にチェックを入れます。Wake on LAN 用の決まった信号でだけ起きるようになります。

        スリープから戻ったあとに Wi-Fi や有線 LAN がつながらないときは、同じタブの「電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする」のチェックも外して試します。この項目は、Windows がネットワークアダプターの電源を切ってよいかを決めます。

      • キーボードやマウスがパソコンを起こさないようにする

        1. デバイス マネージャーで、「キーボード」または「マウスとそのほかのポインティング デバイス」を開きます。
        2. 使っている機器を右クリックし、「プロパティ」を選びます。
        3. 「電源の管理」タブで、「このデバイスで、コンピューターのスタンバイ状態を解除できるようにする」のチェックを外します。

        今日調べた一覧に出た機器から順に変えます。マウスだけを止めて、キーボードでは起こせるように残す方法もあります。両方を止めたときは、電源ボタンを短く押してスリープから戻します。

        コマンドに慣れている人は、管理者のターミナルで powercfg /devicedisablewake "機器の名前" と入力しても、同じように止められます。機器の名前は、powercfg /devicequery wake_armed の結果をそのまま使います。

      • Windows Update のアクティブ時間を確かめる

        • Windows 11：スタート→「設定」→「Windows Update」→「詳細オプション」→「アクティブ時間」と進みます。
        • Windows 10：スタート→「設定」→「更新とセキュリティ」→「Windows Update」→「アクティブ時間の変更」と進みます。

        アクティブ時間は、ふだんパソコンを使う時間帯に合わせます。Windows は、更新のための再起動を、アクティブ時間の外で行います。「自動」にすると、使い方に合わせて Windows が調整します。夜中にパソコンが起きるのを止めるのは、この設定ではありません。上のスリープ解除タイマーとメンテナンスの設定です。

      • 毎朝、起きていたかを記録する

        朝、パソコンが起きていたかどうかを、1行だけメモします。起きていたら、その日のうちに powercfg /lastwake を実行して、結果を残します。

    3. 1か月の見直し

      目安：30分ほど

      • 勝手に起きる回数が減ったかを確かめる

        1週間分のメモを見て、起きる回数が減ったかを確かめます。まだ起きる日があれば、powercfg /lastwake の結果を、最初に調べたときと見比べます。原因が変わっていれば、新しく出た機器やタイマーの設定を見直します。

      • 直らないときは、メーカーのソフトと BIOS/UEFI を確かめる

        メーカー製パソコンでは、メーカー独自の電源管理ソフトの設定を確かめます。パソコンの BIOS/UEFI に、Wake on LAN や、USB 機器で起きる設定がある場合もあります。BIOS/UEFI の画面の開き方と項目の名前は、メーカーや機種で違います。変える前に、メーカーの説明書や公式サイトで確かめ、元の値を控えます。

      • 画面が真っ黒になるのが続くなら、ドライバーを更新する

        • Windows Update で、更新プログラムをすべて入れます。
        • デバイス マネージャーの「ディスプレイ アダプター」で、使っている機器を右クリックし、「ドライバーの更新」を選びます。
        • パソコンやグラフィックスのメーカーの公式サイトで、新しいドライバーが出ていないかを確かめます。
        • ドライバーを更新したあとに真っ黒になり始めた場合は、同じ機器の「プロパティ」→「ドライバー」タブで、「ドライバーのロールバック」を選びます。

      • スリープの方式を確かめる

        ターミナルで powercfg /a と入力します。「スタンバイ (S0 低電力アイドル)」が利用可能の側にあれば、モダン スタンバイの機種です。電源につないだスリープ中に、更新などのメンテナンスが行われることがあります。夜のファンの音が気になるなら、夜は電源を切ります。

      • 夜に使わないなら、電源を切る習慣にする

        夜にパソコンを使わない人は、スリープではなく、電源を切る習慣にします。Microsoft の技術文書では、Windows 10 では、シャットダウンした状態からネットワークの信号で起きることには対応していません。ただし、一部の機種は、BIOS などの設定で起きることがあります。

      • ノートパソコンは、カバンに入れる前に確かめる

        カバンに入れる前に、電源が切れているかを確かめます。スリープのまま入れると、カバンの中で起きて、熱がこもることがあります。

    1か月たったら、効いた設定と効かなかった設定を分けます。効かなかった設定は、控えておいた写真を見て元に戻して構いません。手順の名前や設定の場所は、Windows のバージョンやメーカーで変わることがあります。分からないところは、Microsoft やメーカーの公式サイト・公式ヘルプで確かめてください。
