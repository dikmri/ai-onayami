パソコンで大事なファイルを誤って削除してしまった。元に戻せる？

    AIの見立て

    ファイルを削除しても、ゴミ箱に残っているあいだは『元に戻す』で復元できる場合が多い。ゴミ箱を空にしてしまった後でも、削除してすぐなら復元ソフトで取り戻せることがある。ただし新しいデータを書き込むと上書きされて戻らなくなるため、まずパソコンをあまり使わず、ゴミ箱とバックアップの有無を確かめることが近道

    ファイルを削除しても、ゴミ箱に残っているあいだは「元に戻す」で復元できる場合が多いです。ゴミ箱を空にしてしまった後でも、削除してすぐなら、復元ソフトで取り戻せることがあります。ただし、新しいデータを書き込むと、残っていたデータが上書きされて戻らなくなります。まずはパソコンをあまり使わずに、ゴミ箱とバックアップがあるかを確かめることが近道です。

    ボトルネックは3つです。1つ目は、ゴミ箱を空にした後だと戻せないと思い込んでしまうことです。2つ目は、削除した後に新しいデータを書き込んで、上書きしてしまうことです。3つ目は、バックアップを取っていないことです。

    慌てて色々触る前に、まずゴミ箱、クラウドのゴミ箱、バックアップの順に確かめることが近道です。

    この記事は、2026年11月時点のMicrosoftとGoogleの公式ヘルプの情報をもとにしています。手順の名前や設定の場所は、Windows のバージョンで変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    大事な書類を、間違えて削除してしまった
    ふつうの消し方なら、ファイルはまずゴミ箱に移動します。ゴミ箱に入っているあいだは、元の場所に戻せます。
    ゴミ箱を探したが、どこにも見当たらない
    自分でゴミ箱を空にしたか、Windows の機能がゴミ箱の中身を自動で消した可能性があります。ゴミ箱を通らない消し方をした可能性や、削除したつもりで別のフォルダーに移動しただけの可能性もあります。
    仕事で使う表計算のファイルで、作り直すには何日もかかりそう
    メールで送ったもの、共有フォルダーに置いたもの、クラウドに保存したものなど、コピーが残っている場所がないかを探す価値があります。
    削除した直後なら戻せると聞いたが、どうすればいいか分からない
    確かめる場所と順番が分からないため、手が止まっています。
    これ以上触ると、余計に悪くなりそうで怖い
    この心配には理由があります。新しいデータを書き込むと、消したファイルのデータが上書きされることがあるからです。一方で、ゴミ箱やクラウドを開いて見るだけなら、大きなデータは書き込みません。クラウドのゴミ箱は、スマホからも確かめられます。
    二度とこんな思いをしたくないので、普段からの備えを知りたい
    ファイル履歴やクラウドを使い、大事なファイルを2か所以上に保存する仕組みを作れば、同じことが起きても取り戻せます。

    削除したファイルが戻せる仕組み

    仕組みを知ると、どこを探せばよいか、何をしてはいけないかが分かります。

    ファイルを削除すると、まずゴミ箱に移動する
    Microsoft のキーボード ショートカットの一覧では、Delete キーの働きを「選択した項目を削除し、ごみ箱に移動する。」と説明しています。ゴミ箱に入っているあいだは、右クリックで元に戻せます。Microsoft によると、戻したファイルは「元のフォルダーに復元されます。」
    ゴミ箱を通らない消し方もある
    Shift + Delete で削除すると、ファイルはゴミ箱に入りません。Microsoft は、この操作を「選択した項目を、ごみ箱に移動せずに完全に削除します。」と説明しています。USBメモリやネットワーク上の場所から削除したファイルも、ゴミ箱に入らずに消える場合があります。
    ゴミ箱の中身は、Windows が自動で消すこともある
    Windows の「ストレージ センサー」は、空き容量を増やすために、一時ファイルやゴミ箱の中身を自動で削除する機能です。Microsoft によると、ストレージ センサーは既定ではオフです。ただし、ディスクの空きが少なくなると、Windows がオンにすることがあります。オンになっていると、ゴミ箱の中身は一定の期間が過ぎたあとに自動で消えます。自分で空にした覚えがなくても、ゴミ箱が空になっていることがあるのはこのためです。
    ゴミ箱を空にしても、データそのものはすぐには消えない
    Microsoft は、「削除されたファイルで使用される領域は空き領域としてマークされます」と説明しています。パソコンからは見えなくなりますが、その場所に別のデータが書き込まれるまでは、元のデータが残っている場合があります。復元ソフトは、この残っているデータを探して取り戻します。
    新しいデータを書き込むと、上書きされて戻らなくなる
    空き領域とされた場所には、新しく保存するファイルやダウンロードしたデータが書き込まれます。Microsoft も、「ファイルを回復する可能性を高める場合は、コンピューターの使用を最小限に抑えるか、避けてください。」と書いています。また、SSD では特に、空き領域が上書きされている可能性があるとも説明しています。
    クラウドに保存していたファイルは、クラウドにもゴミ箱がある
    OneDrive と Google ドライブには、パソコンとは別のゴミ箱があります。OneDrive の個人用アカウントでは、ゴミ箱の中身は30日後に自動で削除されます。職場や学校のアカウントでは、管理者が設定を変えていなければ93日後です。Google ドライブのゴミ箱は30日です。Microsoft によると、クラウドから削除したファイルはパソコンのゴミ箱には出てこず、Web版のゴミ箱から復元します。

    原因の切り分け方

    ファイルがどこに残っていそうかによって、取り戻し方が変わります。上から順に確かめます。

    ゴミ箱の中にファイルが残っている
    右クリックして「元に戻す」を選べば、すぐ戻ります。いちばん確実な方法です。
    削除した直後で、ほかの操作をしていない
    エクスプローラーで Ctrl + Z を押すと、削除を取り消せる場合があります。ほかの操作をした後だと効きません。
    OneDrive や Google ドライブのフォルダーに保存していた
    Web版の OneDrive や Google ドライブのゴミ箱に、ファイルが残っている場合があります。削除してから30日以内（OneDrive の職場・学校アカウントは93日以内）なら、まず確かめます。
    メールで送った、共有フォルダーやUSBメモリに置いた
    そちらにコピーが残っています。少し前の版でも、コピーから取り戻すのが確実です。仕事のファイルなら、同僚や取引先に送ったことがないかも思い出します。
    ファイル履歴やバックアップを取っていた
    ファイル履歴をオンにしていたなら、フォルダーの以前の版から戻せます。外付けHDDにコピーを取っていたなら、そちらを探します。
    削除したつもりで、別のフォルダーに移動しただけだった
    エクスプローラーの検索で、ファイル名を探すと見つかることがあります。ファイルの探し方は、お悩み No.041「ダウンロードしたファイルが見つからない。保存場所の探し方と、もう迷わない整理のコツ」で説明しています。
    ゴミ箱を空にした直後で、まだ新しいデータをあまり書き込んでいない
    復元ソフトで取り戻せることがあります。Microsoft は、「Windows ファイル回復」という復元用のアプリを Microsoft Store で提供しています。
    削除してから時間がたち、新しいデータをたくさん書き込んだ
    上書きされて、戻らないことが多いです。パソコンのストレージが SSD の場合も、戻せる見込みは低くなります。

    落とし穴

    次のことを知らないと、取り戻そうとして、かえって戻せなくなることがあります。

    復元ソフトを同じドライブに入れたり、復元したファイルを同じドライブに書き戻したりすると、上書きしてしまうことがある
    ソフトを入れることも、復元したファイルを保存することも、ドライブへの書き込みです。消したファイルと同じドライブに書き込むと、まだ残っていたデータを上書きしてしまうことがあります。Microsoft も、Windows ファイル回復について「ソース ドライブと移行先ドライブは異なる必要があります。」と書いています。ドライブが1つしかない場合は、USBメモリや外付けHDDを復元先にするよう案内しています。いくつもの復元ソフトを次々に入れて試すのも、書き込みが増えるので避けます。
    「無料の復元ソフト」と名乗る広告や怪しいソフトの中には、かえって害になるものがある
    「どんなファイルでも無料で復元」とうたう広告やソフトの中には、入れたあとに広告を何度も出したり、個人情報を集めたりするものがあります。慌てているときほど、広告から入れてしまいがちです。復元ソフトを入れるときは、提供元と評判を確かめます。警告画面で有料ソフトを勧めるものについては、お悩み No.058「パソコンに『ウイルスに感染しました』という警告が出て消えない。電話してはいけない理由と消し方」で説明しています。
    Ctrl + Z は、ほかの操作をした後だと効かない
    Microsoft のショートカットの一覧では、Ctrl + Z は「直前の操作を元に戻す。」と説明されています。削除のあとに別の操作をすると、取り消されるのはその別の操作です。何度も押すと、関係のない操作まで取り消してしまうことがあります。
    ゴミ箱を空にする前に中身を確かめないと、大事なファイルまで一緒に消える
    Microsoft は、ゴミ箱を空にすると、ファイルがデバイスから完全に削除されると説明しています。Google ドライブのヘルプも、ゴミ箱を空にする前に「保管が必要なファイルがないことを確認します。」と案内しています。
    ファイル履歴で戻すと、今あるファイルが置き換わることがある
    Microsoft は、ファイル履歴で復元すると「コンピューター上に現在あるバージョンは置き換えられます。この操作を取り消すことはできません。」と説明しています。同じ名前のファイルが今もある場合は、「復元先」を選んで、別の場所に戻します。

    公式情報で確かめたこと

    次のことを、Microsoft と Google の公式ヘルプで確かめました。Windows のバージョンによって、手順や画面の名前が違うことがあります。なお、Windows と OneDrive の画面では「ごみ箱」、Google ドライブの画面では「ゴミ箱」と表示されます。この記事では、画面の名前を書くときだけ、それぞれの表示に合わせています。

    Windows のゴミ箱からの復元（Microsoft「OneDrive で削除したファイルまたはフォルダーを復元する」）
    Windows では、ごみ箱を開き、戻したいファイルやフォルダーを選んで右クリックし、「復元」を選びます。ファイルやフォルダーは、元のフォルダーに戻ります。
    削除とショートカット（Microsoft「Windows のキーボード ショートカット」）
    Ctrl + D または Delete は、「選択した項目を削除し、ごみ箱に移動する。」と説明されています。Shift + Delete は、「選択した項目を、ごみ箱に移動せずに完全に削除します。」とあります。Ctrl + Z は、「直前の操作を元に戻す。」です。
    ファイル履歴の設定と復元（Microsoft「ファイル履歴を使用したバックアップと復元」）
    対象は Windows 11 と Windows 10 です。外付けドライブかネットワークの場所をつなぎ、コントロール パネルの「システムとセキュリティ」で「ファイル履歴を使用してファイルのバックアップ コピーを保存する」を選び、「オンにする」を選びます。ドキュメント、画像、ビデオ、デスクトップなどのフォルダーが、自動でバックアップされます。戻すときは、エクスプローラーでファイルがあったフォルダーを右クリックし、「以前のバージョンの復元」を選びます。ファイルを含む以前のバージョンを選んで「復元」を選ぶか、「復元」を展開して「復元先」を選びます。
    復元用のアプリ（Microsoft「Windows ファイル回復」）
    Windows ファイル回復は、Microsoft Store から入れる、コマンドで操作するアプリです。ごみ箱から復元できないファイルを、パソコンの内部のドライブ、外付けドライブ、USBメモリから取り戻すためのものです。クラウドストレージとネットワーク上の共有フォルダーは対象外です。取り戻す元のドライブと、保存先のドライブは別にする必要があります。モードは「標準」と「広範」の2つで、迷ったら標準から始めるよう書かれています。Windows の標準的なドライブ（NTFS）で最近削除したファイルには、標準モードが勧められています。
    ストレージ センサー（Microsoft「Windows でドライブの空き領域を増やす」「ストレージ センサーでドライブ領域を管理する」）
    ストレージ センサーは、一時ファイルやごみ箱の中身などを自動で削除して、空き領域を増やす機能です。既定ではオフですが、ディスクの空きが少なくなると、Windows がオンにして通知することがあります。既定では、ごみ箱の中身は一定の時間がたつと削除されます。設定は「スタート」→「設定」→「システム」→「ストレージ」→「ストレージ センサー」で、ごみ箱のファイルを削除するタイミングを選べます。
    OneDrive のごみ箱（Microsoft「OneDrive で削除したファイルまたはフォルダーを復元する」）
    OneDrive の Web サイトにサインインし、左側の「ごみ箱」を選びます。戻したいファイルの丸いチェックボックスを選び、「復元」を選びます。個人用アカウントでは30日後、職場や学校のアカウントでは管理者が設定を変えていなければ93日後に、ごみ箱の中身が自動で削除されます。クラウドから削除したファイルは、パソコンのごみ箱には表示されません。Microsoft 365 を契約している人は、OneDrive 全体を以前の状態に戻すこともできます。
    Google ドライブのゴミ箱（Google ドライブ ヘルプ「Google ドライブで削除したファイルを復元する」「Google ドライブのファイルを削除、復元する」）
    パソコンで drive.google.com を開き、左側の「ゴミ箱」を選びます。戻したいファイルを右クリックし、「復元」を選びます。ゴミ箱のファイルは30日後に完全に削除されます。「ゴミ箱を空にする」を選んだ場合も、完全に削除されます。パソコンとドライブの間でファイルを同期している場合、ファイルをゴミ箱に入れると、すべての場所でゴミ箱に移動します。完全に削除したファイルについては、Google アカウントにログインしてヘルプを開くと、復元を頼めるようになっています。

    エクスプローラーで削除した直後に、Ctrl + Z で削除を取り消せることは、今回確かめた Microsoft の公式ヘルプには載っていませんでした。USBメモリやネットワーク上の場所から削除したファイルが、ゴミ箱に入らない場合があることも載っていませんでした。日本語版の Windows で、ゴミ箱を右クリックしたときの項目が「元に戻す」と表示されることも同じです。Microsoft のヘルプでは、この項目は「復元」と書かれています。Windows 11 で「以前のバージョンの復元」が「その他のオプションを確認」の中にあることも、公式ヘルプには載っていませんでした。この記事では、どれも一般によく知られている操作や画面の表示として書いています。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. 大事なファイルを、うっかり削除してしまう
    2. ゴミ箱に見当たらず、「もう戻せない」と思い込むか、慌てて色々なソフトを試す
    3. 新しいデータが書き込まれ、残っていたデータが上書きされる
    4. バックアップがないので作り直すしかなく、備えをしないまま使い続ける

    4のあと、また1に戻ります。

    この流れは、2と4のところで止められます。2では、パソコンをなるべく使わずに、ゴミ箱、クラウドのゴミ箱、バックアップの順に確かめます。ゴミ箱を空にした後でも、データが残っている場合があることを知っていれば、あきらめずに済みます。4では、ファイル履歴やクラウドを使い、大事なファイルを2か所以上に保存する仕組みを作ります。仕組みがあれば、次に消してしまっても取り戻せます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • すでに上書きされてしまったデータ
    • パソコンのストレージの種類（SSD か HDD か）
    • クラウドのゴミ箱の保存期間（OneDrive の個人用と Google ドライブは30日）
    • 復元ソフトで、必ず取り戻せるかどうか

    変えやすいこと

    • 削除に気づいたら、パソコンをなるべく使わないこと
    • ゴミ箱、クラウドのゴミ箱、バックアップを確かめる順番
    • メールや共有フォルダーなど、コピーが残っていそうな場所を探すこと
    • 復元ソフトを選ぶときに、提供元と評判を確かめること
    • ファイル履歴やクラウドで、バックアップを取る仕組み
    • ゴミ箱を空にする前に、中身を確かめる習慣

    次の行動プランは3段階です。今日は、上書きを防ぎながら、ゴミ箱、クラウドのゴミ箱、バックアップの順に確かめます。1週間で、バックアップの仕組みを整えます。1か月で、バックアップが本当に取れているかを確かめ、家族にも伝えます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。今日の手順は、上から順に試してください。見つかったら、そこで止めて構いません。

    手順は、2026年11月時点のMicrosoftとGoogleの公式ヘルプをもとにした、Windows 11 の例です。手順の名前や設定の場所は、Windows のバージョンで変わることがあります。分からないところは、Microsoft やクラウドサービスの公式サイト・公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分〜1時間

      • まず、パソコンをなるべく使わない

        新しいファイルの保存、大きなダウンロード、アプリのインストールを控えます。動画を見るのも、ファイルを確かめ終わるまで後にします。新しいデータを書き込むと、消したファイルのデータが上書きされることがあるからです。

        ネットで調べものをするときは、できるだけスマホを使います。

      • 削除した直後なら、Ctrl + Z を1回押す

        エクスプローラーで削除した直後で、ほかの操作をしていなければ、Ctrl + Z で削除を取り消せる場合があります。ほかの操作をした後は効きません。何度も押すと、関係のない操作まで取り消すことがあるので、押すのは1回だけにします。

      • ゴミ箱を開いて探す

        デスクトップの「ごみ箱」をダブルクリックして開きます。デスクトップに見当たらないときは、タスクバーの検索欄に「ごみ箱」と入力して開きます。

        ファイルが見つかったら、右クリックして「元に戻す」を選びます。Microsoft のヘルプでは、この項目は「復元」と書かれています。ファイルは、削除する前のフォルダーに戻ります。

        ファイル名を覚えていないときは、表示を「詳細」にして、削除した日時の列で並べ替えると探しやすくなります。

      • OneDrive や Google ドライブを使っているなら、クラウドのゴミ箱も確かめる

        • OneDrive：ブラウザで onedrive.com を開いてサインインし、左側の「ごみ箱」を選びます。戻したいファイルの丸いチェックボックスを選び、「復元」を選びます。個人用アカウントでは、削除してから30日以内のファイルが残っています。
        • Google ドライブ：ブラウザで drive.google.com を開き、左側の「ゴミ箱」を選びます。戻したいファイルを右クリックし、「復元」を選びます。削除してから30日以内のファイルが残っています。

        パソコンへの書き込みを減らしたいときは、スマホの OneDrive アプリや Google ドライブ アプリでも、ゴミ箱を確かめられます。パソコンのゴミ箱を空にした後でも、クラウドと同期していたファイルなら、クラウドのゴミ箱に残っている場合があります。

      • コピーが残っていそうな場所を探す

        次の場所に、同じファイルや少し前の版が残っていないかを確かめます。

        • メールの「送信済み」フォルダー（ファイルを添付して送ったことがある場合）
        • 職場の共有フォルダーやチャットのやり取り
        • USBメモリや外付けHDD
        • ファイルを送ったことがある同僚や取引先

        削除したつもりで、別のフォルダーに移動しただけのこともあります。エクスプローラーの右上の検索欄に、ファイル名の一部を入れて探します。Excel で作ったファイルなら、Excel の「ファイル」→「開く」の「最近使ったアイテム」に、保存していた場所が出ていることがあります。

        勤務先のパソコンや、職場の OneDrive・共有フォルダーに保存していたファイルなら、職場の管理者や情報システムの担当者が戻せる場合があります。自分で色々試す前に、相談します。

      • ファイル履歴やバックアップにコピーがないか確かめる

        エクスプローラーで、ファイルがあったフォルダー（たとえば「ドキュメント」や「デスクトップ」）を右クリックし、「以前のバージョンの復元」を選びます。見当たらないときは、「その他のオプションを確認」を選ぶと出てきます。

        一覧に以前の版が出てきたら、削除する前の日付の版を選びます。「開く」で中身を確かめてから、「復元」の横の矢印を選び、「復元先」を選んで、別のフォルダーに戻します。同じ名前のファイルがあると、今あるファイルが置き換わり、元に戻せないからです。

        一覧に何も出てこないときは、ファイル履歴がオフだった可能性があります。外付けHDDにコピーを取っていたなら、つないで中を探します。

      • どうしても見つからないときは、復元ソフトを検討する

        Microsoft は、「Windows ファイル回復」という復元用のアプリを、Microsoft Store で提供しています。キーボードでコマンドを入力して使うアプリです。復元したファイルの保存先には、USBメモリや外付けHDDなど、消したファイルがあったドライブとは別のドライブを使います。

        たとえば、Cドライブで最近消した表計算のファイル（Excel のファイル）を探し、USBメモリ（Eドライブ）に保存する場合は、次のように入力します。

        winfr C: E: /regular /n *.xlsx

        保存先のドライブには、「Recovery_」で始まるフォルダーが作られ、見つかったファイルがその中に入ります。ドライブの文字（C や E）は、パソコンによって違います。エクスプローラーの「PC」で確かめてから入力します。

        コマンドの入力に不安があるときは、無理に試さないでください。パソコンに詳しい人や、パソコンのメーカー・販売店のサポートに相談します。ほかの復元ソフトを使うときも、提供元と評判を確かめてから入れます。いくつものソフトを次々に試すのは避けます。

    2. 1週間の行動

      目安：1日15分ほどを、何日かに分けて

      • ファイル履歴をオンにする

        外付けHDDをパソコンにつなぎます。「コントロール パネル」を開き、「システムとセキュリティ」→「ファイル履歴を使用してファイルのバックアップ コピーを保存する」を選び、「オンにする」を選びます。

        ドキュメント、画像、ビデオ、デスクトップなどのフォルダーが、自動でバックアップされるようになります。バックアップの始め方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」でも説明しています。

      • 大事なファイルは、パソコンとクラウドの2か所に保存する

        仕事で使う大事なファイルは、パソコンの中だけに置かず、OneDrive や Google ドライブにも保存します。外付けHDDへのコピーと合わせると、さらに安心です。

        ただし、クラウドと同期しているフォルダーでファイルを消すと、クラウド側でも消えます。同期は、それだけではバックアップの代わりになりません。クラウドのゴミ箱は30日ほどで空になるので、外付けHDDやファイル履歴と組み合わせます。同期のしくみは、お悩み No.047「クラウドのファイルが同期されない。消えたように見えるときの確認と直し方」で説明しています。

      • ゴミ箱を空にする前に、中身を確かめる習慣をつける

        ゴミ箱を空にする前に、一度開いて、大事なファイルが入っていないかを確かめます。Shift + Delete は、ゴミ箱を通らずに消えるので、ふだんは使いません。

        「スタート」→「設定」→「システム」→「ストレージ」→「ストレージ センサー」を開き、オンになっているかを確かめます。オンなら、ゴミ箱のファイルを何日で削除するかの設定も確かめます。うっかり消すことが心配なら、短すぎない期間にしておきます。

      • 復元ソフトは、提供元と評判を確かめてから選ぶ

        困ったときに慌てて探さないよう、使うソフトを落ち着いているうちに決めておきます。まず、Microsoft の「Windows ファイル回復」を候補にします。ほかのソフトを使う場合は、提供している会社の名前と公式サイトを確かめ、広告から入れないようにします。

    3. 1か月の見直し

      目安：月に1回、15分ほど

      • バックアップが本当に取れているかを確かめる

        月に1回、大事なファイルがあるフォルダーを右クリックし、「以前のバージョンの復元」に最近の日付の版が出ているかを確かめます。

        試しに1つ、「復元先」を選んで別のフォルダーに戻し、ファイルを開いてみます。実際に戻せることを一度試しておくと、本当に困ったときに慌てずに済みます。クラウドに保存したファイルも、ブラウザで開けるかを確かめます。

      • 大事なファイルの置き場所を決める

        仕事のファイルは「ドキュメント」の中の決まったフォルダーに置くなど、置き場所を決めます。ファイル履歴やクラウドでバックアップされる場所にしておくと、守られる範囲が分かりやすくなります。デスクトップに散らかさないようにすると、間違えて消すことも減ります。整理の仕方は、お悩み No.070「パソコンのデスクトップがファイルだらけで、必要なものがすぐ見つからない。探さずに済む整理のコツ」で説明しています。

      • 家族にも、ゴミ箱の仕組みとバックアップのやり方を伝える

        消したファイルはまずゴミ箱に入ること、ゴミ箱を空にする前に中身を確かめることを伝えます。消してしまったときは、パソコンをなるべく使わずに、ゴミ箱、クラウドのゴミ箱、バックアップの順に確かめることも伝えます。家族が消してしまったときも、慌てずに確かめられるようになります。

    手順の名前や設定の場所は、Windows のバージョンで変わることがあります。分からないところは、Microsoft やクラウドサービスの公式サイト・公式ヘルプで確かめてください。
