パソコンに『ウイルスに感染しました』という警告が出て消えない。電話してはいけない理由と消し方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    ほとんどの場合は本物の感染ではなく広告を使った詐欺の画面で、電話せずにブラウザを閉じれば消える

    調べものの途中で突然出てくる「ウイルスに感染しました」という画面は、ほとんどの場合、本物の感染の知らせではありません。見ていたサイトの広告などから開かれた、ウイルス警告にそっくりな偽の画面です。表示された番号に電話をかけさせて、お金を払わせる手口です。「サポート詐欺」や「偽セキュリティ警告」と呼ばれています。この画面はブラウザの中に表示されているだけなので、電話をせずにブラウザを閉じれば消えます。

    ボトルネックは、画面の見た目と音で「本当に感染した」と思い込み、落ち着いて閉じる操作ができなくなることです。×を押しても消えない理由と、ブラウザを閉じる方法を知っていれば、その場で画面を消せます。表示された番号に電話していなければ、お金を取られることはありません。

    この記事では、Windows のパソコンで Microsoft Edge や Google Chrome を使っている場合の手順を中心に説明します。手順の名前や場所は一例で、機種やバージョンによって違うことがあります。分からないときは、使っている機種やソフトの公式ヘルプで確かめてください。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    調べものをしていたら、突然大きな音とともに赤い画面が出た
    何がきっかけで画面が出たのかが分からない。
    「ウイルスに感染しました」「今すぐこの番号に電話してください」と表示された
    表示が本物の警告なのか、偽物なのかを見分けられない。
    画面を閉じようとしても、×を押しても消えない
    画面を閉じる方法が分からない。
    音も鳴り続けて怖くなり、そのままにしている
    触ると悪くなるのではと不安で、何も操作できずにいる。
    電話をかけたほうがいいのか分からない
    電話をかけた場合に何が起きるのかが分からない。

    考えられる原因

    お悩みの状況は、ウイルス警告をまねた詐欺の画面の特徴とよく一致します。画面が出る仕組みと、消えない理由は、次のとおりです。

    見ていたサイトの広告が、ウイルス警告にそっくりな画面を開いた
    調べもので開いたサイトの広告の中には、詐欺のサイトにつながるものがあります。広告を押した覚えがなくても、ページのどこかを押したときに、別の画面が開くことがあります。開いた画面には、有名な会社の名前やロゴが使われています。本物の警告に見えるように作られているので、見た目では区別がつきにくくなっています。
    本物のセキュリティソフトの警告ではなく、ブラウザの中だけの表示
    画面は、ブラウザ（Edge や Chrome など）の中に表示された Web ページです。Web ページには、パソコンの中のファイルを調べる機能がありません。そのため、ページに書かれた「感染しました」という内容も、見つかったというウイルスの名前も、作り話です。
    ×を押しても消えないのは、ブラウザの全画面表示で開かれているため
    偽の画面は、ブラウザを全画面表示にして開くことがあります。全画面表示では、ブラウザのタブや、いちばん右上の×が見えなくなります。画面の中に見えている×や「閉じる」のボタンは、画面に描かれた絵であることが多く、押しても消えません。押すたびに同じ画面を開き直すように作られていることもあります。閉じにくくしてあるだけで、パソコン自体が乗っ取られたわけではありません。
    警告音は、ブラウザが鳴らしているだけ
    警告音や「感染しています」という音声は、Web ページが流している音のファイルです。音が鳴っていても、感染が進んでいるわけではありません。ブラウザを閉じれば止まります。
    表示されている会社名や電話番号は、本物の企業をかたった偽物
    画面には「Microsoft」「Windows」や、セキュリティソフトの会社の名前が書かれていることがあります。しかし、書かれている電話番号は、その会社の番号ではありません。電話に出るのは、詐欺をしているグループです。Microsoft は、自社のエラーや警告のメッセージに電話番号が含まれることはないと案内しています。
    電話をかけると、遠隔操作ソフトの導入や、プリペイドカードでの支払いを求められる
    電話に出た相手は、サポートの担当者を名乗ります。そして、パソコンを直すためと言って、遠隔操作ソフトを入れさせようとします。遠隔操作ソフトは、離れた場所からほかの人のパソコンを操作できるソフトです。そのあと、修理代やサポート契約の料金として、コンビニで買えるギフトカードや電子マネーの番号を伝えるよう求めてきます。遠隔操作で、パソコンの中の情報を見られたり、ネットバンキングを操作されたりするおそれもあります。

    どこが原因かを切り分ける方法

    出ている警告が本物か偽物かは、次の方法で見分けられます。具体的な閉じ方は、行動プランで説明します。

    警告がどこに出ているかを見る
    本物のセキュリティソフトの警告は、ブラウザの中ではなく、画面の右下に出る Windows の通知や、セキュリティソフト自体の画面に出ます。Windows に最初から入っている「Windows セキュリティ」も、警告は Windows の通知と「Windows セキュリティ」の画面に出します。警告がブラウザの画面の中に出ていれば、Web ページの表示です。
    電話番号が書いてあるかを見る
    警告に電話番号が書いてあり、電話をかけるよう求めていること自体が、詐欺のサインです。本物のセキュリティソフトは、ウイルスを見つけても、画面の番号に電話をかけるよう求めることはありません。
    ブラウザを閉じたら消えるかを見る
    ブラウザを閉じて画面が消えれば、ほぼ間違いなく広告から開いた偽の警告です。
    ブラウザを閉じたあとに、何か起きるかを見る
    ブラウザをもう一度開いても警告が出ず、ほかに変わったことも起きなければ、感染はしていません。念のため、1週間の行動でセキュリティソフトのスキャンを実行します。
    画面の右下に、ブラウザの名前が付いた警告の通知が出る場合
    右下の通知に、ブラウザの名前とサイトのアドレスが書かれていることがあります。これは、前に開いたサイトで通知を「許可」したために届いている、サイトからの通知です。「ウイルスが見つかりました」と書いてあっても、セキュリティソフトの警告ではありません。止める方法は、1週間の行動で説明します。

    直る見込み

    ブラウザを閉じるだけで、画面は消える
    偽の画面はブラウザの中の表示なので、ブラウザを閉じれば消えます。画面の中の×で消えなくても、キーボードやタスクマネージャーを使えば閉じられます。
    電話をかけていなければ、お金を取られることはない
    お金を取られるのは、電話をかけて、相手の言うとおりに支払った場合です。画面が出ただけで、お金を取られることはありません。
    念のためスキャンすれば、安心して使い続けられる
    セキュリティソフトでパソコン全体を調べて、何も見つからなければ、そのまま使い続けて構いません。
    手口を知っておけば、次に出ても慌てずに閉じられる
    同じような画面は、ほかのサイトを見ているときにも出ることがあります。閉じ方を知っていれば、次は落ち着いて対応できます。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 調べものの途中で、突然、警告の画面と大きな音が出る
    2. 本当に感染したと思い込み、慌てる
    3. 画面の中の×やボタンを押しても消えず、さらに不安になる
    4. 怖くて触れなくなるか、電話をかけるしかないと思ってしまう

    4のあと、画面を見るたびに、また2に戻ります。

    この循環は、2と3のところで止められます。警告がブラウザの中の表示だと分かれば、慌てる理由はなくなります。画面の中のボタンを使わずに、キーボードやタスクマネージャーでブラウザを閉じれば、画面は消えます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 見ているサイトに、どんな広告が出るか
    • 偽の画面が、本物の警告にそっくりに作られていること
    • 偽の画面が、全画面表示や音を使って閉じにくくしてあること
    • 詐欺の手口や画面の見た目が、次々に変わること

    変えやすいこと

    • 表示された電話番号に電話しないこと
    • 画面の中のボタンを押さずに、ブラウザを閉じる方法を知っておくこと
    • セキュリティソフトでスキャンして、念のため確かめること
    • サイトからの通知の許可を見直すこと
    • OS、ブラウザ、セキュリティソフトを最新にしておくこと
    • 家族や身近な人と、手口と閉じ方を話しておくこと

    次の行動プランは3段階です。今日は、電話をせずに、キーボードやタスクマネージャーでブラウザを閉じます。1週間で、セキュリティソフトのスキャンと、サイトからの通知の見直しをします。1か月後に、OS やブラウザを最新にして、家族にも閉じ方を伝えます。

    3具体的な行動プラン

    いちばん大事なのは、表示された電話番号に電話しないことです。今日の手順は、上から順に試してください。画面が消えたところで止めて構いません。

    設定やボタンの名前と場所は、機種やバージョンによって違うことがあります。この記事の手順と画面が違うときは、使っている機種やソフトの公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：5〜10分ほど。警告の画面が出たままなら、今すぐ試せます

      • 表示された電話番号には電話しない。画面のボタンも押さない

        • 画面に書かれた電話番号には、絶対に電話しないでください。
        • 「OK」「今すぐスキャン」「ダウンロード」などのボタンも押さないでください。押すと、別の詐欺の画面が開いたり、不要なソフトのダウンロードが始まったりすることがあります。
        • 画面の中に見えている×も、偽物のことがあります。画面を消すときは、次の手順のようにキーボードを使います。

      • 音が気になるときは、パソコンの音を消す

        • キーボードにスピーカーの形のマークが付いたキーがあれば、押して音を消すか、小さくします。
        • そのようなキーがなければ、画面の右下のスピーカーのアイコンを押して、音量を下げるかミュートにします。
        • 音を消しても、パソコンに悪いことは起きません。ブラウザを閉じたあとに、音量を元に戻します。

      • Esc キーを押したまま、ブラウザの×を押す

        • キーボードの左上にある Esc キーを、2〜3秒押したままにします。全画面表示が解除されて、ブラウザのタブや、いちばん右上の×が見えるようになります。
        • Esc キーを押したまま、ブラウザのいちばん右上の×を押します。画面の中に描かれた×ではなく、ブラウザの枠にある×を押します。
        • ページを離れるかどうかの確認が出たら、「離れる」など、ページを離れるほうのボタンを押します。

      • Alt＋F4 キーでブラウザを閉じる

        • Esc キーでうまくいかないときは、Alt キーを押しながら F4 キーを押します。いちばん手前に出ているウィンドウ（ブラウザ）が閉じます。
        • ノートパソコンでは、Fn キーも一緒に押さないと F4 キーが働かない機種があります。
        • ブラウザが閉じたら、それ以上は押さないでください。続けて押すと、ほかのウィンドウも閉じ、最後に「Windows のシャットダウン」の画面が出ます。この画面が出たら、「キャンセル」を押すか Esc キーを押して閉じます。

      • 閉じられないときは、タスクマネージャーでブラウザを終了する

        • Ctrl キーと Shift キーを押しながら Esc キーを押すと、タスクマネージャーが開きます。開かないときは、Ctrl＋Alt＋Delete キーを押して、出てきた画面で「タスク マネージャー」を選びます。
        • 「プロセス」の一覧から、使っているブラウザ（「Microsoft Edge」や「Google Chrome」など）を選びます。
        • 「タスクの終了」（Windows 11 では「タスクを終了する」）を押します。ブラウザのウィンドウがすべて閉じます。

      • それでもだめなら、電源ボタンを長押しして強制終了する

        • パソコンの電源ボタンを、画面が消えるまで押し続けます。多くの機種では、5〜10秒ほどで電源が切れます。
        • 保存していない作業は消えますが、強制終了したことで感染が進むことはありません。
        • 少し待ってから、もう一度電源ボタンを押して起動します。

      • ブラウザをもう一度開いて、警告が出ないかを確かめる

        • ブラウザをもう一度開きます。強制終了したあとは、前のページを復元するかどうかの案内が出ることがあります。復元すると偽の画面がまた開くので、「復元」は押さずに、案内を閉じます。
        • ブラウザを開いても警告が出なければ、それで解決しています。
        • 開くたびに同じ警告が出るときは、起動時に前回のページを開く設定になっている可能性があります。警告のタブを Ctrl＋W キーで閉じてから、起動時の設定を「新しいタブ ページを開く」に変えます。Edge は「設定」→「[スタート]、[ホーム]、および [新規] タブ」→「Microsoft Edge の起動時」、Chrome は「設定」→「起動時」で変えられます。

      • Mac を使っている場合

        • Command キーを押しながら Q キーを押すと、ブラウザを終了できます。
        • 終了できないときは、Option キーと Command キーを押しながら Esc キーを押します。「アプリケーションの強制終了」の画面が開くので、ブラウザを選んで「強制終了」を押します。

    2. 1週間の行動

      目安：設定の見直しに15分ほど。スキャンは、終わるまでに1時間以上かかることがあります

      • セキュリティソフトでフルスキャンを1回実行する

        • Windows に最初から入っている「Windows セキュリティ」を使う場合は、スタートメニューで「Windows セキュリティ」を開きます。「ウイルスと脅威の防止」→「スキャンのオプション」→「フル スキャン」を選んで、「今すぐスキャン」を押します。
        • 有料のセキュリティソフトを入れている場合は、そのソフトの画面からフルスキャンを実行します。「完全スキャン」などと書かれていることもあります。
        • スキャンにかかる時間は、パソコンの中のファイルの量で変わります。スキャンの間も、パソコンは使えます。
        • 何も見つからなければ、そのまま使い続けて構いません。何か見つかったときは、セキュリティソフトの画面の案内に従って、削除や隔離をします。

      • 見覚えのないサイトからの通知をブロックする

        • サイトに通知を許可していると、ブラウザの画面を閉じていても、右下に偽の警告の通知が届くことがあります。許可しているサイトの一覧を見直します。
        • Edge：「設定」→「Cookie とサイトのアクセス許可」→「通知」を開きます。「許可」の一覧に見覚えのないサイトがあれば、右側の「…」から「ブロック」を選びます。
        • Chrome：「設定」→「プライバシーとセキュリティ」→「サイトの設定」→「通知」を開きます。通知の送信を許可しているサイトの一覧に、見覚えのないサイトがあれば、右側の「︙」から「ブロック」を選びます。
        • これからは、知らないサイトで通知を許可するかを聞かれたら、「ブロック」を選びます。

      • 警告が出たサイトを、次から開かないようにする

        • 警告が出る直前に見ていたサイトのアドレスを、ブラウザの履歴で確かめて控えておきます。Edge と Chrome では、Ctrl＋H キーで履歴が開きます。
        • 次からは、そのサイトを開かないようにします。お気に入り（ブックマーク）に入れていれば、削除します。

      • 困ったときの相談先を知っておく

        • 消費者ホットライン「188」：支払いや契約のトラブルについて、近くの消費生活センターなどの相談窓口を案内してもらえます。
        • 警察相談専用電話「#9110」：急ぎではない、警察への相談を受け付けています。
        • IPA（情報処理推進機構）の「情報セキュリティ安心相談窓口」：偽の警告やウイルスなど、情報セキュリティの技術的な相談を受け付けています。
        • 相談先の番号は、公式のサイトで確かめます。警告の画面に書かれていた番号は使いません。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • OS、ブラウザ、セキュリティソフトを最新にしておく

        • Windows：「設定」→「Windows Update」を開き、更新があれば入れます。更新をためずに、再起動の案内が出たら早めに再起動します。
        • Edge は「設定」→「Microsoft Edge について」、Chrome は「設定」→「Chrome について」を開くと、更新の確認が始まります。
        • 有料のセキュリティソフトは、有効期限が切れていないかと、最新の状態に更新されているかを確かめます。Windows セキュリティは、Windows Update などで自動的に更新されます。

      • 怪しいサイトをブロックする機能を確かめる

        • Edge の「Microsoft Defender SmartScreen」と、Chrome の「セーフ ブラウジング」は、危険なサイトを開く前に警告を出す機能です。Edge は「設定」→「プライバシー、検索、サービス」、Chrome は「設定」→「プライバシーとセキュリティ」→「セキュリティ」で、オンになっているかを確かめます。
        • Edge のバージョンによっては、全画面の偽の警告を見つけて止める「スケアウェア ブロッカー」という機能もあります。同じ設定の画面にあれば、オンにします。
        • 有料のセキュリティソフトには、危険なサイトをブロックする機能が付いていることがあります。ソフトの設定で、オンになっているかを確かめます。
        • 広告ブロックの拡張機能を入れる場合は、Chrome ウェブストアや Microsoft Edge アドオンから入れます。広告ブロックを名乗る怪しい拡張機能もあるので、提供元と利用者数、評価を確かめてから入れます。

      • 家族や身近な人にも、閉じ方を伝えておく

        • 「警告画面が出ても電話しない。ブラウザを閉じるだけ」と、家族や身近な人に伝えておきます。
        • パソコンに慣れていない家族がいれば、Esc キーの長押し、Alt＋F4 キー、タスクマネージャーの順に閉じる方法を紙に書いて、パソコンの近くに置いておきます。

      • 同じ警告が何度も出るときは、履歴とキャッシュを削除する

        • Edge と Chrome では、Ctrl＋Shift＋Delete キーで、閲覧データを削除する画面が開きます。
        • 期間を「全期間」（Edge では「すべての期間」）にして、閲覧履歴と「キャッシュされた画像とファイル」にチェックを入れて削除します。Cookie も削除すると、多くのサイトからログアウトされます。Cookie を選ぶのは、ログインに使うパスワードを確かめてからにします。
        • それでも同じ警告が出るときは、ブラウザの拡張機能の一覧に、見覚えのないものがないかを確かめます。見覚えのないものがあれば、オフにします。
        • ここまでしても警告が出るときは、使っているセキュリティソフトのサポートに相談します。
