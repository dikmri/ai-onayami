お悩み No.035 ・ 2026年11月23日公開

パソコンのキーボードの一部のキーが反応しない。打てないときの切り分けと直し方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    キーが打てなくなる原因の多くは、接続、電池、設定、キーの下のゴミやホコリです。これらは、差し直し、電池の交換、設定の確認、掃除など、自分でできる対処で確かめられます。CapsLock で日本語がおかしくなる問題や、電池の向きの間違いは、原因が分かればその場で直せます。このため、改善できる見込みがあります。

    ただし、キーそのものの故障や、キーボードの内部の配線の問題は、自分では直せません。打てないキーが増えている場合は、故障が進んでいる可能性もあります。その場合は、メーカーの修理や買い替えを考えます。

    近道は、最初に3つのことを確かめることです。「一部のキーだけか、全体か」「外付けキーボードをつなぐと打てるか」「ほかのアプリでも同じか」です。結果によって、直す場所を絞れます。

    いきなり買い替えたり、キーボードを分解したりする前に、設定と接続の確認から進めます。ノートパソコンのキーボードの交換は、機種によっては本体の分解が必要です。自分で分解すると、ほかの部品を壊したり、メーカーの保証が受けられなくなったりするおそれがあります。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    一部のキーが急に打てなくなった
    朝まで普通に打てていたのに、昼になって「G」「H」「Backspace」が押しても出なくなった。
    掃除しても直らず、打てないキーが増えている気がする
    キーのすき間を掃除しても変わらない。ほかのキーまで打てなくなってきた気がしている。
    日本語に変な文字が混ざった
    文章を打っている途中で「お世話になってorimasu」のような文字が混ざった。よく見たら CapsLock が点いていた。
    ワイヤレスのキーボードが動かなかった
    電池を入れ替えても動かず、故障かと思ったら、電池の向きが逆だった。
    壊れたのか設定の問題か分からない
    原因が分からないため、買い替えるべきか迷っている。

    キーが打てない主な原因

    一部のキーだけが打てない場合
    キーボードの側に原因がある可能性が高いと考えられます。
    • キーそのものの接触不良。押したことをキーボードが読み取れなくなっています。
    • キーの下に入ったゴミやホコリ、食べかす。キーが最後まで沈まず、押したことにならない場合があります。
    • キーボードの内部の配線や、ノートパソコンの中のケーブルのゆるみ。キーボードの中では、いくつかのキーが同じ配線を共有しています。そのため、近くのキーがまとめて打てなくなったり、打てないキーが少しずつ増えたりすることがあります。
    全体が打てない場合
    キーボードとパソコンのつながりや、パソコンの側に原因がある可能性が高いと考えられます。
    • 接続の問題。USB の差し込みがゆるんでいる、Bluetooth の接続が切れている、といった場合です。
    • ドライバー（キーボードを動かすためのソフト）や、Windows・macOS の設定の問題。
    CapsLock がオンになっている
    CapsLock は、アルファベットを大文字で打つための機能です。誤って押してオンになると、日本語入力のソフトや設定によっては、ローマ字がひらがなに変わらず、大文字のアルファベットのまま入力されます。そのため、日本語の変換がおかしくなります。日本語配列のキーボードの多くでは、Shift キーを押しながら CapsLock キー（「英数」とも書かれたキー）を押すと、オンとオフが切り替わります。文章を急いで打っているときに、Shift と一緒に押してしまうことがあります。
    ワイヤレスキーボードの電池と受信機
    ワイヤレスキーボードでは、電池切れや、電池の向き（＋と−）の間違いがよくある原因です。USB に差す小さな受信機（USB レシーバー）を使う機種では、受信機の差し込みがゆるんでいるだけで、全体が打てなくなります。電源スイッチが切れていることもあります。
    キーボードの故障に見えて、実は設定やほかの部品の問題
    ノートパソコンでは、キーボードが壊れたように見えて、実はソフトウェアの設定や、ほかの部品の問題である場合もあります。
    • Windows の「フィルター キー」：短いキー入力や繰り返しの入力を無視する、アクセシビリティの機能です。マイクロソフトの案内では、右の Shift キーを8秒間押し続けると、オンとオフが切り替わります。オンになると、キーを押しても文字が出ないように見えることがあります。
    • Mac の「スローキー」と「マウスキー」：Apple の公式のヘルプによると、スローキーがオンだと、キーをふだんより長く押さないと入力されません。マウスキーがオンの間は、一部のキーがポインタの移動に使われるため、そのキーだけが反応しないように見えることがあります。
    • NumLock：テンキーのない一部のノートパソコンでは、文字のキーに小さく数字が書かれています。NumLock がオンになると、そのキーを押したときに数字が出るようになります。
    • Mac のノートブックで、内蔵キーボードのすべてのキーが反応しない場合：Apple の公式のヘルプによると、バッテリーの残量が少ないという警告が出ているのに、画面で見えていない可能性があります。

    3つのことを確かめると、原因を絞れる

    原因の候補が多いため、まず打てなくなり方を確かめます。結果によって、次のように見当をつけられます。

    一部のキーだけか、全体か
    一部のキーだけなら、キーの接触不良、ゴミやホコリ、内部の配線など、キーボードの側を先に疑います。全体が打てないなら、接続、電池、ドライバー、設定を先に疑います。
    外付けキーボードをつなぐと打てるか
    ノートパソコンに外付けのキーボードをつないで打てるなら、本体のキーボードの側の問題と分かります。外付けのキーボードでも同じキーが打てないなら、パソコンの設定やドライバーの側を疑います。外付けのキーボードで打てないときは、別のパソコンにつないでみる方法もあります。
    ほかのアプリでも同じか
    メモ帳（Windows）やテキストエディット（Mac）など、ほかのアプリでも打ってみます。1つのアプリだけで打てないなら、そのアプリの問題です。特定のキーが、どのアプリでも打てないなら、アプリや設定、ドライバーよりも、キーボードの側の問題の可能性が高いと考えられます。

    日本語に変な文字が混ざるのは、CapsLock や入力モードのため

    「お世話になってorimasu」のように、日本語の途中にアルファベットが混ざるときは、キーボードの故障ではない可能性が高いと考えられます。次の2つを確かめます。

    • CapsLock のランプが点いていないか。点いていたら、Shift キーを押しながら CapsLock キーを押して消します。Mac では、caps lock キーをランプが点くか消えるまで押し続けます。Apple は、誤って押したときに反応しないよう、caps lock キーは少し遅れて動くと案内しています。
    • 日本語入力がオフになっていないか。オフになると、打った文字がローマ字のまま出ます。Windows では、タスクバーの右下の表示が「A」なら、半角／全角 キーを押して「あ」に戻します。入力モードの直し方は、お悩み No.030「パソコンで日本語が変換できない。ひらがなのまま・カタカナになる・ブラウザだけおかしいときの直し方」で詳しく説明しています。

    試す順番

    次の順番で試します。上ほど手間が少なく、すぐに試せます。1つ試すたびに、打てるようになったかを確かめます。

    1. CapsLock と NumLock のランプを確かめる
    2. パソコンを再起動する
    3. ワイヤレスキーボードなら電池と受信機、USB なら差し込み口、Bluetooth なら接続を確かめる
    4. 電源を切ってから、キーのすき間のゴミを取り除く
    5. 外付けキーボードとほかのアプリで試して、どこに原因があるかを絞る
    6. フィルター キーなどの設定と、キーボードのドライバーを確かめる
    7. それでも直らなければ、メーカーのサポート窓口に相談する

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. キーが打てなくなる、または変な文字が出る
    2. 一部か全体か、外付けで打てるかを確かめないまま、思いついた方法を試す
    3. 直らないと、壊れたのか設定の問題か分からないまま、不安だけが大きくなる
    4. 次に別の症状が出たときも、同じように慌てて対処する

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。お悩みの中の CapsLock と電池の向きの件は、どちらも原因が分かればその場で直りました。キーが打てないときに、まず「一部か全体か」「外付けで打てるか」「ほかのアプリでも同じか」を確かめると、直す場所が分かります。直す場所が分かれば、買い替えが必要かどうかも判断しやすくなります。

    この記事で挙げる手順の名前や場所は一例です。パソコンの機種や、Windows・macOS のバージョンによって違うことがあります。分からないときは、マイクロソフトや Apple、パソコンやキーボードのメーカーのサポートページなど、公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • キーそのものの故障や、キーボードの内部の配線の問題
    • ノートパソコンの内蔵キーボードの交換（機種によっては分解が必要）
    • メーカーの保証期間と、保証の内容

    変えやすいこと

    • CapsLock と NumLock の状態を確かめること
    • パソコンを再起動すること
    • 電池の交換と、電池の向きの確認
    • USB の差し直しと、Bluetooth のつなぎ直し
    • 電源を切ってから、キーのすき間のゴミを取り除くこと
    • 外付けキーボードやほかのアプリで、原因を切り分けること
    • フィルター キーなどの設定と、ドライバーを確かめること
    • キーボードの近くに飲み物を置かないなどの、予防の習慣

    次の行動プランは3段階です。今日は、CapsLock の確認、再起動、電池と接続の確認、掃除、外付けキーボードでの切り分けを行います。1週間で、ドライバーと入力の設定を確かめ、打てないキーを記録します。1か月後に、悪化していないかを見直し、修理や買い替えが必要かを決めます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、打てなかったキーが打てるようになったかを確かめます。

    設定の名前や場所は、機種や Windows・macOS のバージョンによって違うことがあります。この記事の手順と画面が違うときは、マイクロソフトや Apple、パソコンやキーボードのメーカーのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：20〜30分ほど。作業中のファイルを保存してから行います

      • CapsLock と NumLock のランプを確かめる

        • キーボードやパソコン本体の CapsLock のランプが点いていないかを見ます。点いていたら、Shift キーを押しながら CapsLock キーを押して消します。Mac では、caps lock キーをランプが消えるまで押し続けます。
        • ランプがない機種では、メモ帳などで試しに打って、大文字になるかで確かめます。
        • テンキーで数字が出ない場合は、NumLock がオフになっていないかを確かめます。逆に、文字のキーを押して数字が出る場合は、NumLock がオンになっています。NumLock キーを押してオフにします。機種によっては、Fn キーと一緒に押します。
        • 日本語にローマ字が混ざる場合は、入力モードも確かめます。Windows では、タスクバーの右下の表示が「A」なら、半角／全角 キーで「あ」に戻します。

      • パソコンを一度再起動する

        • 作業中のファイルを保存してから、再起動します。一時的な不具合なら、再起動で直ることがあります。
        • Windows：キーボードが使えなくても、マウスで「スタート」→「電源」→「再起動」の順に選べます。
        • Mac：アップルメニュー →「再起動」を選びます。

      • ワイヤレスキーボードなら、電池と受信機を確かめる

        • 電池を新しいものに替えます。入れるときは、電池ボックスの＋と−の印に合わせて、向きを確かめます。
        • キーボードに電源スイッチがある機種は、スイッチが入っているかを確かめます。いったん切って、入れ直します。
        • USB に差す受信機を使う機種は、受信機を抜きます。マイクロソフトは、約10秒置いてから差し直すよう案内しています。別の USB の差し込み口に差してみる方法もあります。
        • マイクロソフトは、キーボードの裏などにリセットのボタンがあるかを確かめるよう案内しています。ボタンがある機種は、取扱説明書に沿って押します。
        • キーボードを受信機やパソコンに近づけて試します。

      • USB のキーボードなら、別の差し込み口に差し直す

        • キーボードのケーブルを抜きます。マイクロソフトは、Windows がドライバーを外すまで少し待ってから、差し直すよう案内しています。
        • 別の USB の差し込み口に差してみます。
        • USB ハブ（差し込み口を増やす機器）を使っている場合は、ハブを外し、パソコン本体の差し込み口に直接差して試します。
        • ケーブルに傷や折れがないかも見ます。

      • Bluetooth のキーボードなら、一度切断してつなぎ直す

        • キーボードの電源が入っていて、電池が残っているかを確かめます。
        • Windows：「設定」→「Bluetooth とデバイス」で、Bluetooth がオンになっているかを確かめます。キーボードの名前の横の「…」から「デバイスの削除」を選び、キーボードをペアリングできる状態にしてから、「デバイスの追加」でつなぎ直します。
        • Mac：「システム設定」→「Bluetooth」で、Bluetooth がオンになっているかを確かめます。Apple は、キーボードの Bluetooth 接続をいったん解除してから、つなぎ直すよう案内しています。
        • キーボードをペアリングできる状態にする方法は、機種によって違います。キーボードの取扱説明書で確かめてください。

      • 電源を切ってから、キーのすき間のゴミを軽く取り除く

        • 先にパソコンの電源を切ります。外付けのキーボードは、ケーブルや受信機を抜くか、電源スイッチを切ります。
        • キーのすき間を、エアダスターで軽く吹くか、柔らかいブラシで軽くはらいます。
        • 強くこすったり、水やぬれた布で拭いたりしないでください。キーを外すのも避けます。ノートパソコンのキーは、外すと元に戻せなくなることがあります。
        • エアダスターには、燃えやすいガスを使った製品があります。火の気のない場所で、缶の注意書きに従って使います。
        • Mac：Apple は、MacBook（2015 以降）や MacBook Pro（2016 以降）で反応しないキーがある場合の掃除の方法を案内しています。本体を75度に傾けて持ち、ストローの先をキーボードから1センチ強ほど離して、左から右に吹き付けます。本体を右に傾けたとき、左に傾けたときも、同じように吹き付けます。スプレー中に逆噴射しないようにします。

      • 外付けキーボードとほかのアプリで試して、原因を絞る

        • 家にほかのキーボードがあれば、つないでみます。USB のキーボードなら、差すだけで使えることが多いです。
        • 外付けのキーボードで打てるなら、本体のキーボードの側の問題と分かります。外付けのキーボードでも同じキーが打てないなら、設定やドライバーの側を疑います。
        • メモ帳（Windows）やテキストエディット（Mac）、ブラウザの検索欄など、ほかのアプリでも同じキーを打ってみます。
        • 打てないキーと、どこで試したかを、紙にメモしておきます。

      • キーを押しても出ない設定がオンになっていないかを確かめる

        • Windows：「設定」→「アクセシビリティ」→「キーボード」で、「フィルター キー」がオフになっているかを見ます。右の Shift キーを長く押したあとから打てなくなった場合は、特に確かめます。
        • Mac：「システム設定」→「アクセシビリティ」→「キーボード」で、「スローキー」がオフになっているかを見ます。「アクセシビリティ」→「ポインタコントロール」で、「マウスキー」がオフになっているかも見ます。

      • 直るまでは、画面のキーボードで一時的に入力する

        • 画面にキーボードを出して、マウスでキーをクリックすると入力できます。打てないキーがあるときの、急ぎのメールなどに使えます。
        • Windows 11：「スタート」→「設定」→「アクセシビリティ」→「キーボード」で、「スクリーン キーボード」をオンにします。マイクロソフトによると、Windows キー + Ctrl + O でも開けます。
        • Windows 10：「スタート」→「設定」→「簡単操作」→「キーボード」で、「スクリーン キーボードを使用する」をオンにします。
        • Mac：メニューバーの入力メニューから「キーボードビューアを表示」を選びます。または、「システム設定」→「アクセシビリティ」→「キーボード」で、「アクセシビリティキーボード」をオンにします。入力メニューが見当たらないときは、「システム設定」→「キーボード」→「テキスト入力」の「編集」で、「メニューバーに入力メニューを表示」をオンにします。

    2. 1週間の行動

      目安：1日5〜10分ほど。設定を1つずつ確かめ、打てないキーを記録します

      • Windows なら、キーボードのドライバーを確かめる

        • 「設定」→「Bluetooth とデバイス」→「デバイス」で、キーボードが一覧に表示されているかを確かめます。
        • 「スタート」を右クリックして、「デバイス マネージャー」を開きます。「キーボード」の項目を開いて、黄色い「!」の印が付いたものがないかを見ます。
        • キーボードの名前を右クリックして「ドライバーの更新」を選び、「ドライバーを自動的に検索」を選びます。
        • 「設定」→「Windows Update」で「更新プログラムのチェック」も行います。マイクロソフトは、ドライバーを Windows Update で更新する方法を勧めています。
        • パソコンやキーボードのメーカーの公式サイトに専用のドライバーやソフトがある機種は、そちらから入れます。メーカーの公式サイト以外から、ドライバーをダウンロードしないでください。

      • 直らなければ、キーボードのデバイスをアンインストールして、再起動で再認識させる

        • デバイス マネージャーで、キーボードの名前を右クリックして「デバイスのアンインストール」を選びます。そのあとパソコンを再起動すると、Windows がキーボードを認識し直して、ドライバーを入れ直します。
        • アンインストールすると、再起動するまで、そのキーボードが使えなくなることがあります。先に作業中のファイルを保存し、マウスで再起動できることを確かめてから行います。

      • 入力方式の設定を確かめる

        • 手元のキーボードが日本語配列なのに、設定が英語配列（英語キーボード）になっていると、記号のキーなどで、キーに書かれた文字と違う文字が出ます。
        • 「かな入力」になっていると、キーに書かれたひらがなが出ます。たとえば A のキーを押すと、「ち」が出ます。
        • Windows での確かめ方は、お悩み No.030 の「キーボードの配列が日本語配列になっているかを確かめる」で説明しています。
        • Mac：入力メニューで、使いたい入力ソース（日本語のローマ字入力など）とキーボードのレイアウトが選ばれているかを確かめます。

      • 打てないキーの一覧をメモして、増えていないかを確かめる

        • 打てないキー、気づいた日、どのアプリで試したか、外付けのキーボードで打てたかを書きます。
        • 2〜3日おきに見直して、打てないキーが増えていないかを確かめます。
        • 近くのキーがまとめて打てなくなっている場合や、強く押すと打てる場合も、書いておきます。修理の窓口に相談するときに役立ちます。

      • 掃除しても直らないキーは、メーカーのサポートページで調べる

        • パソコンの型番を確かめます。型番は、本体の裏のシールや、購入したときの箱、保証書に書かれています。
        • メーカーのサポートページで、型番と「キーボード 反応しない」などで調べます。同じ症状の情報や、メーカーの診断の方法が載っていることがあります。
        • 外付けのキーボードの場合は、キーボードのメーカーのサポートページで調べます。

    3. 1か月の見直し

      目安：1か月後に20〜30分

      • 悪化していないかを見直し、修理や買い替えを考える

        • 打てないキーのメモを見返します。
        • 打てないキーが増えている場合や、全体が打てなくなった場合は、修理や買い替えを考えます。
        • 外付けのキーボードの場合は、修理より買い替えのほうが早く、安く済むことがあります。
        • ノートパソコンの内蔵キーボードは、機種によっては本体の分解が必要です。自分で交換しようとせず、メーカーの修理窓口に相談します。

      • 保証が使えるかを確かめる

        • ノートパソコンの内蔵キーボードの修理は、保証期間内なら、メーカーの保証が使えることがあります。保証書や、メーカーのサイトの保証の確認ページで、期間を確かめます。
        • 購入したお店の延長保証に入っている場合は、お店の保証が使えるかも確かめます。
        • 窓口には、型番、いつから起きているか、打てないキー、試したこと（再起動、掃除、外付けのキーボードなど）を伝えます。1週間のメモが役に立ちます。
        • 修理に出す前に、大事なデータのバックアップを取っておきます。

      • 外付けキーボードで代用する場合は、配列と接続方式を選ぶ

        • 配列：日本で売られているパソコンの多くは日本語配列です。ふだん日本語配列を使っているなら、日本語配列のキーボードを選ぶと、記号の位置が変わらず打ちやすくなります。英語配列は、記号の位置や Enter キーの形が違います。
        • 接続方式：有線（USB）は、電池が要らず、つなぐだけで使えることが多いです。無線には、USB の受信機を使うものと Bluetooth のものがあります。無線は机の上がすっきりしますが、電池の交換や充電が必要です。
        • パソコンの差し込み口の形（USB-A、USB-C）に合うかも確かめます。
        • できれば店頭で実際に打ってみて、手に合うものを選びます。

      • 予防の習慣をつける

        • キーボードの近くに飲み物を置かないようにします。
        • キーボードの上で食べたり飲んだりするのを避けます。
        • ホコリがたまりにくい場所に置き、使わないときはカバーをかけるなどします。
        • 月に1回ほど、電源を切ってから表面のホコリをはらいます。
        • ワイヤレスキーボードの予備の電池を用意しておきます。

    まず今日、CapsLock と NumLock のランプを確かめ、パソコンを再起動します。ワイヤレスキーボードなら電池を替えて向きを確かめ、受信機を差し直します。USB なら別の差し込み口に、Bluetooth ならつなぎ直します。電源を切ってからキーのすき間のゴミを軽く取り除き、外付けのキーボードやほかのアプリで試して、原因を絞ります。急ぎの入力は、画面のキーボードで済ませます。次の1週間は、ドライバーと入力方式の設定を確かめ、打てないキーを記録します。1か月後に、悪化していないかを見直し、保証を確かめたうえで修理や買い替えを決めます。手順の名前や場所は、機種や Windows・macOS のバージョンで変わることがあります。分からないところは、マイクロソフトや Apple、パソコンやキーボードのメーカーのサポートページなど、公式のヘルプで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理やセキュリティについての専門的な助言ではありません。特定の製品やサービスを勧めるものでもありません。設定の変更は、ご自身の判断と責任で行ってください。

    キーボードやパソコンを、自分で分解しないでください。メーカーの保証が受けられなくなったり、ほかの部品を壊したりするおそれがあります。ノートパソコンのキーボードの交換は、メーカーや修理の窓口に相談してください。

    キーボードに飲み物をこぼしたときは、すぐにパソコンの電源を切り、電源ケーブルを抜いてください。乾いたように見えても、すぐに電源を入れ直さず、メーカーや修理の窓口に相談してください。

    ノートパソコンの本体がふくらんでいる、キーボードやタッチパッドが浮き上がっている、といった場合は、内部のバッテリーがふくらんでいるおそれがあります。使うのと充電をやめて、メーカーの窓口に相談してください。

    インターネットで見つかる、怪しい「ドライバー更新ツール」や、有料の遠隔サポートには、安易に手を出さないでください。不要なソフトや悪意のあるプログラムが入ったり、高額な料金を求められたりするおそれがあります。ドライバーは、Windows Update か、パソコンやキーボードのメーカーの公式サイトから入れてください。

    パスワードや確認コードは、公式サイトと公式アプリ以外には入力しないでください。メールや SMS、検索結果の広告のリンクから開いたサイトは、偽のサイトのおそれがあります。迷惑メールの見分け方は、お悩み No.007「宅配便やカード会社を名乗る迷惑メールが毎日届く。見分けて安心して使うには」も参考にしてください。

    サポートを名乗る電話やメールで、パスワードや確認コードを聞かれても、教えないでください。「ウイルスに感染しました」「今すぐ電話してください」という画面が出ても、表示された電話番号には電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。電話をかけてしまった、お金を払ってしまったという場合は、下の相談先に相談してください。

    公式のヘルプ

    • Windows でのマウス、キーボードの問題（Microsoft サポート）
    • スクリーン キーボード (OSK) を使用して入力する（Microsoft サポート）
    • Windows のデバイス マネージャーを使用してドライバーを更新する（Microsoft サポート。ドライバーの再インストールの手順も載っています）
    • アクセシビリティのための Windows のキーボード ショートカット（Microsoft サポート。フィルター キーの切り替えを含みます）
    • Windows で Bluetooth デバイスをペアリングする（Microsoft サポート）
    • Windows の Bluetooth の問題を解決する（Microsoft サポート）
    • キーを押してもMacが反応しない場合（Apple サポート）
    • MacBook や MacBook Pro のキーボードのお手入れ方法（Apple サポート）
    • Macでキーボードビューアを使用する（Apple サポート）
    • Macでアクセシビリティキーボードを使用する（Apple サポート）
    • Magic Keyboard、Magic Mouse、Magic TrackpadをMacに接続できない場合（Apple サポート）
    • 使っているパソコンやキーボードのメーカーのサポートページ（「キーボードが反応しない」「一部のキーが入力できない」などの案内）

    相談先の例
