パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    パソコンが壊れる前にコピーを取っておけば、壊れたあとでも写真や書類を取り戻せます。バックアップとは、大事なデータを2か所以上に置いておくことです。まず大切な写真と書類だけをコピーするところから始めれば、今日から不安を減らせる見込みがあります。

    コピーを取る作業で、今のパソコンのデータが消えることはありません。コピーは、元のファイルをそのまま残して、同じ内容のファイルを別の場所に作る操作です。

    お悩みの文章だけでは、どのデータがどこにあるのかまでは分かりません。「何が一番大切なデータか」「そのデータが今どこにしかないか」を確かめながら、コピーする範囲と方法を絞り込みます。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    壊れたときへの不安
    パソコンが壊れたら、中にある写真や書類のデータが全部消えてしまうのではないかと不安に感じている。
    何をどこにどうコピーするか
    バックアップをしたほうがいいとは聞くが、何をどこにどうコピーすればいいのか分からず、先延ばしにしている。
    外付けかクラウドか
    外付けのハードディスクを買えばいいのか、クラウドを使えばいいのかが分からない。
    頻度と始め方
    月に一度くらいはコピーしたほうがいいと聞いたが、どこから手をつければいいのか分からず、何もできていない。
    子どもの写真と大切な書類
    パソコンが急に動かなくなったら、子どもの写真や大切な書類がどうなるのかを心配している。

    バックアップが進まない理由の候補

    お悩みの文章から、バックアップが進まない理由として、次の候補が考えられます。理由は1つとは限らず、いくつかが重なっていることもあります。

    方法が分からない
    何を、どこへ、どうやってコピーするのかが決まっていないと、最初にする操作が分かりません。操作が分からないままだと、始めるのがおっくうになりやすくなります。
    「壊れるのはまだ先だろう」と先延ばしにしている
    パソコンが今は動いているので、急いでやる理由が見えにくくなります。ただ、パソコンは前触れなく動かなくなることもあります。そのときにコピーがなければ、データを取り戻せないことがあります。お悩みの文章からは、方法が分からないことと、この先延ばしの2つが重なっている可能性があります。
    「移す」と「コピー」の違い
    ファイルを別の場所へ移すと、元の場所からはなくなります。データが1か所にしかない状態は変わらないので、移すだけではバックアップになりません。バックアップは、大事なデータを2か所以上に置いておくことです。
    外付けかクラウドかで迷っている
    どちらか1つに決めようとすると、比べる段階で止まってしまいます。実際には、外付けハードディスクとクラウドは、どちらもバックアップに使えます。片方だけより、2か所に置くほうが安心です。

    まず確かめる2つのこと

    コピーする範囲と方法を絞り込むために、次の2つを先に確かめます。どちらもフォルダの中を見るだけなので、データは変わりません。

    何が一番大切なデータか
    「写真（ピクチャ）」「書類（ドキュメント）」「デスクトップ」の3つのフォルダを開き、中に何があるかを見ます。なくなって一番困るものから順に、コピーする候補にします。お悩みの文章からは、子どもの写真と大切な書類が候補になりそうです。
    そのデータが今どこにしかないか
    同じ写真や書類が、スマホやクラウド、USBメモリなどにも入っているかを確かめます。パソコンの中にしかないデータは、パソコンが壊れると取り戻せないことがあります。パソコンにしかないものから、先にコピーします。

    ボトルネック

    AIは、「バックアップのやり方を全部決めてから始めようとして、最初の一歩が決まらないこと」が、いちばん大きなボトルネックだと考えます。外付けハードディスクかクラウドか、どのくらいの頻度か、何をコピーするかを一度に決めようとすると、決めることが多くて手が止まります。まず大切な写真と書類だけを1か所にコピーすれば、そのデータは2か所にある状態になります。

    もう一つのボトルネックは、「壊れるのはまだ先だろう」と考えて、後回しにしやすいことです。バックアップは、パソコンが動いているうちにしか取れません。今日のうちに少しだけでもコピーしておくと、そのぶん不安が減ります。

    バックアップを始めるための3つの考え方

    1. まずは写真・書類・デスクトップの3つだけをコピーすれば十分
    2. 外付けハードディスクは、パソコンの標準機能で自動コピーできる
    3. クラウドはパソコンと別の場所に置けるので、家で何かあっても残る
    3つのフォルダから始める
    自分で撮った写真や作った書類は、多くの場合「写真（ピクチャ）」「書類（ドキュメント）」「デスクトップ」のどれかに入っています。アプリやパソコンの設定は、パソコンが壊れても入れ直せることが多いです。一方で、自分で撮った写真や作った書類は、コピーがなければ取り戻せないことがあります。最初は、この3つのフォルダだけで十分です。
    外付けハードディスクへの自動コピー
    Windows には「ファイル履歴」、Mac には「Time Machine」という機能が、もともと入っています。どちらも、外付けハードディスクへ自動でコピーする機能です。一度設定すれば、外付けハードディスクをつないでいる間、決まった間隔でコピーされます。毎回、手でコピーする必要はありません。
    クラウドは家の外に置ける
    クラウドは、インターネットの先にある保存場所です。パソコンと外付けハードディスクを同じ部屋に置いていると、火事や水濡れ、盗難のときに両方を失うことがあります。クラウドにもコピーしておけば、家で何かあってもデータが残ります。Googleドライブ、OneDrive、iCloud などには、無料で使える容量があります。容量を増やすには、有料のプランが必要になる場合があります。クラウドの多くは「同期」という仕組みで動きます。設定によっては、パソコンでファイルを消すと、クラウドからも消えることがあります。そのため、クラウドだけに頼らず、外付けハードディスクと組み合わせると安心です。
    コピーでは今のデータは消えない
    コピーは、元のファイルを残したまま、同じ内容のファイルを別の場所に作る操作です。コピーを取っても、今のパソコンの写真や書類は消えません。ただし、外付けハードディスクを Time Machine 用に設定するときに、そのハードディスクの中身を消去するよう求められることがあります。このとき消えるのは外付けハードディスクの中身で、パソコンのデータではありません。詳しくは、行動プランの「1週間の行動」に書いています。

    この3つを組み合わせると、写真や書類を、パソコン・外付けハードディスク・クラウドの3か所に置けます。まずは2か所に置くことを目指します。

    次の行動プランは、この3つの順番に沿って並べています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるものを試してください。

    画面や設定の名前は、パソコンの機種やOSのバージョンによって違うことがあります。ここでは、Windows 11 と、macOS Ventura 13 以降の画面の名前を例にしています。見つからないときは、設定画面の検索欄に「バックアップ」と入れて探すか、公式のヘルプ（Microsoft サポート、Apple サポート、各クラウドのヘルプ）で確かめてください。各ヘルプへのリンクは、注意書きにまとめています。

    1. 今日からできる小さな一歩

      目安：30分ほど。フォルダを見てコピーするだけなので、今のデータは消えません

      • 3つのフォルダの中身を確かめ、一番大切なものを決める

        • Windows では、エクスプローラーを開き、左側の「ピクチャ」「ドキュメント」「デスクトップ」を順に開きます。Mac では、Finder の「ピクチャ」「書類」「デスクトップ」を開きます。
        • なくなって一番困るものを1つ決めます。たとえば、子どもの写真や、家の契約に関する書類などです。
        • 写真や書類を、この3つ以外のフォルダに保存している場合は、その場所もメモしておきます。

      • USBメモリや外付けハードディスクがあれば、大切な写真と書類だけをコピーする

        • 家にUSBメモリや外付けハードディスクがあれば、パソコンにつなぎます。
        • 一番大切な写真や書類のフォルダを、USBメモリや外付けハードディスクのウィンドウへドラッグ＆ドロップします。パソコンから別のドライブへドラッグ＆ドロップすると、移動ではなくコピーになります。
        • コピーか移動かが心配なときは、フォルダを右クリックして「コピー」を選び、USBメモリや外付けハードディスクのウィンドウで右クリックして「貼り付け」を選びます。
        • 一度に全部をコピーしなくて構いません。今日は、一番大切なものだけで十分です。容量が足りないときは、入る分だけコピーします。

      • コピーが終わったら、元のファイルが残っていることを確かめる

        • パソコンの元のフォルダを開き、写真や書類がそのまま残っていることを確かめます。
        • USBメモリや外付けハードディスクのほうでも、写真を1枚開いて、表示されるかを確かめます。
        • 確かめたら、取り外しの操作をしてから抜きます。Windows では、エクスプローラーでドライブを右クリックし、「取り出す」を選びます。Mac では、Finder のサイドバーで、ドライブの横にある取り出しボタンを押します。

      • パソコンにもともとあるバックアップの機能を確かめる

        • Windows 11 では、「設定」→「アカウント」→「Windows バックアップ」を開きます。ここでは、「ドキュメント」「ピクチャ」「デスクトップ」などのフォルダを、OneDrive（Microsoft のクラウド）にバックアップする設定を見られます。
        • Windows には、外付けハードディスクへ自動でコピーする「ファイル履歴」もあります。コントロール パネルの「システムとセキュリティ」→「ファイル履歴」で見られます。タスクバーの検索欄に「ファイル履歴」と入れても探せます。
        • Mac では、「システム設定」→「一般」→「Time Machine」を開きます。
        • 今日は、これらの画面があることを確かめるだけで構いません。設定は「1週間の行動」で行います。

      • 大切なデータが「今どこにあるか」をメモする

        一番大切なデータについて、「パソコンにしかない」「スマホにもある」「今日USBメモリにコピーした」のどれに当てはまるかを、紙やメモに書いておきます。1週間の行動で、残りのコピー先を決めるときに使います。

    2. 1週間の行動

      目安：設定に30分〜1時間ほど。最初のコピーは、データの量によって数時間かかることもあります

      • 自動バックアップ用の外付けハードディスクを用意する

        • パソコンの容量より大きめの外付けハードディスクを用意します。Apple は、Time Machine 用には Mac のストレージの2倍以上の容量を目安にしています。
        • パソコンの容量は、Windows 11 では「設定」→「システム」→「ストレージ」、Mac では「システム設定」→「一般」→「ストレージ」で確かめられます。
        • 自動バックアップ用の外付けハードディスクは、ほかのファイルの保管には使わず、バックアップ専用にします。今日コピーに使ったUSBメモリとは分けておきます。
        • 家にある外付けハードディスクを使う場合は、中に残したいファイルが入っていないかを先に確かめます。

      • Windows：「ファイル履歴」で自動バックアップを設定する

        • 外付けハードディスクをパソコンにつなぎます。
        • コントロール パネルを開き、「システムとセキュリティ」の「ファイル履歴」を選びます。
        • 「オンにする」を選びます。使いたいドライブが選ばれていないときは、「ドライブの選択」から外付けハードディスクを選びます。
        • ファイル履歴は、「ドキュメント」「ピクチャ」「ビデオ」「デスクトップ」などのフォルダを、自動でバックアップします。
        • 詳しい手順と、ファイルを取り戻す手順は、Microsoft サポートの「ファイル履歴を使用したバックアップと復元」に載っています。

      • Mac：「Time Machine」で自動バックアップを設定する

        • 外付けハードディスクを Mac につなぎます。
        • 「システム設定」→「一般」→「Time Machine」を開き、「バックアップディスクを追加」を選びます。
        • 外付けハードディスクを選び、「ディスクを設定」を選びます。
        • 途中で、外付けハードディスクの消去を求められることがあります。消えるのは外付けハードディスクの中身で、Mac のデータは消えません。外付けハードディスクに残したいファイルがある場合は、消去する前に別の場所へコピーします。
        • 設定が終わると、外付けハードディスクをつないでいる間、自動でバックアップされます。すぐに始めたいときは、メニューバーの Time Machine のメニューから「今すぐバックアップを作成」を選びます。

      • 写真や動画を、クラウドにもコピーする

        • Googleドライブ、OneDrive、iCloud など、使い慣れたものを1つ選びます。スマホでふだん使っているサービスに合わせると、操作を覚える手間が少なくなります。
        • パソコンからは、各サービスのパソコン用アプリ（パソコン版 Google ドライブ、OneDrive、Windows 用 iCloud など）を使うか、ブラウザでサービスのページを開いて、ファイルをアップロードします。
        • Windows 11 では、「Windows バックアップ」で、「ドキュメント」「ピクチャ」「デスクトップ」などを OneDrive にバックアップできます。
        • 無料で使える容量には上限があります。写真や動画が多くて入りきらない場合は、一番大切なものから順にコピーします。容量を増やすプランの内容と料金は、各サービスの公式ページで確かめます。
        • クラウドにコピーしたら、写真を1枚開いて、表示されるかを確かめます。

      • 月に一度の「バックアップの日」を決める

        • 毎月の日付を1つ決めて、カレンダーやスマホの予定に書き込みます。たとえば、毎月1日などです。
        • その日には、外付けハードディスクをつないで、自動バックアップが動くようにします。ふだん外付けハードディスクを外している場合も、この日だけはつなぎます。
        • 同じ日に、この1か月に増えた写真や書類を、クラウドにもコピーします。

    3. 1か月の見直し

      目安：1か月後に20分ほど

      • 自動バックアップが動いているか確かめる

        • Windows では、コントロール パネルの「ファイル履歴」の画面で、最後にコピーされた日時を確かめます。
        • Mac では、メニューバーの Time Machine のメニューで、前回のバックアップの日時を確かめます。
        • 外付けハードディスクに、この1か月に増えた写真や書類が入っているかも確かめます。日時が古いままの場合は、外付けハードディスクがつながっているか、設定がオンになっているかを見直します。

      • コピーしたファイルを1つ開いて、読めるか試す

        • 外付けハードディスクやクラウドから、写真か書類を1つだけ開きます。ちゃんと表示されれば、そのコピーからデータを取り戻せることが分かります。これが「復元できるか」の確かめ方です。
        • Windows のファイル履歴では、「ファイル履歴」の画面の「個人用ファイルの復元」から、バックアップした写真や書類を見られます。Mac の Time Machine では、メニューバーの Time Machine のメニューから、過去のバックアップを開けます。
        • 確かめるときは、開いて見るだけにします。「復元」を選ぶと、今パソコンにあるファイルが、バックアップのファイルで置き換わることがあります。

      • 続けられたかを見直す

        • 月に一度のバックアップの日に、外付けハードディスクをつなげたか、クラウドにコピーできたかを確かめます。
        • 続かなかった場合は、手間の少ない方法に切り替えます。たとえば、クラウドへの自動のバックアップ（Windows バックアップやパソコン用アプリの設定）を使う方法があります。

      • 次は、スマホの写真も同じ考え方で整える

        • スマホの写真も、スマホの中にしかなければ、スマホが壊れたときに取り戻せないことがあります。
        • パソコンと同じように、「一番大切な写真はどれか」「今どこにしかないか」を確かめ、2か所に置くようにします。
        • スマホの写真を失わずに整理する方法は、お悩み No.006「写真が何千枚もたまって容量がいっぱい。大切な写真を失わずに整理するには」にまとめています。

    まず、一番大切な写真と書類を、今日のうちに1か所へコピーします。次の1週間で、外付けハードディスクへの自動バックアップと、クラウドへのコピーを整えます。1か月後に、コピーしたファイルが開けるかを確かめます。手順の名前や場所は、機種やOSのバージョンで変わることがあります。分からないところは、Microsoft サポート、Apple サポート、パソコンのメーカーや各クラウドのサポートページで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの操作やデータの管理についての専門的な助言ではありません。設定の変更は、ご自身の判断で行ってください。

    外付けハードディスクやUSBメモリの購入、クラウドの容量の追加には、費用がかかる場合があります。料金や無料で使える容量は、サービスや時期によって違います。各サービスの公式ページで確かめてください。

    設定の名前や場所は、パソコンの機種やOSのバージョンによって変わることがあります。この記事の手順と画面が違うときは、設定画面の検索欄で探すか、公式のヘルプで確かめてください。

    パソコンがすでに動かなくなっている場合や、いつもと違う音がする場合は、電源の入れ直しを何度も繰り返す前に、パソコンのメーカーのサポートに相談してください。

    会社や学校から借りているパソコンは、管理者の決まりで、外付けハードディスクやクラウドの利用が制限されていることがあります。その場合は、管理している担当者に確かめてください。
