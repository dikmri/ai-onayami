パソコンが急に重くなった。原因を調べるにはどうすればいい？

    AIの見立て

    パソコンが急に重くなる原因は、ストレージの空き不足だけとは限らず、裏で動いているアプリやブラウザのタブ、Windows Update の最中、セキュリティソフトのスキャンなどが CPU やメモリ、ディスクを食いつぶしている場合が多い。タスクマネージャーで『何が重いのか』を確かめれば、買い替えが必要なのか、ちょっとした対処で直るのかが見えてくる場合が多い

    パソコンが急に重くなる原因は、ストレージの空き不足だけとは限りません。裏で動いているアプリやブラウザのタブ、Windows Update、ウイルス対策のスキャンなどが、CPU・メモリ・ディスクを使い切っている場合が多いです。タスクマネージャーで「何が重いのか」を確かめれば、買い替えが必要なのか、ちょっとした対処で直るのかを判断できる場合が多いです。

    ボトルネックは3つです。1つ目は、CPU・メモリ・ディスクのどれが100%近くまで使われているかが分からないことです。2つ目は、裏で動いている重い処理に気づけないことです。3つ目は、重さの原因がハードウェア（部品の性能）なのか、ソフトウェア（アプリや設定）なのかが分からないことです。

    いきなり買い替えるのではなく、まずタスクマネージャーで原因を切り分けることが近道です。

    この記事は、2026年11月時点のMicrosoftとGoogleの公式ヘルプの情報をもとにしています。手順の名前や設定の場所は、Windows やブラウザのバージョンで変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    立ち上げてしばらくすると、文字を打ってもワンテンポ遅れて表示される
    起動と同時に開くアプリや、起動後に始まる更新・スキャンが、CPU やディスクを使っている可能性がある。
    ブラウザのタブを切り替えるだけで、ぐるぐる回る
    開いているタブや拡張機能が多く、メモリが足りなくなっている可能性がある。
    動画の音が途切れる、オンライン会議の途中で画面が固まる
    パソコンの処理が追いついていない場合と、ネットの回線が原因の場合がある。
    ストレージの空きはまだあるはずなのに、急に遅くなった
    重さの原因は、空き容量だけではない。裏で動いている処理が、CPU・メモリ・ディスクを使っている可能性がある。
    何がパソコンを重くしているのか分からない
    原因を確かめる道具（タスクマネージャー）の使い方を知らないため、原因の見当がつかない。
    買い替えた方がいいのか、直せるものなのかも分からない
    原因が分からないため、部品の性能の問題なのか、アプリや設定の問題なのかを判断できない。

    パソコンが重くなる仕組み

    仕組みを知ると、どこを見ればよいかが分かります。

    パソコンの速さは、CPU・メモリ・ストレージ（ディスク）の3つの働きで決まる
    CPU は、計算をする部品です。メモリは、作業中のデータを一時的に置く場所です。ストレージ（ディスク）は、ファイルやアプリを保存しておく場所です。3つのうち1つでも100%近くまで使われると、ほかの2つに余裕があっても、パソコン全体が待たされます。
    タスクマネージャーは、3つの使われ方と、使っているアプリを見せてくれる
    Microsoft は、タスク マネージャーで「CPU 負荷、メモリ使用量、ディスク アクティビティ、およびネットワーク使用量を評価できます」と説明しています。「プロセス」の画面では、動いているものが「アプリ」「バックグラウンド プロセス」「Windows プロセス」に分けて表示されます。「パフォーマンス」の画面では、CPU・メモリ・ディスクの使われ方がグラフで表示されます。
    ディスクの使用率が100%に張り付くと、文字入力や画面の切り替えまで待たされる
    アプリを開く、ファイルを読む、といった操作では、そのたびにディスクを読み書きします。メモリが足りないときは、Windows はディスクの一部をメモリの代わりにも使います。ディスクが休みなく使われていると、ほかの操作は順番待ちになります。そのため、文字を打つ、画面を切り替える、といった軽い操作まで遅れます。
    ブラウザのタブや拡張機能も、1つずつメモリを使う
    タブを1つ開くたび、拡張機能を1つ入れるたびに、使うメモリが増えます。Google は、Chrome のヘルプで「開いているタブが多いほど、Chrome の動作は遅くなります」と説明しています。Chrome と Microsoft Edge には、タブや拡張機能ごとのメモリの使用量を見られる、ブラウザ用のタスクマネージャーがあります。
    Windows Update やウイルス対策のスキャンは、裏で動いている
    Windows Update は、更新のダウンロードやインストールを裏で進めます。ウイルス対策ソフトも、裏でファイルを検査します。どちらも画面に表示されにくいため、気づかないうちにパソコンが重くなります。Microsoft の IT 管理者向けの技術文書にも、ウイルス対策のスキャンが原因でパフォーマンスの問題が起きた場合の調べ方が載っています。また、Microsoft は「マルウェアは CPU とディスク リソースを消費し、システム パフォーマンスを低下させる可能性があります」とも説明しています。

    原因の切り分け方

    タスクマネージャーで見えた様子によって、原因として考えられるものが変わります。

    ディスクの使用率が100%に近い
    裏で何かがディスクを使っているか、ストレージがほぼいっぱいになっていることが多いです。「プロセス」でディスクの列を見て、どのアプリが使っているかを確かめます。更新やスキャンの最中なら、終わると下がることがあります。Cドライブの空き容量も確かめます。Microsoft は、空き容量が足りないと、Windows の更新が遅くなったり、インストールできなかったりする場合があると説明しています。
    メモリの使用率が高い
    開いているアプリやブラウザのタブが多すぎることが多いです。使っていないアプリとタブを閉じて、使用率が下がるかを見ます。ブラウザが上位に出ている場合は、ブラウザ用のタスクマネージャーで、どのタブや拡張機能が多く使っているかを確かめます。タブの整理は、お悩み No.081「ブラウザのタブを開きすぎてパソコンが重い・目的のタブが見つからない」で詳しく説明しています。
    CPU の使用率が高い
    特定のアプリや、更新の処理が動いていることが多いです。「プロセス」で、CPU の列の上位に出る名前を確かめます。
    起動直後だけ重い
    パソコンの起動と同時に開くアプリ（スタートアップ アプリ）が、たくさん登録されている場合が多いです。タスクマネージャーの「スタートアップ アプリ」で、起動への影響が大きいアプリを確かめます。整理の仕方は、お悩み No.096「パソコンの電源を入れると勝手にアプリが開く。起動を速くするスタートアップの整理方法」で詳しく説明しています。
    いつも同じ時間帯だけ重い
    自動の更新や、ウイルス対策のスキャンの時間と重なっていることが多いです。重いときにタスクマネージャーを開き、上位に出ている名前と時刻をメモします。
    3つとも余裕があるのに、動画や会議だけ止まる
    パソコンではなく、ネットの回線が原因のことがあります。回線の切り分けは、お悩み No.089「10ギガで契約したのにネットが遅い。速度が出ないときの原因の切り分け方」で説明しています。
    本体が熱く、ファンの音が大きい
    熱がこもると、パソコンは部品を守るために動作を遅くすることがあります。冷やし方は、お悩み No.037「パソコンが熱くなる・ファンがうるさい。買い替える前にできる冷却と静音の工夫」で説明しています。

    落とし穴

    次のことを知らないと、直そうとしてかえって困ることがあります。

    見慣れない名前の処理をむやみに止めると、Windows の大事な働きまで止まることがある
    タスクマネージャーでは、動いているものを選んで「タスクの終了」で止められます。ただし、「Windows プロセス」に分類されたものの中には、Windows を動かすのに必要な処理があります。止めると、画面が正しく動かなくなったり、再起動が必要になったりすることがあります。止めるのは、自分で開いたことが分かるアプリだけにします。アプリを止めると、保存していない作業は消えます。
    「高速化ソフト」や「クリーナー」の中には、広告を出したり個人情報を集めたりするものもある
    「パソコンを速くする」とうたう無料ソフトの中には、入れたあとに広告を何度も出したり、個人情報を集めたりするものがあります。入れたソフトそのものが、裏で CPU やメモリを使うこともあります。Windows には、ストレージ センサーやディスク クリーンアップなど、空き容量を増やす機能が最初から入っています。まずはこれらを使います。「ウイルスに感染しました」などの警告で有料ソフトを勧める画面については、お悩み No.058「パソコンに『ウイルスに感染しました』という警告が出て消えない。電話してはいけない理由と消し方」で説明しています。
    空き容量を増やそうとして大事なファイルを消すと、元に戻せないことがある
    ごみ箱を空にすると、ファイルは完全に消えます。Microsoft は、以前のバージョンの Windows を削除すると元に戻せないとも説明しています。消す前に、必要なファイルかどうかを確かめます。分からないファイルは消さずに残します。大事なファイルは、先に外付けのストレージやクラウドにコピーしておきます。バックアップの始め方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」で説明しています。
    再起動をせずに何日もつけっぱなしにすると、更新がたまって急に重くなることがある
    Windows の更新の中には、再起動しないとインストールが終わらないものがあります。Microsoft も、「インストール プロセスを完了するために必要な場合は、デバイスが再起動することがあります。」と説明しています。再起動しないまま使い続けると、終わっていない更新が残ります。閉じたつもりのアプリが、裏で動き続けていることもあります。ときどき再起動すると、残った更新が終わり、裏で動いていたアプリも閉じられます。

    公式情報で確かめたこと

    次のことを、Microsoft と Google の公式ヘルプで確かめました。Windows やブラウザのバージョンによって、手順や画面の名前が違うことがあります。

    タスクマネージャーの開き方（Microsoft「Windows のキーボード ショートカット」「Windows のシステム構成ツール」）
    Ctrl + Shift + Esc で、タスク マネージャーが開きます。Windows 11 では、Ctrl + Alt + Del で出るセキュリティ画面から、タスク マネージャーを開けます。「スタート」を右クリックして「タスク マネージャー」を選ぶ方法も載っています。
    タスクマネージャーの見方（Microsoft「Windows のシステム構成ツール」「スクリーン リーダーを使用して Windows サポート ツールを移動する」）
    タスク マネージャーでは、CPU、メモリ、ディスク、ネットワークの使われ方を見られます。「プロセス」では、動いているものが「アプリ」「バックグラウンド プロセス」「Windows プロセス」に分けて表示されます。「パフォーマンス」では、CPU、メモリ、ディスクなどの使われ方がグラフで表示されます。「タスクの終了」で、応答しないプロセスを止められます。Windows 10 では、［詳細］ボタンを選ぶと、主なタブが表示されます。
    パソコンの動作を速くする方法（Microsoft「Windows で PC のパフォーマンスを向上させるためのヒント」）
    対象は Windows 11 と Windows 10 です。Windows Update、マルウェアのスキャン、ディスクの空き領域の解放、スタートアップ アプリの無効化、タスク マネージャーでの確認、アプリを閉じての再起動などが挙げられています。タスク マネージャーでは、左のメニューで「スタートアップ アプリ」を選び、アプリを右クリックして「無効にする」を選びます。再起動は、「スタート」→「電源」→「再起動」です。古いハードウェアでは、これらを試しても大きく改善しないことがあり、新しいデバイスへの切り替えが長い目で見て最善の場合がある、とも書かれています。このページでは、Microsoft の「Microsoft PC マネージャー」アプリも案内されています。
    スタートアップ アプリの止め方（Microsoft「Windows でスタートアップ アプリケーションを構成する」）
    「スタート」→「設定」→「アプリ」→「スタートアップ」で、アプリのトグルをオフにすると、自動で起動しなくなります。タスク マネージャーの「スタートアップ アプリ」タブでアプリを選び、「無効にする」を選ぶ方法もあります。各アプリの起動への影響が、小さい・中くらい・高いの段階で表示されます。影響が高いのは、CPU の合計使用時間が1秒以上か、ディスクの合計使用量が3 MB を超えるものです。
    空き容量の確かめ方と増やし方（Microsoft「Windows でドライブの空き領域を増やす」）
    エクスプローラーで左側の「この PC」を選ぶと、「デバイスとドライブ」にドライブの空き領域が表示されます。記憶域が不足すると、Windows の更新のパフォーマンスが低下したり、インストールできなかったりする場合がある、と書かれています。Windows 11 では、「スタート」→「設定」→「システム」→「ストレージ」→「クリーンアップの推奨事項」で、消せるファイルの候補が表示されます。ストレージ センサーを使うと、一時ファイルやごみ箱の中身などを Windows が自動で削除します。ファイルを削除したあと、ごみ箱を空にすると完全に削除される、とあります。
    Chrome のタスク マネージャと拡張機能（Google Chrome ヘルプ「Google Chrome の動作を速くする」）
    右上のその他アイコンから「その他のツール」→「タスク マネージャ」を選びます。「メモリ使用量」を選ぶと、メモリ使用量が多い順に並べ替えられます。「プロセスを終了」で止められますが、保存していない作業内容は失われます。拡張機能は、その他アイコンから「拡張機能」→「拡張機能を管理」を開き、無効にするか削除します。
    Microsoft Edge のブラウザー タスク マネージャーと拡張機能（Microsoft Learn「Microsoft Edgeブラウザーでの CPU 使用率またはメモリ使用率の高い問題を修正する」「リアルタイムでメモリ使用量を監視する (ブラウザー タスク マネージャー)」）
    Shift + Esc を押すか、「設定など」（…）→「その他のツール」→「ブラウザー タスク マネージャー」を選びます。CPU またはメモリで並べ替えると、負荷の高いタブや拡張機能が分かります。拡張機能は、アドレスバーに edge://extensions/ と入力して開きます。すべてオフにして様子を見て、使用量が戻ったら1つずつオンに戻すと、原因の拡張機能が分かります。サポートに相談するときは、CPU 順とメモリ順のスクリーンショットを1枚ずつ撮るよう案内されています。
    ウイルス対策のスキャンと動作の重さ（Microsoft Learn「Microsoft Defenderウイルス対策スキャンの問題のトラブルシューティング」）
    IT 管理者向けの技術文書です。スキャンが原因でデバイスのパフォーマンスに問題が出ている場合の調べ方が載っています。スキャン中の CPU 使用率を抑える設定があることも書かれています。

    Windows のタスクマネージャーで、列の見出しを選んで並べ替える操作は、今回確かめた Microsoft の公式ヘルプには載っていませんでした。「空きが全体の1割を切ったら整理する」という目安も、公式ヘルプには載っていませんでした。この記事では、どちらも一般によく使われる操作や目安として書いています。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. パソコンが重いと感じる
    2. 何が重くしているのかを確かめる方法を知らず、原因が分からない
    3. 「空きはあるのに遅いから、古くなったのだろう」と考え、対処しないまま使い続ける
    4. 裏の処理や開いたままのタブが増え、さらに重くなる

    4のあと、また1に戻ります。

    この流れは、2のところで止められます。タスクマネージャーを開けば、CPU・メモリ・ディスクのどれが100%近くまで使われているか、どのアプリが使っているかが分かります。裏で動いている重い処理にも気づけます。

    特定のアプリやタブのせいで使用率が高いなら、アプリやタブ、設定の見直しで直る見込みがあります。アプリを閉じても使用率が高いままなら、部品の性能が足りないか、故障している可能性があります。この見分けがつけば、買い替えるかどうかを判断しやすくなります。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • パソコンに載っている CPU の性能と、メモリの量
    • ストレージの種類（HDD か SSD か）と容量
    • 機種によっては、メモリの増設やストレージの交換ができないこと
    • Windows Update やウイルス対策のスキャンが行われること自体

    変えやすいこと

    • 再起動すること
    • 使っていないアプリやタブを閉じること
    • タスクマネージャーで、重さの原因を確かめること
    • スタートアップ アプリの見直し
    • 空き容量の整理
    • Windows Update を、時間のあるときに済ませること
    • ブラウザの拡張機能の見直し

    次の行動プランは3段階です。今日は、再起動とタスクマネージャーで、何が重いのかを確かめます。1週間で、スタートアップ、空き容量、Windows Update、拡張機能を見直します。1か月で、使い方を見直し、それでも重いときは相談します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は、2026年11月時点のMicrosoftとGoogleの公式ヘルプをもとにした、Windows 11 の例です。Windows 10 で違うところは、その都度書いています。手順の名前や設定の場所は、Windows のバージョンで変わることがあります。分からないところは、Microsoft やブラウザの公式サイト・公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：15〜30分

      • まず、パソコンを再起動する

        開いているファイルを保存してから、「スタート」→「電源」→「再起動」を選びます。再起動のあとで、重さが変わったかを確かめます。

        再起動の途中で、更新中であることを示す画面が出たら、電源を切らずに終わるまで待ちます。更新が終わらないときの対処は、お悩み No.020「パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？」で説明しています。

      • タスクマネージャーを開く

        Ctrl + Shift + Esc を同時に押します。

        開かないときは、Ctrl + Alt + Delete を同時に押し、出てきた画面で「タスク マネージャー」を選びます。「スタート」ボタンを右クリックして、「タスク マネージャー」を選んでも開けます。

        Windows 10 で小さな画面だけが出たときは、［詳細］を選ぶと、タブが表示されます。

      • 「プロセス」で、何がたくさん使っているかを確かめる

        「プロセス」の画面で、「CPU」「メモリ」「ディスク」の列の見出しを選ぶと、その列の順に並べ替えられます。使用率の高いものが上に来るようにして、上位のアプリの名前を確かめます。

        パソコン全体でどれくらい使われているかは、「パフォーマンス」の画面で、CPU・メモリ・ディスクのグラフを見ます。100%近くに張り付いているものがあれば、それが重さの原因の候補です。

        ブラウザが上位に出ているときは、ブラウザ用のタスクマネージャーで、どのタブや拡張機能が多く使っているかを確かめます。

        • Chrome：右上のその他アイコン（︙）から、「その他のツール」→「タスク マネージャ」を選びます。「メモリ使用量」を選ぶと、多い順に並べ替えられます。
        • Microsoft Edge：Shift + Esc を押すか、右上の「設定など」（…）から、「その他のツール」→「ブラウザー タスク マネージャー」を選びます。CPU やメモリの列で並べ替えます。

      • 使っていないタブやアプリを閉じて、軽くなるかを確かめる

        使っていないブラウザのタブと、使っていないアプリを、ふだんどおり閉じます。閉じたあとで、文字入力やタブの切り替えが軽くなったかを確かめます。

        閉じられないアプリは、タスクマネージャーの「プロセス」で右クリックし、「タスクの終了」を選びます。保存していない作業は消えます。止めるのは、自分で開いたことが分かるアプリだけにします。「Windows プロセス」に分類されたものや、名前を見ても分からないものは止めません。

      • タスクマネージャーの画面を、スマホで写真に撮っておく

        重いときのタスクマネージャーの画面を、スマホで写真に撮ります。「プロセス」を CPU 順・メモリ順・ディスク順に並べたものと、「パフォーマンス」の画面を撮っておくと、詳しい人やメーカーのサポートに相談するときに役立ちます。Microsoft も、Edge の重さをサポートに相談するときは、CPU 順とメモリ順の画面を1枚ずつ撮るよう案内しています。

        パソコンの画面を画像で保存する方法は、お悩み No.045「パソコンやスマホの画面をきれいに撮りたい。スクショと画面録画の簡単なやり方」で説明しています。

    2. 1週間の行動

      目安：1日15分ほどを、何日かに分けて

      • スタートアップ アプリを見直す

        タスクマネージャーを開き、左側の「スタートアップ アプリ」を選びます。Windows 10 では、上の「スタートアップ」タブです。パソコンの起動と同時に自動で開くアプリの一覧と、起動への影響の大きさが表示されます。

        要らないアプリを選んで、「無効にする」を選びます。「スタート」→「設定」→「アプリ」→「スタートアップ」で、アプリのスイッチをオフにしても同じです。

        何のアプリか分からないものは、無効にしません。名前をメモしておき、パソコンのメーカーのサイトなどで調べてから決めます。影響が大きいと表示されたものから見直すと、効果が出やすくなります。整理の仕方は、お悩み No.096「パソコンの電源を入れると勝手にアプリが開く。起動を速くするスタートアップの整理方法」で詳しく説明しています。

      • Cドライブの空き容量を確かめ、少ないときは整理する

        エクスプローラーを開き、左側の「この PC」を選びます。「デバイスとドライブ」に、Cドライブの空き容量が表示されます。

        空きが少ないときは、次の順に整理します。

        • 「ダウンロード」フォルダーを開き、要らないファイルを消します。Microsoft によると、ダウンロードや動画などのフォルダーには、大きなファイルがたまりやすくなります。
        • Windows 11 では、「スタート」→「設定」→「システム」→「ストレージ」→「クリーンアップの推奨事項」を開くと、消せる一時ファイルや大きなファイルの候補が表示されます。Windows 10 では、「設定」→「システム」→「ストレージ」です。
        • 「設定」→「システム」→「ストレージ」→「ストレージ センサー」をオンにすると、一時ファイルやごみ箱の中身などを Windows が自動で消します。

        消す前に、必要なファイルかどうかを確かめます。ごみ箱を空にすると、元に戻せません。空き容量の増やし方は、お悩み No.002「パソコンが遅くて容量もいっぱい、買い替える前にできること」でも説明しています。

      • Windows Update を、時間のあるときに済ませる

        「スタート」→「設定」→「Windows Update」を開き、「更新プログラムのチェック」を選びます。更新があれば、画面の案内に従ってインストールします。Windows 10 では、「設定」→「更新とセキュリティ」→「Windows Update」です。

        更新のあとに、再起動が必要なことがあります。作業を保存してから、時間に余裕のあるときに始めます。

      • ブラウザの拡張機能を見直す

        • Chrome：右上のその他アイコン（︙）から、「拡張機能」→「拡張機能を管理」を開きます。使っていない拡張機能を、無効にするか削除します。
        • Microsoft Edge：アドレスバーに edge://extensions/ と入力して開きます。重さの原因を探すときは、いったんすべてオフにして様子を見ます。軽くなったら、1つずつオンに戻すと、原因の拡張機能が分かります。

        何の拡張機能か分からないときは、削除せずにオフにしておきます。

      • ウイルスなどの検査をする

        「Windows セキュリティ」を開き、「ウイルスと脅威の防止」から「クイック スキャン」を実行します。ほかのウイルス対策ソフトを使っている場合は、そのソフトで検査します。Microsoft は、マルウェアが CPU やディスクを使い、パソコンを遅くすることがあると説明しています。

      • 重くなった日時をメモする

        重いと感じたら、日時と、タスクマネージャーで上位に出ていた名前をメモします。1週間続けると、決まった時間帯に重くなっていないか、毎回同じ名前が出ていないかが分かります。

    3. 1か月の見直し

      目安：月に1回、15分ほど

      • 重さの原因になっていた使い方を見直す

        1週間のメモで、上位によく出ていたアプリやタブの使い方を見直します。使い終わったタブやアプリを閉じる習慣をつけ、開きっぱなしにする癖を減らします。タブが多くなりがちな場合は、お悩み No.081で紹介しているタブの整理の仕方も試します。

      • 空き容量を、月に1回確かめる

        エクスプローラーの「この PC」で、Cドライブの空き容量を月に1回確かめます。空きが全体の1割を切ったら、整理の合図にします。この目安は Microsoft の公式ヘルプには載っていませんが、余裕のあるうちに整理するための区切りとして使えます。

        ストレージ センサーをオンにしておくと、一時ファイルなどを Windows が自動で消します。

      • それでもディスクが100%に張り付くなら、相談する

        ここまで試しても、ディスクの使用率が100%に張り付く状態が続くなら、部品の性能や故障が原因の可能性があります。タスクマネージャーの「パフォーマンス」で「ディスク」を選ぶと、ストレージの種類（SSD か HDD か）が分かります。「メモリ」を選ぶと、搭載しているメモリの量が分かります。

        メモリの増設やストレージの交換ができる機種かどうかは、パソコンのメーカーのサイトや取扱説明書で確かめます。自分で判断できないときは、パソコンに詳しい人や、メーカーのサポートに相談します。撮っておいたタスクマネージャーの写真を見せると、状況が伝わりやすくなります。

        Microsoft は、古いハードウェアでは、設定を見直しても大きくは改善しないことがあり、新しいデバイスへの切り替えが長い目で見て最善の場合がある、と説明しています。Windows 10 のサポートは、2025年10月14日に終了しています。Windows 10 のパソコンを使っている場合は、買い替えを考える材料の1つになります。

      • 家族にも、タスクマネージャーの見方を伝える

        Ctrl + Shift + Esc で開くことと、「プロセス」で使用率の高い順に並べることを、家族にも伝えます。名前の分からない処理は止めないことも、あわせて伝えます。重くなったときに、家族も自分で原因を確かめられるようになります。

    1か月たっても重さが続く場合は、パソコンのメーカーのサポートに相談してください。手順の名前や設定の場所は、Windows のバージョンで変わることがあります。分からないところは、Microsoft やブラウザの公式サイト・公式ヘルプで確かめてください。
