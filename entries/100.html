    つないでも映らない・同じ画面しか出ないのは、たいていケーブルの種類の取り違えか、表示モードが「複製」になっていることが原因で、2か所を確かめれば広い2画面で使えるようになる場合が多い

    モニターをつないでも映らない、または同じ画面しか出ないのは、たいていケーブルの種類の取り違えか、画面の表示モードが「複製」になっていることが原因です。ケーブルと設定の2か所を確かめれば、多くの場合は広い2画面で使えるようになります。

    ボトルネックは3つです。1つ目は、どのケーブルでつなげばいいか分からないことです。2つ目は、「複製」と「拡張」の違いが分からないことです。3つ目は、モニター側の入力切替や、解像度の設定を見落としていることです。

    モニターを新しく買わなくても、家に余っているモニターやテレビで試せる場合が多いです。

    この記事は、2026年11月時点の Microsoft の公式サポートの情報をもとにしています。手順は Windows 11 の画面を例にしています。手順や画面の名前は、Windows のバージョンや、パソコンとモニターの機種で変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    ノートパソコン1台で、表や資料を見比べるのが大変
    画面が1つしかないため、ウィンドウを何度も切り替えながら作業している。
    画面が真っ暗なまま映らない
    ケーブルの種類、端子の対応、モニター側の入力切替のどれかが合っていない可能性がある。
    映っても、ノートパソコンと同じ画面が2つ出るだけ
    表示モードが「複製」になっている可能性が高い。「複製」と「拡張」のどちらを選べばよいか分からず、そのままになっている。
    HDMI や USB-C など、どのケーブルを使えばいいか分からない
    パソコンとモニターの両方の端子の形と、その端子が映像を出せるかどうかを確かめていない。
    画面の並び順が逆で、マウスが思った方向と違うほうに動く
    Windows の表示設定でのモニターの並び順が、机の上の実際の置き方と合っていない。

    2画面で表示する仕組み

    仕組みを知ると、どこを確かめればよいかが分かります。

    表示モードは、Windows + P で切り替えられる
    Windows + P を押すと、表示モードを選ぶ画面が出ます。Windows は、Windows のロゴが書かれたキーです。選べるのは「PC 画面のみ」「複製」「拡張」「セカンド スクリーンのみ」の4つです。
    「複製」は同じ画面を2つ出し、「拡張」は2台を1つの広い画面として使う
    Microsoft の説明では、「複製」は「すべてのディスプレイに同じものを表示する」モードです。「拡張」は、複数の画面にまたがってデスクトップを表示するモードで、2つの画面の間で項目を移動できます。表や資料を見比べたいときは「拡張」を選びます。
    表示設定で、並び順とメインの画面を変えられる
    「設定」→「システム」→「ディスプレイ」に、つないでいる画面が四角い図で並びます。図をドラッグすると、並び順を変えられます。マウスは、この図の並びのとおりに画面の間を動きます。図の並びが実際の置き方と逆だと、マウスが思った方向と違うほうに動きます。
    使えるケーブルは、パソコン側とモニター側の端子の形で決まる
    映像をつなぐ端子には、HDMI、DisplayPort、USB-C、VGA などがあります。パソコンとモニターの両方に同じ端子があれば、その端子用のケーブル1本でつなげます。端子の形が違うときは、変換ケーブルや変換アダプタが必要です。VGA は古いモニターに多い、青い台形の端子です。
    USB-C で映像を出すには、パソコン、モニター、ケーブルのすべてが対応している必要がある
    USB-C は、映像を送る「DisplayPort 代替モード（DisplayPort Alt Mode）」などに対応している場合だけ、映像を出せます。Microsoft の案内では、パソコン、外部ディスプレイ、ケーブルのすべてが代替モードに対応している必要があります。対応していれば、設定を変えなくても自動で使われます。
    モニター側の入力切替が合っていないと、「信号なし」のままになる
    モニターには、HDMI1、HDMI2、DisplayPort のように、入力の端子が複数あることがあります。モニターは、選ばれている入力の映像だけを表示します。ケーブルを HDMI1 に挿していても、モニターが HDMI2 を選んでいると、「信号なし」と出て映りません。テレビでも同じです。
    映らないときは、ケーブル、モニター、パソコンの順に確かめる
    まずケーブルを抜き差しします。次に、モニターの電源と入力切替を確かめます。それでも映らなければ、パソコンを再起動します。Microsoft の案内では、このほかに、別のケーブルや別の端子を試すことと、ドックや変換アダプタを外して直接つなぐことが挙げられています。

    原因の切り分け方

    画面の様子によって、原因として考えられるものが変わります。

    モニターが真っ暗で「信号なし」と出る
    ケーブルの種類が合っていないか、モニターの入力切替が合っていないことが原因のことが多いです。USB-C でつないでいる場合は、パソコンの端子かケーブルが映像に対応していないこともあります。
    同じ画面が2つ出るだけ
    表示モードが「複製」になっていることが原因のことが多いです。Windows + P で「拡張」に切り替えます。
    画面は出るが、マウスが逆の方向に動く
    表示設定でのモニターの並び順が、実際の置き方と逆になっていることが原因のことが多いです。
    画面がぼやける、文字が小さすぎる
    解像度の設定が、モニターに合っていないことが原因のことが多いです。Microsoft の案内では、「（推奨）」と書かれた解像度を選ぶのが通常は最適です。文字の大きさは「スケール」で変えられます。
    ノートパソコンを閉じると、画面が消える
    電源の設定で、「カバーを閉じたとき」の動作が「スリープ」になっていることが原因のことが多いです。
    モニターをつないだら、音が出なくなった
    音の出力先が、モニターやテレビに切り替わっていることがあります。スピーカーのないモニターに切り替わると、どこからも音が出ません。

    落とし穴

    次のことを知らないと、何度つなぎ直しても映らなかったり、作業中に困ったりします。

    USB-C のケーブルには、充電だけのものと映像も送れるものがある
    見た目が同じでも、映像に対応していないケーブルでは、いくらつないでも映りません。パソコンの USB-C 端子にも、映像を出せないものがあります。パソコンの取扱説明書やメーカーの仕様表で、映像出力に対応しているかを確かめます。
    VGA ケーブルでは、音声が伝わらない
    VGA は映像だけを送るケーブルです。モニターにスピーカーがあっても、VGA でつないだだけでは音は出ません。音はパソコンのスピーカーから出すか、別の音声ケーブルでつなぎます。
    テレビで代用するときは、入力切替と解像度を確かめる
    テレビのリモコンで、つないだ HDMI 端子（HDMI1 など）に入力を切り替えます。パソコン側では、解像度が「（推奨）」になっているかを確かめます。テレビは机から離れた場所にあることが多いので、文字が読みにくければスケールを大きくします。
    画面を広げたまま、ウィンドウを見失う
    閉じたつもりのウィンドウが、もう一方の画面に残っていることがあります。モニターの電源を切っていると、ウィンドウがそちらにあることに気づきません。見つからないときは、Windows + Shift + 方向キーで、ウィンドウを手元の画面に移します。
    安い変換アダプタやドックで、うまく映らない
    Microsoft の案内では、ドック、ドングル、アダプターなどがつながっていると、競合が起きることがあります。変換アダプタの中には、相性が合わないものもあります。新しく買う前に、まず手持ちのケーブルで直接つなげる組み合わせがないかを確かめます。
    分配器（スプリッター）では、画面を広げられない
    Microsoft の案内では、スプリッターは同じ信号を複製するだけなので、画面の拡張には使えません。2つの画面に別々の内容を出すには、パソコンの映像の端子につなぎます。

    公式情報で確かめたこと

    次のことを、Microsoft の公式サポートと、モニターのメーカーのよくある質問で確かめました。Windows のバージョンや機種によって、手順や画面の名前が違うことがあります。

    表示モードの切り替え（Microsoft サポート「Windows で複数のモニターを使用する方法」）
    Windows + P を押して、「PC 画面のみ」「複製」「拡張」「セカンド スクリーンのみ」から選びます。「拡張」は、複数の画面にデスクトップを表示し、2つの画面の間で項目を移動できるモードです。
    並び順の変更と画面の確かめ方（同じページ）
    「スタート」→「設定」→「システム」→「ディスプレイ」で、画面の図を動かしたい位置へドラッグし、「適用」を選びます。そのあと、マウス ポインターを画面の間で動かして確かめます。どの番号がどの画面かは、「識別」を選ぶと、それぞれの画面に番号が表示されます。つないだ画面が表示されないときは、「複数のディスプレイ」を開いて「検出」を選びます。Windows 11 では、「複数のディスプレイ」に「モニターの接続に基づいてウィンドウの場所を記憶する」「モニターが切断されているときにウィンドウを最小化する」のチェックがあります。
    メインの画面の項目名（Microsoft サポート「複数モニターでプレゼンテーションを行う (および、発表者のノートを個別に表示する)」）
    PowerPoint の発表者ツールの説明の中に、画面を選んで「メインディスプレイにする」を選ぶ手順があります。この手順は Windows 8 向けとして書かれています。Windows 11 での場所は、「Windows で複数のモニターを使用する方法」のページには載っていませんでした。
    映らないときの確かめ方（Microsoft サポート「Windows での外部モニター接続のトラブルシューティング」）
    まず Windows を最新にします。Windows + P で「拡張」が選ばれているかを確かめます。ドック、ドングル、アダプターなどのアクセサリをすべて外し、ケーブルがしっかり挿さっているかを確かめます。別のケーブルや、別の映像の端子（HDMI、VGA、DVI、DisplayPort）も試します。Windows + Ctrl + Shift + B で、グラフィック ドライバーをリセットできる場合があります。「スタート」→「電源」→「再起動」で、パソコンを再起動します。2台目以降のモニターを足すときは、まず1台で映ることを確かめます。スプリッターは同じ信号を複製するだけなので、画面の拡張には使えません。
    USB-C での映像出力（Microsoft サポート「Windows の USB-C の問題を修正する」）
    パソコン、外部ディスプレイ、ケーブルのすべてが、DisplayPort または MHL の代替モードに対応している必要があります。DisplayPort 代替モードのアダプターは、パソコンの、DisplayPort 代替モードに対応した USB-C 端子につなぐ必要があります。外部のハブやドックを通していると、つながりにくいことがあります。代替モードは、設定を変えなくても自動で使われます。
    解像度とスケール（Microsoft サポート「Windows で画面の解像度とレイアウトを変更する」）
    「スタート」→「設定」→「システム」→「ディスプレイ」で、変えたい画面を選びます。「ディスプレイの解像度」のリストから選び、通常は「（推奨）」と書かれたものが最適です。文字やアプリの大きさは、「スケールとレイアウト」の「スケール」で変えます。
    スナップ（Microsoft サポート「ウィンドウのスナップ」）
    ウィンドウを画面の端にドラッグすると、スナップ レイアウトが表示され、使いたい配置に置けます。キーボードでは、Windows + 方向キーでウィンドウを画面の左右や上下に寄せられます。スナップは、「設定」→「システム」→「マルチタスク」の「スナップ ウィンドウ」でオンとオフを切り替えます。
    ウィンドウを別の画面へ移すキー（Microsoft サポート「Windows のキーボード ショートカット」）
    Windows 11 では、Windows + Shift + 左方向キーで、作業中のウィンドウを左側のモニターに移動します。右方向キーなら、右側のモニターに移動します。
    ふたを閉じたときの動作（Microsoft サポート「PC をシャットダウン、スリープ、休止状態にする」）
    Windows 11 では、タスク バーの検索で「コントロール パネル」を開き、「システムとセキュリティ」を選びます。「電源オプション」の「電源ボタンの動作の選択」→「現在利用可能ではない設定を変更します」と進みます。「バッテリ駆動時」と「電源に接続」の列ごとに、「カバーを閉じたとき」の動作を選び、「変更の保存」を選びます。
    音の出力先（Microsoft サポート「Windows のサウンドまたはオーディオの問題を修正する」）
    「スタート」→「設定」→「システム」→「サウンド」と進み、「出力」で再生に使うデバイスを選びます。選んだデバイスは、既定のデバイスにもなります。Windows 11 では、タスク バーのスピーカーのアイコンを選び、音量のスライダーの右の矢印からも選べます。
    モニターの入力切替（JAPANNEXT のよくある質問「「信号なし」になって画面が表示されません（入力切替の方法）。」）
    モニターのメーカーの案内の例です。「信号なし」と出たときは、モニターの入力切替のボタンで入力切替のメニューを出し、入力が「自動（AUTO）」になっているかを確かめます。ボタンの名前や操作は機種によって違うため、取扱説明書で確かめます。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. どのケーブルでつなげばいいか分からないまま、手持ちのケーブルでつなぐ
    2. 映らない、または同じ画面しか出ない
    3. ケーブルと設定のどちらが原因か分からず、そのままにする
    4. ノートパソコン1台で作業を続け、見比べる大変さが続く

    4のあと、しばらくしてまた1からつなぎ直し、同じところで止まります。

    この流れは、2と3のところで止められます。真っ暗で映らないなら「ケーブルと入力切替」、同じ画面が出るなら「表示モード」というように、画面の様子で確かめる場所が決まります。確かめる場所が分かれば、1つずつ試して直せます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • パソコンとモニターに付いている端子の種類
    • パソコンの USB-C 端子が映像を出せるかどうか
    • モニターが表示できる解像度
    • Windows のバージョンによる、設定の名前や場所の違い

    変えやすいこと

    • どのケーブルで、どの端子どうしをつなぐか
    • モニター側の入力切替
    • 表示モード（「複製」か「拡張」か）
    • モニターの並び順と、メインにする画面
    • 解像度とスケール
    • 画面ごとの使い方
    • モニターとノートパソコンの置き方と高さ
    • ふたを閉じたときの動作

    次の行動プランは3段階です。今日は、端子を確かめてつなぎ、入力切替と表示モードを合わせます。1週間で、並び順とメインの画面を整え、画面ごとの使い方を決めます。1か月後には、設定が今も合っているかを見直し、置き方を整えます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は、2026年11月時点の Microsoft の公式サポートをもとにした、Windows 11 の例です。Windows 10 では、一部の項目の名前や場所が違います。Microsoft の案内では、Windows 10 のサポートは2025年10月14日に終了しています。手順の名前や設定の場所は、Windows のバージョンやモニターのメーカーで変わることがあります。分からないところは、Microsoft やモニターのメーカーの公式サイト・公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：20〜30分

      • パソコンとモニターの端子の形を確かめて、手持ちのケーブルでつなぐ

        ノートパソコンの側面と、モニターの裏側の端子を見比べます。

        • 両方に HDMI があれば、HDMI ケーブルでつなぎます。いちばん分かりやすい組み合わせです。
        • パソコンに USB-C しかないときは、その端子が映像を出せるかを、パソコンの取扱説明書やメーカーの仕様表で確かめます。モニターにも USB-C があれば、映像に対応した USB-C ケーブルでつなげます。モニターが HDMI だけなら、USB-C から HDMI への変換ケーブルや変換アダプタが必要です。
        • モニターが VGA（青い台形の端子）だけのときは、パソコンに VGA がなければ変換アダプタが必要です。VGA では音は出ません。

        ケーブルは、パソコン側とモニター側の両方を奥までしっかり挿します。

      • モニターの入力切替を、つないだ端子に合わせる

        モニターのボタン（「INPUT」「入力切替」などの名前が多いです）で、つないだ端子（HDMI1 など）を選びます。入力の選択に「自動（AUTO）」がある機種なら、それを選んでも構いません。ボタンの場所や操作は機種によって違うため、分からないときはモニターの取扱説明書を見ます。テレビで代用するときは、テレビのリモコンの「入力切換」で、つないだ HDMI 端子を選びます。

      • Windows + P を押して、「拡張」を選ぶ

        Windows は、Windows のロゴが書かれたキーです。表示モードを選ぶ画面が出たら、「拡張」を選びます。同じ画面しか出ないときは、ここが「複製」になっていることが多いです。

      • 映らないときは、次の順に確かめる

        1. ケーブルを、パソコン側とモニター側の両方で抜き差しします。
        2. モニターの電源を入れ直し、入力切替がつないだ端子になっているかをもう一度確かめます。
        3. パソコンを再起動します（「スタート」→「電源」→「再起動」）。
        4. 「設定」→「システム」→「ディスプレイ」で「複数のディスプレイ」を開き、「検出」を選びます。

        それでも映らないときは、別のケーブルや、パソコンの別の端子を試します。変換アダプタやドックを使っているなら、外して直接つなげないかを試します。Windows + Ctrl + Shift + B を同時に押すと、グラフィック ドライバーをリセットできる場合があります。

    2. 1週間の行動

      目安：1日10分を数日

      • モニターの並び順を、実際の置き方に合わせる

        「設定」→「システム」→「ディスプレイ」を開きます。「識別」を選ぶと、それぞれの画面に番号が表示されます。図の番号と机の上の画面を見比べて、図の四角を実際の置き方と同じ並びにドラッグします。「適用」を選んだら、マウスを画面の間で動かして、思った方向に動くかを確かめます。

        図の四角は、上下の位置も動かせます。モニターがノートパソコンより高い位置にあるときは、モニターの四角も少し上にずらします。マウスが画面の間を移るときに、実際の位置に近い高さで移るようになります。

      • よく使う画面を、メインの画面にする

        「設定」→「システム」→「ディスプレイ」の図で、メインにしたい画面を選びます。「メイン ディスプレイにする」という項目にチェックを入れます。Microsoft のヘルプでは「メインディスプレイにする」という名前で書かれています。項目の名前や場所は、Windows のバージョンで違うことがあります。見つからないときは、「複数のディスプレイ」を開いて探すか、パソコンのメーカーのヘルプで確かめます。

      • 画面ごとの使い方を決める

        たとえば、表はモニター、資料はノートパソコンの画面に置く、と決めます。毎回同じ画面に同じものを置くと、どこに何があるかを探す手間が減ります。

      • スナップで、ウィンドウを半分ずつに並べる

        • ウィンドウを画面の左右の端にドラッグすると、画面の半分にそろえて置けます。画面の端に近づけるとスナップ レイアウトが表示されるので、使いたい配置に置きます。
        • キーボードでは、Windows + 左方向キーで画面の左半分、Windows + 右方向キーで右半分に寄せます。
        • うまく並ばないときは、「設定」→「システム」→「マルチタスク」の「スナップ ウィンドウ」がオンになっているかを確かめます。

      • ウィンドウを、キーで別の画面に移す

        Windows + Shift + 左方向キーで、作業中のウィンドウを左側の画面に移します。右方向キーなら、右側の画面に移します。マウスで長くドラッグしなくても、すぐに移せます。

      • 音が出ないときは、出力先を確かめる

        「設定」→「システム」→「サウンド」の「出力」で、音を出したいスピーカーを選びます。モニターやテレビの名前が選ばれていたら、音はそちらから出ます。タスク バーのスピーカーのアイコンを選び、音量のスライダーの右の矢印から選ぶこともできます。

    3. 1か月の見直し

      目安：15分ほど

      • 並び順と解像度が、今も合っているかを確かめる

        マウスを画面の間で動かして、思った方向に動くかを見ます。「設定」→「システム」→「ディスプレイ」で、それぞれの画面の「ディスプレイの解像度」が「（推奨）」になっているかを確かめます。文字が小さすぎるときは、「スケール」で大きくします。

      • ケーブルを抜いたときに、画面が元に戻るかを確かめる

        モニターのケーブルを抜いて、ウィンドウがノートパソコンの画面に戻るかを確かめます。外したモニターにウィンドウが残っていないかも見ます。Windows 11 では、「設定」→「システム」→「ディスプレイ」の「複数のディスプレイ」で、モニターを外したときにウィンドウを最小化するか、つなぎ直したときに元の場所に戻すかを選べます。ウィンドウが見つからないときは、Windows + P で「PC 画面のみ」を選ぶと、ノートパソコンの画面だけの表示になります。

      • ふたを閉じたまま使いたいときは、「カバーを閉じたとき」の動作を確かめる

        タスク バーの検索で「コントロール パネル」を開き、「システムとセキュリティ」→「電源オプション」の「電源ボタンの動作の選択」と進みます。「現在利用可能ではない設定を変更します」を選び、「カバーを閉じたとき」の動作を確かめます。ここが「スリープ」だと、ふたを閉じるとパソコンが止まり、モニターも消えます。

        モニターだけで使いたい場合は、「電源に接続」の列だけ、スリープ以外の動作を選ぶ方法があります。「バッテリ駆動時」はスリープのままにしておくと、ふたを閉じてカバンに入れたときに動き続けずに済みます。最後に「変更の保存」を選びます。

      • もっと広く使いたくなったら、まず置き方と高さを整える

        モニターを買い足す前に、今の2つの画面の置き方を見直します。ノートパソコンを台や本の上に置いて、2つの画面の高さをそろえます。よく見る画面を正面に置きます。それでも足りないときに、買い足しを考えます。

        買い足すときは、パソコンが何台の画面に対応しているかを、パソコンのメーカーの仕様表で確かめます。Microsoft の案内では、映像の端子が1つしかない場合は、ドッキング ステーションや USB アダプターが必要になります。分配器（スプリッター）では、画面を広げられません。

    1か月たったら、2画面で作業が楽になったところと、まだ使いにくいところを分けます。使いにくいところは、並び順、メインの画面、置き方のどれかを1つずつ変えて試します。手順の名前や設定の場所は、Windows のバージョンやモニターのメーカーで変わることがあります。分からないところは、Microsoft やモニターのメーカーの公式サイト・公式ヘルプで確かめてください。
