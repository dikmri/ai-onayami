お悩み No.140 ・ 2026年11月28日公開

パソコンのショートカットキーが覚えられず、コピー＆ペーストをいつもマウスでやっている

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    ショートカットキーは、一度に全部覚えようとすると挫折するが、よく使う3つだけに絞れば1週間ほどで指が覚えるもので、解決・軽減できる。ボトルネックは一覧表の数が多すぎて何から覚えればいいか分からないこと、指が覚える前にマウスに戻ってしまうこと、閉じたタブの復元やクリップボードの履歴など便利な操作を知らないこと

    ショートカットキーは、一度に全部覚えようとすると、どれも身につかずに終わりがちです。よく使う3つだけに絞れば、1週間ほどで指が自然に動くようになる人が多いでしょう。このお悩みは、解決・軽減できると考えます。

    ボトルネックは3つです。1つ目は、一覧表の数が多すぎて、何から覚えればいいか分からないことです。2つ目は、指が覚える前に、慣れたマウスに戻ってしまうことです。3つ目は、コピー＆ペースト以外の便利な操作を知らないことです。たとえば、閉じたタブを開き直す操作や、クリップボードの履歴です。

    ただし、キーボードの配置や手の大きさ、使っているアプリによって、合う覚え方は違います。一覧表の順番ではなく、自分が毎日使う3つから始めることが大切です。

    お悩みの中には、ショートカットキーとは別の方法で減らせる手間もあります。同じ文章の打ち直しは、日本語入力（IME）の「ユーザー辞書」で減らせます。Excel のパスワードの打ち直しは、パスワード管理アプリで減らせます。

    この記事は、2026年11月時点の Microsoft・Google・Apple の公式情報と、Windows 11 の画面の表示をもとにしています。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    コピーと貼り付けを、いつも右クリックのメニューで選んでいる
    右クリックのメニューでも、コピーと貼り付けはできます。ただ、マウスを動かしてメニューを選ぶ分だけ、1回ごとに時間がかかります。1日に何十回もくり返すと、その差が積み重なります。
    Ctrl + C と Ctrl + V を知っているのに、指が動かない
    知っていることと、手が自然に動くことは別です。キーの組み合わせは、くり返し押すうちに考えなくても押せるようになります。最初の数日は、マウスより遅く感じても、キーで押す回数を増やすことが近道です。
    Excel のファイルを開くたびに、パスワードを手で打ち直している
    これは、ショートカットキーの問題とは別です。パスワードを安全な場所に保存しておき、コピー＆ペーストで入力すれば、打ち直す手間と打ち間違いを減らせます。
    同じ文章を何度も打ち直している
    住所やあいさつ文など、決まった文章を何度も打っている場合は、IME の「ユーザー辞書」に登録できます。短い読みを入力して変換するだけで、長い文章が出るようになります。
    一覧表のショートカットが多すぎて、どれから覚えればいいか分からない
    Microsoft の一覧には、文字の編集、ウィンドウの操作、エクスプローラーなど、場面ごとに多くのショートカットが並んでいます。全部を覚える必要はありません。自分が毎日する操作に使うものだけで足ります。
    ブラウザのタブを間違えて閉じ、ページを探し直した
    閉じた直後なら、Ctrl + Shift + T で開き直せます。Microsoft Edge でも Google Chrome でも使えるキーです。このキーを1つ知っておくだけで、探し直す手間が無くなります。

    ショートカットキーの仕組み

    お悩みに関係する操作を、順に説明します。キーの名前と働きは、Microsoft・Google・Apple の公式の説明に合わせています。

    Ctrl + C は「コピー」、Ctrl + V は「貼り付け」
    Ctrl + C は、選んだ文字や項目をコピーして、クリップボードにしまう操作です。クリップボードは、コピーしたものを一時的に置いておく場所です。Ctrl + V は、クリップボードから取り出して、今いる場所に貼り付ける操作です。キーは、Ctrl キーを押したまま、C や V を押します。
    コピーしても元は消えない。Ctrl + X の「切り取り」だけが元を消す
    コピーした文字は、元の場所にもそのまま残ります。Ctrl + X の「切り取り」は、元の場所から消して、クリップボードにしまう操作です。文章を別の場所へ移したいときに使います。
    Ctrl + Z は「元に戻す」、Ctrl + Y は「やり直し」
    Ctrl + Z は、直前の操作を元に戻します。間違えて消したり貼り付けたりしても、すぐ押せば戻せます。Ctrl + Y は、Ctrl + Z で戻した操作をやり直します。Microsoft は、一部のショートカットの動作はアプリによって違う場合があると説明しています。
    ブラウザでは、Ctrl + W で今のタブが閉じ、Ctrl + Shift + T で開き直せる
    Microsoft Edge と Google Chrome では、Ctrl + W が「現在のタブを閉じる」キーです。Ctrl + Shift + T を押すと、最後に閉じたタブがもう一度開きます。Chrome のヘルプには、「閉じたタブを閉じた順序で再び開く」と書かれています。
    Windows + V で「クリップボードの履歴」が開く
    ふつうのクリップボードには、最後にコピーした1つだけが入ります。クリップボードの履歴をオンにすると、過去にコピーしたものが一覧になり、選んで貼り付けられます。Microsoft によると、履歴は最初はオフになっています。オンにすると、コピーした25項目までが残ります。パソコンを再起動すると、ピン留めした項目を除いて消えます。
    Alt + Tab で、開いているウィンドウを切り替える
    Alt キーを押したまま Tab キーを押すと、開いているウィンドウが並びます。Alt キーを押したまま Tab キーを何回か押して選び、指を離すと切り替わります。Excel とブラウザを行き来しながらコピー＆ペーストするときに便利です。
    Windows キーと組み合わせるショートカットもある
    Windows キーは、キーボードの左下にある Windows のマークのキーです。Windows + D でデスクトップの表示と非表示が切り替わり、Windows + E でエクスプローラーが開きます。
    Mac では、Ctrl の代わりに command キーを使う
    Mac では、コピーは command + C、貼り付けは command + V、元に戻すは command + Z です。やり直しは、shift + command + Z です。Chrome や Edge で閉じたタブを開き直すときは、command + shift + T を押します。

    原因の切り分け方

    困っている場面ごとに、何を覚えればよいか、何を使えばよいかをまとめます。

    コピー＆ペーストだけが遅い
    まず、Ctrl + C（コピー）、Ctrl + V（貼り付け）、Ctrl + Z（元に戻す）の3つだけを練習します。この3つが自然に押せるようになるまで、ほかのキーは足しません。
    同じ文章を何度も打ち直している
    コピー＆ペーストの問題ではありません。IME の「ユーザー辞書」に単語や文章を登録すると、短い読みで変換できるようになります。すぐに始めたいときは、よく使う文章をメモ帳に1つにまとめておき、そこからコピーして使う方法もあります。
    Excel のファイルのパスワードを毎回打ち直している
    パスワード管理アプリにパスワードを保存し、開くときにコピー＆ペーストで入力する方法があります。ただし、会社のパソコンでは、パスワード管理アプリの利用が制限されている場合があります。会社のルールを先に確かめてください。
    ブラウザのタブを間違えて閉じてしまう
    閉じた直後なら、Ctrl + Shift + T で開き直せます。Chrome では、続けて押すと、その前に閉じたタブも順に開きます。タブが多すぎて目的のページを見失う場合は、お悩み No.081「ブラウザのタブを開きすぎてパソコンが重い・目的のタブが見つからない」も参考にしてください。
    キーの位置が分かりにくく、手元を見ないと押せない
    よく使う3つのキー（Ctrl・C・V など）に、小さなシールを貼るなどして目印をつける方法があります。目印があると、手元を何度も見なくても指を置けるようになります。
    Ctrl キーを押しても、ショートカットが効かない
    アプリによっては、同じキーでも働きが違うことがあります。メモ帳でも効かない場合は、キーボードの故障や設定が原因かもしれません。確かめ方は、お悩み No.035「パソコンのキーボードの一部のキーが反応しない。打てないときの切り分けと直し方」で説明しています。

    落とし穴

    速く使えるようにしようとして、かえって困ったことにならないように、気をつけたい点があります。

    一度に何十個も覚えようとする
    一覧表を上から順に覚えようとすると、どれも身につかずに続かなくなりがちです。まず3つに絞り、指が自然に動くようになってから、次の3〜4個を足します。
    見知らぬショートカットキー集のソフトや、有料の「効率化ツール」を入れる
    インターネットの広告に、「パソコンが速くなります」「作業が効率化します」といったソフトが出てくることがあります。こうしたソフトを入れると、広告が増えたり、課金を求められたりすることがあります。この記事で紹介する操作は、どれも Windows に最初からある機能だけでできます。
    Ctrl + W を押し間違えて、作業中の画面が消える
    Ctrl + W は、ブラウザでは今のタブを閉じるキーです。Excel では、ブックを閉じるキーです。同じ左手で押す Ctrl + S（保存）や Ctrl + Z（元に戻す）と押し間違えると、画面が消えて慌てることがあります。多くのキーボードでは、W は S のすぐ上にあります。ブラウザのタブなら、慌てずに Ctrl + Shift + T で開き直します。
    Mac の command + Q は、アプリごと終了する
    Mac では、command + Q が「現在のアプリを終了」するキーです。Q は W のすぐ左にあるため、タブを閉じるつもりでアプリごと閉じてしまうことがあります。Windows の Chrome や Edge では、Ctrl + Q はアプリを終了するキーではありません。Windows で作業中のウィンドウを閉じるキーは Alt + F4 です。Chrome と Edge では、Ctrl + Shift + W でも今のウィンドウが閉じます。
    パスワードをメモ帳や付箋にそのまま書いて貼る
    パソコンに貼った付箋や、デスクトップのメモ帳にパスワードを書いておくと、他人に見られる心配があります。パスワードは、パスワード管理アプリに保存します。会社のパソコンで使えない場合の扱い方は、下の行動プランで説明します。
    コピーしたパスワードが、クリップボードの履歴に残る
    クリップボードの履歴をオンにしていると、コピーしたパスワードも一覧に残ります。Windows + V を押せば、ほかの人にも見えてしまいます。パスワードを貼り付けたあとは、履歴からその項目を削除します。パスワードの項目は、ピン留めしないでください。
    Ctrl + S がアプリによって違う働きをする
    Excel では、Ctrl + S でブックを保存します。Microsoft Edge では、同じキーで見ているページがファイルとして保存されます。ブラウザで押して、保存の画面が出たら「キャンセル」を選びます。

    公式情報で確かめたこと

    次のことを、Microsoft・Google・Apple の公式情報と、Windows 11 の画面の表示で確かめました。Windows やアプリのバージョンによって、手順や画面の名前が違う場合があります。

    Windows の基本のショートカット（Microsoft サポート「Windows のキーボード ショートカット」）
    Windows 11 と Windows 10 が対象の記事です。Ctrl + C は「選択した文字列をコピーします」、Ctrl + V は「クリップボードから最後の項目を貼り付けます」と書かれています。Ctrl + X は「選択した文字列を切り取ります」、Ctrl + Z は「直前の操作を元に戻す」です。Ctrl + Y は、Ctrl + Z で元に戻した操作をやり直します。Ctrl + A は、すべてのテキストやアイテムを選択します。Alt + Tab は、開いているウィンドウを切り替えるキーです。Windows + D はデスクトップの表示と非表示、Windows + E はエクスプローラーを開くキーです。一部のショートカットの動作は、アプリによって違う場合があるとも書かれています。
    クリップボードの履歴（Microsoft サポート「Windows のキーボード ショートカット」「クリップボードの使用」）
    Windows + V でクリップボードが開きます。クリップボードの履歴は、既定では有効になっていません。初めて使うときは、Windows + V を押して「有効にする」を選びます。「スタート」→「設定」→「システム」→「クリップボード」で、「クリップボードの履歴」をオンにする方法もあります。Windows 10 では、この設定でオンにしてから使うと書かれています。履歴は、コピーした25項目までです。PC を再起動するたびに、ピン留めした項目を除いて消えます。項目を1つだけ消すときは、項目の横の「詳細（…）」から「削除」を選びます。全部を消すときは、上にある「すべてクリア」を選びます。
    ブラウザのタブの操作（Microsoft サポート「Microsoft Edge のキーボード ショートカット」）
    Windows の Edge では、Ctrl + Shift + T が「最後に閉じたタブをもう一度開いて、そのタブに切り替える」キーです。Ctrl + W は「現在のタブを閉じる」、Ctrl + Shift + W は「現在のウィンドウを閉じる」キーです。Ctrl + S は「現在のページを保存する」と書かれています。Mac の Edge では、Ctrl の代わりにコマンド キーを使います。
    ブラウザのタブの操作（Google Chrome ヘルプ「Chrome のキーボード ショートカット」）
    Windows の Chrome では、Ctrl + Shift + T が「閉じたタブを閉じた順序で再び開く」キーです。Ctrl + W または Ctrl + F4 で、現在のタブを閉じます。Chrome を終了する操作は、Alt + F の後に X と書かれています。Mac の Chrome では、⌘+q で Chrome を終了し、⌘+w で現在のタブを閉じます。
    Mac のショートカット（Apple サポート「Mac のキーボードショートカット」）
    command + X は切り取り、command + C はコピー、command + V はペーストです。command + Z で直前のコマンドを取り消し、shift + command + Z でやり直せます。command + Q は「現在のアプリを終了」、command + W は「最前面のウインドウを閉じる」キーです。
    Excel の保存と閉じる（Microsoft サポート「Excel のキーボード ショートカット」）
    よく使うショートカットの表に、Ctrl + S で「ブックを保存します」、Ctrl + W で「ブックを閉じます」と書かれています。
    Excel のファイルのパスワード（Microsoft サポート「Excel ファイルを保護する」）
    「ファイル」→「情報」→「ブックの保護」→「パスワードで暗号化」で、ファイルにパスワードを設定できます。パスワードを忘れてしまった場合、Microsoft はそれを回復できないと書かれています。パスワードの大文字と小文字は区別されます。
    ユーザー辞書への単語の追加（Microsoft サポート「Microsoft 日本語 IME」「東アジア言語用の高度な入力方式」）
    タスクバーの IME のアイコンを右クリックして、単語の追加の項目を選ぶと、辞書に新しい単語を追加できると書かれています。ヘルプでは、この項目は「Wordの追加」と書かれています。登録した単語は、「ユーザー辞書ツール」で編集できます。IME の設定の「ラーニングと辞書」から、ユーザー辞書ツールを開く方法も書かれています。
    Windows 11 の画面の表示
    IME のアイコンを右クリックしたときのメニューの項目は「単語の追加」です。以前のバージョンの IME では、「単語の登録」と表示されます。開く画面には「単語」「よみ」「品詞」の欄があり、品詞の選択肢に「短縮よみ」があります。IME の設定の画面では、「学習と辞書」の中に「ユーザー辞書ツールを開く」が表示されます。クリップボードの設定の画面には、「クリップボードの履歴」と「デバイス間のクリップボード履歴」があります。後者の説明には、オンにすると Microsoft がクリップボードのデータを受け取って、デバイス間で同期すると書かれています。

    3つに絞って覚えると続きやすい点と、1週間ほどで慣れる人が多いという点は、一般的な説明です。キーにシールを貼る方法、メモ帳に定型文をまとめる方法、見知らぬ効率化ソフトの危険も、一般的な説明です。パスワードの保管については、会社のルールがあればそれに従ってください。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. ショートカットを覚えようとして、一覧表を見る
    2. 数が多すぎて、どれから覚えるか決められない
    3. いくつか試すが、指が覚える前に慣れたマウスに戻る
    4. マウスのままなので作業に時間がかかり、また覚えようと思う

    4のあと、また一覧表を見て1に戻ります。

    この流れは、2のところで止められます。覚えるキーを、毎日使う3つに先に決めてしまえば、一覧表を見る必要はありません。3つだけなら、マウスに戻りそうになっても思い出せます。慣れたら少しずつ足していきます。

    もう一つのボトルネックは、キーで速くする以外の方法を知らないことです。同じ文章の打ち直しや、パスワードの打ち直しは、ユーザー辞書やパスワード管理アプリで手間そのものを減らせます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • キーボードの配置や、キーの大きさ
    • アプリによって、同じキーの働きが違うこと
    • 会社のパソコンで、使えるアプリやソフトが決められていること
    • Excel のファイルにパスワードがかかっていること
    • 画面の名前や手順が、Windows のバージョンで違うこと

    変えやすいこと

    • 最初に覚えるキーを3つに絞る
    • 右クリックの代わりに、キーで押す回数を増やす
    • 閉じたタブを Ctrl + Shift + T で開き直す
    • クリップボードの履歴をオンにする
    • よく打つ文章を、メモ帳やユーザー辞書にまとめる
    • パスワードを安全な場所に保存して、コピー＆ペーストで入力する
    • よく使うキーの一覧を紙にして、パソコンのそばに置く

    次の行動プランは3段階です。今日は、3つのキーを練習し、閉じたタブの開き直し方を試し、よく使う文章をメモ帳にまとめます。1週間で、覚えるキーを4つ足し、クリップボードの履歴をオンにし、パスワードの保管場所を決めます。1か月で、自分用の一覧を作り、ユーザー辞書に単語を登録し、使うキーだけを残します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。できそうなものを1つ選ぶところから始めてください。

    手順は、2026年11月時点の Microsoft・Google・Apple の公式情報と、Windows 11 の画面の表示をもとにしています。手順の名前や画面の表示は、Windows のバージョンによって変わることがあります。分からないところは、Microsoft の公式サポートページで確かめてください。Mac を使っている場合は、Ctrl を command キーに読み替えてください。

    1. 今日からできる小さな一歩

      目安：15分ほど

      • 覚えるのは3つだけと決める

        今日覚えるのは、次の3つだけです。ほかのキーは、まだ覚えなくて構いません。

        • Ctrl + C：コピー
        • Ctrl + V：貼り付け
        • Ctrl + Z：元に戻す

        3つとも、左手の小指で Ctrl キーを押したまま、人差し指や中指で文字のキーを押します。押しやすい指の置き方は人によって違うので、自分が楽に押せる形で構いません。

      • メモ帳で、コピーと貼り付けを5回くり返す

        1. 「スタート」を押して「メモ帳」と入力し、メモ帳を開きます。
        2. 好きな文章を1行打ちます。
        3. 文字の上をマウスでドラッグして選び、Ctrl + C を押します。
        4. 別の行をクリックして、Ctrl + V を押します。同じ文章が貼り付けられれば成功です。
        5. この一連の動きを、5回くり返します。

        最後に Ctrl + Z を押して、貼り付けた文章が消えることを確かめます。間違えても Ctrl + Z で戻せると分かれば、安心してキーを使えます。練習が終わったら、メモ帳は保存せずに閉じて構いません。

        仕事中も、今日からは右クリックのメニューの代わりに、この3つのキーを使います。マウスに戻りそうになったら、思い出したときだけで構いません。

      • 閉じたタブを開き直す方法を試しておく

        1. ブラウザで、新しいタブを開いて適当なページを表示します。
        2. そのタブの「×」を押して閉じます。
        3. Ctrl + Shift + T を押します。閉じたタブが開き直せば成功です。

        Microsoft Edge でも Google Chrome でも、同じキーで開き直せます。間違えてタブを閉じたときは、すぐにこのキーを押します。

      • よく使う文章を、メモ帳に1つにまとめる

        住所や、定型のあいさつ文など、何度も打っている文章をメモ帳に書き出します。「名前を付けて保存」で、デスクトップに保存します。ファイル名は「よく使う文章」など、分かりやすい名前にします。

        使うときは、このファイルを開いて、使いたい文章を選んで Ctrl + C を押します。使う場所で Ctrl + V を押せば、打ち直さずに済みます。

        このファイルには、パスワードは書かないでください。デスクトップのファイルは、パソコンをのぞいた人にも見えてしまいます。

    2. 1週間の行動

      目安：毎日5分の練習を7日間

      • 3つが自然に押せるようになったら、4つ足す

        Ctrl + C・Ctrl + V・Ctrl + Z を、考えなくても押せるようになったら、次の4つを足します。

        • Ctrl + X：切り取り（文章を別の場所へ移すとき）
        • Ctrl + A：全部選ぶ
        • Ctrl + S：保存（Word や Excel などで使う）
        • Alt + Tab：ウィンドウの切り替え

        まだ3つに慣れていなければ、足すのは来週でも構いません。Ctrl + S は、ブラウザで押すとページを保存する画面が出ます。出たときは「キャンセル」を選びます。

      • クリップボードの履歴をオンにする

        1. Windows + V を押します。
        2. クリップボードの画面が開きます。Microsoft のヘルプによると、初めてのときは「有効にする」を選びます。
        3. 何回かコピーしてから、もう一度 Windows + V を押します。コピーしたものが一覧に並べば成功です。
        4. 貼り付けたい項目を選ぶと、その場所に貼り付けられます。

        画面の表示が違ってオンにできないときは、「スタート」→「設定」→「システム」→「クリップボード」を開き、「クリップボードの履歴」をオンにします。Windows 10 も同じ場所です。

        履歴は、パソコンを再起動するとピン留めした項目以外が消えます。毎日使う文章の項目は、ピン留めしておくと消えません。パスワードは、ピン留めしないでください。

      • Excel のファイルのパスワードの保管場所を決める

        まず、会社のルールで、パスワード管理アプリを使ってよいかを確かめます。使ってよいアプリがあれば、そこに Excel のファイルのパスワードを保存します。ファイルを開くときは、アプリからパスワードをコピーし、パスワードを入れる欄で Ctrl + V を押します。

        パスワード管理アプリの選び方と使い方は、お悩み No.004「パスワードが覚えられない、使い回しも不安。安全にラクに管理するには」で説明しています。

        会社のパソコンで使えない場合は、パスワードを紙の手帳に控え、机の引き出しなど人目につかない場所にしまいます。付箋に書いてパソコンに貼ったり、デスクトップのメモ帳に書いたりはしないでください。会社にパスワードの保管のルールがあれば、そちらに従います。

        Microsoft は、Excel のファイルのパスワードを忘れると回復できないと説明しています。どこに保管したかは、必ず分かるようにしておきます。

      • コピーしたパスワードは、履歴から消す

        クリップボードの履歴をオンにしていると、コピーしたパスワードも一覧に残ります。パスワードを貼り付けたら、Windows + V で履歴を開きます。その項目の横の「…」を選び、「削除」を選びます。

        パスワードをコピーするパソコンでは、「デバイス間のクリップボード履歴」はオフのままにしておくと安心です。オンにすると、コピーした内容がほかのデバイスと同期されます。

      • キーボードの Ctrl キーに目印をつける

        キーの位置が分かりにくいときは、Ctrl キーに小さなシールを貼るなどして目印をつけます。見なくても指が届くようになったら、はがして構いません。会社の備品のキーボードなら、シールを貼ってよいか先に確かめます。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • 自分がよく使うショートカットを10個ほどに絞り、紙に一覧にする

        1か月の間に実際に使ったキーを、10個ほど書き出します。紙に一覧にして、パソコンのそばに貼ります。たとえば次のような一覧です。

        • Ctrl + C：コピー
        • Ctrl + V：貼り付け
        • Ctrl + X：切り取り
        • Ctrl + Z：元に戻す
        • Ctrl + Y：やり直し
        • Ctrl + A：全部選ぶ
        • Ctrl + S：保存
        • Alt + Tab：ウィンドウの切り替え
        • Ctrl + Shift + T：閉じたタブを開き直す
        • Windows + V：クリップボードの履歴

        一覧は、自分が使うものだけで作ります。人の一覧をそのまま使うより、自分の作業に合ったものになります。

      • よく打つ単語や定型文を、IME のユーザー辞書に登録する

        1. タスクバーの右側にある、IME のアイコン（「あ」や「A」の表示）を右クリックします。
        2. 「単語の追加」を選びます。以前のバージョンの IME では「単語の登録」と表示されます。Microsoft のヘルプでは「Wordの追加」と書かれています。
        3. 開いた画面の「単語」の欄に、登録したい文章を入れます。たとえば、自分の住所です。
        4. 「よみ」の欄に、短い読みをひらがなで入れます。たとえば「じゅうしょ」です。
        5. 「品詞」は「短縮よみ」を選び、「登録」を押します。

        登録したら、メモ帳で「じゅうしょ」と打って変換し、住所が候補に出るかを確かめます。登録した単語を直したり消したりするときは、同じメニューの「ユーザー辞書ツール」を使います。

        日本語の変換そのものがうまくいかないときは、お悩み No.030「パソコンで日本語が変換できない。ひらがなのまま・カタカナになる・ブラウザだけおかしいときの直し方」も参考にしてください。

      • Windows キーとの組み合わせを、1つずつ足す

        慣れてきたら、Windows キーとの組み合わせも1つずつ足します。Windows + D でデスクトップを表示し、もう一度押すと元の画面に戻ります。Windows + E でエクスプローラーが開きます。足すのは、1週間に1つくらいで構いません。

      • 使わないショートカットは、一覧から外す

        一覧に書いたのに、1か月使わなかったキーは、無理に覚えなくて構いません。一覧から外して、毎日使うものだけを残します。

      • 分からないところは、公式サポートで確かめる

        手順の名前や画面の表示は、Windows のバージョンによって違います。分からないところは、Microsoft の公式サポートページで確かめます。Microsoft の「Windows のキーボード ショートカット」のページには、ほかのキーも場面ごとに載っています。

    1か月たったら、右クリックのメニューを使う回数が減ったかを振り返ります。減っていれば、紙の一覧から次の1つを選んで足します。減っていなければ、もう一度3つに戻って練習します。続けられたものだけを残して、次の1か月の計画を立て直します。
