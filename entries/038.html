お悩み No.038 ・ 2026年11月23日公開

パソコンの画面がちらつく・ビリビリする。グラフィックの故障か、設定で直るか見分ける方法

    AIの見立て

    改善できる見込みあり

    画面のちらつきの原因には、ケーブルや接続のゆるみ・劣化、グラフィックスドライバーの不具合、モニター側の設定、電源まわりの問題などがあります。これらの多くは、ケーブルの差し直しや交換、設定の見直し、ドライバーの更新といった、自分でできる対処で確かめられます。このため、ちらつきを改善できる見込みがあります。

    ボトルネックは、「いつ・どんなときに起きるか」が分からないまま、故障か、設定か、買い替えかを考えていることです。ちらつきは出たり消えたりするため、起きる場面を切り分けないと、原因を絞れません。

    「ちらつく＝すぐ壊れる」わけではありません。ただし、画面が真っ暗になる、焦げ臭いにおいがする、電源が落ちる、といった症状が重なるときは、使い続けると危険な場合があります。その場合は、自分で直そうとせず、メーカーや販売店に相談してください。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    画面がちらつく・波打つように乱れる
    ときどき画面がチラチラしたり、ビリビリと波打つように乱れたりする。ひどいときは文字が読めず、資料作りが止まってしまう。
    2台のモニターが一瞬暗くなり、USBの機器も切れる
    外付けのモニターを2台つなぐと、15秒に1回くらいの間隔で画面が一瞬暗くなる。そのたびに、USBの機器も切れることがある。
    放っておくと直ることがある
    しばらく使わずにいたら直っていたこともあり、原因が分からない。
    目が疲れ、頭が痛くなる
    目が疲れやすく、画面を見ていると頭が痛くなる日もある。
    修理か買い替えかが分からない
    グラフィックの部品の故障か、設定やケーブルの問題か、買い替えのサインかが分からず、修理に出すべきか迷っている。

    画面がちらつく主な原因

    画面のちらつきには、大きく分けて次の原因が考えられます。1つだけでなく、いくつかが重なっていることもあります。

    ケーブルや接続のゆるみ・劣化
    HDMI や DisplayPort のケーブルが端子から少し浮いている、ケーブルが折れ曲がって中で傷んでいる、端子にホコリがたまっている、といった場合です。机の上の物を動かしたときにケーブルが引っ張られて、接触が悪くなることもあります。また、高い解像度やリフレッシュレートで使っていると、ケーブルがその設定に対応していないために、画面が一瞬消えることがあります。
    グラフィックスドライバーの不具合
    グラフィックスドライバーは、パソコンが画面に映像を出すためのソフトウェアです。ドライバーが古い場合や、更新した直後に相性の問題が出た場合に、ちらついたり、画面が固まったりすることがあります。Microsoft は、Windows の画面のちらつきの多くは、ディスプレイドライバーの問題か、互換性のないアプリが原因だと案内しています。
    モニター側の設定が合っていない
    リフレッシュレートは、画面を1秒間に描き直す回数です。たとえば 60Hz のモニターは、1秒間に60回描き直します。リフレッシュレートや解像度が、モニターやケーブルに合っていないと、ちらつきや乱れの原因になることがあります。
    電源まわりの問題
    モニターやパソコンの電源ケーブルのゆるみ、電源タップの不具合、ドッキングステーションや USB ハブの電気が足りないこと、などです。ノートパソコンでは、電源アダプターをつないでいるときだけ、または外したときだけ症状が出ることもあります。
    グラフィックの部品やモニターの故障
    上の原因をすべて確かめても直らない場合は、パソコンのグラフィックの部品や、モニター本体の故障の可能性があります。部品が熱くなりすぎると、症状が出たり消えたりすることもあります。

    お悩みにある「しばらく放っておいたら直っていた」という状態は、接触の悪いケーブル、部品の熱、ドライバーの一時的な不具合のいずれでも起こりえます。このため、直ったときの状況も含めて記録しておくと、原因を絞りやすくなります。熱の対策は、お悩み No.037「パソコンが熱くなる・ファンがうるさい。買い替える前にできる冷却と静音の工夫」で説明しています。

    2台つないだときだけ症状が出る場合

    1台だけのときは平気で、2台つないだときにちらつく、暗くなる、という場合は、2台目の接続や、グラフィックの負荷が関係している可能性が高いと考えられます。たとえば、次のような場合です。

    • 2台目のモニターのケーブルや、端子の変換アダプターの接触が悪い。
    • 2台分の映像を出すことで、グラフィックの部品にかかる負荷が増えている。
    • パソコンの映像の出力が、2台のモニターに対応していない。Microsoft は、映像の出力端子が1つだけのパソコンは、基本的に外付けのモニターを1台しか使えないと案内しています。また、1つの映像を2つに分ける「スプリッター」では、2台に別々の画面を出せません。

    お悩みのように、画面が暗くなるのと同時に USB の機器も切れる場合は、映像と USB が同じ経路を通っている可能性があります。たとえば、ドッキングステーションや USB-C のハブを使っている場合、またはモニターに付いている USB 端子に機器をつないでいる場合です。この経路のどこか（ケーブル、ドック、ハブ、その電源）で接続がいったん切れて、つなぎ直しを繰り返している可能性があります。Microsoft も、ドック、ドングル、アダプターなどがつながっていると、競合が起きることがあると案内しています。

    「いつ・どんなときに起きるか」で原因を絞る

    原因の候補が多いため、まずちらつく場面を切り分けます。結果によって、次のように見当をつけられます。確かめ方は、行動プランで説明します。

    タスクマネージャーも一緒にちらつくか
    Microsoft の案内では、タスクマネージャーも画面のほかの部分と一緒にちらつく場合は、ディスプレイドライバーが原因の可能性が高いとされています。タスクマネージャーはちらつかず、ほかの部分だけがちらつく場合は、互換性のないアプリが原因の可能性があります。
    特定のアプリを使っているときだけか
    特定のアプリや、動画の再生のときだけ起きるなら、そのアプリやドライバーとの相性の可能性があります。
    2台目のモニターだけか、1台にしても起きるか
    片方のモニターだけで起きるなら、そのモニター、ケーブル、端子の可能性が高いと考えられます。1台に減らすと起きなくなるなら、2台目の接続やドック、グラフィックの負荷の可能性があります。
    明るさを下げたときだけか
    明るさを下げたときに目が疲れやすい、ちらつきを感じるなら、下で説明する「PWM調光」が関係している可能性があります。
    別のパソコンにつないでも起きるか
    モニターを別のパソコンにつないでも同じ症状が出るなら、モニター側の問題の可能性が高いと考えられます。出なければ、パソコン側の問題の可能性が高くなります。

    グラフィックスドライバーをその場でリセットするキー

    Windows には、グラフィックスドライバーをその場でリセットするショートカットがあります。Windows + Ctrl + Shift + B を同時に押す方法です。Microsoft は、画面のちらつきのトラブルシューティングの最初の手順として、このキーを案内しています。うまくいくと、画面が一瞬暗くなって戻るか、ビープ音が鳴ります。

    このキーで直るなら、ドライバーが原因の手がかりになります。ただし、機種や状況によっては効かない場合もあります。効かない場合は、パソコンを再起動します。

    目の疲れと「PWM調光」

    多くのモニターやノートパソコンの画面は、明るさを下げるときに、光を目に見えないほど速く点けたり消したりして、暗く見せています。この仕組みを「PWM調光」と呼びます。点滅は速すぎてふつうは見えませんが、明るさを下げるほど、消えている時間が長くなります。この点滅は、目の疲れや頭痛の原因の一つとして知られています。感じ方には個人差があります。

    明るさを少し上げる、夜間モードやブルーライト軽減の設定を使う、20分に1回は画面から目を離す、といった工夫で、目の疲れを軽くできる場合があります。モニターによっては、点滅を抑えた「フリッカーフリー」の方式を使っているものもあります。

    ただし、頭痛や目の痛みが続く場合は、無理をしないでください。画面の設定だけで解決しようとせず、眼科などの医療機関で確かめてもらいます。

    すぐに使うのをやめて相談する症状

    次の症状がある場合は、ちらつきの対策を試す前に、使うのをやめます。電源を切り、充電器や電源ケーブルを外して、メーカーや販売店に相談してください。

    • 焦げ臭いにおいがする、煙が出る。
    • 画面が真っ暗になり、そのまま戻らないことがある。
    • 使っている途中で、突然電源が落ちる。
    • モニターやパソコンの本体が、触れないほど熱い。

    くわしい対応は、注意書きにまとめています。

    試す順番

    次の順番で試します。上ほど手間が少なく、お金もかかりません。1つ試すたびに、ちらつきが変わったかを確かめます。

    1. ちらついたら、Windows + Ctrl + Shift + B を押し、直らなければ再起動する
    2. ケーブルを抜いて差し直し、別のケーブルや別の端子に替えてみる
    3. モニターを1台だけにして、どちらでちらつくかを確かめる
    4. リフレッシュレートと解像度、明るさの設定を確かめる
    5. グラフィックスドライバーを更新する（更新の直後から起きているなら、元に戻す）
    6. モニターの設定メニューと、モニターやドックのファームウェアを確かめる
    7. モニターを別のパソコンにつないで、どちらの問題かを切り分ける
    8. 直らなければ、メーカーのサポートに相談し、修理か買い替えかを決める

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 画面がちらついたり、暗くなったりして、作業が止まる
    2. いつ・どんなときに起きるかを確かめないまま、しばらく放っておく
    3. たまたま直ることがあるため、原因が分からないまま使い続ける
    4. また同じ症状が出て、故障への不安と目の疲れだけが大きくなる

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。ケーブルの差し直し、モニターを1台にする切り分け、ドライバーのリセットは、お金をかけずにすぐ試せます。起きる場面が分かれば、ケーブルを替えればよいのか、設定を直せばよいのか、修理の相談が必要なのかを判断しやすくなります。

    この記事で挙げる手順の名前や場所は一例です。パソコンやモニターの機種、Windows のバージョンによって違うことがあります。分からないときは、Microsoft やパソコン・モニターのメーカーのサポートページなど、公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • パソコンのグラフィックの部品と、映像の出力端子の数
    • モニターの明るさの調整方式（PWM調光かどうか）
    • 長く使って劣化した部品
    • 修理の費用と、メーカーの保証期間

    変えやすいこと

    • ケーブルの差し直しと交換、つなぐ端子
    • つなぐモニターの台数と、ドックやハブの使い方
    • リフレッシュレート、解像度、明るさの設定
    • グラフィックスドライバーの更新
    • モニターの設定メニューの項目
    • 夜間モードと、画面から目を離す習慣
    • ちらつく場面のメモ
    • データのバックアップ

    次の行動プランは3段階です。今日は、ケーブルを確かめ、ドライバーをリセットし、モニターの設定と明るさを見て、1台ずつで切り分けます。1週間で、ドライバーを更新し、モニターの設定メニューを確かめ、ちらつく場面を記録します。1か月後に、記録を見返して、メーカーへの相談や修理、買い替えが必要かを決めます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、ちらつきが変わったかを確かめます。

    設定の名前や場所は、機種や Windows のバージョンによって違うことがあります。この記事の手順と画面が違うときは、Microsoft や、パソコン・モニターのメーカーのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分ほど。お金はかかりません

      • ちらついたら、まずグラフィックスドライバーをリセットする

        • 画面がちらついたり、固まったりしたら、Windows + Ctrl + Shift + B を同時に押します。Windows は、Windows のロゴが書かれたキーです。
        • 画面が一瞬暗くなって戻るのが正常な反応です。ビープ音が鳴ることもあります。
        • 直らなければ、作業中のファイルを保存してから、パソコンを再起動します。「スタート」→ 電源のボタン →「再起動」です。

      • タスクマネージャーも一緒にちらつくかを見る

        • 画面がちらついているときに、Ctrl + Shift + Esc を同時に押して、タスクマネージャーを開きます。
        • タスクマネージャーも一緒にちらつくなら、ドライバーの問題の可能性があります。1週間の行動の「グラフィックスドライバーを更新する」に進みます。
        • タスクマネージャーはちらつかず、ほかの部分だけがちらつくなら、その時に開いているアプリが原因の可能性があります。アプリの名前をメモしておきます。

      • ケーブルを抜いて差し直す

        • パソコンとモニターの両方で、HDMI や DisplayPort のケーブルを一度抜いて、奥までしっかり差し直します。
        • 抜いたときに、コネクタや端子の中にホコリがたまっていないか、ゆるみやぐらつきがないかを見ます。ホコリは、乾いた柔らかい布で軽く拭き取ります。端子の中に、金属の物を差し込まないでください。
        • ケーブルが強く折れ曲がっていないか、引っ張られていないかも見ます。机の上の物を動かしたときに引っ張られない位置に、ケーブルを通します。
        • モニターの電源ケーブルも、抜けかけていないかを確かめます。
        • 別のケーブルや、パソコンの別の映像の端子があれば、替えてみます。ケーブルを替えて直るなら、もとのケーブルの不具合の可能性が高いと考えられます。

      • モニターを1台だけにして、どちらでちらつくかを確かめる

        • 2台のモニターのうち、1台のケーブルをパソコンから外します。しばらく使って、残った1台でちらつきや一瞬暗くなる症状が出るかを見ます。
        • 次に、もう片方だけをつないで、同じように確かめます。
        • 片方だけで起きるなら、そのモニター、ケーブル、端子の可能性があります。1台にすると起きないなら、2台目の接続やドック、グラフィックの負荷の可能性があります。
        • ドッキングステーションや USB-C のハブを使っている場合は、可能であれば、ドックを通さずにパソコンとモニターを直接つないでも試します。USB の機器が一緒に切れる症状が止まるかも見ます。
        • ドックやハブに専用の電源アダプターが付いている場合は、それがつながっているかを確かめます。

      • リフレッシュレートと解像度を確かめる

        • Windows 11：「スタート」→「設定」→「システム」→「ディスプレイ」を開きます。2台つないでいる場合は、画面の上の図で、確かめたいモニターを選びます。
        • 「ディスプレイの解像度」が、「（推奨）」と書かれた値になっているかを見ます。違う場合は、推奨の値に変えてみます。
        • 同じ画面の下にある「ディスプレイの詳細設定」を開き、「リフレッシュ レートの選択」の値を見ます。Microsoft のヘルプでは、この画面が「詳細表示」と書かれていることもあります。モニターの説明書に書かれた、対応している値の中から選びます。高い値でちらつく場合は、一段低い値（60Hz など）にして、変わるかを試します。
        • 値を変えると、多くの場合、設定をそのままにするかを確かめる画面が出ます。画面が映らなくなったときは、何も押さずに15秒ほど待つと、元の設定に戻ります。

      • 画面の明るさを下げすぎていないかを見る

        • ノートパソコンの画面は、「設定」→「システム」→「ディスプレイ」の「明るさ」で調整できます。外付けのモニターは、モニター本体のボタンで開くメニューで調整します。
        • 明るさを極端に下げている場合は、少し上げてみます。PWM調光のモニターでは、明るさを少し上げると、目の疲れが軽くなる場合があります。
        • ノートパソコンでは、機種によって「明るさ」の項目に「コンテンツに基づいて明るさを変更」があります。これが「常に」になっていると、表示する内容によって明るさが変わります。明るさの変化が気になる場合は、「オフ」にして変わるかを試します。

      • 裏で動いている重いアプリがないかを確かめる

        • タスクマネージャーの「プロセス」の画面で、「CPU」の列の見出しを押すと、CPU を多く使っている順に並びます。「GPU」の列が表示されている場合は、同じように確かめます。何もしていないのに、上のほうに同じアプリがずっと出ている場合は、名前をメモします。
        • 使っていないアプリは、そのアプリの画面に戻って閉じます。名前を見ても何か分からないものは、終了させないでください。タスクマネージャーの使い方は、お悩み No.002「パソコンが遅くて容量もいっぱい、買い替える前にできること」でも説明しています。

    2. 1週間の行動

      目安：ドライバーの更新とモニターの設定に30〜60分ほど。あとは1日1〜2分の記録です

      • グラフィックスドライバーを更新する

        • 更新の前に、大事なファイルのバックアップを取り、ノートパソコンは電源アダプターにつないでおきます。
        • Windows 11：「設定」→「Windows Update」を開き、「更新プログラムのチェック」を押します。続けて、「詳細オプション」→「オプションの更新プログラム」を開き、ドライバーの更新が出ていないかを確かめます。Microsoft によると、オプションのドライバーは自動ではインストールされません。
        • グラフィックの部品の名前は、「スタート」ボタンを右クリック →「デバイス マネージャー」→「ディスプレイ アダプター」を開くと確かめられます。
        • メーカーの公式サイトから最新のドライバーを入れる場合は、機種名や部品の名前、Windows のバージョンを間違えないようにします。メーカー製のパソコン、特にノートパソコンでは、まずパソコンのメーカーのサポートページで、その機種向けのドライバーを確かめます。グラフィックの部品のメーカー（Intel、NVIDIA、AMD など）の公式サイトで配布されている場合もあります。
        • Windows Update でドライバーが更新された直後からちらつくようになった場合は、ドライバーを元に戻す方法もあります。「デバイス マネージャー」→「ディスプレイ アダプター」で部品の名前を右クリック →「プロパティ」→「ドライバー」タブ →「ドライバーを元に戻す」です。前のドライバーが残っていない場合は、このボタンを押せません。管理者の権限も必要です。
        • 更新の途中で止まったときの対処は、お悩み No.020「パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？」で説明しています。

      • モニターの設定メニューとファームウェアを確かめる

        • モニター本体のボタンで設定メニューを開き、「フリッカーフリー」「アイケア」「ブルーライト軽減」などの項目がないかを確かめます。項目の名前はメーカーによって違います。分からないときは、モニターの説明書かメーカーのサポートページで確かめます。
        • モニターの説明書で、使っている解像度とリフレッシュレートに必要なケーブルの種類も確かめます。今使っているケーブルが対応していない場合は、対応したケーブルに替えます。
        • モニターやドッキングステーションのメーカーのサポートページで、ファームウェア（本体の中のソフトウェア）の更新が出ていないかを確かめます。更新できるのは一部の機種だけです。更新するときは、メーカーの案内のとおりに進め、途中で電源を切らないでください。

      • ちらつく場面をメモする

        • 日時、していた作業、開いていたアプリ、つないでいたモニターの台数、ドックやハブを使っていたか、明るさ、症状（ちらつき、波打つ乱れ、一瞬暗くなる、USB が切れる）を書きます。
        • 直ったときの状況も書きます。「しばらく放っておいたら直った」「ケーブルを触ったら直った」「再起動したら直った」などです。
        • 今日確かめた、タスクマネージャーがちらついたかどうかと、1台ずつで試した結果も書きます。
        • 「特定のアプリのときだけ」「2台目のモニターだけ」「明るさを下げたときだけ」のどれに当てはまるかが分かると、原因を絞れます。メーカーに相談するときにも役立ちます。

      • 目の疲れを軽くする設定と習慣を取り入れる

        • 夜間モード：「設定」→「システム」→「ディスプレイ」で「夜間モード」をオンにします。「夜間モード」の項目を開くと、強さの調整と、自動でオンにする時間の設定ができます。夜間モードは、画面の青い光を減らして、暖かい色で表示する機能です。
        • 20分に1回は画面から目を離して、20秒ほど遠くを見ます。
        • 厚生労働省のガイドラインでは、パソコンなどを使う作業について、続けて作業する時間が1時間を超えないようにし、次の作業までに10〜15分の作業休止を設けることが示されています。続けて作業する時間の中で、1〜2回の小休止を取ることも示されています。
        • 画面の文字が小さくて目が疲れる場合は、「設定」→「システム」→「ディスプレイ」の「拡大/縮小」で、文字や画面の表示を大きくする方法もあります。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • メモを見返して、原因の見当をつける

        • ケーブルの交換、ドライバーの更新、設定の見直しで直ったなら、その状態を続けます。
        • 特定のアプリのときだけ起きる場合は、そのアプリを更新するか、アプリのメーカーのサポートページで同じ症状の情報を調べます。
        • ケーブル交換やドライバーの更新でも直らない場合は、次の項目に進みます。

      • モニターを別のパソコンにつないで、どちらの問題かを切り分ける

        • 家族のパソコンなど、別のパソコンにモニターをつないで、同じ症状が出るかを確かめます。
        • 別のパソコンでも同じ症状が出るなら、モニター側の問題の可能性が高いと考えられます。出なければ、パソコン側の問題の可能性が高くなります。
        • 結果によって、相談する先を、モニターのメーカーにするか、パソコンのメーカーにするかを決めます。

      • メーカーのサポートページで同じ症状の情報を調べる

        • パソコンとモニターの機種名を確かめます。本体の底面や背面のラベル、保証書、購入したときの箱で確かめられます。
        • メーカーのサポートページで、機種名と「ちらつき」「画面が暗くなる」「USB が切れる」などの言葉で、同じ症状の情報を調べます。
        • 窓口に相談するときは、機種名、いつから起きているか、症状、試したこと（ケーブルの交換、ドライバーの更新、1台ずつの確認など）を伝えます。1週間のメモが役に立ちます。

      • 危ない症状があれば、修理の見積もりを取る

        • 画面が真っ暗になる、焦げ臭い、電源が落ちる、といった症状があれば、使うのをやめて、メーカーや販売店に修理の見積もりを頼みます。
        • 電源を入れても画面が映らなくなった場合は、お悩み No.029「パソコンの電源を入れても画面が真っ暗。起動しないときにまず確かめること」も参考にしてください。

      • 長く使っているパソコンは、修理と買い替えの費用を比べて決める

        • 5年以上使っていて、修理の費用が高い場合は、修理の見積もりと、買い替えの費用を比べて決めます。
        • モニターだけの問題なら、パソコンではなくモニターだけを替える方法もあります。
        • Windows 10 のパソコンは、Microsoft のサポートが2025年10月14日に終了しています。Windows 11 にできない古い機種では、そのことも考えに入れます。
        • 保証期間が残っているか、購入したお店の延長保証に入っているかも確かめます。

      • 大切なデータのバックアップを取っておく

        • グラフィックの部品の故障で修理に出すと、データが消えることがあります。外付けのハードディスクや SSD、クラウドのサービスに、大切なファイルをコピーしておきます。
        • バックアップの始め方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」で説明しています。

      • 目の痛みや頭痛が続く場合は、早めに医療機関へ行く

        • 明るさの調整や夜間モード、休憩を取り入れても、目の痛みや頭痛が続く場合は、早めに眼科などの医療機関に相談します。
        • 見え方が変わった、急に目が見えにくくなった、といった場合は、画面の対策より先に受診してください。

    まず今日、ちらついたら Windows + Ctrl + Shift + B を押し、タスクマネージャーも一緒にちらつくかを見ます。ケーブルを抜いて差し直し、別のケーブルや端子も試します。モニターを1台ずつにして、どちらでちらつくかを確かめ、リフレッシュレート、解像度、明るさの設定を見直します。次の1週間は、グラフィックスドライバーを更新し、モニターの設定メニューとファームウェアを確かめます。ちらつく場面をメモし、夜間モードと休憩の習慣を取り入れます。1か月後に、メモを見返し、モニターを別のパソコンにつないで切り分けます。直らなければメーカーに相談し、危ない症状があれば修理の見積もりを取ります。長く使っているパソコンは、買い替えと比べて決めます。バックアップも取っておきます。目の痛みや頭痛が続く場合は、早めに医療機関へ行きます。手順の名前や場所は、機種や Windows のバージョンで変わることがあります。分からないところは、Microsoft や、パソコン・モニターのメーカーのサポートページなど、公式のヘルプで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理や電気製品の安全、目の健康についての専門的な助言ではありません。特定の製品や修理、買い替えを勧めるものでもありません。設定の変更は、ご自身の判断と責任で行ってください。

    パソコンの本体やモニターを自分で分解したり、内部の部品を触ったりしないでください。感電やけが、故障のおそれがあります。メーカーの保証が受けられなくなることもあります。

    グラフィックスドライバーやファームウェアの更新は、Windows Update か、パソコン・モニター・部品のメーカーの公式サイトからだけ行ってください。見知らぬサイトや広告で勧められる「ドライバー更新ツール」は使わないでください。不要なソフトや、偽のソフトを入れてしまうおそれがあります。

    画面が真っ暗になる、焦げ臭いにおいがする、煙が出る、といった場合は、すぐに電源を切り、充電器や電源ケーブルを外してください。パソコンやモニターは、燃えやすいものから離した、火の気のない場所に置き、メーカーや販売店に相談してください。火が出ているときは、無理に近づかず、119番に通報してください。

    目の痛みや頭痛が続く場合は、自己判断で市販薬に頼り続けず、早めに眼科などの医療機関に相談してください。

    怪しい修理業者や、「無料点検」を名乗る電話・メール・SMS には、安易に応じないでください。修理は、メーカーの窓口や、パソコンを買ったお店の窓口に相談するのが確実です。メーカー以外で修理すると、メーカーの保証が受けられなくなることがあります。

    パスワードや確認コードは、公式サイトと公式アプリ以外には入力しないでください。メールや SMS、検索結果の広告のリンクから開いたサイトは、偽のサイトのおそれがあります。迷惑メールの見分け方は、お悩み No.007「宅配便やカード会社を名乗る迷惑メールが毎日届く。見分けて安心して使うには」も参考にしてください。

    「画面の異常を検出しました」「ウイルスに感染しました」「今すぐ電話してください」といった画面が出ても、表示された電話番号には電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。電話をかけてしまった、お金を払ってしまったという場合は、下の相談先に相談してください。
