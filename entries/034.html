お悩み No.034 ・ 2026年11月23日公開

スマホの指紋認証・顔認証がうまくいかない。冬に失敗が増えるときの直し方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    冬に指紋認証の失敗が増える主な原因は、指先の乾燥です。センサーの汚れ、保護フィルム、指紋の登録のしかたも、失敗の原因になります。顔認証の失敗は、顔の角度や明るさが登録したときと違うことや、マスクやサングラスで顔の一部が隠れることが主な原因です。これらは、センサーの掃除、指紋や顔の登録し直し、指先の保湿など、自分でできる対処で減らせます。このため、改善できる見込みがあります。

    ただし、失敗を完全になくすことはできません。指紋認証と顔認証は、便利さと安全性のバランスをとって作られています。似た指紋や顔でスマホが開いてしまわないように、ある程度厳しく照合します。何度か失敗するとパスコードの入力を求められるのは、故障ではなく、仕組みとして決められた動きです。

    近道は、最初に2つのことを確かめることです。1つめは、失敗するのが指紋だけか、顔認証も失敗するかです。2つめは、冬や乾燥した日だけ失敗するのか、季節に関係なく失敗するのかです。結果によって、直す場所を絞れます。

    認証の失敗が増えても、パスコードを簡単なものに変えたり、画面ロックを外したりするのは避けます。指紋や顔が通らないとき、最後にスマホを開く手段はパスコードです。Apple の公式のヘルプによると、iPhone のパスコードを忘れた場合は、iPhone を消去しないと使えるようになりません。Android でも、パスコード（PIN やパターンなど）を忘れると、初期化が必要になることがあります。パスコードを忘れないようにしておくことが大切です。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    冬に指紋認証が通らない
    冬になると、指をセンサーに当てても「認識できませんでした」と表示され、何度もやり直している。
    息を吹きかける方法しか知らない
    指を湿らせると開くことがあるが、家族に見られて笑われてしまった。人前で気軽にできる方法ではない。
    顔認証も失敗する
    横を向いたとき、笑ったとき、マスクやサングラスをしているときに、失敗することが多い。
    パスコードのほうが早い日がある
    指紋や顔で何度も試すより、パスコードを打つほうが早いと感じる日がある。
    急いでいるときほど困る
    指紋も顔も反応しない日は、急いでいる場面ほどイライラする。

    指紋認証・顔認証が失敗する主な原因

    冬の乾燥で、指先の水分が減っている
    指紋センサーは、指紋の凹凸（盛り上がった線と、その間の溝）を読み取ります。冬は空気が乾燥し、指先の水分も少なくなります。指先が乾いていると、センサーが凹凸を読み取りにくくなります。Apple の公式のヘルプでも、乾燥肌が指紋の認識に影響することがあると書かれています。息を吹きかけると開くことがあるのは、指先が少し湿って、読み取りやすくなるためと考えられます。
    指先の荒れやひび割れ
    指先が荒れていたり、ひび割れていたりすると、登録したときの指紋と今の指紋の形が少し変わります。登録した指紋と合わない部分が増えると、照合に失敗しやすくなります。Apple は、切り傷も指紋の認識に影響することがあると案内しています。
    指が濡れすぎている、油分が付いている
    乾燥だけでなく、濡れすぎも失敗の原因になります。Apple は、水分、油分、ローション、汗も指紋の認識に影響することがあると案内しています。手を洗った直後や、ハンドクリームを塗った直後は、失敗しやすくなります。
    顔の角度・表情・明るさが、登録したときと違う
    顔認証は、登録したときの顔と、今カメラに映っている顔を比べます。横を向いたとき、大きく笑ったとき、顔が近すぎたり遠すぎたりするときは、照合が難しくなります。
    • Apple によると、iPhone の Face ID は、顔から約25〜50センチ離した位置で機能しやすくなります。
    • Apple によると、iOS 16 以降の iPhone 13 以降では、iPhone を横向きにしても Face ID が使えます。それより前の機種では、縦向きのときだけ使えます。
    • 明るさの影響は、顔認証の方式によって違います。Apple によると、iPhone の Face ID は真っ暗な中でも使えます。一方で、Google は Pixel の顔認証について、暗い場所では機能しないことがあると案内しています。
    マスク・サングラス・帽子で、顔の一部が隠れる
    顔の一部が隠れると、照合に使える特徴が減ります。Apple は、iPhone の Face ID では目、鼻、口がカメラにしっかり映っているかを確かめるよう案内しています（「マスク着用時Face ID」を使う場合は、目元が隠れていないことを確かめます）。また、偏光サングラスは赤外線を遮ることがあるため、外して使うよう案内しています。Google も Pixel の顔認証について、サングラスやマスクなど顔を隠しているものを外して試すよう案内しています。
    センサーやカメラの汚れ、保護フィルムやケース
    指紋センサーや前面のカメラに皮脂や汚れが付いていると、読み取りが悪くなります。保護フィルムやケースがセンサーやカメラにかかっている場合も、同じように失敗しやすくなります。Apple は、ケースや保護フィルムが Touch ID のセンサーや Face ID のカメラにかからないようにするよう案内しています。Google は、画面の中に指紋センサーがある Pixel では「Made for Google」認定の画面保護シートを使い、シートを貼ったり交換したりしたら指紋を登録し直すよう案内しています。
    指紋を1本の指、顔を1つの見た目しか登録していない
    指紋を1本の指しか登録していないと、その指が荒れたときや、スマホの持ち方が違うときに開けません。顔も、メガネをかけたときなど、見た目が変わったときに照合できないことがあります。iPhone では「もう一つの容姿」を追加で登録できます。

    何度か失敗するとパスコードになるのは、決められた動き

    指紋認証と顔認証は、便利さと安全性のバランスで作られています。照合をゆるくすると開きやすくなりますが、似た指紋や顔でも開いてしまうおそれが出ます。そのため、ある程度厳しく照合します。

    また、決まった条件では、指紋や顔が正しくても、パスコードの入力を求められます。Apple の公式のヘルプによると、iPhone では次のような場合です。

    • 電源を入れたときや、再起動したとき
    • 48時間以上ロックを解除していないとき
    • Face ID または Touch ID でのロック解除に5回失敗したあと

    Google Pixel でも、数回試しても指紋が認識されなかったときや、再起動したあとなどに、PIN やパターンなどの入力を求められます。ほかの Android の機種の条件は、メーカーの公式のヘルプで確かめてください。パスコードを求められても、故障ではありません。パスコードで開けば、また指紋や顔が使えるようになります。

    「指紋だけか、顔もか」「冬だけか」で原因を絞れる

    原因の候補が多いため、まず失敗のしかたを確かめます。結果によって、次のように見当をつけられます。

    指紋も顔も失敗する
    スマホ側の原因を先に疑います。センサーやカメラの汚れ、保護フィルムやケースの影響の可能性が高いと考えられます。OS のアップデートのあとから失敗が増えた場合は、OS を最新にして様子を見ます。
    指紋だけ失敗する
    指先の乾燥や荒れ、指紋の登録のしかたの可能性が高いと考えられます。冬や乾燥した日だけ失敗が増えるなら、指先の乾燥の影響が大きいと考えられます。
    顔だけ失敗する
    顔の角度や距離、明るさ、マスクやサングラスの影響の可能性が高いと考えられます。失敗したのがどんな場面だったかを思い出すと、手がかりになります。
    季節に関係なく失敗する
    登録のしかた、センサーの汚れ、保護フィルムを疑います。登録し直しても改善しない場合や、登録そのものが完了しない場合は、故障の可能性もあります。Apple は、Touch ID の設定が完了できない場合やオンにならない場合は、修理サービスが必要な可能性があると案内しています。

    試す順番

    次の順番で試します。上ほど手間が少なく、すぐに試せます。

    1. 指紋センサーと前面のカメラのまわりを拭き、保護フィルムやケースがかかっていないかを確かめる
    2. 指先の乾燥や濡れを整えてから試す
    3. よく使う指を登録し直し、2本以上の指を登録する
    4. 顔を明るい場所で登録し直し、必要ならメガネやマスクの状態も登録する
    5. OS を最新にする
    6. それでも改善しなければ、スマホのメーカーのサポート窓口に相談する

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 急いでいるときに、指紋や顔が通らない
    2. 原因を確かめないまま、何度もやり直す
    3. 失敗が続いてパスコードを求められ、イライラする
    4. 落ち着いたあとも、掃除や登録し直しをしないまま次の日も同じように使う

    4のあと、また1に戻ります。

    この循環は、2と4のところで止められます。急いでいないときに一度、センサーの掃除と登録し直しを行います。失敗した場面を覚えておくと、何を直せばいいかが分かります。急いでいるときは、2〜3回失敗した時点でパスコードに切り替えるほうが、早く開けることがあります。

    この記事で挙げる設定の名前や場所は一例です。機種や OS のバージョンによって違うことがあります。分からないときは、Apple や Google、スマホのメーカーのサポートページなど、公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 冬の空気の乾燥
    • 指紋や顔をどのくらい厳しく照合するか（スマホの仕組みで決まっている）
    • 決まった条件で、パスコードの入力を求められること
    • 指紋センサーやカメラの種類と位置

    変えやすいこと

    • センサーやカメラのまわりを拭くこと
    • 保護フィルムやケースを見直すこと
    • 指先を保湿すること
    • 指紋を登録し直し、2本以上の指を登録すること
    • 顔を明るい場所で登録し直し、見た目を追加すること
    • スマホを持つ角度や、顔との距離
    • パスコードを忘れないように控えること

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、指紋や顔で開けるかを確かめます。

    設定の名前や場所は、機種や OS のバージョンによって違うことがあります。この記事の手順と画面が違うときは、Apple や Google、スマホのメーカーのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：20〜30分ほど。急いでいないときに行います

      • 指紋センサーと前面のカメラのまわりを拭く

        • 指紋センサーを、柔らかい布で軽く拭きます。センサーの場所は、ホームボタン、電源ボタン、背面、画面の下のほうなど、機種によって違います。Apple は、糸くずの出ない柔らかい布で拭き取るよう案内しています。
        • 顔認証を使う場合は、画面の上のほうにある前面のカメラのまわりも拭きます。
        • 指も、手を洗ってから水気をよく拭き取った状態で試します。

      • 保護フィルムとケースを確かめる

        • 保護フィルムやケースが、指紋センサーや前面のカメラにかかっていないかを見ます。
        • 保護フィルムに、気泡、浮き、ズレ、傷がないかを見ます。
        • 画面の中に指紋センサーがある機種では、Google は Pixel について「Made for Google」認定の画面保護シートを使うよう案内しています。ほかの機種でも、メーカーが指紋認証への対応を案内している保護フィルムを選びます。
        • 保護フィルムを貼り替えたときは、次の手順で指紋を登録し直します。

      • よく使う指の指紋を登録し直す

        • iPhone（Touch ID）：「設定」→「Touch IDとパスコード」を開き、パスコードを入力します。「指紋を追加」をタップして、画面の指示に従って同じ指を登録し直します。新しい指紋で開けることを確かめてから、古い指紋をタップして「指紋を削除」を選びます。
        • Android（Google Pixel）：「設定」→「セキュリティとプライバシー」→「デバイスのロック解除」→「指紋」（機種によっては「顔認証と指紋認証」）の順に開き、PIN などを入力します。古い指紋を削除アイコンで消してから、「指紋を追加」で登録し直します。
        • Android（そのほかの機種）：多くの機種では、「設定」の「セキュリティ」や「生体認証」に近い名前の項目の中に、指紋の設定があります。見つからないときは、「設定」の検索欄に「指紋」と入力して探します。
        • 登録するときは、指を当てるたびに、位置と角度を少しずつ変えます。指の中心だけでなく、指の端や先端まで読み取らせます。Google も Pixel の登録の手順で、指の位置をずらして、指の端と先端の指紋を読み取るよう案内しています。
        • ふだんスマホを持つときと同じ持ち方で登録すると、実際に使うときの当て方に近くなります。
        • 指先がひどく乾いているときは、ハンドクリームなどで軽く保湿し、クリームがなじんでから登録します。

      • 顔を明るい場所で登録し直す

        • 登録し直す前に、パスコードを覚えているかを確かめます。顔の登録を消しても、パスコードがあればスマホは開けます。
        • iPhone（Face ID）：「設定」→「Face IDとパスコード」を開き、パスコードを入力します。「Face IDをリセット」をタップしてから、「Face IDを設定」を選び、画面の指示に従います。Apple は、照明の明るい場所で設定するよう案内しています。
        • Android（Google Pixel）：「設定」→「セキュリティとプライバシー」→「デバイスのロック解除」→「顔認証」の順に開きます。古い顔モデルを削除アイコンで消してから、「顔を追加」で登録し直します。Google は、ふだん使うときと同じ状態（メガネの有無など）で設定するよう案内しています。
        • Android（そのほかの機種）：「設定」の検索欄に「顔」と入力して、顔認証の設定を探します。
        • 登録するときは、明るい場所で正面を向き、画面の指示どおりに顔をゆっくり動かします。

      • マスクをよく着ける場合は、マスクを着けたままの認証が使えるかを確かめる

        • iPhone：Apple によると、iOS 15.4 以降の iPhone 12 以降では、「設定」→「Face IDとパスコード」で「マスク着用時Face ID」をオンにできます。マスクを着けていても、目の周りの特徴で照合します。
        • ただし、Apple は、Face ID は顔全体で照合するときに最も精度が高くなると案内しています。オンにするかどうかは、マスクを着ける回数に合わせて決めます。
        • ふだんメガネをかけている人は、「メガネを追加」で登録します。Apple によると、このときはサングラスではなく透明なメガネをかけていると、精度を上げられます。
        • Apple によると、マスクを着けたままの Face ID は、iPhone を縦向きにしたときだけ使えます。
        • Android：Google は Pixel の顔認証について、マスクを外して試すよう案内しています。マスクを着けている日は、指紋かパスコードを使います。

      • 失敗が続くときは、指と持ち方を整えてから試す

        • 指先が乾いているときは、指を軽く湿らせてから試します。Google も Pixel について、指が乾燥しすぎている場合は湿らせてから試すよう案内しています。息を吹きかける代わりに、手を洗ったあとで水気を軽く拭いた状態で試す方法もあります。
        • 濡れすぎていると、かえって失敗します。水滴が付いているときは拭いてから試します。
        • ハンドクリームで保湿すると、乾燥による失敗を減らせることがあります。塗った直後は、クリームの油分で失敗しやすくなります。クリームがなじんでから試します。
        • 手が冷たいときは、手を温めてから試します。
        • 指はセンサーにしっかり当て、読み取りが終わるまで動かしません。Apple は、指で Touch ID のセンサーをしっかり覆い、読み取りの途中ですばやくタップしたり指を動かしたりしないよう案内しています。
        • 顔認証は、スマホを顔から25〜50センチほど離して、正面から画面を見ます。

      • どうしても開かないときは、パスコードで開く

        • 2〜3回失敗したら、パスコードに切り替えます。何度もやり直すより、早く開けることがあります。
        • パスコードを続けて間違えると、しばらく入力できなくなります。思い出せないときに、思いつく番号を次々に入れるのは避けます。

    2. 1週間の行動

      目安：1日5分ほど。指先の手入れと、失敗する場面の確認を続けます

      • 指紋を2本以上登録する

        • 利き手の親指と人さし指など、ふだんよく使う指を2本以上登録します。1本の指が荒れているときや、持ち方が違うときにも開けるようになります。
        • 反対の手の指も登録しておくと、片手がふさがっているときにも使えます。
        • 登録できる指紋の数には上限があり、機種によって違います。

      • 寝る前にハンドクリームを塗る習慣をつける

        • 乾燥しやすい時期は、寝る前に指先までハンドクリームを塗ります。指先の荒れやひび割れが進むと、登録したときの指紋と形が変わりやすくなります。
        • 日中は、手を洗ったあとに水気をよく拭き取ります。

      • 顔認証が失敗しやすい場面を確かめる

        • 1週間、顔認証が失敗した場面をメモします。たとえば、暗い部屋、横を向いたとき、笑っているとき、寝転がっているとき、顔が近すぎるときです。
        • 開きやすい角度と距離を覚えます。正面から、顔から25〜50センチほど離すのが目安です。
        • 横向きで失敗する場合は、使っている iPhone が横向きの Face ID に対応しているかを確かめます。対応していない機種では、縦向きで使います。

      • メガネ・サングラス・帽子をよく使う人は、見た目を追加する

        • iPhone：「設定」→「Face IDとパスコード」→「もう一つの容姿を設定」で、メガネをかけた状態などを追加で登録できます。Apple は、メガネをかけていると認識されない場合は、メガネをかけたまま「もう一つの容姿」を追加するよう案内しています。
        • Apple によると、Face ID は帽子、メガネ、多くのサングラスに対応しています。ただし、偏光サングラスは赤外線を遮ることがあります。サングラスで失敗する場合は、外して試すか、指紋やパスコードを使います。
        • Google Pixel では、古い顔モデルを削除してから新しいモデルを追加します。いちばんよく使う状態（メガネの有無など）で登録します。

      • パスコードを控えておく

        • パスコードを覚えているかを確かめます。
        • 紙のメモに書く場合は、他人に見られない家の決まった場所に保管します。スマホのケースに挟んだり、財布に入れたりするのは避けます。
        • パスワード管理アプリに控える場合、そのスマホの中にだけ保存すると、スマホが開かないときに見られません。パソコンなど、別の機器からも見られるようにしておきます。
        • パスワードの管理のしかたは、お悩み No.004「パスワードが覚えられない、使い回しも不安。安全にラクに管理するには」も参考にしてください。
        • パスコードを忘れて消去や初期化が必要になったときに備えて、スマホのバックアップも取っておきます。iPhone は iCloud やパソコンに、Android は Google アカウントにバックアップできます。手順は下の公式のヘルプで確かめてください。

    3. 1か月の見直し

      目安：1か月後に15〜20分

      • 指紋と顔の登録を見直す

        • 季節の変わり目や、指先の荒れやけがで指の状態が変わったときは、指紋を登録し直します。
        • Apple によると、Face ID は、化粧を変えたなどの小さな見た目の変化には自動で対応します。濃いひげをそったなど、見た目が大きく変わったときは、パスコードで本人確認をしてから顔のデータを更新します。顔認証の失敗が増えたときは、顔の登録も見直します。

      • 保護フィルムを貼り替えたら、指紋を登録し直す

        Google は Pixel について、画面保護シートを貼る前に指紋を登録した場合や、シートを交換した場合は、指紋を登録し直すよう案内しています。ほかの機種でも、貼り替えたあとに失敗が増えたら登録し直します。

      • OS のアップデートのあとは、認証が通るかを確かめる

        • OS のアップデートで、認証の仕組みや設定の画面が変わることがあります。アップデートのあとは、指紋と顔で開けるかを確かめます。
        • Apple と Google は、Touch ID、Face ID、指紋認証センサーがうまく動かないときの対処として、OS を最新にすることを案内しています。

      • 家族と「スマホが開かなくなったときの連絡方法」を決めておく

        • 外出先でスマホが開かず、連絡できなくなったときにどうするかを決めておきます。たとえば、家族の電話番号を紙にも控えておく、待ち合わせの場所と時間を先に決めておく、などです。
        • 「サポートを名乗る電話やメールで、パスコードやコードを聞かれても教えない」という決まりも、家族で共有しておきます。

      • 認証が安定しない場合は、パスコードと組み合わせて使う

        • 登録し直しても失敗が多い場合は、「急いでいるときは、最初からパスコードで開く」と決めておきます。指紋や顔は、急いでいないときに使います。
        • パスコードを短く簡単なものに変える必要はありません。
        • 登録し直しても登録が完了しない、設定がオンにならない場合は、故障の可能性があります。スマホのメーカーのサポート窓口や、スマホを買ったお店に相談します。

    まず今日、指紋センサーと前面のカメラのまわりを拭き、保護フィルムやケースがかかっていないかを確かめます。よく使う指の指紋を、位置と角度を変えながら登録し直します。顔は、明るい場所で正面を向いて登録し直し、マスクをよく着けるなら「マスク着用時Face ID」が使えるかを確かめます。失敗が続くときは、指を軽く湿らせるか保湿し、手を温めてから試します。それでも開かなければ、パスコードで開きます。次の1週間は、指紋を2本以上登録し、寝る前のハンドクリームを習慣にし、顔認証が失敗しやすい場面を確かめます。パスコードも控えておきます。1か月後に、指紋と顔の登録、保護フィルム、OS のアップデートのあとの動きを見直し、家族と連絡方法を決めます。手順の名前や場所は、機種や OS のバージョンで変わることがあります。分からないところは、Apple や Google、スマホのメーカーのサポートページなど、公式のヘルプで確かめてください。

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。スマホの修理やセキュリティについての専門的な助言ではありません。特定の製品やサービスを勧めるものでもありません。設定の変更は、ご自身の判断と責任で行ってください。

    指紋や顔の登録は、自分のスマホで行ってください。登録し直すときに、他人のスマホに自分の指紋や顔を登録しないでください。自分のスマホに、他人の指紋や顔を登録させることも避けてください。登録された人は、そのスマホを開けるようになります。

    認証の失敗が増えても、パスコードを簡単なもの（誕生日や同じ数字の並びなど）に変えたり、画面ロックを外したりしないでください。スマホをなくしたときに、中の写真や連絡先、決済のアプリなどを他人に使われるおそれがあります。

    インターネットで見つかる「認証解除ツール」や「ロック解除ツール」、有料のロック解除業者には、安易に手を出さないでください。ツールに悪意のあるプログラムが含まれていたり、高額な料金を求められたりするおそれがあります。スマホの中の写真や個人情報を、知らない人に預けることにもなります。困ったときは、Apple や Google、スマホのメーカー、携帯電話会社など、公式の窓口に相談してください。

    パスワードや確認コードは、公式サイトと公式アプリ以外には入力しないでください。メールや SMS、検索結果の広告のリンクから開いたサイトは、偽のサイトのおそれがあります。迷惑メールの見分け方は、お悩み No.007「宅配便やカード会社を名乗る迷惑メールが毎日届く。見分けて安心して使うには」も参考にしてください。

    サポートを名乗る電話やメールで、パスコードや確認コードを聞かれても、教えないでください。「ウイルスに感染しました」「今すぐ電話してください」という画面が出ても、表示された電話番号には電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。電話をかけてしまった、お金を払ってしまったという場合は、下の相談先に相談してください。
