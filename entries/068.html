お悩み No.068 ・ 2026年11月24日公開

スマホで撮った写真をパソコンに移したい。ケーブルでつないでも表示されないときの取り込み方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    ケーブル接続時の『ファイル転送』の選択や、Windowsのフォトアプリ・スマホ連携などの取り込み手順を知れば、写真をパソコンへ移すことができ、スマホの容量不足も軽減できる見込みあり

    スマホをケーブルでパソコンにつないだあと、スマホ側で接続を許可する操作をすると、パソコンから写真が見えるようになります。Android では「ファイル転送」を選び、iPhone では「このコンピュータを信頼しますか？」で「信頼」を押します。そのあと、Windows のフォト アプリの「インポート」を使えば、写真をまとめて取り込めます。取り込んだ写真がパソコンで開けることを確かめてからスマホ側を整理すれば、容量不足も軽減できる見込みがあります。

    ボトルネックは、ケーブルをつないだあとにスマホ側で必要な操作を知らないことです。この操作をしないと、パソコンには写真が表示されません。そのため、メールで送る方法に頼ることになり、枚数が多いので途中で止まっています。

    ただし、充電専用のケーブルを使っている場合は、スマホ側の操作だけでは写真を取り込めません。写真の元のデータがクラウドにしかない場合も、先にクラウドから写真をダウンロードする必要があります。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    写真が何千枚もたまり、スマホの容量がいっぱいになってきた
    写真を消せば容量は空くが、家族の写真なので、別の場所に残すまでは消せない。
    ケーブルでつないでも、パソコンに何も表示されなかった
    つないだあとにスマホ側で何を押せばよいかを知らない。ケーブルが写真の転送に対応しているかも、まだ確かめていない可能性がある。
    メールで自分宛てに送ると、1枚ずつしか送れず途中で止まる
    メールは、何千枚もの写真を送る方法には向いていない。まとめて移す別の方法を知らない。
    パソコンに移したあと、スマホ側を消してよいか不安
    パソコンに写真が正しく入ったかを確かめる方法が分からないため、消してよいかを判断できない。
    SDカードに移したとき、写真の並び順が変わった
    写真の「撮影した日時」と「ファイルを保存した日時」が別の情報であることを知らない可能性がある。
    家族の思い出の写真をなくしたくない
    移す途中や移したあとに、写真を失うことをいちばん心配している。写真を何か所に残すかも、まだ決まっていない。

    考えられる原因

    ケーブルでつないでも写真が表示されない原因と、移す途中で止まる原因として、次のことが考えられます。

    Android が「充電のみ」の状態だと、パソコンに写真が出てこない
    Android をケーブルでつなぐと、スマホに「このデバイスを USB で充電中」という通知が出ます。Google の案内では、この通知をタップして「USB の使用」で「ファイル転送」を選びます。この選択をするまでは、充電だけが行われ、パソコンからスマホの中の写真は見えません。
    iPhone で「信頼」を押さないと、パソコンから写真が見えない
    iPhone をパソコンに初めてつなぐと、「このコンピュータを信頼しますか？」と表示されます。Apple の案内では、「信頼しない」を選ぶと、そのパソコンから iPhone の中身にアクセスできなくなります。iPhone のロックを解除しないと、この確認自体が表示されないこともあります。
    充電専用のケーブルでは、写真を転送できない
    USB ケーブルには、充電だけができて、データを送れないものがあります。Google の案内にも、一部の USB ケーブルではファイルを転送できないことがあると書かれています。スマホは充電されるのに写真が出てこないときは、ケーブルが原因の可能性があります。
    パソコン側で、どこを開けば写真が出てくるかを知らない
    Windows では、フォト アプリの「インポート」で取り込む方法と、エクスプローラーでスマホの中のフォルダーを開く方法があります。どちらも、スマホ側の操作が済むまでは写真が出てきません。
    クラウドの容量がいっぱいだと、同期が止まってしまう
    iCloud写真や Google フォトなどのクラウドへ写真を預けている場合、クラウドの容量がいっぱいになると、新しい写真の同期が止まります。iPhone で「ストレージを最適化」をオンにしていると、本体には容量の小さい版だけがあり、元の画質の写真はクラウドにだけある場合もあります。Microsoft の案内では、写真が iCloud にだけあると、パソコンへ取り込めないことがあります。
    写真の枚数が多いと、メールやメッセージアプリでは途中で止まりやすい
    メールには、1通に添付できる大きさに上限があります。スマホの写真は1枚でも数MBになることが多く、何千枚を送るには向いていません。メッセージアプリにも、一度に送れる枚数や大きさに上限があることが多くあります。

    どこが原因かを切り分ける方法

    次のことを順に確かめると、どこでつまずいているかが分かります。具体的な手順は、行動プランで説明します。

    スマホ側の通知で、「ファイル転送」になっているかを確かめる
    Android は、ケーブルでつないだときに出る通知を開き、「ファイル転送」が選ばれているかを見ます。iPhone は、「このコンピュータを信頼しますか？」が出たか、「信頼」を押したかを確かめます。
    別のケーブルで試して、写真が表示されるかを確かめる
    スマホを買ったときに付いてきたケーブルや、データ転送に対応していると書かれたケーブルに替えて試します。替えたら表示されたなら、元のケーブルが充電専用だった可能性があります。パソコンの別の USB 端子に差し替えて試すこともできます。
    パソコンのエクスプローラーに、スマホの名前が出ているかを確かめる
    エクスプローラーの「PC」を開き、スマホの名前（機種名や「Apple iPhone」など）が出ているかを見ます。名前が出ていれば、ケーブルとスマホ側の設定はできています。出ていなければ、スマホ側の通知とケーブルをもう一度確かめます。
    写真の枚数によって、移す方法を分ける
    1枚だけなら、メールで送れるかを試しても構いません。何十枚、何千枚とあるときは、ケーブルか Wi-Fi で移す方法を使います。

    直る見込み

    スマホ側で「ファイル転送」を選ぶだけで、写真が表示されるようになる
    原因が「充電のみ」の状態だった場合は、Android で「ファイル転送」を選ぶだけで、パソコンからスマホの中の写真が見えるようになります。iPhone は、「信頼」を押してパスコードを入力すると見えるようになります。
    Windows のフォト アプリの「インポート」で、まとめて取り込める
    Microsoft の案内では、フォト アプリの「インポート」で、取り込む写真と保存先を選べます。1枚ずつ送る必要はありません。枚数が多いと、写真を見つけて転送するまでに時間がかかります。
    Android なら、スマートフォン連携で Wi-Fi 経由でも写真を移せる
    Windows の「スマートフォン連携」（スマホ連携）を使うと、ケーブルなしで、同じ Wi-Fi につないだ Android の写真をパソコンに保存できます。Microsoft の案内では、表示されるのは最新の 2,000 枚の写真とスクリーンショットで、動画は対象外です。最近の写真を移すときに向いています。
    パソコンで開けることを確かめてからスマホ側を整理すれば、容量も空く
    写真がパソコンで開けることを確かめてからスマホ側の写真を消せば、写真を失わずにスマホの容量を空けられます。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. ケーブルでつないでも、パソコンに写真が表示されない
    2. メールで1枚ずつ送ろうとして、途中で止まる
    3. パソコンに移せないので、スマホ側の写真を消せない
    4. 写真が増え続け、スマホの容量がさらに足りなくなる

    4のあと、また1に戻ります。

    この循環は、1のところで止められます。ケーブルをつないだあとにスマホ側で行う操作と、パソコン側で開く場所が分かれば、写真をまとめてパソコンへ移せます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 使っているスマホとパソコンの機種
    • 機種や OS のバージョンによる、手順や設定名の違い
    • クラウドの無料で使える容量の上限
    • メールやメッセージアプリで送れる大きさの上限

    変えやすいこと

    • ケーブルでつないだあと、スマホ側で「ファイル転送」や「信頼」を選ぶこと
    • データ転送に対応したケーブルを使うこと
    • フォト アプリの「インポート」で取り込むこと
    • 写真を少しずつ分けて移すこと
    • パソコンで開けることを確かめてから、スマホ側を整理すること
    • 大切な写真を2か所以上に残すこと
    • 写真を撮影日時で並べ替えること

    次の行動プランは3段階です。今日は、ケーブルでつないで写真が表示されるようにし、数枚だけ取り込みます。1週間で、取り込んだ写真が開けることを確かめてから、残りを少しずつ移してスマホ側を整理します。1か月後には、取り込みを習慣にして、写真を2か所以上に残す形を整えます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    パソコン側の手順は Windows 11 の例です。設定やボタンの名前と場所は、スマホの機種や、Android・iOS・Windows のバージョンによって違うことがあります。この記事と画面が違うときは、使っているスマホやパソコンの公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分ほど。スマホ、ケーブル、パソコンを用意し、パソコンは電源につないでおきます

      • スマホのロックを解除して、ケーブルでパソコンにつなぐ

        Microsoft の案内では、スマホがロックされたままだと、パソコンはスマホを見つけられません。スマホの画面をつけ、ロックを解除してからつなぎます。つないだら、スマホの画面に通知や確認が出ていないかを見ます。

      • Android の場合：通知から「ファイル転送」を選ぶ

        1. 画面の上から下へスワイプして、通知を開きます。
        2. 「このデバイスを USB で充電中」という通知をタップします。
        3. 「USB の使用」で「ファイル転送」を選びます。
        • 機種によっては、通知の名前が「USB の設定」などになっていたり、選択肢が「写真を転送」や「PTP」になっていたりします。写真を移すときは、「ファイル転送」か「写真を転送」を選びます。
        • 通知が出ないときは、ケーブルを一度抜いて、ロックを解除したままつなぎ直します。

      • iPhone の場合：「このコンピュータを信頼しますか？」で「信頼」を押す

        1. Apple の案内では、Windows パソコンに読み込む前に、Microsoft Store から「Apple デバイス」アプリを入れておきます。
        2. iPhone のロックを解除して、ケーブルでパソコンにつなぎます。
        3. 「このコンピュータを信頼しますか？」と表示されたら、「信頼」をタップします。「許可」と表示される場合は「許可」をタップします。
        4. パスコードの入力を求められたら、iPhone のパスコードを入力します。
        • 間違えて「信頼しない」を押したときは、ケーブルを抜いてつなぎ直します。Apple の案内では、信頼しなかったパソコンにつなぐと、そのたびに同じ確認が表示されます。
        • 確認が表示されないときは、Apple デバイス アプリを最新版にし、ケーブルの抜き差し、パソコンの再起動、iPhone の再起動を順に試します。

      • Windows のフォト アプリで「インポート」を試す

        1. パソコンで「スタート」→「フォト」の順に選び、フォト アプリを開きます。
        2. 「インポート」を選び、つないでいるスマホを選びます。
        3. 画面の指示に従って、取り込む写真と保存先を選びます。
        • 今日は、最近撮った写真を数枚だけ選んで取り込みます。保存先のフォルダーをメモしておきます。
        • Microsoft の案内では、写真を見つけて転送するまでに少し時間がかかります。取り込みが終わるまで、ケーブルを抜かずに待ちます。

      • 写真が出てこないときは、別のケーブルで試す

        充電専用のケーブルでは、写真を転送できません。スマホを買ったときに付いてきたケーブルや、パッケージに「データ転送対応」などと書かれたケーブルに替えて、もう一度つなぎます。Google の案内では、パソコンの別の USB 端子に差し替える、パソコンやスマホを再起動する、といった方法も挙げられています。

    2. 1週間の行動

      目安：1回20〜30分ほどを、数日に分けて

      • 取り込んだ写真が、パソコンで開けるかを確かめる

        1. エクスプローラーで、取り込んだときの保存先（初めは「ピクチャ」フォルダーになっていることが多い）を開きます。
        2. 写真を何枚か開いて、きちんと表示されるかを確かめます。動画があれば、再生できるかも確かめます。
        3. 取り込んだ枚数が、スマホで選んだ枚数とおおよそ合っているかを確かめます。
        • iPhone の写真がパソコンで開けないときは、写真の保存形式が Windows に合っていない可能性があります。Apple の案内では、iPhone の「設定」→「カメラ」→「フォーマット」で「互換性優先」を選ぶと、そのあとに撮る写真が JPEG という形式で保存されます。

      • 開けることを確かめてから、スマホ側の写真を整理する

        • パソコンで開けることを確かめた分だけ、スマホ側から消します。古い月の写真から、少しずつ整理します。
        • iCloud写真や Google フォトのバックアップを使っている場合は、スマホで消すと、ほかのデバイスやクラウドからも消えることがあります。消す前に、下の注意書きも読んでください。
        • iPhone の「最近削除した項目」や Google フォトのゴミ箱に入った写真は、30日間残ります。完全に消えるまでは、スマホの容量も空かないことがあります。
        • Google フォトには、クラウドのバックアップを残したまま、スマホの中の写真だけを消す「デバイスから削除」という機能もあります。

      • Android の場合：エクスプローラーで DCIM フォルダーを開く

        フォト アプリでうまく取り込めないときは、エクスプローラーからコピーする方法もあります。

        1. 「ファイル転送」を選んだ状態で、エクスプローラーの「PC」を開きます。
        2. スマホの名前→「内部共有ストレージ」などの順に開きます。
        3. 「DCIM」フォルダーを開きます。カメラで撮った写真は、多くの機種でこの中の「Camera」フォルダーに入っています。
        4. パソコンに写真用のフォルダーを作り、そこへ写真をコピーします。
        • フォルダーの名前は、機種によって違うことがあります。

      • Android の場合：スマートフォン連携で Wi-Fi 経由で移す

        ケーブルを使わずに、最近の写真をパソコンへ移す方法です。Microsoft の案内では、Windows 11、または Windows 10（October 2022 Update 以降）と、Android 10 以降が必要です。スマホとパソコンは、同じ Wi-Fi につなぎます。

        1. パソコンのタスク バーの検索で「スマートフォン連携」と入力し、アプリを開きます。
        2. スマホのブラウザーで www.aka.ms/yourpc を開き、「Windows にリンク」アプリを入れるか開きます。
        3. パソコンと同じ Microsoft アカウントでサインインし、パソコンに出る QR コードをスマホで読み取ってつなぎます。
        4. パソコンのスマートフォン連携で「フォト」を選びます。
        5. 保存したい写真を右クリックして「名前を付けて保存」を選び、保存先のフォルダーを選んで「保存」を押します。
        • 表示されるのは、スマホの「カメラ ロール」と「スクリーンショット」のフォルダーにある、最新の 2,000 枚の写真です。動画は表示されません。何千枚もの写真をまとめて移すときは、ケーブルを使う方法が向いています。
        • アプリの名前は、「スマートフォン連携」や「スマホ連携」と書かれていることがあります。

      • iPhone の場合：フォト アプリと iCloud の取り込みも確かめる

        • フォト アプリの「インポート」で取り込めることを確かめたら、同じ手順で残りの写真を分けて取り込みます。エクスプローラーの「PC」にある「Apple iPhone」から、「DCIM」フォルダーの写真をコピーする方法もあります。
        • iCloud写真を使っていて「ストレージを最適化」をオンにしている場合は、iPhone 本体に容量の小さい版しかない写真があります。Apple の案内では、Windows パソコンに読み込む前に、元の画質の写真を iPhone にダウンロードしておく必要があります。
        • iPhone の容量がいっぱいで元の写真をダウンロードできないときは、Microsoft の案内にある「Windows 用 iCloud」を使うか、パソコンのブラウザーで icloud.com を開いて写真をダウンロードします。

      • ケーブルがうまくいかないときは、Wi-Fi で送るアプリを試す

        LocalSend は、同じ Wi-Fi につないだ機器どうしでファイルを送る、無料のアプリです。公式サイトによると、Windows、macOS、Linux、Android、iOS で使えて、アカウントの登録はいりません。インターネットを通さず、家の中のネットワークだけで送ります。

        • スマホとパソコンの両方に LocalSend を入れ、同じ Wi-Fi につないで使います。
        • アプリは、公式サイト（localsend.org）か、スマホの公式ストアから入れます。名前の似た別のアプリに注意します。
        • 自宅など、自分が管理している Wi-Fi で使います。

      • 写真の枚数が多いときは、少しずつ分けて移す

        • 1回に1か月分や数百枚ずつなど、区切りを決めて移します。1回分を移したら、開けることを確かめてから次へ進みます。
        • 取り込んでいる間は、ケーブルを抜かずに待ちます。パソコンは電源につなぎ、スマホも充電しながら移します。
        • パソコンの保存先も、「2026年」の中に「2026年11月」を作るように、年と月でフォルダーを分けると、どこまで移したかが分かりやすくなります。

    3. 1か月の見直し

      目安：1回30分ほど

      • パソコンへの取り込みを習慣にして、スマホの容量を確かめる

        • 月に1回など、取り込む日を決めます。今日と1週間で試した手順を、そのまま繰り返します。
        • スマホの容量に余裕ができたかを確かめます。iPhone は「設定」→「一般」→「iPhoneストレージ」、Android は「設定」→「ストレージ」などで確かめられます。場所は機種によって違います。
        • スマホの容量がまたいっぱいになったら、同じ手順で取り込み、開けることを確かめてから整理します。

      • 大切な写真を、2か所以上に残す

        パソコンだけに写真を置いていると、パソコンが壊れたときに写真を失うおそれがあります。パソコンのほかにもう1か所、写真を残す場所を決めます。

        • 外付けのハードディスクや SSD に、パソコンの写真のフォルダーをコピーします。
        • iCloud写真や Google フォト、OneDrive などのクラウドに預けます。容量が足りないときは、有料のプランが必要なこともあります。
        • コピーしたら、コピー先でも写真が開けるかを何枚か確かめます。

      • 写真の並び順が変わったときは、撮影日時で並べ替える

        写真には、カメラが記録した「撮影日時」と、ファイルを保存した「更新日時」や「作成日時」があります。SDカードやパソコンへコピーすると、更新日時や作成日時がコピーした日になることがあります。そうなると、更新日時の順に並べたときに、撮った順とは違う並び順になります。

        1. エクスプローラーで、写真のフォルダーを開きます。
        2. 「表示」で「詳細」を選びます。
        3. 列の見出し（「名前」や「日付」などが並んでいるところ）を右クリックし、「撮影日時」にチェックを入れます。
        4. 「撮影日時」の見出しを押すと、撮った順に並びます。もう一度押すと、新しい順と古い順が入れ替わります。
        • 「撮影日時」が一覧にないときは、右クリックのメニューの「その他」から探します。
        • フォト アプリにも、写真の並べ替えの機能があります。

    1か月たったら、パソコンに移した写真の範囲と、2か所目に残した写真の範囲をメモにまとめます。スマホの容量に余裕ができ、写真がパソコンと2か所目の両方で開ければ、その方法を続けます。うまく移せない手順が残るときは、使っているスマホやパソコンの公式ヘルプや、メーカーのサポート窓口で相談してください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンやスマホの操作についての専門的な助言ではありません。写真の移動や削除は、ご自身の判断と責任で行ってください。

    スマホ側の写真を消す前に、パソコンで写真が開けることを必ず確かめてください。枚数が合っているかと、動画が再生できるかも、あわせて確かめてください。

    iCloud写真や Google フォトのバックアップを使っている場合は、スマホで写真を消すと、同じアカウントを使うほかのデバイスやクラウドからも消えることがあります。Apple の案内では、iCloud写真を使っている1台のデバイスで写真を消すと、iCloud写真を使っているすべてのデバイスから消えます。

    取り込みやコピーの途中で、ケーブルを抜かないでください。途中で抜くと、写真が一部だけしか移らないことがあります。

    SDカードへ写真を移すと、写真の並び順が、保存した日付の順に変わることがあります。撮った順に並べたいときは、撮影日時で並べ替えてください。

    大切な写真は、1か所だけに置かないでください。パソコンと外付けドライブ、パソコンとクラウドのように、2か所以上に残してください。

    手順や設定の名前は、スマホの機種や、Android・iOS・Windows のバージョンによって変わることがあります。この記事は、2026年11月時点の公式ヘルプをもとにしています。使っているスマホやパソコンの公式ヘルプで確かめてください。

    公式のヘルプ

    • スマートフォンから PC に写真とビデオをインポートする（Microsoft サポート。フォト アプリの「インポート」の手順と、ロックの解除、ファイルを転送できるケーブル、iCloud にだけある写真についての注意が載っています）

    • iPhone、iPad、iPod touchで表示される「このコンピュータを信頼しますか？」という警告メッセージについて（Apple サポート。「信頼」を選ぶ手順と、確認が表示されないときの対処が載っています）
