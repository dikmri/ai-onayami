パソコンの画面が急に暗くなる・明るさが勝手に変わって見えにくい

カテゴリ

    AIの見立て

    パソコンの画面の明るさが勝手に変わる問題は、Windows の省エネ・夜間モード・自動明るさ調整といった設定が原因のことが多く、設定を確かめて切り分ければかなり軽くできる見込みが高い。設定の見直しと再起動で直ることが多く、故障の心配はまず小さい

    Windows には、画面の明るさを自動で変える機能がいくつかあります。部屋の明るさに合わせて変える機能、表示している内容に合わせて変える機能、バッテリーが減ったときに画面を暗くする省電力の機能です。夜間モードは、決まった時刻に画面の色を暖かい色に変えます。どの機能も設定画面で確かめられ、オフにしたり、働く時刻や条件を変えたりできます。

    ボトルネックは3つです。1つ目は、明るさのつまみを動かしても直らないのは設定のせいだと気づきにくいことです。2つ目は、暗くなる原因が省電力・夜間モード・自動調整・ドライバーのどれなのか分からないことです。3つ目は、部屋の明るさに合わせた調整の仕方が分からないことです。

    設定の見直しと再起動で直ることが多く、故障の心配はまず小さいと考えます。ただし、画面がまったく映らない場合は、明るさの問題ではなく故障の可能性があります。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    使っている途中で、急に画面が暗くなる
    Windows が自動で明るさを変えている可能性があります。候補は、部屋の明るさに合わせる自動調整、表示している内容に合わせる自動調整、バッテリーが減ったときの省電力の3つです。どれが働いているかは、暗くなったときの状況で絞れます。
    明るさのつまみを一番明るくしても暗いまま。再起動で直るときと直らないときがある
    つまみを上げても、自動調整や省電力が明るさを下げ直していることがあります。再起動で直るときと直らないときがあるのは、画面を映すためのソフトウェア（グラフィックドライバー）の調子が原因のこともあります。設定を確かめ、ドライバーを更新すると切り分けられます。
    朝、暗い部屋で開くとまぶしすぎて目が疲れる
    前の日の明るい部屋に合わせた明るさのままになっていると考えられます。画面と部屋の明るさの差が大きいと、まぶしく感じやすくなります。画面を暗くするか、部屋を明るくして差を小さくします。
    昼間に外で使うと、明るさが足りず文字が読めない
    日差しの下では、画面を一番明るくしても読みにくいことがあります。画面の明るさの上限は機種で決まっていて、設定では上げられません。日陰に移ると読みやすくなります。
    夕方や夜も画面が昼間のように明るく、目がチカチカする
    夜間モードがオフのままか、時刻の設定が合っていない可能性があります。夜間モードは色を変える機能なので、まぶしさが残るときは明るさも一緒に下げます。
    どこで調整すればいいのか、故障なのか、自分に合った明るさにそろえたい
    明るさは、クイック設定のスライダー、設定画面、ノートパソコンのキーの3か所で変えられます。勝手に変わる機能を1つずつ確かめれば、故障かどうかを判断できます。

    画面の明るさが変わる仕組み

    明るさを変える方法と、明るさや色を自動で変える機能を分けて説明します。手順は Windows 11 を前提にしています。

    クイック設定の明るさのスライダー
    Windows ロゴ キー + A を押すか、タスク バーの右側にあるネットワークのアイコン（Wi-Fi のマーク）を選ぶと、クイック設定が開きます。太陽のマークが付いた「明るさ」のスライダーを動かすと、画面の明るさが変わります。
    設定画面の「明るさ」
    「設定」→「システム」→「ディスプレイ」にも、明るさのスライダーがあります。自動調整の項目も、ここにまとまっています。
    ノートパソコンのキーボードの明るさのキー
    多くのノートパソコンでは、キーボードの上の段に太陽のマークが付いたキーがあり、押すと明るさが変わります。Fn キーと一緒に押す機種もあります。キーの場所と押し方は機種によって違うので、パソコンの説明書で確かめます。
    照明の変化に合わせて明るさを自動で変える機能
    部屋の明るさを測るセンサーがあるパソコンでは、周りが暗くなると画面を暗くし、明るくなると画面を明るくする機能があります。オンになっていると、つまみで決めた明るさから勝手に変わったように見えます。Microsoft は、外出先で画面が読みやすくなる機能だと説明しています。センサーがないパソコンには、この項目がありません。
    表示している内容に合わせて明るさを自動で変える機能
    一部の Windows 11 のパソコンには、画面に映っている内容に合わせて、明るさとコントラストを自動で変える機能があります。設定画面では「コンテンツに基づいて明るさを変更」という項目で、「オフ」「常に」「バッテリーのみの場合」から選びます。暗い場面から明るい場面に変わる動画などで、明るさが変わることがあります。Microsoft は、これは正常な動きだと説明しています。
    省電力（省エネ機能）
    バッテリーの残量が決めた値まで減ると働き、画面を暗くして、裏で動く処理を減らします。「省電力を使用するときに画面の明るさを下げる」という設定がオンのときに、画面が暗くなります。バッテリーで使っている途中で急に暗くなる場合は、この機能の可能性が高いです。Windows のバージョンによって、「省電力」「省エネ機能」のように名前が違います。
    夜間モード
    画面から出るブルー ライトを減らし、暖かい色で表示する機能です。Microsoft は、夜に眠りやすくするための機能だと説明しています。「日没から朝まで」か、自分で決めた時刻に、自動でオンとオフを切り替えられます。「強度」のスライダーで、色の変え方の強さを変えられます。
    外付けモニター
    Microsoft の説明では、外付けモニターでは Windows の明るさのスライダーが出ない場合があります。そのときは、モニター本体のボタンで明るさを変えます。
    しばらく操作しないと画面が消える設定
    「設定」→「システム」→「電源とバッテリー」→「画面、スリープ、休止のタイムアウト」で、操作しないときに画面を消すまでの時間を決めます。画面が真っ暗になるのが、しばらく操作しなかったときだけなら、この設定の働きです。

    原因の切り分け方

    どんなときに暗くなるか、まぶしくなるかによって、先に確かめる設定が違います。次のように切り分けます。

    使っている途中で、急に暗くなる
    まず、そのとき充電器をつないでいたかと、バッテリーの残量を見ます。バッテリーで使っていて残量が減っていたなら、省電力の可能性が高いです。充電中でも暗くなるなら、照明の変化や表示内容に合わせる自動調整を、いったんオフにして様子を見ます。「設定」→「システム」→「電源とバッテリー」の「エネルギーに関する推奨事項」で「すべて適用」を選ぶと、明るさや自動調整の設定がまとめて変わることがあります。最近この操作をしたなら、それも原因の候補です。
    つまみを一番明るくしても暗いまま
    まず再起動します。直らなければ、グラフィックドライバーを更新します。Microsoft は、スライダーが出ない場合や動かない場合に、ディスプレイのドライバーを更新するよう案内しています。電源モードを「バランス」か「最高のパフォーマンス」にして、変わるかどうかも見ます。それでも暗いままなら、パソコンのメーカーに相談します。
    暗い部屋で開くと、まぶしすぎる
    画面の明るさを下げます。または、部屋の明かりをつけたり、カーテンを開けたりして、画面と部屋の明るさの差を小さくします。照明の変化に合わせる自動調整があるパソコンなら、オンにしておくと暗い部屋で自動的に暗くなります。
    夕方や夜になっても、昼間のように明るい
    夜間モードを、決まった時刻に自動でオンにする設定にします。夜間モードは色を変える機能なので、まぶしさが残るときは、夜だけ明るさのスライダーも下げます。
    外で使うと文字が読めない
    明るさを一番明るくして、日陰で使います。画面に日光が直接当たらない向きに座ると、読みやすくなります。明るくするとバッテリーの減りが早くなるので、残量にも気をつけます。
    外付けモニターだけ暗い・明るい
    Windows のスライダーではなく、モニター本体のボタンで明るさを変えます。ボタンの使い方は、モニターの説明書で確かめます。
    画面がまったく映らない、ちらつく、スマホの画面で困っている
    画面がまったく映らないときは、お悩み No.029「パソコンの電源を入れても画面が真っ暗。起動しないときにまず確かめること」を見てください。画面がちらつくときは、お悩み No.038「パソコンの画面がちらつく・ビリビリする。グラフィックの故障か、設定で直るか見分ける方法」にあります。スマホの明るさは、お悩み No.046「スマホの画面が急に暗くなる。勝手に明るさが変わる原因と調整のやり方」で説明しています。

    落とし穴

    明るさを調整するときに、つまずきやすい点があります。

    明るさのスライダーと夜間モードは別の設定
    夜間モードは画面の色を暖かい色にする機能で、明るさのスライダーとは別の設定です。夜間モードをオンにしても、スライダーで決めた明るさは変わりません。夜にまぶしいときは、夜間モードと明るさの両方を調整します。
    外付けモニターでは、Windows のスライダーが効かないことがある
    Windows のスライダーが出ない、または動かしても変わらないときは、モニター本体のボタンで調整します。Microsoft の省エネの推奨設定にある画面の明るさの設定も、外付けのディスプレイには使えないと書かれています。
    画面がまったく映らないのは、明るさの問題ではないことがある
    電源は入っているのに何も映らない場合は、明るさの設定ではなく、故障や接続の問題の可能性があります。明るさの調整を続けるより、No.029 の手順で確かめるか、メーカーに相談します。
    ドライバーは、公式の方法でだけ更新する
    Microsoft は、ドライバーを入手する最適な方法は Windows Update だと案内しています。メーカーのサイトから入手する場合も、Microsoft は「製造元の公式サイト以外の Web サイトからドライバーをダウンロードしないでください」と書いています。広告や見知らぬサイトで勧められる「ドライバー更新ツール」は使わないでください。
    夜間モードのスイッチが灰色で押せないことがある
    Microsoft の説明では、DisplayLink や基本ディスプレイなどのドライバーを使っていると、夜間モードを使えません。スイッチが灰色のときは、ディスプレイのドライバーを更新する必要がある場合があります。
    色や明るさを大きく変える設定は、写真の色の見え方にも影響する
    夜間モードがオンだと、画面全体が黄色っぽく見えます。表示内容に合わせる自動調整も、明るさとコントラストを変えます。写真の色を確かめたり、画像を編集したりするときは、これらをいったんオフにします。Microsoft も、色の正確さが大事な写真やビデオのアプリでは、設定を見直すよう案内しています。
    自動調整や省電力をオフにすると、バッテリーの持ちが短くなることがある
    Microsoft は、表示内容に合わせる自動調整をオフにすると、バッテリーの持ちが短くなる可能性があると書いています。バッテリーで長く使う日は、オフにする代わりに、充電器を持ち歩く方法もあります。
    項目の名前は、Windows のバージョンやページによって違う
    同じ機能でも、Microsoft のページによって「照明が変化したときに明るさを自動的に切り替える」「照明が変わったときに明るさを自動的に変更する」のように書き方が違います。Windows 10 では「照明が変化した場合に明るさを自動的に調整する」です。画面の表示と完全に同じでなくても、「照明」「明るさ」「自動」という言葉が入った項目を探します。

    公式情報で確かめたこと

    次のことを、Microsoft の公式サポートで確かめました。手順は Windows 11 を前提にしています。Windows 10 では、表示が多少違う場合があります。なお、Microsoft のページには、Windows 10 のサポートが2025年10月14日に終了したと書かれています。

    明るさの変え方と自動調整（Microsoft サポート「Windows でディスプレイの明るさと色を変更する」）
    Windows 11 では、タスク バーの右側にある「ネットワーク」アイコンを選び、「明るさ」のスライダーで調整します。「設定」→「システム」→「ディスプレイ」でも調整できます。照明の状態に合わせた自動調整は、「ディスプレイ」で「明るさ」を選んだ中にあり、PC によっては使えます。一部の Windows 11 PC では、「コンテンツに基づいて明るさを変更」で「オフ」「常に」「バッテリーのみの場合」を選べます。外付けモニターでは「明るさ」のスライダーが表示されない場合があり、モニターのボタンで変えると書かれています。Windows 10 では、「明るさと色」の「照明が変化した場合に明るさを自動的に調整する」のチェック ボックスです。スライダーが表示されない、または動作しないときは、デバイス マネージャーの「ディスプレイ アダプター」から「ドライバーの更新」を選ぶよう案内されています。
    夜間モード（同じページ）
    夜間モードは、夜に暖かく目に優しい色で表示する機能です。「設定」→「システム」→「ディスプレイ」→「夜間モード」で、「強度」のスライダーと「夜間モードのスケジュール」を設定します。スケジュールは「日没から朝まで」か「時間の設定」を選びます。DisplayLink や基本ディスプレイなどのドライバーでは使えず、スイッチが灰色ならドライバーの更新が必要な場合があると書かれています。
    クイック設定を開くキー（Microsoft サポート「Windows のキーボード ショートカット」）
    Windows キー + A は、「Windows 11 アクション センターを開きます」と書かれています。この記事では、このとき開く画面をクイック設定と呼んでいます。
    省電力と画面を消すまでの時間（Microsoft サポート「Windows 11 の電源設定」）
    省電力は「設定」→「システム」→「電源 & バッテリー」→「省電力」にあり、「バッテリー残量が少なくなると作動します。画面を暗くし、バックグラウンド プロセスを制限します」と書かれています。「省電力を使用するときに画面の明るさを下げる」設定についても書かれています。画面を消すまでの時間は「画面、スリープ、& 休止のタイムアウト」で選びます。
    省電力が始まる残量（Microsoft サポート「Windows のバッテリーを節約するためのヒント」）
    Windows 11 24H2 以降では、「省電力」を開いて「バッテリー レベルに達したら省電力を有効にする」の横で残量を選びます。「常に省電力機能を使用する」をオンにすると、すぐに省電力が働きます。通知領域の「バッテリー」アイコンから開くクイック設定にも、省電力機能のボタンがあります。「エネルギーに関する推奨事項」では、「すべて適用」で、画面の明るさなどの設定をまとめて変えられます。
    エネルギーに関する推奨事項（Microsoft サポート「エネルギーに関する推奨事項の詳細」）
    推奨事項には、「画面の明るさを設定する」、表示されるコンテンツの「画面のコントラストと明るさで電力を保存する」、「周囲の照明が変化したときに明るさを自動的に変更する」が含まれています。画面の明るさの設定は、外部ディスプレイにはまだ使えないと書かれています。
    電源モード（Microsoft サポート「Windows PCの電源モードを変更する」）
    「設定」→「システム」→「電源 & バッテリー」の「電源モード」で、「電源接続」と「バッテリー駆動」のそれぞれについて、「最高の電力効率」「バランス」「最高のパフォーマンス」から選びます。電源モードを変えられない場合は、「コントロール パネル」→「システムとセキュリティ」→「電源オプション」で「バランス」を選ぶよう書かれています。電源モードが画面の明るさにどう影響するかは、今回確かめた公式情報には書かれていませんでした。
    ドライバーの更新（Microsoft サポート「Windows のデバイス マネージャーを使用してドライバーを更新する」）
    「スタート」を右クリックして「デバイス マネージャー」を開き、デバイスを右クリックして「ドライバーの更新」→「ドライバー ソフトウェアの最新版を自動的に検索する」を選びます。見つからないときは「Windows Update で更新されたドライバーを検索する」を選びます。ドライバーを入手する最適な方法は Windows Update を使うことで、製造元の公式サイト以外からはダウンロードしないよう書かれています。

    ノートパソコンのキーボードにある明るさのキーについては、今回確かめた Microsoft のページには書かれていませんでした。キーの場所と押し方は、パソコンのメーカーの説明書で確かめてください。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. 画面が急に暗くなったり、まぶしくなったりする
    2. 明るさのつまみを動かすが、自動調整や省電力がまた明るさを変える
    3. 設定のせいだと気づかず、故障ではないかと不安になる
    4. 原因が分からないまま、見えにくい画面を我慢して使い続ける

    4のあと、また1に戻ります。

    この流れは、2のところで止められます。自動で明るさを変える機能を1つずつオフにして試せば、どの機能が働いていたかが分かります。原因が分かれば、3の不安も小さくなります。設定を見直しても直らないときに初めて、ドライバーや故障を疑えば十分です。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 画面の明るさの上限（日差しの下での見え方）
    • パソコンに明るさのセンサーがあるかどうか
    • 外付けモニターを Windows から調整できるかどうか
    • 設定の項目の名前や場所（Windows のバージョンで違う）
    • 画面や部品の故障

    変えやすいこと

    • スライダーとキーでの明るさの調整
    • 照明や表示内容に合わせる自動調整のオンとオフ
    • 省電力が始まる残量と、画面を暗くするかどうか
    • 夜間モードを自動でオンにする時刻
    • 公式の方法でのドライバーの更新
    • 電源モードの選択
    • 部屋の明かり、カーテン、座る位置、外で使う場所

    次の行動プランは3段階です。今日は、明るさのスライダーが効くかを確かめ、自動調整と夜間モードを見直し、暗いままなら再起動します。1週間で、省電力と電源モードを確かめ、ドライバーを更新し、夜間モードの時刻を決めます。1か月で、部屋の明るさや座る位置を整え、直らない場合はメーカーに相談します。

      • 明るさのスライダーで、明るさが変わるか確かめる

        1. Windows ロゴ キー + A を押して、クイック設定を開きます。タスク バーの右側にあるネットワークのアイコンを選んでも開きます。
        2. 太陽のマークが付いた「明るさ」のスライダーを、左右に動かします。
        3. 画面の明るさが、スライダーに合わせて変わるかを見ます。

        ノートパソコンなら、キーボードの太陽のマークのキーでも試します。反応しないときは、Fn キーを押しながら押してみます。

        スライダーが見当たらないときや、外付けモニターを使っているときは、モニター本体のボタンで明るさを変えます。

      • 明るさを自動で変える設定を、いったんオフにする

        1. 「スタート」→「設定」→「システム」→「ディスプレイ」を開きます。
        2. 「明るさ」の行を選んで、詳しい項目を開きます。
        3. 照明の変化に合わせて明るさを自動で変える項目があれば、チェックを外します。
        4. 「コンテンツに基づいて明るさを変更」があれば、「オフ」を選びます。
        5. スライダーで、今の部屋で見やすい明るさに合わせます。

        これらの項目は、パソコンによっては表示されません。表示されないパソコンには、その機能がありません。オフにしたあと、急に暗くなることがなくなれば、自動調整が原因だったと分かります。

      • 夜間モードがオンになっていないか確かめる

        「設定」→「システム」→「ディスプレイ」で、「夜間モード」のスイッチを見ます。昼間なのに画面が黄色っぽいときは、夜間モードがオンになっている可能性があります。今日はいったんオフにして、色と明るさの見え方を確かめます。

      • 暗いままなら、パソコンを再起動する

        作業中のファイルを保存してから、「スタート」→「電源」→「再起動」を選びます。再起動のあとにスライダーを動かして、明るさが変わるかをもう一度確かめます。

    2. 1週間の行動

      目安：設定の見直しに30分ほど、そのあとは暗くなったときに1分の記録

      • 省電力の設定を確かめる

        1. 「設定」→「システム」→「電源とバッテリー」を開きます。Microsoft のページでは「電源 & バッテリー」と書かれています。
        2. 「省電力」（「省エネ機能」と表示される場合もあります）を選んで、詳しい項目を開きます。
        3. 「バッテリー レベルに達したら省電力を有効にする」の横で、何％で働く設定かを見ます。
        4. 「常に省電力機能を使用する」がオンになっていないかを見ます。
        5. 「省電力を使用するときに画面の明るさを下げる」がオンかどうかを見ます。

        急に暗くなるのが、バッテリーの残量が減ったときだけなら、省電力が原因の可能性が高いです。暗くなるのが困る場合は、早めに充電器をつなぐか、画面の明るさを下げる設定をオフにします。オフにすると、バッテリーの持ちは短くなります。

      • 電源モードを「バランス」にしてみる

        1. 「設定」→「システム」→「電源とバッテリー」の「電源モード」を見ます。
        2. 「最高の電力効率」になっていたら、「バランス」に変えます。
        3. つまみを一番明るくしても暗いときは、「最高のパフォーマンス」も試します。

        電源モードは、パソコンのハードウェアやメーカーによっては選べないことがあります。電源モードを変えられないときは、「コントロール パネル」→「システムとセキュリティ」→「電源オプション」で「バランス」を選びます。

      • グラフィックドライバーを更新する

        まず、Windows Update で更新を確かめます。「設定」→「Windows Update」を開き、「更新プログラムのチェック」を選びます。Microsoft は、ドライバーを入手する最適な方法は Windows Update だと案内しています。

        続けて、デバイス マネージャーでも確かめます。

        1. 「スタート」を右クリックして、「デバイス マネージャー」を選びます。
        2. 「ディスプレイ アダプター」の横の矢印を選んで、中身を開きます。
        3. 表示された名前を右クリックして、「ドライバーの更新」を選びます。
        4. 「ドライバー ソフトウェアの最新版を自動的に検索する」を選びます。
        5. 見つからないときは、「Windows Update で更新されたドライバーを検索する」を選びます。
        6. 終わったら「閉じる」を選び、パソコンを再起動します。

        「ディスプレイ アダプター」の名前に「基本ディスプレイ」と入っているときは、そのパソコン用のドライバーが入っていない可能性があります。パソコンのメーカーの公式サポートページで、機種に合ったドライバーを確かめます。ドライバーを更新した直後から調子が悪くなった場合の戻し方は、お悩み No.038「パソコンの画面がちらつく・ビリビリする。グラフィックの故障か、設定で直るか見分ける方法」で説明しています。

      • 夜間モードを、決まった時刻に自動でオンにする

        1. 「設定」→「システム」→「ディスプレイ」→「夜間モード」を開きます。
        2. 「夜間モードのスケジュール」をオンにします。
        3. 「時間の設定」を選び、オンにする時刻を19時、オフにする時刻を朝7時のように入れます。「日没から朝まで」を選ぶこともできます。
        4. 「強度」のスライダーで、見やすい色の強さにします。

        夜間モードは色を変える機能です。夜にまだまぶしいときは、明るさのスライダーも下げます。

      • 暗い部屋で作業するときは、部屋の明かりをつける

        真っ暗な部屋で明るい画面を見ると、画面と部屋の明るさの差が大きくなり、まぶしく感じやすくなります。作業するときは部屋の明かりをつけて、差を小さくします。

      • 暗くなったときの状況をメモする

        画面が急に暗くなったら、時刻、充電器をつないでいたか、バッテリーの残量、部屋の明るさ、画面に何を映していたかをメモします。1週間分のメモがあると、どの機能が働いたかを絞りやすくなります。メーカーに相談するときにも役に立ちます。

    3. 1か月の見直し

      目安：1か月後に20〜30分ほど

      • 朝は、カーテンを開けてからパソコンを開く

        暗い部屋で画面を開くと、前の日の明るさのままでまぶしく感じます。カーテンを開けるか明かりをつけてから開くと、画面と部屋の明るさの差が小さくなります。

      • 画面から、腕一本分ほど離れて座る

        画面に顔を近づけすぎないようにします。画面に窓の光や照明が映り込むときは、画面の向きや座る位置を変えます。

      • 外で使うときは、明るさを一番明るくして日陰で使う

        日差しの下では、一番明るくしても読みにくいことがあります。日陰に移り、画面に日光が直接当たらない向きに座ります。明るくするとバッテリーの減りが早くなるので、残量に気をつけます。照明の変化に合わせる自動調整があるパソコンなら、外で使う日だけオンにする方法もあります。

      • 1か月のメモを見返す

        暗くなった場面に、共通する条件がないかを確かめます。

        • バッテリーの残量が減ったときに暗くなっていたなら、省電力の設定を見直します。
        • 部屋の明るさが変わったときに暗くなっていたなら、照明に合わせる自動調整を見直します。
        • 動画など、映す内容が変わったときに暗くなっていたなら、表示内容に合わせる自動調整を見直します。
        • 条件に関係なく暗くなり、ドライバーを更新しても直らないなら、次の項目に進みます。

      • 直らない場合は、メーカーの公式サポートで調べる

        パソコンのメーカーの公式サポートページで、機種名と「画面が暗い」で調べます。機種名は、パソコンの裏側のシールや購入時の書類で確かめます。メーカーに相談するときは、いつから起きているか、どんなときに暗くなるか、試したことを伝えます。1週間のメモが役に立ちます。

        画面がまったく映らないときは、お悩み No.029「パソコンの電源を入れても画面が真っ暗。起動しないときにまず確かめること」も見てください。

    手順の名前や画面の表示は、Windows のバージョンによって変わることがあります。分からないところは、Microsoft の公式サポートページで確かめてください。
