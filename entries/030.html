お悩み No.030 ・ 2026年11月23日公開

パソコンで日本語が変換できない。ひらがなのまま・カタカナになる・ブラウザだけおかしいときの直し方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    日本語入力のトラブルの多くは、入力モードが切り替わっていることや、ブラウザと日本語入力のソフトの連携が一時的にずれていることで起きます。どちらも、キーを1回押す、ブラウザを再起動する、といった操作で直ることがよくあります。設定を変えずに試せることが多いため、改善できる見込みがあります。

    原因は1つではありません。ブラウザだけで起きるのか、どのソフトでも起きるのかを分けると、確かめる場所を絞れます。設定を変える前に、まず切り替えキーと再起動で直るかを確かめるのが近道です。

    一方で、キーボードそのものが故障している場合は、自分では直せません。この記事の手順で切り分けても直らない場合は、キーボードやパソコンのメーカーの窓口に相談してください。修理や買い替えが必要かどうかは、窓口の診断をもとに決めます。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    漢字に変換できない
    ひらがなは出るのに、漢字に変換できない。ブラウザでだけ起きていて、メールソフトでは変換できる。タブをたくさん開いたまま使い続けていた。
    勝手にカタカナやローマ字になる
    別の日には、打った文字がカタカナになったり、ローマ字のまま出たりした。入力モードがどうなっているのか分からない。
    キーを押しても何も出ない
    キーボードのキーを押しても、何も出ないことがある。
    急ぎの仕事が進まない
    仕事のメールや書類を急いで打たなければいけないのに、日本語入力だけがおかしい。
    設定を触るのが不安
    設定をいじって余計に悪くしないか不安で、どこを触ればよいのか分からない。

    まず「どこで起きているか」を分ける

    日本語入力がおかしいときは、どこで起きているかによって、原因の見当がつきます。

    ブラウザだけでおかしい
    メールソフトやメモ帳では変換できる場合は、パソコン全体ではなく、ブラウザの側の問題の可能性が高いと考えられます。お悩みの「ブラウザでだけ起きている」という状況は、これに当たります。
    どのソフトでもおかしい
    入力モード、日本語入力のソフト、キーボードの配列など、パソコン全体の設定を確かめます。
    どのソフトでも、キーを押して何も出ない
    キーボードの接続や、キーボードそのものの問題のことがあります。

    ひらがなは出るのに漢字に変換できない原因

    文字を打つと、ブラウザと日本語入力のソフト（IME）のあいだで、やりとりが行われます。このやりとりが一時的にずれると、ひらがなは出るのに漢字に変換できない、という状態になることがあります。この場合は、ブラウザを再起動すると直ることがあります。

    タブをたくさん開いていることが直接の原因かどうかは、はっきりとは分かりません。ただ、ブラウザを再起動すると、ブラウザの状態がいったん初めからやり直しになります。設定を変えずに試せるので、最初に試す価値があります。

    打った文字がカタカナやローマ字になる原因

    打った文字がカタカナやローマ字のまま出る場合は、故障ではなく、入力モードが切り替わっているだけのことが多くあります。気づかないうちにキーを押してしまい、入力モードが変わるのがよくある原因です。マイクロソフトの案内をもとに、関係するキーをまとめました。

    半角／全角 キー
    日本語入力のオンとオフを切り替えます。オフになると、打った文字がローマ字（半角の英数字）のまま出ます。キーボードの左上、Esc キーの下あたりにあります。
    無変換 キー
    入力中の文字を、ひらがな、全角カタカナ、半角カタカナに切り替えます。スペースキーの左隣にあることが多いため、押し間違えやすいキーです。
    Shift + カタカナ ひらがな キー
    カタカナを入力するモードに切り替わります。
    F6〜F10 キー
    確定する前の文字を、F6 でひらがな、F7 で全角カタカナ、F8 で半角カタカナ、F9 で全角英数字、F10 で半角英数字に変換します。F7 を押してしまうと、カタカナになります。
    Windows + スペース キー
    パソコンに入っているキーボードの種類（日本語の Microsoft IME、英語のキーボード、Google 日本語入力など）を順番に切り替えます。英語のキーボードに切り替わると、日本語入力が使えなくなります。

    今の入力モードは、タスクバーの表示で分かる

    画面右下のタスクバーの、時計の近くに、今の入力モードが表示されます。Microsoft IME の場合、主な表示の意味は次のとおりです。

    • 「あ」：ひらがな（日本語入力がオン）
    • 「カ」：全角カタカナ
    • 「Ａ」：全角英数字
    • 「_ｶ」：半角カタカナ
    • 「A」：半角英数字（日本語入力がオフ）

    表示を右クリックすると、入力モードを選ぶメニューが出ます。メニューで「ひらがな」を選べば、「あ」に戻せます。表示の形は、Windows のバージョンや、使っている日本語入力のソフトによって違います。

    キーを押しても何も出ない原因

    文字を打つ場所が選ばれていない
    入力欄をクリックしていないと、キーを押しても文字は出ません。
    キーボードの接続が切れている
    USB の差し込みがゆるんでいる、ワイヤレスキーボードの電池が切れかけている、Bluetooth の接続が切れている、といった場合です。
    「フィルター キー」がオンになっている
    Windows には、短いキー入力や繰り返しの入力を無視する「フィルター キー」というアクセシビリティの機能があります。マイクロソフトの案内では、右の Shift キーを8秒間押し続けると、この機能のオンとオフが切り替わります。オンになると、キーを押しても文字が出ないように見えることがあります。
    キーボードそのものの故障
    別のキーボードでは問題なく打てる場合は、元のキーボードが故障している可能性があります。

    キーに書かれた文字と違う文字が出る原因

    キーボードの配列が英語配列になっている
    日本で売られているパソコンのキーボードは、多くが日本語配列です。Windows の設定が英語配列（英語キーボード）になっていると、記号のキーなどで、キーに書かれた文字と違う文字が出ます。たとえば、Shift キーを押しながら 2 を押すと、「"」ではなく「@」が出ます。
    「かな入力」になっている
    入力モードの表示を右クリックしたメニューで「かな入力」がオンになっていると、キーに書かれたひらがなが入力されます。たとえば A のキーを押すと、「ち」が出ます。

    日本語入力のソフトが替わっている

    Windows には、Microsoft IME という日本語入力のソフトが最初から入っています。Google 日本語入力など、別のソフトを入れて使っている人もいます。Windows + スペース キーなどで、使うソフトが切り替わっていることもあります。

    使っているソフトによって、キーの動きや設定の場所が変わります。設定を確かめるときは、先にどのソフトを使っているかを確かめます。確かめ方は、行動プランの「1週間の行動」に書いています。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 日本語入力がおかしくなり、原因が分からない
    2. 急いでいるので、あちこちのキーや設定を触る
    3. 入力モードや設定がさらに変わり、どこを直せばよいか分からなくなる
    4. 仕事が進まず、焦ってさらに触る

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。タスクバーの表示を見る、切り替えキーを押す、ブラウザを再起動する、パソコンを再起動する、という順番で確かめます。ここまでは設定を変えないので、元に戻せなくなる心配はほとんどありません。設定を変えるのは、それでも直らないときだけにします。

    画面の名前やボタンの場所、キーの位置は、パソコンの機種や Windows のバージョン、日本語入力のソフトによって違います。この記事で挙げる名前は一例です。分からないときは、メーカーやマイクロソフトのサポートページなど、公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • キーボードやパソコンの部品の故障
    • ブラウザや日本語入力のソフトの不具合そのもの
    • 機種ごとのキーの位置や割り当て
    • 設定画面の名前や作り

    変えやすいこと

    • タスクバーの入力モードの表示を見ること
    • 切り替えキーで入力モードを戻すこと
    • ブラウザやパソコンを再起動すること
    • キーボードの接続や電池を確かめること
    • 設定を変える前に、元の設定を控えておくこと
    • 困ったときの手順をメモにしておくこと

    次の行動プランは、今日「入力モードの確認」「切り替えキー」「再起動」「キーボードの接続の確認」から始め、1週間で切り替えキーに慣れて設定を1つずつ確かめ、1か月後に切り分けの手順をメモにまとめる順番にしています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、文字が正しく出るかを確かめます。

    ボタンの名前や場所、キーの位置は、パソコンの機種や Windows のバージョン、日本語入力のソフトによって違います。この記事の手順と画面が違うときは、メーカーやマイクロソフトのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：10〜20分。設定を変えずにできる確認から順に試します

      • 画面右下の入力モードの表示を確かめる

        • タスクバーの時計の近くに出ている「あ」や「A」の表示を見ます。
        • 「A」になっていたら、半角／全角 キーを1回押して「あ」に戻します。半角／全角 キーは、キーボードの左上、Esc キーの下あたりにあります。
        • 「カ」や「_ｶ」になっていたら、表示を右クリックして、メニューから「ひらがな」を選びます。
        • 「あ」や「A」の表示が見当たらないときは、Windows + スペース キーを押して、日本語の入力（Microsoft IME など）に切り替えます。押すたびに、入っているキーボードが順番に切り替わります。押しても何も変わらない場合は、キーボードが1種類しか入っていません。

      • カタカナになってしまった文字は、確定する前なら F6 キーでひらがなに戻す

        • 文字に下線がついている（まだ確定していない）状態なら、F6 キーを押すと、ひらがなに変換されます。そのあと、スペースキーで漢字に変換できます。
        • ノートパソコンでは、Fn キーと一緒に押す機種もあります。
        • 入力中に 無変換 キーを押すと、カタカナに切り替わります。スペースキーの左隣にあることが多いので、押し間違えに気をつけます。

      • ブラウザだけで変換できない場合は、ブラウザを再起動する

        • 再起動の前に、書きかけのメールや入力中の文章をコピーして、メモ帳などに貼り付けておきます。再起動すると、送信していない入力内容が消えることがあります。
        • Google Chrome では、アドレスバーに chrome://restart と入力して、Enter キーを押します。Chrome がいったん閉じて、開き直します。開いていたタブは、通常は元どおりに戻ります。シークレット ウィンドウのタブは戻りません。
        • Microsoft Edge では、アドレスバーに edge://restart と入力します。
        • アドレスバーに入力するときは、半角／全角 キーで「A」にしてから打ちます。「あ」のままだと、ひらがなが入力されます。
        • 再起動したら、ブラウザの入力欄で、漢字に変換できるかを確かめます。

      • それでも直らなければ、パソコンを再起動する

        保存していない書類やメールを保存してから、「スタート」→「電源」→「再起動」を選びます。再起動したら、ブラウザとメールソフトの両方で、変換できるかを確かめます。

      • キーを押しても何も出ない場合は、キーボードの接続を確かめる

        • まず、文字を打ちたい入力欄を一度クリックしてから打ちます。
        • USB でつなぐキーボードは、いったん抜いて、差し直します。別の USB の差し込み口に差してみる方法もあります。
        • ワイヤレスキーボードは、電池が切れかけていないかを確かめます。電源スイッチがある機種は、いったん切って入れ直します。USB に差す小さな受信機を使う機種は、受信機も差し直します。
        • Bluetooth でつなぐキーボードは、「設定」の「Bluetooth とデバイス」で、接続済みになっているかを確かめます。
        • 別のキーボードがあれば、つないで試します。ノートパソコンの場合は、外付けのキーボードをつなぐと確かめられます。別のキーボードで打てるなら、元のキーボードの問題の可能性が高いと考えられます。
        • 右の Shift キーを長く押したあとから打てなくなった場合は、「フィルター キー」がオンになっているかもしれません。「設定」→「アクセシビリティ」→「キーボード」で、「フィルター キー」がオフになっているかを確かめます。

    2. 1週間の行動

      目安：1日5分ほど。切り替えキーに慣れ、設定は1つずつ確かめます

      • 困ったら、まず 半角／全角 キーを押す習慣にする

        • 文字がおかしいと感じたら、まずタスクバーの表示を見て、半角／全角 キーを押します。
        • 入力モードがおかしくなったら、そのとき何のキーを押したか、表示が何になっていたかを、メモに残します。同じことが何度も起きる場合は、押し間違えやすいキーが分かります。

      • どの日本語入力のソフトを使っているかを確かめる

        • Windows 11 では、「設定」→「時刻と言語」→「言語と地域」の順に開きます。「日本語」の右の「…」から「言語のオプション」を選びます。
        • 「キーボード」の欄に、入っている日本語入力のソフトが並んでいます。Microsoft IME のほかに、Google 日本語入力などが並んでいる場合は、Windows + スペース キーで切り替わることがあります。

      • Microsoft IME の設定を開いて、今の状態を確かめる

        • 上の「言語のオプション」の「キーボード」の欄で、「Microsoft IME」の右の「…」から「キーボード オプション」を選びます。タスクバーの「あ」や「A」の表示を右クリックして、「設定」を選んでも開けます。
        • 「全般」で、予測入力（入力の途中で変換の候補を出す機能）などの設定が、自分の使い方に合っているかを確かめます。
        • 「キーとタッチのカスタマイズ」では、無変換 キーや 変換 キーに割り当てる機能を選べます。押し間違えでカタカナになることが多い場合は、無変換 キーの割り当てを見直す方法があります。
        • マイクロソフトの案内では、今のバージョンの Microsoft IME で問題が起きた場合に、以前のバージョンに戻す設定（「以前のバージョンの Microsoft IME を使う」）があります。ほかの手順で直らない場合に限って試し、効果がなければ元に戻します。
        • どの設定も、変える前に今の状態を写真に撮るかメモして、元に戻せるようにしておきます。

      • Google 日本語入力を使っている場合は、プロパティでキーの設定を確かめる

        • タスクバーの入力モードの表示を右クリックし、「プロパティ」を選びます。
        • 「一般」タブの「キー設定の選択」の横にある「編集」を押すと、キーごとの動き（コマンド）の一覧が出ます。
        • 一覧で 無変換 キー（一覧では「Muhenkan」）に、どのコマンドが割り当てられているかを確かめます。入力中にカタカナにするコマンドが割り当てられていると、押し間違えでカタカナになります。「確定」や「ひらがなに変換」などに変えると、意図しないカタカナ変換を防げる場合があります。
        • コマンドの名前は、Google 日本語入力のバージョンによって違う場合があります。変える前に今の設定を写真に撮っておき、分からないときは Google 日本語入力のヘルプで確かめます。

      • キーボードの配列が日本語配列になっているかを確かめる

        • 「設定」→「時刻と言語」→「言語と地域」の順に開き、「日本語」の右の「…」から「言語のオプション」を選びます。
        • 「キーボード レイアウト」が「日本語キーボード（106/109 キー）」になっているかを見ます。手元のキーボードが日本語配列なのに、英語キーボードになっている場合は、「レイアウトを変更する」から日本語キーボードを選びます。変更は、パソコンを再起動したあとに有効になります。
        • 「設定」→「時刻と言語」→「入力」→「キーボードの詳細設定」では、最初に使う入力方式（「既定の入力方式の上書き」）を選べます。日本語の入力方式、または「言語リストを使用します（推奨）」が選ばれているかを見ます。
        • 項目の名前は、Windows のバージョンによって違います。管理者ではないアカウントでは、変更できない項目もあります。

      • Windows Update とブラウザの更新を確かめる

        • 「設定」→「Windows Update」で、更新プログラムがあるかを確かめます。
        • ブラウザも新しい版にします。Chrome では、右上の「︙」のメニューから「ヘルプ」→「Google Chrome について」を開くと、更新を確かめられます。

        更新の途中で電源を切ってよいか迷うときは、お悩み No.020「パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？」も参考にしてください。

      • 使い終わったタブは閉じ、1日の終わりにブラウザを閉じる

        タブが原因かどうかははっきりしませんが、タブを開いたままにしないと、ブラウザが重くなるのを防げます。1週間続けて、変換できなくなることが減ったかを確かめます。

    3. 1か月の見直し

      目安：1か月後に20〜30分

      • 入力がおかしくなったときの切り分け手順をメモに残す

        1. タスクバーの入力モードの表示（「あ」「A」など）を見る
        2. 半角／全角 キーを押す。カタカナなどになっていたら、表示を右クリックして「ひらがな」を選ぶ
        3. ブラウザだけでおかしいなら、書きかけの文章を残してから、ブラウザを再起動する
        4. それでも直らなければ、パソコンを再起動する
        5. キーを押しても何も出ないなら、キーボードの接続と電池を確かめる

        紙に書いてパソコンの近くに置くか、スマホのメモに残しておきます。パソコンの調子が悪いときでも見られます。1か月のあいだのメモを見返し、どの手順で直ることが多かったかも書き足します。

      • よく使う単語や住所を、ユーザー辞書に登録する

        • よく使う単語や、名前・住所などを、短い読みで登録しておくと、変換が楽になります。
        • Microsoft IME では、入力モードの表示を右クリックして「単語の追加」を選ぶと登録できます。設定の「学習と辞書」から、登録した単語を確かめられます。
        • Google 日本語入力を使っている場合も、単語を登録できます。登録の方法は、Microsoft IME や Google 日本語入力の公式ヘルプで確かめてください。
        • 家族などと共用のパソコンでは、登録した住所や電話番号が、ほかの人の変換の候補に出ることがあります。登録する内容に気をつけます。

      • キーボードの調子が悪い日が続く場合は、接続を見直し、メーカーの窓口に相談する

        • 特定のキーだけ反応しない、押していないのに文字が続けて出る、といった症状が続くときは、電池や接続のしかたを見直します。
        • 別のキーボードでは問題なく打てるのに、元のキーボードでは直らない場合は、キーボードやパソコンのメーカーの窓口に相談します。
        • 窓口には、型番、いつから起きているか、どんな症状か、試したこと（再起動、差し直し、別のキーボードなど）を伝えます。保証期間が残っているかも確かめます。
        • キーボードの掃除は、取扱説明書の案内に沿って、表面だけにします。キーを外したり、分解したりはしません。

    まず今日、タスクバーの入力モードの表示を見て、「A」なら 半角／全角 キーで「あ」に戻します。ブラウザだけで変換できない場合は、書きかけの文章を残してから、chrome://restart でブラウザを再起動します。それでも直らなければ、パソコンを再起動します。キーを押しても何も出ない場合は、キーボードの差し直しや電池を確かめ、別のキーボードでも試します。次の1週間は、困ったら 半角／全角 キーを押す習慣をつけ、使っている日本語入力のソフト、キーの割り当て、キーボードの配列を、1つずつ確かめます。1か月後に、切り分けの手順をメモにまとめ、よく使う単語を辞書に登録します。キーボードの調子が悪い日が続くなら、メーカーの窓口に相談します。手順の名前や場所は、機種や Windows のバージョンで変わることがあります。分からないところは、メーカーやマイクロソフトのサポートページなど、公式のヘルプで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理や設定についての専門的な助言ではありません。特定の製品や修理、買い替えを勧めるものでもありません。

    設定の変更は、ご自身の判断と責任で行ってください。設定を変える前に、元の設定がどうなっていたかを、画面の写真やメモで控えておいてください。うまくいかなかったときに、元に戻せるようにするためです。

    日本語入力のソフトの設定を大きく変える場合は、一度にたくさん変えないでください。1つ変えるたびに、文字が正しく入力できるかを確かめます。そうすると、どの変更で症状が変わったのかを見分けられます。

    キーボードやパソコンを分解しないでください。故障の原因になるほか、メーカーの保証が受けられなくなる場合があります。

    パスワードや個人情報を、他人に見せないでください。パスワードや個人情報を入力するのは、公式アプリと公式サイトだけにします。

    「パソコンが壊れています」「ウイルスに感染しました」「今すぐ電話してください」という画面やメッセージが出ても、慌てて電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。表示された電話番号やリンクは使わず、メーカーやマイクロソフトの公式の窓口に、自分から連絡して確かめます。電話をかけてしまった、遠隔操作のアプリを入れてしまった、お金を払ってしまったという場合は、下の相談先に相談してください。
