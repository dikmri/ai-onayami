お悩み No.045 ・ 2026年11月23日公開

パソコンやスマホの画面をきれいに撮りたい。スクショと画面録画の簡単なやり方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    画面を画像に撮ることも、動画に録ることも、Windows やスマホに最初から入っている機能でできます。特別なソフトを買う必要はありません。撮り方と、撮った画像や動画の行き先の2つが分かれば、次からは迷わずに使えます。このため、改善できる見込みがあります。

    今は撮り方が分からないため、スマホのカメラでパソコンの画面を撮っています。カメラで撮ると、照明の映り込みや角度のずれが避けにくくなります。スクリーンショットなら、画面に表示されている内容がそのまま画像になります。

    Print Screen キーで「何も起きないように見える」のは、故障ではない可能性が高いです。Windows 10 などでは、Print Screen キーを押すと、画面全体の画像がクリップボードに入ります。クリップボードは、コピーした内容を一時的に置いておく場所です。画面には何も表示されないので、撮れたかどうかが分かりにくくなります。

    ボトルネックは、撮った画像が「どこに入ったか」を確かめる方法を知らないことです。クリップボードに入ったのか、フォルダーに保存されたのかが分かれば、貼り付けや送信まで進めます。

    この記事では、主に Windows 11 と Windows 10 の画面で手順を説明します。スマホは iPhone と Android（主に Google Pixel）の手順です。手順の名前や場所は一例で、パソコンやスマホの種類、Windows・iOS・Android のバージョンによって違うことがあります。分からないときは、使っている機種の説明書や、Microsoft、Apple、Google、メーカーのサポートページなど、公式のヘルプで確かめてください。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    スクリーンショットの撮り方が分からず、スマホのカメラで画面を撮っている
    パソコンの画面を人に伝えたいとき、スマホのカメラで画面を写真に撮って送っている。
    写真が反射したり斜めになったりして、見づらいと言われる
    画面の反射や角度のずれのせいで、相手に見づらいと言われることがある。
    Print Screen キーを押しても、何も起きないように見える
    キーを押してみたが、画面に変化がなく、どこに保存されたのかも分からない。
    仕事の手順を、画面録画で残したい
    仕事の手順を動画で残したいが、画面録画のやり方が分からない。
    録画に音声が入るかが気になって、試せない
    自分の声や周りの音まで入ってしまうのかが気になり、踏み出せない。

    うまく撮れない主な原因

    画面をきれいに撮れない原因は、大きく分けると次のようなものです。

    スクリーンショットの方法を知らないため、スマホのカメラで画面を撮っている
    カメラで画面を撮ると、照明の映り込みや角度のずれが写ります。画面に細かい縞模様が出ることもあります。スクリーンショットは画面の表示をそのまま画像にするので、こうしたことは起きません。
    Print Screen キーを押しても画面に変化がなく、撮れたかどうかも保存先も分かりにくい
    Microsoft によると、Windows 10 の Print Screen キーは、画面全体のスクリーンショットを撮ってクリップボードにコピーするキーです。ファイルとしては保存されず、画面にも何も表示されません。ペイントなどに貼り付けて、初めて撮れていたことが分かります。Windows 11 では、Print Screen キーを押すと、撮る範囲を選ぶ画面が開くのが既定の動作です。ただし、設定でこの動作をオフにしていると、Windows 10 と同じ動きになります。ノートパソコンでは、Fn キーと一緒に押さないと、Print Screen キーとして働かない機種もあります。
    Windows の画面キャプチャは、無料の標準機能でできるのに、その存在が知られていない
    Windows には、画面を撮るための「Snipping Tool」というアプリが最初から入っています。Windows + Shift + S を押すと、撮る範囲を選ぶ画面が開き、画面の一部や全体を撮れます。料金はかかりません。
    画面録画も標準機能でできるが、音声が入るかどうかや保存先が分からず不安
    Windows では、「Xbox Game Bar」（ゲームバー）という標準の機能で、アプリの画面を録画できます。Microsoft によると、Windows + Alt + R で録画が始まり、もう一度押すと止まります。動画は「ビデオ」フォルダーの「キャプチャ」フォルダーに、MP4 ファイルで保存されます。録画中は、Windows + Alt + M でマイクのオンとオフを切り替えられます。Windows 11 では、Snipping Tool でも画面録画ができます。
    スマホでは、スクリーンショットや画面録画の操作が機種によって違う
    iPhone は、Face ID のある機種とホームボタンのある機種で、押すボタンが違います。Android は、多くの機種で電源ボタンと音量を下げるボタンを同時に押しますが、ほかの方法がある機種もあります。画面録画のボタンは、iPhone ではコントロールセンターに、Android ではクイック設定にあります。最初は表示されていないこともあります。

    どこが原因かを切り分ける方法

    次の順番で試すと、撮れていないのか、撮れているのに行き先が分からないだけなのかを切り分けられます。具体的な手順は、行動プランで説明します。

    まず Windows + Shift + S を押して、画面の一部を撮れるか試す
    画面が少し暗くなり、上のほうに撮り方を選ぶボタンが出れば、撮影の機能は動いています。撮りたい部分をドラッグして囲みます。
    撮った画像を、ペイントやメールに貼り付けてみる
    撮った画像はクリップボードに入ります。ペイントを開いて Ctrl + V を押し、画像が出れば撮れています。
    Print Screen キーだけを押して、ペイントに貼り付けてみる
    画面に変化がなくても、ペイントに画面全体の画像が貼り付けられれば、Print Screen キーは働いています。何も貼り付けられない場合は、Fn キーと一緒に押してみます。それでも撮れない場合は、キー自体が反応していない可能性があります。
    Windows + Alt + R で録画を始めて、保存先を確かめる
    録画したいアプリの画面を開いてから押します。数秒録画して止め、「ビデオ」フォルダーの「キャプチャ」に動画があるかを見ます。デスクトップやエクスプローラーの画面では、ゲームバーで録画できないことがあります。
    スマホでは、ボタンの同時押しでスクリーンショットが撮れるか試す
    撮れたら、写真アプリやギャラリーのアプリに、画像が入っているかを確かめます。

    直る見込み

    標準の機能だけで、撮る・録る・保存先を確かめるところまでできる
    Windows の Snipping Tool とゲームバー、スマホのスクリーンショットと画面録画は、どれも最初から入っている機能です。
    特別なソフトを買わなくても、画面をきれいに残せる
    スクリーンショットは、画面の表示をそのまま画像にします。反射や斜めの写り込みがなくなるので、相手も見やすくなります。
    保存先と貼り付けの流れが分かれば、次から迷わない
    「撮る」「クリップボードやフォルダーに入る」「貼り付ける・送る」の流れを一度通せば、次からも同じ手順で使えます。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 画面を人に伝えたいが、スクリーンショットの撮り方が分からない
    2. スマホのカメラでパソコンの画面を撮って送る
    3. 反射や斜めの写り込みで、相手に見づらいと言われる
    4. Print Screen キーを試しても何も起きないように見え、撮り方を調べるのをあきらめる

    4のあと、また1に戻ります。

    この循環は、4のところで止められます。Print Screen キーを押したら、ペイントに貼り付けてみます。画像が出れば、撮れていたことが分かります。Windows + Shift + S なら、撮る範囲を自分で選べるので、撮れたかどうかが分かりやすくなります。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • パソコンやスマホの種類と、Windows・iOS・Android のバージョン
    • アップデートで、Snipping Tool やゲームバーの画面が変わること
    • ノートパソコンのキーの配置（Print Screen キーの場所や、Fn キーが必要かどうか）
    • 一部のアプリや動画で、録画が許可されていないこと
    • キーボードやパソコン本体の故障

    変えやすいこと

    • 画面を撮る方法（Windows + Shift + S や Print Screen キー）
    • 撮った画像を貼り付ける先
    • 保存するフォルダーと、ファイルの名前
    • Print Screen キーを押したときの動作の設定
    • クリップボードの履歴の設定
    • 録画のときのマイクのオンとオフ
    • 録画する範囲と長さ
    • 送る前に、写り込みを確かめる習慣

    次の行動プランは3段階です。今日は、Windows + Shift + S と Print Screen キーで画面を撮ってペイントに貼り付け、Windows + Alt + R で短い録画を試し、スマホでもスクリーンショットを撮ります。1週間で、Snipping Tool の撮り方を増やし、クリップボードの履歴をオンにし、録画の前にマイクを確かめる習慣をつけます。1か月後に、よく使う撮り方を1つに決め、Print Screen キーの設定を整え、仕事で使う動画を短く試します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。今日の手順は、急ぎの仕事がないときに、練習のつもりで行います。

    設定やボタンの名前と場所は、パソコンやスマホの種類、Windows・iOS・Android のバージョンによって違うことがあります。この記事の手順と画面が違うときは、使っている機種の説明書や、Microsoft、Apple、Google、メーカーのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分ほど。お金はかかりません

      • Windows + Shift + S で、画面の一部を撮ってみる

        • Windows は、Windows のロゴが書かれたキーです。Windows と Shift を押したまま、S を押します。
        • 画面が少し暗くなり、画面の上のほうに撮り方を選ぶボタンが出ます。Windows 11 では、「四角形」「ウィンドウ」「全画面表示」「フリーフォーム」などから選べます。最初は「四角形」のまま使います。
        • 撮りたい部分を、マウスで左上から右下へドラッグして囲みます。ボタンを離すと撮れます。
        • 撮った画像はクリップボードに入ります。画面の右下に通知が出ることがあり、通知を押すと Snipping Tool が開きます。Snipping Tool では、画像に印を付けたり、保存したりできます。
        • Microsoft によると、Windows 11 の Snipping Tool では、撮った画像がスクリーンショットのフォルダーにも自動で保存されます。多くの場合、「ピクチャ」フォルダーの中の「スクリーンショット」フォルダーです。自動で保存するかどうかは、Snipping Tool の設定で変えられます。

      • 撮った画像を、ペイントやメールに貼り付けてみる

        • スタートボタンを押して「ペイント」と入力し、ペイントを開きます。
        • Ctrl + V を押すと、撮った画像が貼り付けられます。
        • 保存するときは、Ctrl + S を押し、保存する場所とファイル名を決めて「保存」を押します。ファイルの種類は PNG を選ぶと、画面の文字がくっきり残ります。
        • Word やメール、チャットの入力欄でも、多くの場合は Ctrl + V で同じように貼り付けられます。

      • 画面全体を撮るときは、Print Screen キーを使う

        • Print Screen キーは、キーボードの右上のほうにあることが多いキーです。「PrtSc」「PrtScn」「Prt Sc」などと書かれています。
        • Windows 10 では、Print Screen キーを押すと、画面全体の画像がクリップボードに入ります。画面には何も表示されません。ペイントを開いて Ctrl + V を押すと、撮れていたかを確かめられます。
        • Windows 11 では、多くの場合、Print Screen キーを押すと、Windows + Shift + S と同じ撮影の画面が開きます。画面全体を撮りたいときは、「全画面表示」を選びます。
        • 画面全体をすぐにファイルとして保存したいときは、Windows + PrtScn を押します。Microsoft によると、画像は「ピクチャ」フォルダーの中の「スクリーンショット」フォルダーに保存されます。
        • 開いているウィンドウだけを撮りたいときは、そのウィンドウを1回クリックしてから、Alt + PrtScn を押します。画像はクリップボードに入ります。
        • ノートパソコンでは、Fn キーを押したまま Print Screen キーを押さないと撮れない機種があります。Print Screen キーに2つの文字が書かれている場合は、Fn キーと一緒に押してみます。
        • 撮った画像の場所が分からないときは、エクスプローラーを開き、左のメニューの「ピクチャ」から「スクリーンショット」フォルダーを開きます。OneDrive を使っている場合は、OneDrive のフォルダーの中に「スクリーンショット」フォルダーがあることもあります。ファイルの探し方は、お悩み No.041「ダウンロードしたファイルが見つからない。保存場所の探し方と、もう迷わない整理のコツ」も参考にしてください。

      • Windows + Alt + R で、10秒ほどの画面録画を試す

        • 録画したいアプリ（ブラウザや Excel など）を開き、そのウィンドウを1回クリックしておきます。Microsoft の手順でも、録画したいゲームやアプリの画面に移ってから録画を始めるよう案内されています。
        • 声を入れたくない場合は、録画の前に Windows + G を押してゲームバーを開き、「キャプチャ」の小さな画面にあるマイクのボタンがオフになっているかを確かめます。
        • Windows + Alt + R を押すと、録画が始まります。画面の端に、録画の時間を示す小さな表示が出ます。
        • 10秒ほど操作したら、もう一度 Windows + Alt + R を押して止めます。
        • エクスプローラーで「ビデオ」フォルダーの中の「キャプチャ」フォルダーを開きます。Microsoft によると、動画は MP4 ファイルで保存され、ファイル名にはアプリの名前と録画した日時が入ります。動画を再生して、映り方と音を確かめます。
        • 押しても何も起きない場合は、ゲームバーが使えない設定になっている可能性があります。Windows 11 では、「設定」の検索欄に「xbox」と入力し、「Xbox Game Bar を有効にする」の項目を開いて、オンになっているかを確かめます。
        • デスクトップやエクスプローラーの画面を開いているときは、ゲームバーで録画できないことがあります。デスクトップも含めて録画したい場合は、1週間の行動で説明する Snipping Tool の録画（Windows 11）を使います。

      • スマホで、スクリーンショットを1回撮ってみる

        • Face ID のある iPhone は、サイドボタンと音量を上げるボタンを同時に押して、すぐに離します。
        • ホームボタンのある iPhone は、サイドボタン（またはトップボタン）とホームボタンを同時に押して、すぐに離します。
        • Android は、多くの機種で、電源ボタンと音量を下げるボタンを同時に押します。うまくいかない場合は、電源ボタンを数秒間長押しして、「スクリーンショット」をタップする方法もあります。
        • iPhone では、写真アプリの「コレクション」→「メディアタイプ」→「スクリーンショット」で、撮った画像を確かめます。
        • Android では、Google フォトの「コレクション」→「このデバイス上」→「スクリーンショット」で確かめます。Google フォトがない機種では、ギャラリーのアプリの「スクリーンショット」のフォルダーを見ます。

      • Mac を使っている場合は、Shift + Command のキーで撮る

        • Apple によると、Shift + Command + 3 で画面全体を、Shift + Command + 4 で画面の一部を撮れます。
        • Shift + Command + 5 を押すと、スクリーンショットアプリが開きます。ここからは画面の収録もできます。
        • 撮った画像は、最初の設定ではデスクトップに保存されます。

    2. 1週間の行動

      目安：1回10〜20分ほどを、1週間のうちに数回

      • Snipping Tool を開いて、撮り方を増やす

        • スタートボタンを押して「Snipping Tool」と入力し、開きます。Windows 10 では、「切り取り & スケッチ」という名前のアプリが入っていることもあります。
        • 撮り方を選ぶボタンで、「四角形」「ウィンドウ」「全画面表示」「フリーフォーム」を選べます。「ウィンドウ」を選ぶと、開いているウィンドウだけをきれいな四角で撮れます。
        • メニューを開いた状態を撮りたいときは、タイマーを使います。Microsoft によると、Windows 11 では「遅延」で「5 秒」などを選び、撮り方を選んでから「新規」を押すと、カウントダウンが始まります。その間にメニューを開いておきます。
        • 撮った画像には、Snipping Tool のペンなどで印を付けられます。相手に見てほしい場所を丸で囲むと、伝わりやすくなります。

      • クリップボードの履歴をオンにする

        • Windows + V を押します。Microsoft によると、クリップボードの履歴は、最初はオフになっています。表示された案内からオンにします。
        • 「設定」→「システム」→「クリップボード」で、「クリップボードの履歴」をオンにする方法もあります。
        • オンにすると、続けて何枚か撮っても、Windows + V で前に撮った画像を選んで貼り付けられます。
        • 履歴には、コピーした文字も残ります。パスワードなどをコピーした場合は、履歴の一覧から消しておきます。

      • 録画の前に、マイクと音の設定を確かめる

        • ゲームバーで録画している間は、Windows + Alt + M でマイクのオンとオフを切り替えられます。
        • 録画を始める前に Windows + G を押し、「キャプチャ」の小さな画面のマイクのボタンで、マイクの状態を確かめます。自分の声を入れたくないときは、オフにします。
        • マイクをオフにしても、パソコンから出る音（動画の音や通知の音）は録音されることがあります。録画の前に、ほかのアプリの音や通知が鳴らないようにしておきます。
        • Windows 11 では、「設定」→「ゲーム」→「キャプチャ」で、録画のときに音を録音するかどうかなどの設定を見直せます。
        • 録り終えたら、動画を再生して、音が入っているかを確かめます。

      • Windows 11 では、Snipping Tool で画面の一部を録画する

        • Microsoft によると、Windows + Shift + R を押すと、録画する範囲を選ぶ画面が開きます。Snipping Tool を開いて「録画」のボタンを選び、「新規」を押す方法もあります。
        • 録画したい範囲をドラッグして囲み、「開始」を押します。終わったら「停止」を押します。
        • 選んだ範囲をそのまま録画するので、デスクトップやエクスプローラーの操作も録画できます。
        • Snipping Tool のバージョンによっては、録画の前に、マイクやパソコンの音を入れるかどうかを選ぶボタンが表示されます。「開始」を押す前に確かめます。
        • 録画したあとは、Snipping Tool の画面で保存できます。保存先が分からないときは、Snipping Tool の設定で確かめます。
        • Microsoft は、Windows 10 では Clipchamp というアプリで画面を録画する方法も案内しています。

      • スマホで、画面録画を1回試す

        • iPhone では、画面の右上から下にスワイプしてコントロールセンターを開き、録画のボタンをタップします。ホームボタンのある iPhone は、画面の下から上にスワイプします。3秒のカウントダウンのあと、録画が始まります。
        • iPhone で止めるときは、画面上部の録画中の表示をタップして、停止をタップします。録画した動画は、写真アプリに入ります。
        • iPhone で自分の声も入れたいときは、録画のボタンを長押しして、マイクのボタンをオンにします。声を入れたくないときは、同じ画面でマイクがオフになっているかを確かめます。
        • 録画のボタンがない場合は、コントロールセンターに「画面収録」を追加します。追加の方法は iOS のバージョンで違うので、Apple のヘルプで確かめてください。
        • Android では、画面の上から下に2回スワイプしてクイック設定を開き、「スクリーン レコード」をタップします。録画する対象と、音声を録音するかどうかを選んで、「開始」をタップします。
        • Android で止めるときは、画面の上から下にスワイプして、スクリーン レコーダーの通知をタップします。録画した動画は、Google フォトの「コレクション」→「このデバイス上」→「映画」で確かめられます。アイコンや名前は機種によって違います。

      • 撮った画像を、フォルダーに分けて保存する

        • 「ピクチャ」フォルダーの中に、「仕事の手順」「問い合わせ用」など、使い道ごとのフォルダーを作ります。
        • 残しておく画像は、「2026-11-23_経費精算の画面.png」のように、日付と内容が分かる名前に付け直します。
        • 送ったあとで要らなくなった画像は、消しておきます。

    3. 1か月の見直し

      目安：1か月後に20〜30分ほど

      • よく使う撮り方を1つ決めて、ショートカットを覚える

        • 1か月の間にいちばんよく使った撮り方を1つ選び、ふだんはその方法を使います。
        • 迷ったら、Windows では Windows + Shift + S を基本にします。範囲を選べて、画面の一部も全体も撮れます。
        • ショートカットを紙に書いて、モニターの横に貼っておくと、思い出しやすくなります。

      • Print Screen キーを押すと、撮影の画面が開くようにする

        • Windows 11 では、最初からこの設定がオンになっていることが多いです。確かめるときは、「設定」→「アクセシビリティ」→「キーボード」を開き、Print Screen キーで画面の切り取りを開く項目がオンかを見ます。項目の名前は、Windows のバージョンによって少し違います。
        • Windows 10 では、「設定」→「簡単操作」→「キーボード」を開き、「Print Screen のショートカット」の下のスイッチをオンにします。
        • オンにすると、Print Screen キー1つで、範囲を選んで撮る画面が開きます。

      • 仕事の手順を共有する動画は、短く試してから使う

        • 本番の前に、30秒ほどの短い動画を撮って、相手に見てもらいます。
        • 文字が小さすぎないか、音声が聞き取れるか、余計なものが映っていないかを確かめます。
        • 長い手順は、1つの長い動画にするより、手順ごとの短い動画に分けると、相手が見返しやすくなります。
        • 動画のファイルが大きくて送れない場合は、お悩み No.039「スマホで撮った写真・動画を送ると画質が落ちる。重い動画もきれいなまま届ける方法」も参考にしてください。
        • 職場によっては、画面録画や動画の共有に決まりがあります。仕事で使う前に、職場のルールを確かめます。

      • 大きなアップデートの後は、撮り方を1回試す

        • Windows や iOS、Android の大きなアップデートの後は、Snipping Tool やゲームバー、スマホの録画のボタンの場所や動きが変わることがあります。
        • アップデートの後に、スクリーンショットと短い録画を1回ずつ試し、保存先が変わっていないかを確かめます。

    まず今日、Windows + Shift + S で画面の一部を撮って、ペイントに貼り付けます。Print Screen キーも押して、ペイントに貼り付けて確かめます。Windows + Alt + R で10秒ほど録画し、「ビデオ」フォルダーの「キャプチャ」に動画があるかを見ます。スマホでも、ボタンの同時押しでスクリーンショットを撮ります。次の1週間で、Snipping Tool の撮り方とタイマーを試し、クリップボードの履歴をオンにし、録画の前にマイクを確かめます。スマホの画面録画も1回試します。1か月後に、よく使う撮り方を1つに決め、Print Screen キーの設定を整え、仕事で使う動画を短く試してから使います。手順の名前や場所は、パソコンやスマホの種類やバージョンで変わることがあります。分からないところは、使っている機種の説明書や、公式のヘルプで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンやスマホの修理や、法律についての専門的な助言ではありません。特定の製品やアプリを勧めるものでもありません。設定の変更は、ご自身の判断と責任で行ってください。

    画面録画やスクリーンショットに、他人の著作物（動画、音楽、有料の記事や画像など）や、他人の個人情報を映し込まないでください。撮った画像や動画を人に送ったり公開したりすると、著作権やプライバシーの問題になることがあります。

    画面録画で音声を入れるときは、周りの人の声や、オンライン会議の相手の声が入らないように気をつけてください。他人の声が入る録画をするときは、事前に相手の了解を得てください。

    撮った画像や動画を送る前に、写り込んだ個人情報がないかを確かめてください。たとえば、住所、氏名、電話番号、メールアドレス、パスワード、画面に出た通知のメッセージ、ブラウザのタブの名前などです。見せたくない部分は、送る前に切り取るか、ペンで塗りつぶしてください。蛍光ペンは下の文字が透けて見えることがあります。

    よく分からない「画面を撮る」アプリや、「パソコンを速くする」とうたうソフトを入れて、直そうとしないでください。不要なアプリや悪意のあるプログラムが入ったり、高額な料金を求められたりするおそれがあります。アプリを新しく入れる場合は、Microsoft Store や App Store、Google Play などの公式のストアから入れ、提供元を確かめてください。

    「ウイルスに感染しました」「今すぐ電話してください」という画面が出ても、表示された電話番号には電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。サポートを名乗る人に、画面を見せたり、遠隔操作のソフトを入れたりしないでください。

    Print Screen キーやほかのキーを押しても反応しない、画面が映らない、パソコンが何度も固まる、といった場合は、パソコン本体やキーボードが故障している可能性があります。パソコンを自分で分解せず、メーカーのサポートや、パソコンを買ったお店、修理店に相談してください。キーが反応しない場合は、お悩み No.035「パソコンのキーボードの一部のキーが反応しない。打てないときの切り分けと直し方」も参考にしてください。

    困ったときは、一人で抱え込まずに、家族や職場の人にも相談してください。
