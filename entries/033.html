お悩み No.033 ・ 2026年11月23日公開

パソコンにログインできない。パスワードやPINを忘れたときの対処法

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    パスワードが通らない原因は、パスワードを忘れたことだけではありません。キーボードの状態が変わっていたり、別のアカウントのパスワードを入れていたりしても、同じように「間違っています」と表示されます。これらは、初期化しなくても自分で確かめられます。また、Microsoft アカウントでサインインしている場合は、パスワードをインターネット経由でリセットできます。このため、改善できる見込みがあります。

    近道は、次の2つを最初に確かめることです。1つめは、パソコンに入るときに使っているのが「Microsoft アカウント」か、パソコン本体だけの「ローカルアカウント」かです。2つめは、スマホなど別のデバイスから、同じ Microsoft アカウントに入れるかです。別のデバイスから入れるなら、パスワード自体は正しいと分かります。その場合は、パソコン側の入力や設定の問題の可能性が高いと考えられます。

    初期化は最後の手段です。初期化の方法によっては、パソコンの中の写真や書類がすべて消えます。消えたデータは、バックアップがなければ戻せません。リセットや確認の手順を試す前に初期化するのは避けます。

    一方で、ローカルアカウントを使っていて、リセットの手段（セキュリティの質問やパスワード リセット ディスク）を用意していなかった場合は、回復が難しくなります。Microsoft も公式のヘルプで、案内している方法で解決しない場合は、パスワードの取得や回避を手伝えないと書いています。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    パスワードが通らない
    いつも使っているはずのパスワードを入れても、「間違っています」と表示されて先に進めない。
    PINの入力欄が出てこない
    PINを設定していたはずなのに、PINの入力欄が出てこないことがある。
    初期化への不安
    パソコンの中に写真や大事な書類が入っている。初期化したら全部消えてしまうのではと不安に思っている。
    保存したパスワードの場所が分からない
    ブラウザにパスワードを保存してあった気がするが、どこを見ればいいのか分からない。
    何から試せばいいか分からない
    どうすればまた使えるようになるのか、手順が分からない。

    パスワードが通らない・PINが使えない主な原因

    Windows の画面では、ログインのことを「サインイン」と表示します。この記事でも、画面の説明では「サインイン」と書きます。

    Microsoft アカウントとローカルアカウントの取り違え
    Windows のパソコンに入るためのアカウントには、主に2つの種類があります。「Microsoft アカウント」は、Outlook.com や OneDrive などと共通のアカウントで、メールアドレスとパスワードでサインインします。「ローカルアカウント」は、そのパソコンの中だけで使うアカウントです。どちらを使っているかを取り違えると、別のアカウントのパスワードを入れてしまうことがあります。たとえば、Microsoft アカウントでサインインしているのに、以前にパソコン用に決めた別のパスワードを入れている、といった場合です。
    Caps Lock がオンになっている
    パスワードは、大文字と小文字を区別します。Caps Lock がオンになっていると、大文字と小文字が入れ替わって入力されます。日本語配列のキーボードでは、Shift キーを押しながら「Caps Lock」のキー（「英数」とも書かれています）を押すと、オンとオフが切り替わります。気づかないうちにこの組み合わせを押していることがあります。
    Num Lock の状態が違う
    キーボードの右側にある数字のキー（テンキー）は、Num Lock がオフだと数字を入力できません。また、ノートパソコンには、Num Lock がオンになると、一部の文字のキーで数字が入力される機種があります。どちらの場合も、入力したつもりの文字と違う文字が入ります。
    全角入力になっている
    全角の英数字は、半角の英数字とは別の文字として扱われます。入力が全角になっていると、見た目が同じでも、パスワードとは違う文字が入ることがあります。
    キーボードの配列が違う
    日本語配列のキーボードと英語配列のキーボードでは、記号の位置が違います。たとえば「@」は、日本語配列では P の右隣のキーで入力しますが、英語配列では Shift キーと 2 のキーで入力します。Windows がキーボードの配列を実際と違うものとして扱っていると、記号を含むパスワードが通らなくなることがあります。
    PIN とパスワードは別のもの
    PIN は、そのパソコンでサインインするときに使う暗証番号で、パスワードとは別のものです。PIN を忘れたときは、パスワードでサインインしてから、PIN を作り直します。Microsoft アカウントの場合は、サインイン画面の「PIN を忘れた場合」から作り直すこともできます。Microsoft の公式のヘルプによると、「PIN を忘れた場合」はローカルアカウントでは使えません。
    PIN の入力欄が出てこない
    理由はいくつか考えられ、お悩みの文章からは特定できません。サインイン画面の「サインイン オプション」から、PIN とパスワードのどちらで入力するかを切り替えられる場合があります。
    Microsoft アカウントは、インターネット経由でリセットできる
    Microsoft アカウントのパスワードは、Microsoft のサイトからリセットできます。登録したメールアドレスや電話番号に確認コードが届き、そのコードで本人だと確かめてから、新しいパスワードを決めます。パソコンに入れなくても、スマホのブラウザから手続きできます。
    ローカルアカウントは、オンラインでリセットできない
    ローカルアカウントのパスワードは、Microsoft のサイトからはリセットできません。リセットするには、アカウントを作ったときに設定したセキュリティの質問に答えるか、事前に作ったパスワード リセット ディスクを使います。パソコンにほかの管理者のアカウントがあれば、そのアカウントからパスワードを設定し直せる場合もあります。どれも使えない場合について、Microsoft は、パソコンを初期化する必要があると案内しています。
    ブラウザに保存したパスワード
    Edge や Chrome に保存したパスワードは、同じアカウントでサインインしている別のパソコンやスマホから確認できる場合があります。ブラウザに保存されているのは、ウェブサイトで使ったパスワードです。たとえば、Outlook.com などの Microsoft のサイトにサインインしたときに保存していれば、Microsoft アカウントのパスワードが見つかることがあります。パソコン本体だけのパスワード（ローカルアカウントのパスワード）は、ふつうはブラウザに保存されていません。

    「どちらのアカウントか」「別のデバイスから入れるか」で原因を絞れる

    原因の候補が多いため、まず2つのことを確かめます。結果によって、次のように見当をつけられます。

    Microsoft アカウントで、別のデバイスからは入れる
    パスワード自体は正しいと考えられます。Caps Lock、Num Lock、全角入力、キーボードの配列など、パソコン側の入力を確かめます。最近ほかのデバイスでパスワードを変えた場合は、パソコンがインターネットにつながっていないと、新しいパスワードが通らないことがあります。
    Microsoft アカウントで、別のデバイスからも入れない
    パスワードを忘れているか、別のパスワードと思い違いをしている可能性があります。ブラウザに保存したパスワードを確かめ、見つからなければ Microsoft のサイトからリセットします。
    ローカルアカウントの場合
    オンラインではリセットできません。セキュリティの質問、パスワード リセット ディスク、ほかの管理者のアカウントの順に、使える手段がないかを確かめます。
    どちらのアカウントか分からない
    次のことが手がかりになります。
    • サインイン画面で、名前の下にメールアドレスが表示されている場合は、Microsoft アカウントの可能性が高いと考えられます。ただし、メールアドレスを表示しない設定になっていることもあります。
    • 「PIN を忘れた場合」や「パスワードを忘れた場合」を選んだときに、メールアドレスや確認コードの画面が出る場合も、Microsoft アカウントの可能性が高いと考えられます。
    • パソコンを使い始めたときにメールアドレスを入力した覚えがあるか、同じメールアドレスで OneDrive や Outlook を使っているかも、手がかりになります。

    初期化の前に試す順番

    次の順番で試します。上ほど手間が少なく、データが消える心配もありません。

    1. キーボードの状態を確かめて、パスワードを表示しながらゆっくり打ち直す
    2. パソコンを再起動して、もう一度試す
    3. 「サインイン オプション」で、PIN とパスワードを切り替える
    4. 別のデバイスから、同じ Microsoft アカウントに入れるかを確かめる
    5. ブラウザに保存したパスワードを確かめる
    6. Microsoft アカウントならパスワードをリセットする。ローカルアカウントならセキュリティの質問などを使う

    ここまで試しても入れない場合は、パソコンのメーカーのサポート窓口に相談します。初期化を考えるのは、そのあとです。窓口では、初期化の前にデータだけでも取り出せないかを相談します。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. パスワードが通らない
    2. 原因を確かめないまま、思いつくパスワードを何度も入れる
    3. それでも通らず、「初期化するしかないのでは」と不安になる
    4. 不安で手が止まり、時間をおいてまた試すが、やはり通らない

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。思いつくパスワードを入れ続ける前に、キーボードの状態と、別のデバイスから入れるかを確かめます。それが分かると、次に試すことが決まります。また、何度も続けて間違えると、しばらく入力できなくなる場合があります。1回ずつ確かめながら入力するほうが、結果として早く入れることがあります。

    この記事で挙げる画面の名前やボタンの場所は一例です。Windows のバージョンや機種によって違うことがあります。分からないときは、Microsoft やパソコンのメーカーのサポートページなど、公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • ローカルアカウントで、リセットの手段を事前に用意していなかったこと
    • Microsoft アカウントに登録した回復用の連絡先が、使えなくなっていること
    • サインイン画面の作りや、表示される項目
    • 古いパソコンで、OS のアップデートが来なくなったこと

    変えやすいこと

    • キーボードの状態を確かめること
    • パスワードを表示して、ゆっくり打ち直すこと
    • 別のデバイスから入れるかを確かめること
    • ブラウザに保存したパスワードを確かめること
    • Microsoft アカウントのパスワードをリセットすること
    • 次に備えて、パスワードと回復の手段を控えること
    • 写真や書類のバックアップを取ること

    次の行動プランは3段階です。今日は、キーボードの確認、別のデバイスからの確認、パスワードのリセットを行います。1週間で、次に入れなくならないための備えとバックアップを進めます。1か月後に、全体を見直します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、サインインできるかを確かめます。

    ボタンの名前や場所は、Windows のバージョンや機種によって違うことがあります。この記事の手順と画面が違うときは、Microsoft やパソコンのメーカーのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分ほど。データが消える心配のない確認から順に試します

      • キーボードの状態を確かめる

        • Caps Lock：キーボードに Caps Lock のランプがある場合は、点いていないかを見ます。点いていたら、Shift キーを押しながら「Caps Lock」のキーを押して消します。ランプがない機種もあります。
        • Num Lock：パスワードに数字が入っている場合は、Num Lock の状態を確かめます。テンキーで数字を打つときは、Num Lock をオンにします。ノートパソコンで、文字のキーを押すと数字が入る場合は、Num Lock をオフにします。切り替え方は機種によって違い、「Fn」キーと組み合わせる機種もあります。
        • 全角入力：画面の右下に「あ」と表示されている場合は、「半角/全角」キーを押して「A」に切り替えます。
        • キーボードの配列：パスワードに記号が入っている場合は、記号のキーの位置がずれていないかを疑います。画面の右下に「JPN」や「ENG」などの表示がある場合は、使っているキーボードと合っているかを確かめます。
        • 入力の切り替えについては、お悩み No.030「パソコンで日本語が変換できない。ひらがなのまま・カタカナになる・ブラウザだけおかしいときの直し方」も参考にしてください。

      • パスワードを表示して、一文字ずつゆっくり打ち直す

        パスワードの入力欄の右端にある、目の形のアイコンを押すと、入力した文字を確かめられます。大文字と小文字、数字、記号が、思っているとおりに入っているかを一文字ずつ見ます。周りに人がいないところで行います。

      • パソコンを再起動して、もう一度試す

        サインイン画面の右下にある電源のアイコンを選び、「再起動」を選びます。再起動のあとで、もう一度ゆっくり入力します。

        何度も続けて間違えると、しばらく入力できなくなる場合があります。思いつくパスワードを次々に入れるのは避け、1回ずつ確かめながら入力します。

      • 「サインイン オプション」で、PIN とパスワードを切り替える

        • PIN の入力欄が出ないときや、PIN を忘れたときは、サインイン画面の「サインイン オプション」を選びます。パスワードの入力に切り替えて、パスワードでサインインします。
        • パスワードは分かるが PIN を忘れた場合は、パスワードでサインインしたあとで、PIN を作り直します（1週間の行動の「PIN を設定し直す」を見てください）。
        • Microsoft アカウントの場合は、PIN の入力欄の下にある「PIN を忘れた場合」から、本人確認をして PIN を作り直すこともできます。ローカルアカウントでは、この項目は使えません。

      • スマホや別のパソコンから、同じ Microsoft アカウントに入れるかを確かめる

        • スマホで Outlook や OneDrive の公式アプリを開くか、ブラウザで公式サイトを開きます。パソコンと同じメールアドレスとパスワードで、サインインしてみます。
        • 入れた場合は、パスワードは正しいと分かります。パソコン側の入力の問題の可能性が高いため、上の「キーボードの状態を確かめる」を、もう一度ゆっくり試します。
        • 最近ほかのデバイスでパスワードを変えた場合は、パソコンをインターネットにつないでから試します。サインイン画面の右下にネットワークのアイコンがある場合は、そこから Wi-Fi につなげます。
        • 入れない場合は、パスワードを忘れているか、思い違いをしている可能性があります。次の2つの手順に進みます。

      • ブラウザに保存したパスワードを、別のデバイスで確かめる

        見つかったパスワードを使えば、リセットせずに済むことがあります。

        • Chrome：スマホの Chrome で、その他アイコン →「設定」→「自動入力とパスワード」→「Google パスワード マネージャー」の順に開きます。別のパソコンの Chrome では、その他アイコン →「パスワードと自動入力」→「Google パスワード マネージャー」の順です。ほかのブラウザで passwords.google.com を開き、Google アカウントでログインしても確かめられます。
        • Edge：別のパソコンの Edge で、右上の「…」→「設定」→「パスワードとオートフィル」→「Microsoft パスワード マネージャー」の順に開きます。この画面を使うには、Edge に個人用の Microsoft アカウントでサインインしている必要があります。Edge のバージョンによって、名前や場所が違うことがあります。
        • 一覧から「live.com」や「microsoft.com」を探すと、Microsoft アカウントのパスワードが見つかることがあります。
        • パスワードを表示するときに、そのデバイスの PIN やパスワード、指紋や顔の認証を求められることがあります。
        • 表示したパスワードを、人に見せないでください。
        • パソコン本体だけのパスワード（ローカルアカウントのパスワード）は、ふつうはブラウザに保存されていません。

      • Microsoft アカウントのパスワードをリセットする

        次の手順は、スマホのブラウザからでも行えます。

        • ブラウザで account.live.com/password/reset を開きます。アドレスは自分で入力し、メールや広告のリンクからは開かないでください。パソコンのサインイン画面で「パスワードを忘れた場合」を選んでも、同じ手続きを始められます。
        • Microsoft アカウントのメールアドレスか電話番号を入力し、確認コードを受け取る方法を選びます。
        • 登録したメールアドレスや電話番号に、確認コードが届きます。届いたコードを入力します。メールが見当たらないときは、迷惑メールのフォルダーも確かめます。
        • 新しいパスワードを決めて入力します。決めたパスワードは、すぐに紙などに控えます。
        • パソコンのサインイン画面で、新しいパスワードを入力します。通らない場合は、パソコンがインターネットにつながっているかを確かめます。
        • 登録したメールアドレスや電話番号が使えなくなっている場合は、Microsoft の公式のヘルプの案内に従って、アカウントを回復するための手続きを進めます。

      • ローカルアカウントの場合は、セキュリティの質問を使う

        • サインイン画面で、パスワードの入力欄の横にある矢印を選びます。「OK」→「パスワードのリセット」の順に選び、アカウントを作ったときに設定したセキュリティの質問に答えます。
        • パスワード リセット ディスク（USB メモリ）を作ってある場合は、「パスワード リセット ディスクを使用する」を選んで、画面の指示に従います。
        • 家族のアカウントなど、そのパソコンにほかの管理者のアカウントがある場合は、そのアカウントでサインインして、パスワードを設定し直せる場合があります。手順は Microsoft の公式のヘルプで確かめます。
        • どれも使えない場合は、すぐに初期化せず、パソコンのメーカーのサポート窓口に相談します。初期化の前に、データだけでも取り出せないかを確かめます。パソコンの設定によっては、データを取り出せないこともあります。

    2. 1週間の行動

      目安：1日10〜15分ほど。次に入れなくならないように備えます

      • 新しいパスワードを、なくさない方法で控える

        • 紙に書く場合は、家の決まった場所に保管します。パソコンの画面やキーボードに貼るのは避けます。
        • パスワード管理アプリを使う場合は、Google パスワード マネージャーや、Edge の Microsoft パスワード マネージャーなどがあります。
        • パソコンに入るためのパスワードは、そのパソコンの中に控えただけでは、入れないときに見られません。スマホや紙など、パソコンの外にも控えておきます。
        • 以前は Microsoft Authenticator にもパスワードを保存できましたが、Microsoft はこの機能を 2025 年に終了しました。保存していたパスワードは、Edge から確認できると案内されています。
        • パスワードの管理のしかたは、お悩み No.004「パスワードが覚えられない、使い回しも不安。安全にラクに管理するには」も参考にしてください。

      • PIN を設定し直す

        • 「設定」→「アカウント」→「サインイン オプション」→「PIN (Windows Hello)」→「PIN の変更」の順に選びます。今の PIN を忘れた場合は、「PIN を忘れた場合」を選びます。
        • PIN は、ほかのサービスの暗証番号とは別の番号にします。誕生日など、人に推測されやすい番号は避けます。
        • PIN とパスワードの両方を控えておきます。PIN が使えなくなったときに、パスワードでサインインするためです。

      • Microsoft アカウントのセキュリティ情報を確かめる

        • ブラウザで account.microsoft.com/security を開き、Microsoft アカウントでサインインします。「サインイン方法を管理」を選ぶと、登録している回復用のメールアドレスや電話番号を確かめられます。
        • 使っていないメールアドレスや、解約した電話番号が残っていないかを見ます。今使っているものを追加します。
        • Microsoft の公式のヘルプによると、新しい電話番号を追加できない場合があります。回復用のメールアドレスも登録しておきます。
        • 確認コードが届かないときの備えは、お悩み No.027「二段階認証のコードが届かない。機種変更でログインできなくなったときの備え」も参考にしてください。

      • ローカルアカウントの場合は、回復の手段を用意する

        • パスワード リセット ディスクを作ります。USB メモリをパソコンにつなぎ、コントロール パネルの検索欄に「パスワード リセットの作成」と入力します。「パスワード リセット ディスクの作成」を選び、画面の指示に従います。
        • パスワード リセット ディスクを持っていれば、だれでもパスワードをリセットできてしまいます。USB メモリは、家の決まった場所に保管します。
        • Microsoft の公式のヘルプによると、パスワードを変えても、ディスクを作り直す必要はありません。
        • セキュリティの質問の答えを覚えているかも確かめます。「設定」→「アカウント」→「サインイン オプション」の「パスワード」の欄に、質問を更新する項目がある場合があります。項目の名前は、Windows のバージョンによって違います。
        • Microsoft アカウントに切り替えると、パスワードを忘れても、インターネット経由でリセットできるようになります。切り替えるかどうかは、使い方に合わせて決めます。

      • 大切な写真や書類のバックアップを始める

        • OneDrive（Microsoft のクラウド）、USB メモリ、外付けハードディスクなどに、写真や書類のコピーを保存します。
        • バックアップがあれば、万一初期化が必要になっても、写真や書類を戻せます。
        • OneDrive の無料の容量には上限があります。写真が多い場合は、外付けハードディスクとの組み合わせも考えます。
        • バックアップの始め方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」に詳しく書いています。

    3. 1か月の見直し

      目安：1か月後に20〜30分

      • パスワード、PIN、回復用の連絡先を見直す

        • 控えたパスワードと PIN で、実際にサインインできるかを確かめます。
        • 電話番号やメールアドレスを変えた場合は、Microsoft アカウントのセキュリティ情報も更新します。
        • このあとも、数か月に1回くらい見直します。

      • 家族と「パソコンに入れなくなったときの連絡方法」を決めておく

        • 入れなくなったときに、だれに相談するかを決めておきます。
        • パスワードのメモの保管場所を、信頼できる家族に伝えておくかを話し合います。
        • 「サポートを名乗る電話がかかってきたら、一人で対応せずに家族に相談する」といった決まりも作っておきます。

      • バックアップが自動で取れているかを、月に1回確かめる

        • OneDrive を使っている場合は、パソコンの写真や書類が OneDrive に保存されているかを、スマホのアプリや別のパソコンから確かめます。
        • 外付けハードディスクを使っている場合は、新しい日付のファイルが入っているかを確かめます。

      • 古いパソコンで、OS のアップデートが来なくなっていないかを確かめる

        • Windows 10 は、2025 年 10 月 14 日にサポートが終わりました。サポートが終わった OS には、セキュリティの更新が届きません。
        • Windows のアップデートで、サインインの画面や方法が変わることもあります。画面がこの記事と違うときは、メーカーのサポート情報を確かめます。
        • パソコンを買い替えるかどうかは、メーカーのサポート情報や使い方に合わせて決めます。急いで決める必要はありません。

    まず今日、Caps Lock、Num Lock、全角入力、キーボードの配列を確かめ、パスワードを表示しながらゆっくり打ち直します。再起動し、「サインイン オプション」でパスワードの入力に切り替えて試します。スマホなど別のデバイスから同じ Microsoft アカウントに入れるかを確かめ、ブラウザに保存したパスワードも探します。それでも入れなければ、Microsoft アカウントは account.live.com/password/reset からリセットし、ローカルアカウントはセキュリティの質問を使います。次の1週間は、新しいパスワードを控え、PIN と回復用の連絡先を整え、バックアップを始めます。1か月後に、パスワード、回復の手段、バックアップ、OS のサポートを見直します。初期化は、これらをすべて試し、メーカーの窓口に相談してから考えます。手順の名前や場所は、機種や OS のバージョンで変わることがあります。分からないところは、Microsoft やパソコンのメーカーのサポートページなど、公式のヘルプで確かめてください。

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理やセキュリティについての専門的な助言ではありません。特定の製品やサービスを勧めるものでもありません。設定の変更は、ご自身の判断と責任で行ってください。

    初期化（リカバリ）は、安易に行わないでください。初期化の方法によっては、パソコンの中の写真や書類がすべて消え、元に戻せません。この記事の手順を試し、メーカーの窓口にも相談してから考えてください。

    インターネットで見つかる「パスワード解除ツール」や、有料のパスワード解除業者には、安易に手を出さないでください。ツールに悪意のあるプログラムが含まれていたり、高額な料金を求められたりするおそれがあります。パソコンの中の写真や書類を、知らない人に預けることにもなります。困ったときは、パソコンのメーカーなど、公式の窓口に相談してください。

    パスワードや確認コードは、Microsoft の公式サイト（account.live.com や account.microsoft.com など）と公式アプリ以外には入力しないでください。メールや SMS、検索結果の広告のリンクから開いたサイトは、偽のサイトのおそれがあります。迷惑メールの見分け方は、お悩み No.007「宅配便やカード会社を名乗る迷惑メールが毎日届く。見分けて安心して使うには」も参考にしてください。

    サポートを名乗る電話やメールで、パスワードや確認コードを聞かれても、教えないでください。Microsoft は公式のヘルプで、サポート担当者はパスワードのリセットのリンクを送ったり、アカウントの情報を変更したりできないと案内しています。「ウイルスに感染しました」「今すぐ電話してください」という画面が出ても、表示された電話番号には電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。電話をかけてしまった、お金を払ってしまったという場合は、下の相談先に相談してください。

    パスワードや個人情報を、他人に見せないでください。パスワードや個人情報を入力するのは、公式アプリと公式サイトだけにします。
