お悩み No.067 ・ 2026年11月24日公開

パソコンの文字が小さくて読めない。画面を大きくする設定と見やすくするコツ

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    Windowsの表示倍率やブラウザの拡大、拡大鏡といった設定を知れば、画面全体の文字を大きくでき、読みづらさの多くは軽減できる見込みあり

    Windows とブラウザには、文字を大きく表示する設定がいくつかあります。Windows の表示倍率（スケール）を上げると、文字もアイコンもまとめて大きくなります。ブラウザの拡大はその場で変えられ、元に戻すのも簡単です。画面の一部だけを大きくしたいときは、Windows に入っている拡大鏡を使えます。これらを組み合わせれば、読みづらさの多くは軽減できる見込みがあります。

    ボトルネックは、設定の場所が分からないことと、ブラウザの拡大と Windows 全体の拡大が別々の設定だと知らないことです。そのため、どこを変えればよいかを決められず、我慢して使い続けています。

    ただし、目の見え方そのものに原因がある場合は、設定を変えるだけでは足りないこともあります。眼鏡が画面までの距離に合っているかも、あわせて確かめる必要があります。

    この記事の手順と設定名は、2026年11月時点の Microsoft と Google の公式ヘルプをもとにした Windows 11 の例です。設定名やメニューの場所は、Windows やブラウザのバージョンによって変わることがあります。Windows 10 で違う部分は、それぞれの手順の中に書いています。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    文字が小さくて読みづらく、つい画面に顔を近づけてしまう
    文章を書くときもインターネットを見るときも、文字の大きさが目に合っていない。文字を大きくする設定を、まだ使っていない可能性がある。
    眼鏡をかけても見えにくく、入力ミスも増えてきた
    眼鏡が、パソコンの画面までの距離に合っていない可能性がある。文字が小さいため、打った文字を確かめにくくなっている。
    新しいパソコンに買い替えたら、画面が小さくなって目が疲れるようになった
    画面が小さくなった分、前と同じような設定でも、文字が小さく表示されている可能性がある。
    文字を大きくする設定の場所が分からない
    設定がどこにあり、どの項目を変えればよいかを知らない。迷っているうちに、試せないままになっている。
    ブラウザだけ大きくするのか、パソコン全体を大きくするのか分からない
    ブラウザの拡大と Windows 全体の拡大が、別々の設定であることを知らない。どちらを変えればよいかを見分ける方法も分からない。

    考えられる原因

    文字が小さく見える原因として、次のことが考えられます。

    画面の解像度が高いと、同じ倍率でも文字が小さく表示される
    最近のパソコンには、画面の解像度（画面に並ぶ点の数）が高いものが多くあります。解像度が高いほど細かく表示できますが、表示倍率が同じなら、文字は小さく表示されます。画面の小さいノートパソコンで解像度が高いと、文字はさらに小さく見えます。
    表示倍率（スケール）が100%のままだと、文字やアイコンが小さく感じる
    Windows には、画面に表示するものをまとめて大きくする「スケール」という設定があります。解像度の高い画面でこの倍率が100%のままだと、文字やアイコンが小さく感じます。Windows は、画面に合った倍率に「(推奨)」と表示しますが、その倍率でも小さく感じる人がいます。
    ブラウザの表示倍率と、Windows 全体の表示倍率は別々の設定
    Edge や Chrome などのブラウザには、Webページを大きく表示する「ズーム」の機能があります。これは Windows のスケールとは別の設定です。ブラウザで拡大しても、ほかのソフトや Windows の画面の文字は変わりません。反対に、Windows のスケールを上げると、ブラウザの中の文字も大きくなります。
    年齢による目の変化で、小さい文字を読む負担が大きくなる
    年齢とともに、近くの物にピントを合わせにくくなります（老眼）。そうなると、小さい文字を読むときに目が疲れやすくなります。読書用の眼鏡が、パソコンの画面までの距離に合っていないこともあります。
    特定のソフトだけ文字が小さいときは、ソフト側の表示設定が原因のこともある
    Word や Excel などのソフトには、そのソフトの中だけで表示倍率を変える「ズーム」の機能があります。ソフトのズームが小さく設定されていると、そのソフトの中の文字だけが小さく表示されます。

    どこが原因かを切り分ける方法

    次のことを順に確かめると、どこを変えればよいかが分かります。具体的な手順は、行動プランで説明します。

    ブラウザの文字だけが小さいのか、パソコン全体の文字が小さいのかを確かめる
    Webページの文字と、スタートメニューやファイル名、設定画面の文字を見比べます。Webページだけが読みにくいなら、まずブラウザの拡大を試します。どの画面の文字も小さいなら、Windows のスケールやテキスト サイズを変えます。
    表示倍率を一段階上げて、読みやすさが変わるか試す
    Windows のスケールを一段階だけ上げて、顔を近づけずに読めるようになるかを確かめます。変わらなければ、もう一段階上げます。一度に大きく上げると、画面に収まらないボタンが出ることがあります。
    画面の一部だけを一時的に大きくしたいときは、拡大鏡を試す
    小さい文字が一部の場所だけにあるときは、Windows の拡大鏡で、その部分だけを大きくして読めます。読み終わったら閉じれば、画面の表示は元のままです。
    文字を大きくしても見づらいときは、明るさやコントラストも確かめる
    画面が暗すぎたり明るすぎたりすると、文字を大きくしても読みにくいことがあります。文字と背景の色の差が小さいときも、読みにくくなります。Windows には、画面の明るさの設定や、文字と背景の色の差を大きくする「コントラスト テーマ」があります。

    直る見込み

    スケールを125%や150%に変えるだけで、文字もアイコンも大きくなる
    Windows のスケールを上げると、文字、アイコン、ボタン、ソフトの画面がまとめて大きくなります。Microsoft の案内では、多くの場合、変えるとすぐに反映されます。一部のアプリでは、サインアウトしてサインインし直す必要がある場合があります。
    ブラウザの拡大はその場で変えられ、元に戻すのも簡単
    Edge や Chrome では、Ctrl を押しながら + を押すとページが大きくなり、Ctrl を押しながら 0 を押すと元の大きさに戻ります。設定画面を開かずに試せます。
    拡大鏡を使えば、画面の一部だけを大きくして読める
    拡大鏡は、Windows に最初から入っている機能です。キー操作で、すぐに開いたり閉じたりできます。
    スケールを変えると、よく使うソフトの文字も一緒に大きくなることが多い
    Windows のスケールは、Windows の画面だけでなく、多くのソフトの表示にも反映されます。ソフトごとに設定し直す手間が少なくて済みます。
    解像度は変えずに、スケールで大きくすれば文字がぼやけない
    解像度を下げても文字は大きくなります。ただし、Microsoft の案内では、推奨より低い解像度にすると、文字の表示が鮮明でなくなることがあります。解像度は「(推奨)」のままにして、スケールやテキスト サイズで大きくします。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 文字が小さいまま、画面に顔を近づけて読む
    2. 目が疲れ、入力ミスも増える
    3. 設定の場所が分からないので、そのまま我慢して使う
    4. 次の日も同じ大きさのまま使い、また目が疲れる

    4のあと、また1に戻ります。

    この循環は、3のところで止められます。設定の場所と、変えた設定は元に戻せることが分かれば、我慢して使い続けずに済みます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 買い替えたパソコンの画面の大きさ
    • 年齢による目の見え方の変化
    • Webサイトやソフトごとに決められている文字の大きさ
    • Windows やブラウザのバージョンによる、手順や設定名の違い

    変えやすいこと

    • ブラウザの表示倍率（ズーム）
    • Windows のスケール
    • Windows のテキスト サイズ
    • 拡大鏡を使って、画面の一部を大きくすること
    • ソフトごとのズーム
    • 画面の明るさと、夜間モードの設定
    • 眼鏡が画面までの距離に合っているかを、眼鏡店で相談すること

    次の行動プランは3段階です。今日は、ブラウザの拡大と拡大鏡を試します。1週間で、Windows のスケールとテキスト サイズを変えて、自分に合う大きさを探します。1か月後には、決めた設定で目の疲れ方が変わったかを確かめ、明るさや眼鏡も見直します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は Windows 11 の例です。設定やボタンの名前と場所は、Windows やブラウザ、ソフトのバージョンによって違うことがあります。この記事と画面が違うときは、使っているパソコンやソフトの公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：15分ほど。いつも見ている Webページを1つ開いておきます

      • ブラウザで、ページの文字を大きくする

        • 拡大：Ctrl を押しながら +（プラス）を押します。押すたびに、少しずつ大きくなります。
        • 縮小：Ctrl を押しながら -（マイナス）を押します。
        • 元の大きさに戻す：Ctrl を押しながら 0（ゼロ）を押します。
        • 日本語のキーボードでは、+ は ;（セミコロン）と同じキーに書かれています。
        • マウスを使うときは、Ctrl を押しながらホイールを上（奥）へ回すと拡大、下（手前）へ回すと縮小します。
        • この方法は、Edge でも Chrome でも使えます。変えた倍率は、サイトごとに覚えられることがあります。別のサイトを開いて元の大きさだったら、そのサイトでもう一度拡大します。

      • 画面の一部だけを、拡大鏡で大きくする

        Windows は、キーボードの左下にある Windows のマークが書かれたキーです。

        1. Windows を押しながら + を押すと、拡大鏡が開きます。
        2. 開いたまま Windows + + を押すと、さらに大きくなります。Windows + - で小さくなります。
        3. マウスを動かすと、拡大される場所も一緒に動きます。
        4. 読み終わったら、Windows を押しながら Esc を押して閉じます。
        • 表示のしかたは、画面全体を拡大する「全画面表示」、マウスの周りだけを拡大する「レンズ」、画面の端に拡大した部分を表示する「ドッキング」の3つです。Ctrl + Alt + M で順に切り替えられます。
        • Ctrl + Alt を押しながらマウスのホイールを回しても、拡大と縮小ができます。

      • 大きくしたら、よく見るページが読みやすくなったか確かめる

        椅子にいつもどおり座ったまま、顔を近づけずに読めるかを確かめます。メールやニュースなど、毎日見るページで試します。読みやすくなった倍率をメモしておくと、1週間の行動で使えます。

    2. 1週間の行動

      目安：1回10〜15分ほどを、数日に分けて

      • パソコン全体を大きくする（スケール）

        文字だけでなく、アイコンやボタンも小さいと感じるときは、Windows のスケールを変えます。

        1. Windows + I を押して「設定」を開きます。「スタート」→「設定」でも開けます。
        2. 「システム」→「ディスプレイ」を選びます。
        3. 「スケールとレイアウト」の「スケール」で、今の倍率を確かめてメモします。Microsoft のヘルプでは「拡大縮小」と書かれていることもあります。
        4. 一段階大きい倍率を選びます。今が100%なら125%、125%なら150%を試します。
        5. 文字やアイコンの大きさが変わったか、よく使うソフトが使いやすくなったかを確かめます。
        • Microsoft の案内では、通常は「(推奨)」と付いた倍率を選ぶことが勧められています。推奨の倍率でも文字が小さいと感じるときに、一段階ずつ上げて試します。
        • 多くの場合、変えるとすぐに反映されます。一部のソフトでは、サインアウトしてサインインし直すと反映されることがあります。
        • Windows 10 では、「設定」→「簡単操作」→「ディスプレイ」の「すべてを大きくする」で変えられます。

      • 文字だけを大きくする（テキスト サイズ）

        アイコンやボタンの大きさはそのままで、文字だけを大きくしたいときに使います。

        1. Windows + U を押して、「設定」の「アクセシビリティ」を開きます。「スタート」→「設定」→「アクセシビリティ」でも開けます。
        2. 「テキスト サイズ」を選びます。
        3. 「テキストのサイズ」のスライダーを右へ動かします。見本の文字で、大きさを確かめます。
        4. 「適用」を押します。
        • Windows 10 では、「設定」→「簡単操作」→「ディスプレイ」の「文字を大きくする」のスライダーで変えられます。
        • スケールとテキスト サイズを同時に大きく変えると、文字が大きくなりすぎることがあります。1つずつ変えて確かめます。

      • 一段階ずつ変えて、自分に合う大きさを探す

        • 1つの倍率を2〜3日使ってみて、顔を近づけずに読めるか、入力ミスが減ったかを確かめます。
        • 大きすぎて画面に収まらないときは、一段階戻します。
        • 変えた設定と日付をメモしておきます。元に戻したいときは、メモを見て戻せます。

      • どのサイトも小さいときは、ブラウザの既定の倍率を変える

        サイトを開くたびに拡大するのが手間なときは、ブラウザ全体の既定の倍率を変えます。

        • Edge：右上の「設定など」（…）→「設定」→「アクセシビリティ」の「ページ ズーム」で倍率を選びます。Microsoft の案内では、Alt + F でも「設定など」を開けます。
        • Chrome：右上のその他アイコン（︙）→「設定」→「デザイン」の「ページのズーム」で倍率を選びます。「フォントサイズ」で、文字の大きさだけを変えることもできます。
        • 設定の場所は、ブラウザのバージョンによって違うことがあります。

    3. 1か月の見直し

      目安：1回15分ほど

      • 決めた倍率で使い続け、目の疲れ方を確かめる

        自分に合う倍率が決まったら、そのまま使い続けます。1か月たったら、設定を変える前と比べて、次のことを確かめます。

        • 画面に顔を近づける回数が減ったか
        • 夕方の目の疲れ方が変わったか
        • 入力ミスが減ったか

      • 特定のソフトだけ文字が小さいときは、そのソフトのズームを確かめる

        • Word や Excel：画面の右下にあるズームのスライダーを動かすか、「表示」タブの「ズーム」で倍率を変えます。「100%」を押すと、倍率が100%に戻ります。
        • そのほかのソフト：「表示」メニューや設定画面に、「ズーム」や「文字の大きさ」などの項目がないかを探します。名前はソフトによって違います。

      • 画面の明るさと夜間モードを見直す

        • 明るさ：タスクバーの右側にあるネットワークのアイコンを選び、「明るさ」のスライダーで調整します。「設定」→「システム」→「ディスプレイ」でも変えられます。外付けのモニターは、モニター本体のボタンで調整します。
        • 夜間モード：「設定」→「システム」→「ディスプレイ」の「夜間モード」で、画面のブルーライト（青い光）を減らせます。「強度」のスライダーで強さを変えられます。「夜間モードのスケジュール」で「日没から朝まで」か「時間の設定」を選ぶと、決まった時間に自動で切り替わります。
        • 文字と背景の色の差が小さくて読みにくいときは、「設定」→「アクセシビリティ」→「コントラスト テーマ」も試せます。画面の色が大きく変わるので、合わなければ元の設定に戻します。

      • 見づらさが続くときは、眼鏡を相談する

        設定を変えても見づらさが続くときは、眼鏡が画面までの距離に合っているかを確かめます。眼鏡店では、パソコンを使うことと、画面までのおおよその距離を伝えて相談します。

    1か月たったら、使い続けている設定と、元に戻した設定をメモにまとめます。顔を近づけずに読めて、目の疲れが減っていれば、その設定を使い続けます。見づらさが残るときは、眼鏡店や眼科で相談してください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。医療やパソコンの操作についての専門的な助言ではありません。設定の変更は、ご自身の判断と責任で行ってください。

    表示倍率を大きくしすぎると、画面に収まらないボタンが出たり、ソフトの画面が見切れたりすることがあります。倍率は一段階ずつ変えて、そのたびに確かめてください。

    設定を変える前に、今の設定（スケールの倍率、テキスト サイズ、ブラウザのズームなど）をメモしておくと、元に戻しやすくなります。解像度は「(推奨)」のままにしておくことをお勧めします。Microsoft の案内では、推奨より低い解像度にすると、文字の表示が鮮明でなくなることがあります。

    目の見え方に急な変化があったり、見えづらさが強かったりする場合は、無理をせず眼科などで相談してください。

    手順や設定の名前は、Windows やブラウザ、ソフトのバージョンによって変わることがあります。この記事は、2026年11月時点の公式ヘルプをもとにしています。使っているパソコンやソフトの公式ヘルプで確かめてください。
