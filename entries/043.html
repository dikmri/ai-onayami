パソコンのマウスが動かない。カーソルが止まる・見つからないときの切り分けと直し方

    AIの見立て

    改善できる見込みあり

    カーソルが動かなくなる原因の多くは、マウスの電源や電池、USBの受信機（レシーバー）の差し込み口、USBハブ、机の表面、パソコン側の一時的な不具合です。これらは、電池や差し込み口の確認、紙を1枚敷くこと、再起動など、自分でできる対処で確かめられます。差し込み口を変えるだけで直ることもよくあります。このため、改善できる見込みがあります。

    今回は、新しいマウスに替えても直っていません。2つのマウスで同じことが起きているので、原因はマウス本体ではなく、差し込み口やハブ、机の表面、パソコン側にある可能性が高いと考えられます。タッチパッドも反応しないことも、パソコン側を疑う手がかりになります。

    ボトルネックは、どこが悪いのか確かめないまま、マウスを買い替えていることです。マウスを買う前に、決まった順番で切り分ければ、無駄な買い替えを防げます。ただし、マウス本体のセンサーやスイッチが物理的に壊れている場合は、修理より買い替えが現実的です。

    この記事では、主に Windows 11 の画面で手順を説明します。マウスが使えない間はキーボードで操作する場面が多いため、キーボードでの操作方法も書きます。手順の名前や場所は一例で、パソコンの種類や Windows・macOS のバージョンによって違うことがあります。分からないときは、Microsoft、Apple、パソコンやマウスのメーカーのサポートページなど、公式のヘルプで確かめてください。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    マウスを動かしても、カーソルがまったく動かない
    以前は普通に使えていたのに、急に動かなくなった。
    電池を替えても、新しいマウスに付け替えても直らない
    無線マウスの電池を新しいものに替えた。新しいマウスも買ってきて付け替えたが、同じだった。
    タッチパッドも反応しない
    マウスの代わりにタッチパッドで動かそうとしても、反応しない。
    カーソルがどこに行ったのか分からない
    画面のどこにカーソルがあるのかも、分からなくなった。
    原因が分からず、買い替えるしかないのか迷っている
    机がツルツルしているせいか、差し込み口が悪いのか、マウスが壊れたのかが分からない。

    カーソルが動かない主な原因

    カーソルが動かない原因は、大きく分けると次のようなものです。

    マウスの電池切れや、電源スイッチの切り忘れ
    無線マウスは、電池が切れると動きません。電池の向き（＋と−）が逆の場合や、マウスの裏の電源スイッチが切れている場合も同じです。新しく買ったマウスでは、電池の間に絶縁用のシートがはさまったままになっている製品もあります。
    USBの受信機（レシーバー）や、差し込み口の不具合
    無線マウスの多くは、パソコンに差す小さな受信機を通してつながります。受信機の差し込みがゆるんでいたり、差し込み口そのものが故障していたりすると、マウスが正常でも動きません。また、無線マウスの多くは、一緒に箱に入っていた受信機とだけつながります。新しいマウスに替えたときは、新しいマウスの受信機を差す必要があります。
    USBハブを経由している場合の、ハブの不具合
    USBハブ（差し込み口を増やす機器）を通していると、ハブの不調や電力不足で、つないだ機器が動かないことがあります。Microsoft も、USBハブを使う場合は、ハブに電源が供給されているかを確かめ、改善しなければハブを外してパソコンに直接つなぐよう案内しています。
    ツルツルした机やガラスの上で、マウスが動きを読み取れない
    多くのマウスは、裏のセンサーで机の表面を読み取って、動きを判断します。ガラスや鏡のような面、光をよく反射するツルツルした面では、動きを読み取りにくくなります。センサーにほこりや汚れが付いている場合も、うまく読み取れません。
    パソコン側の一時的な不具合
    Windows は、マウスを動かすためにドライバーというプログラムを読み込みます。この読み込みに失敗すると、マウスが正常でも動かないことがあります。パソコンの再起動で直ることがあります。
    タッチパッドがオフになっている
    ノートパソコンのタッチパッドは、キーボードのファンクションキー（F1〜F12 のどれか）でオフにできる機種があります。Windows 11 には、マウスをつないでいる間はタッチパッドをオフにする設定もあります。この設定になっていると、マウスを付け替えたときに、タッチパッドも反応しなくなったように見えます。
    パソコン全体が固まっている
    パソコンが固まっていると、マウスもタッチパッドもキーボードも反応しなくなります。この場合は、マウスではなくパソコンの状態を確かめる必要があります。
    カーソルが「消えた」ように見えるだけ
    カーソルが画面の端に隠れていたり、表示が小さく薄くて見つけにくかったりすることがあります。テレビや別の画面をつないでいると、カーソルがそちらの画面に移っていることもあります。Windows には、文字の入力中にカーソルを隠す設定もあります。

    マウスを何度替えても直らないときは、マウス以外を疑う

    マウスを何度買い替えても直らない場合は、マウス本体ではなく、差し込み口やハブ、パソコン側に原因があることが多いと考えられます。古いマウスと新しいマウスで同じことが起きるなら、2つに共通しているものが怪しいからです。共通しているのは、差し込み口、ハブ、机の表面、パソコン本体です。

    今回は、タッチパッドも反応していません。マウスとタッチパッドの両方が動かないときは、次の3つを先に確かめます。

    • パソコン全体が固まっていないか
    • タッチパッドがオフになっていないか
    • パソコン側の一時的な不具合（ドライバーの読み込み失敗など）ではないか

    どこが悪いのかを切り分ける方法

    次の順番で確かめると、原因がマウスか、差し込み口やハブか、パソコン側かを切り分けられます。手順は、行動プランで説明します。

    キーボードが反応するかを確かめる
    キーボードの CapsLock キーなどを押して、ランプが点いたり消えたりするかを見ます。Windows キーを押して、スタートメニューが開くかも見ます。反応すれば、パソコン全体は固まっていません。
    マウスの電源スイッチと電池を確かめる
    マウスの裏の電源スイッチが入っているか、電池が正しい向きで入っているかを見ます。
    受信機を、パソコン本体の別の差し込み口に直接差し替える
    無線マウスの受信機を抜き、別の差し込み口に差します。USBハブを使っている場合は、ハブを外して本体に直接差します。別の口で動けば、元の差し込み口かハブの不具合です。
    紙を1枚敷いて、その上で動かす
    ツルツルした机の上では、紙を1枚敷いて動かしてみます。紙の上で動けば、机の表面が原因です。
    タッチパッドがオフになっていないかを確かめる
    ファンクションキーでオフになっていないか、Windows の設定でオフになっていないかを確かめます。
    パソコンを再起動する
    一時的な不具合なら、再起動で直ることがあります。
    別のマウスや、別のパソコンで試す
    別のパソコンでマウスが動けば、マウスは無事で、元のパソコン側に原因があります。別のパソコンでも動かなければ、マウス本体の故障の可能性が高くなります。家族の有線マウスなど、別のマウスを元のパソコンにつないで動くかを見る方法もあります。

    カーソルが見つからないときは、Ctrl キーで位置を表示できる

    Windows には、Ctrl キーを押すと、カーソルの位置を円で示す機能があります。「マウスのプロパティ」の「ポインター オプション」タブで、「Ctrl キーを押すとポインターの位置を表示する」をオンにすると使えます。一度オンにしておけば、次にカーソルを見失ったときも、Ctrl キーを押すだけで見つけられます。マウスが使えない間に、キーボードだけでオンにする方法は、行動プランで説明します。

    直る見込み

    差し込み口を変えるだけで直ることがよくある
    差し込み口の不具合やハブの不調が原因なら、本体の別の差し込み口に直接差すだけで直ります。
    電池や受信機の差し直し、再起動で直る場合も多い
    電池の向きや電源スイッチ、受信機のゆるみは、確かめればその場で直せます。パソコン側の一時的な不具合なら、再起動で直ることがあります。
    マウスを買う前に切り分けると、無駄な買い替えを防げる
    原因が差し込み口やパソコン側にあると、マウスを何度買い替えても直りません。先に切り分けをすれば、買い替えが必要かどうかを判断できます。
    マウス本体が物理的に壊れている場合は、買い替えが現実的
    別のパソコンでも動かない場合などは、マウス本体のセンサーやスイッチが壊れている可能性があります。マウスは、修理より買い替えのほうが早く、安く済むことがあります。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. カーソルが急に動かなくなる
    2. どこが悪いのかを確かめないまま、マウスが壊れたと考えて買い替える
    3. 原因がマウス以外にあると、新しいマウスでも直らない
    4. 原因が分からないまま、不安と出費だけが増え、次に起きたときも同じように慌てる

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。マウスを買う前に、キーボードの反応、電池、差し込み口、机の表面、タッチパッドの設定、再起動の順に確かめれば、直す場所が分かります。直った原因をメモしておけば、次に同じことが起きたときも、慌てずに対処できます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • マウス本体のセンサーやスイッチの物理的な故障
    • パソコンの差し込み口そのものの故障
    • パソコンの差し込み口の数や種類
    • 機種や OS のバージョンによる、画面や項目の名前の違い

    変えやすいこと

    • 電源スイッチと電池の確認
    • 受信機を差す場所（別の差し込み口、ハブを外して直接差す）
    • マウスを動かす面（紙やマウスパッドを敷く）
    • タッチパッドの設定の確認
    • パソコンの再起動
    • 原因を切り分ける順番
    • カーソルを見つけやすくする設定
    • 予備の電池を用意しておく習慣

    次の行動プランは3段階です。今日は、キーボードの反応、電池、差し込み口、机の表面、タッチパッド、再起動の順に確かめて、どこが悪いのかを切り分けます。1週間で、直った原因を記録し、予備の電池やマウスパッドを用意して、カーソルを見つけやすくする設定をします。1か月後に、マウスの買い替えの目安と選び方を確かめ、切り分けの手順を家族とも共有します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、カーソルが動くようになったかを確かめます。

    設定やボタンの名前と場所は、パソコンの機種や Windows・macOS のバージョンによって違うことがあります。この記事の手順と画面が違うときは、使っている機種の説明書や、Microsoft、Apple、メーカーのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：20〜30分ほど。お金はかかりません

      • まず落ち着いて、キーボードが反応するかを確かめる

        • キーボードの CapsLock キーや NumLock キーを押して、キーボードやパソコン本体のランプが点いたり消えたりするかを見ます。CapsLock を押してオンにしたときは、もう一度押してオフに戻します。日本語配列のキーボードの多くでは、Shift キーを押しながら CapsLock キーを押します。
        • Windows キーを押して、スタートメニューが開くかも見ます。Windows は、Windows のロゴが書かれたキーです。開いたら、Esc キーで閉じます。
        • キーボードが反応すれば、パソコン全体は固まっていません。次の項目に進みます。
        • キーボードも反応しない場合は、パソコン全体が固まっている可能性があります。対処の方法は、お悩み No.020「パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？」で説明しています。

      • マウスの電源スイッチと電池を確かめる

        • マウスを裏返して、電源スイッチが「ON」になっているかを見ます。いったん「OFF」にして、もう一度「ON」にします。
        • 電池ボックスを開けて、電池の向きが＋と−の印に合っているかを確かめます。単3形か単4形か、マウスに合う電池が入っているかも確かめます。
        • 新しく買ったマウスは、電池の間に絶縁用のシートがはさまったままになっていないかも見ます。シートがあれば、取り扱い説明書に沿って取り除きます。
        • 充電式のマウスは、しばらく充電してから試します。
        • Microsoft は、マウスの裏や受信機に「リセット」ボタンがあるかを確かめるよう案内しています。ボタンがある機種は、取り扱い説明書に沿って押します。

      • 受信機を一度抜き、USBハブを外して、パソコン本体の別の差し込み口に直接差す

        • 無線マウスの受信機を抜きます。Microsoft は、受信機を抜いて約10秒待ってから差し直すよう案内しています。
        • 差し直すときは、前に差していた口とは別の差し込み口を選びます。デスクトップパソコンでは、本体の背面の差し込み口も試します。
        • USBハブ（差し込み口を増やす機器）や延長ケーブルを使っている場合は外して、パソコン本体の差し込み口に直接差します。
        • 新しいマウスに替えたときは、新しいマウスの箱に入っていた受信機を差しているかを確かめます。多くの無線マウスは、一緒に箱に入っていた受信機とだけつながります。
        • マウスを受信機に近づけて動かしてみます。マウスと受信機の間に、金属のものを置かないようにします。
        • 受信機を使わない Bluetooth のマウスは、パソコンとのペアリング（つなぐための登録）が必要です。「設定」→「Bluetooth とデバイス」で、Bluetooth がオンになっているか、マウスがつながっているかを確かめます。ペアリングのやり方は、マウスの取り扱い説明書で確かめてください。

      • 机がツルツルしているなら、紙を1枚敷いてその上で動かす

        • ガラスの机や、光をよく反射するツルツルした机の上では、コピー用紙などの無地の紙を1枚敷きます。その上でマウスを動かしてみます。
        • 紙の上で動くなら、机の表面が原因です。1週間の行動で、マウスパッドを用意します。
        • マウスの裏のセンサー（光が出る小さな穴）に、ほこりや髪の毛が付いていないかも見ます。付いていたら、やわらかい乾いた布でやさしく拭きます。

      • カーソルが見つからないときは、Ctrl キーで位置を表示させる

        • まず、Ctrl キーを押してみます。カーソルの位置を円で示す設定がオンになっていれば、カーソルのまわりに円が表示されます。
        • 何も表示されないときは、キーボードだけで設定をオンにできます。Windows キーを押しながら R キーを押すと、「ファイル名を指定して実行」が開きます。main.cpl と入力して Enter キーを押すと、「マウスのプロパティ」が開きます。
        • 「マウスのプロパティ」では、Ctrl キーを押しながら Tab キーを押すと、上のタブが切り替わります。「ポインター オプション」タブに切り替えます。
        • Tab キーを押して、「Ctrl キーを押すとポインターの位置を表示する」の項目まで選択を進めます。Space キーを押してチェックを入れ、Enter キーを押して閉じます。
        • マウスかタッチパッドが動くときは、「スタート」→「設定」→「Bluetooth とデバイス」→「マウス」→「その他のマウス設定」でも、「マウスのプロパティ」を開けます。
        • テレビや別の画面をつないでいる場合は、カーソルがそちらの画面に移っていることがあります。Windows キーを押しながら P キーを押し、矢印キーで「PC 画面のみ」を選んで Enter キーを押すと、パソコンの画面だけに表示を戻せます。

      • ノートパソコンのタッチパッドが動かないときは、オフになっていないか確かめる

        • キーボードの F1〜F12 のキーに、タッチパッドの絵が描かれたものがないかを見ます。あれば押してみます。機種によっては、Fn キーを押しながら押します。どのキーかは、パソコンの取り扱い説明書で確かめてください。
        • Windows の設定も確かめます。Windows キーを押して「タッチパッド」と入力し、Enter キーを押すと、タッチパッドの設定が開きます。Tab キーで「タッチパッド」のスイッチまで選択を進め、オフになっていたら Space キーでオンにします。
        • 同じ画面にある「マウスの接続時にタッチパッドをオフにしない」のチェックが外れていると、マウスの受信機を差している間は、タッチパッドがオフになります。受信機を抜くとタッチパッドが動くなら、この設定が原因です。マウスとタッチパッドを両方使いたいときは、チェックを入れます。
        • 機種によっては、タッチパッドの設定がメーカーの専用のソフトにある場合もあります。

      • パソコンを再起動する

        • 作業中のファイルを保存します。多くのアプリでは、Ctrl キーを押しながら S キーを押すと保存できます。
        • Windows キーを押しながら D キーを押して、デスクトップを表示します。
        • Alt キーを押しながら F4 キーを押すと、「Windows のシャットダウン」の画面が出ます。矢印キーで「再起動」を選び、Enter キーを押します。
        • タッチパッドが動くときは、「スタート」→「電源」→「再起動」の順に選んでも構いません。
        • 再起動が終わったら、マウスが動くかを確かめます。一時的な不具合なら、これで直ることがあります。

      • 別のマウスや別のパソコンで試して、どちらが悪いか切り分ける

        • 家族のパソコンなど、別のパソコンが身近にあれば、マウスの受信機をそちらに差して動くかを確かめます。
        • 別のパソコンで動けば、マウスは無事です。原因は元のパソコン側にあるので、上の手順と、1週間の行動の「ドライバーを確かめる」を見直します。
        • 別のパソコンでも動かなければ、マウス本体の故障の可能性が高くなります。
        • 家族の有線マウスなど、別のマウスを元のパソコンにつないでみる方法もあります。有線マウスで動けば、無線の受信機や電池の側に原因があると分かります。

      • 急ぎの操作は、キーボードだけで行う

        • マウスが直るまでの間は、キーボードで操作できます。Tab キーで次の項目へ、Shift キーを押しながら Tab キーで前の項目へ移ります。Enter キーで決定し、Esc キーで閉じます。
        • Alt キーを押しながら Tab キーを押すと、開いているウィンドウを切り替えられます。
        • アプリを開くときは、Windows キーを押してアプリの名前を入力し、Enter キーを押します。
        • テンキーのあるキーボードなら、Windows の「マウス キー」で、テンキーを使ってカーソルを動かせます。「設定」→「アクセシビリティ」→「マウス」で「マウス キー」をオンにします。左の Alt キーと左の Shift キーを押しながら NumLock キーを押しても、オンとオフを切り替えられます。

      • Mac では、接続とポインタの設定を確かめる

        • Mac でも、まずマウスの電源と電池や充電、受信機の差し込み口を確かめます。Bluetooth のマウスは、アップルメニュー →「システム設定」→「Bluetooth」で、Bluetooth がオンになっているかを確かめます。
        • Magic Mouse がつながらない場合の確かめ方は、下の「公式のヘルプ」にある Apple のページで案内されています。
        • ポインタが見つからないときは、マウスやトラックパッドを素早く動かします。「システム設定」→「アクセシビリティ」→「ディスプレイ」で「マウスポインタをシェイクして見つける」がオンになっていれば、ポインタが一時的に大きく表示されます。

    2. 1週間の行動

      目安：記録と設定に10〜20分ほど。マウスパッドや電池を買う場合は数百円から

      • 直った原因をメモしておく

        • 何をしたら直ったのかを、紙やスマホのメモに書いておきます。たとえば、「差し込み口を変えたら直った」「電池の向きが逆だった」「紙を敷いたら動いた」「タッチパッドの設定がオフだった」「再起動で直った」などです。
        • 同じことがまた起きたときは、メモに書いたことから先に確かめます。
        • 同じ差し込み口でまた動かなくなる場合は、その差し込み口を使わないようにします。ほかの機器でも同じ口が使えないなら、パソコンのメーカーに相談します。

      • 無線マウスの予備の電池を1組、パソコンのそばに置いておく

        • マウスに合う電池（単3形か単4形か）を確かめて、予備を1組用意します。
        • パソコンのそばの引き出しなど、すぐ取り出せる場所に置きます。
        • 充電式のマウスは、充電用のケーブルを決まった場所に置いておきます。

      • よく使う機器は、パソコン本体の差し込み口に直接差す

        • USBハブを通すより、パソコン本体に直接差すほうが安定することが多いです。マウスの受信機など、よく使う機器は本体の差し込み口に差します。
        • 差し込み口が足りずにハブを使う場合は、AC アダプター（電源）につなげるハブを選び、電源につないだ状態で使います。
        • USBの差し込み口の不具合については、お悩み No.042「USBメモリを差してもパソコンが認識しない。中の資料を取り出す切り分けと直し方」も参考にしてください。

      • マウスパッドを用意する

        • ツルツルした机やガラスの机で使う場合は、マウスパッドを敷きます。マウスの動きが安定します。
        • マウスパッドは、家電量販店や100円ショップなどで買えます。布製のマウスパッドは、多くのマウスで使えます。
        • マウスパッドが届くまでは、無地の紙やノートを敷いて代わりにします。

      • カーソルを見失いやすい人は、見つけやすくする設定をしておく

        • 「スタート」→「設定」→「Bluetooth とデバイス」→「マウス」→「その他のマウス設定」で「マウスのプロパティ」を開きます。「ポインター オプション」タブで「Ctrl キーを押すとポインターの位置を表示する」にチェックを入れ、「OK」を押します。今日の手順でオンにした場合は、オンになっているかを確かめます。
        • 同じタブの「入力中にポインターを非表示にする」にチェックが入っていると、文字を打っている間はカーソルが消えます。消えると困る場合は、チェックを外します。
        • カーソルを大きくしたり、色を変えたりすることもできます。「設定」→「アクセシビリティ」→「マウス ポインターとタッチ」で、「マウス ポインター スタイル」と「サイズ」を変えます。
        • Mac では、「システム設定」→「アクセシビリティ」→「ディスプレイ」で、「ポインタのサイズ」や、ポインタの枠線と塗りつぶしの色を変えられます。

      • 再起動で直らなかったら、マウスのドライバーを確かめる

        • Windows キーを押して「デバイス マネージャー」と入力し、Enter キーを押します。
        • 「マウスとそのほかのポインティング デバイス」や「ヒューマン インターフェイス デバイス」の項目を開き、黄色い「!」の印が付いたものがないかを見ます。Microsoft の案内では、タッチパッドもこのどちらかの項目にあります。
        • 印の付いた項目を選び、「ドライバーの更新」→「ドライバーを自動的に検索」を選びます。キーボードだけで操作するときは、項目を選んでから Shift キーを押しながら F10 キーを押すと、右クリックと同じメニューが開きます。
        • 「設定」→「Windows Update」で「更新プログラムのチェック」も行います。Microsoft は、ドライバーを Windows Update で更新する方法を勧めています。
        • ドライバーは、Windows Update か、パソコンやマウスのメーカーの公式サイトから入れます。それ以外のサイトから、ドライバーや「ドライバー更新ソフト」をダウンロードしないでください。

    3. 1か月の見直し

      目安：1か月後に20〜30分ほど

      • マウスは消耗品と考え、動きがおかしくなったら早めに買い替えを考える

        • 1週間のメモを見返して、同じことが何度も起きていないかを確かめます。
        • 電池や差し込み口、机の表面を確かめても、カーソルが飛ぶ、動きが途切れる、1回のクリックが2回になる、といったことが続く場合は、マウス本体が傷んできている可能性があります。
        • マウスは消耗品です。動きがおかしくなってきたら、仕事や手続きの途中で動かなくなる前に、早めに買い替えを考えます。

      • 買うときは、手の大きさや持ち方に合うものを選ぶ

        • できれば店頭で実際に握ってみて、手の大きさに合うものを選びます。小さすぎるマウスや大きすぎるマウスは、手が疲れやすくなります。
        • 手のひら全体でかぶせるように持つか、指先でつまむように持つかによっても、合う形が変わります。
        • ツルツルした机で使う場合は、ガラスの上でも使えると書かれた製品もあります。パッケージの説明で確かめます。

      • 電池式か充電式か、つなぎ方を、自分の使い方で選ぶ

        • 電池式は、電池を替えればすぐ使えます。予備の電池を用意しておく必要があります。
        • 充電式は、電池を買う必要がありません。充電を忘れると使えなくなるので、充電する習慣が必要です。
        • 無線マウスには、受信機を差すものと Bluetooth のものがあります。受信機を差すものは、差すだけで使えることが多いです。Bluetooth のものは差し込み口を使いませんが、最初にペアリングが必要です。
        • 電池や接続が心配な場合は、ケーブルでつなぐ有線マウスも選べます。電池が要らず、つなぐだけで使えることが多いです。
        • 受信機や有線マウスの端子の形（USB-A か USB-C か）が、パソコンの差し込み口に合うかも確かめます。

      • 家族にも、切り分けの手順を共有しておく

        • 家族でパソコンを使っている場合は、「カーソルが動かないときは、まず電池と差し込み口を確かめる」と伝えておきます。
        • 確かめる順番（キーボードの反応、電池、差し込み口、紙を敷く、タッチパッドの設定、再起動）を紙に書いて、パソコンのそばに置いておくと、慌てずに済みます。

    まず今日、キーボードが反応するかを確かめ、マウスの電源スイッチと電池の向きを見ます。受信機を一度抜き、USBハブを使わずに、パソコン本体の別の差し込み口に直接差します。机がツルツルしているなら、紙を1枚敷いて動かします。カーソルが見つからないときは Ctrl キーで位置を表示させ、タッチパッドが動かないときは、オフになっていないかを確かめます。それでも直らなければ、パソコンを再起動し、別のマウスや別のパソコンで試して、どちらが悪いかを切り分けます。次の1週間で、直った原因をメモし、予備の電池やマウスパッドを用意して、カーソルを見つけやすくする設定をします。1か月後に、マウスの買い替えの目安と選び方を確かめ、切り分けの手順を家族とも共有します。手順の名前や場所は、パソコンの種類やバージョンで変わることがあります。分からないところは、使っている機種の説明書や、公式のヘルプで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンやマウスの修理についての専門的な助言ではありません。特定の製品やサービスを勧めるものでもありません。設定の変更は、ご自身の判断と責任で行ってください。

    マウスやパソコンを分解したり、中をいじったりしないでください。ほかの部品を壊したり、けがをしたり、メーカーの保証が受けられなくなったりするおそれがあります。

    よく分からない「ドライバー更新ソフト」や「パソコンを速くする」ソフトを入れて、直そうとしないでください。不要なソフトや悪意のあるプログラムが入ったり、高額な料金を求められたりするおそれがあります。ドライバーは、Windows Update か、パソコンやマウスのメーカーの公式サイトから入れてください。

    「ウイルスに感染しました」「今すぐ電話してください」という画面が出ても、表示された電話番号には電話しないでください。IPA（情報処理推進機構）は、このような表示を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。サポートを名乗る電話やメールで、パスワードや確認コードを聞かれても、教えないでください。

    どうしても直らないときは、パソコン教室や、パソコンやマウスのメーカーのサポート、修理店に相談してください。困ったときは、一人で抱え込まずに、家族にも相談してください。

    公式のヘルプ

    • Windows でのマウス、キーボードの問題（Microsoft サポート。受信機の差し直しや、別の USB ポートの試し方が載っています）
    • マウスの設定を変更する（Microsoft サポート。Ctrl キーでポインターの位置を表示する設定を含みます）
    • Windows のタッチパッドの問題を解決する（Microsoft サポート）
    • Windows のデバイス マネージャーを使用してドライバーを更新する（Microsoft サポート。ドライバーの再インストールの手順も載っています）
    • Windows の Bluetooth の問題を解決する（Microsoft サポート）
    • Macでポインタを見やすくする（Apple サポート）
    • Magic Keyboard、Magic Mouse、Magic TrackpadをMacに接続できない場合（Apple サポート）
    • 使っているパソコンやマウスのメーカーのサポートページ（タッチパッドをオンにするキーや、マウスのペアリングの方法などの案内）
