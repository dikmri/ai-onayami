お悩み No.143 ・ 2026年11月28日公開

パソコンの画面下のバー（タスクバー）が消えた・表示されない

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    設定の見直しで直るもので、解決・軽減できる。ボトルネックはタスクバーが隠れる設定になっていることに気づいていないこと、画面の外にはみ出している・別のモニター側に表示されていることに気づいていないこと、タスクバーがフリーズしている場合と設定の問題が混同されやすいこと

    画面の下のバーは「タスクバー」と呼ばれます。タスクバーが消えたように見えるとき、多くの場合はタスクバー自体は壊れていません。隠れる設定になっている、別のモニターの側に出ている、画面の外にはみ出している、のどれかで見えなくなっています。どれも Windows の設定で戻せます。タスクバーを表示するプログラムが止まっている場合も、タスク マネージャーから再起動すると戻ることがあります。

    ボトルネックは3つです。1つ目は、タスクバーが自動的に隠れる設定になっていることに気づいていないことです。2つ目は、タスクバーが画面の外にはみ出していたり、別のモニターの側に出ていたりすることに気づいていないことです。3つ目は、タスクバーが止まっている場合と、設定で隠れている場合が混同されやすいことです。直し方が違うので、先にどちらかを見分けます。

    お悩みのように、ブラウザーが画面いっぱいに表示されている場合は、ブラウザーの全画面表示も疑います。全画面表示では、タスクバーもブラウザーのタブも見えなくなります。キーボードの F11 キーを押すと、全画面表示のオンとオフが切り替わります。

    この記事は、2026年11月時点の Microsoft、Google、富士通の公式情報をもとにしています。Windows の画面では「タスク バー」と、間にスペースを入れて表示されます。この記事では、画面の項目名だけを画面どおりに書きます。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    画面の下のバーが消えた。スタートボタンも、アプリのアイコンも、右下の時計も見えない
    スタートボタン、開いているアプリのアイコン、右下の時計は、どれもタスクバーの部品です。3つが同時に消えたのなら、タスクバー全体が隠れているか、表示されていない状態です。部品が1つずつ壊れたわけではありません。
    画面いっぱいにブラウザーだけが表示されていて、アプリの切り替えも、電源の切り方も分からない
    タスクバーが見えなくても、キーボードで操作できます。アプリの切り替えは Alt キーを押しながら Tab キーを押します。電源を切るときは、Windows キーでスタート メニューを開くか、Ctrl キーと Alt キーを押しながら Delete キーを押した画面から操作します。ブラウザーのタブやアドレス バーまで見えない場合は、ブラウザーが全画面表示になっている可能性があります。
    前にモニターをもう一台つないでいて、その後からおかしくなった気がする
    モニターを2台つないでいると、タスクバーをどの画面に出すかの設定が加わります。メイン ディスプレイの指定や表示のしかたが、モニターを外したあとも前のままになっていることがあります。モニターの台数が変わったときは、表示の設定を確かめます。
    マウスを画面の下に持っていっても何も出てこない
    自動的に隠す設定なら、マウスを画面の下の端に当てると出てきます。それでも出てこない場合は、ほかの原因が考えられます。タスクバーが画面の外にはみ出している、上や横など別の位置にある、別のモニターに出ている、タスクバーを表示するプログラムが止まっている、などです。
    再起動しても直らない
    富士通の Q&A は、デスクトップのアイコンとタスクバーの両方が消えたときは、Windows に一時的な問題が起きている可能性があるとして、再起動を勧めています。再起動で直らないことから、AIは、一時的に止まっているよりも、設定が原因の可能性が高いと考えます。設定は再起動しても変わらないからです。

    タスクバーが見えなくなる仕組み

    タスクバーが消えたように見える理由を、1つずつ説明します。

    タスクバーは、スタートボタン、アプリのアイコン、時計をまとめて表示するバー
    Microsoft は、タスク バーを、アプリの起動、開いているウィンドウの切り替え、スタート メニューなどの機能を使うための、Windows の中心的な部分と説明しています。右下の時計や音量のアイコンも、タスクバーの右端の領域にあります。
    「タスク バーを自動的に隠す」がオンだと、使っていないときは隠れる
    この設定がオンだと、タスクバーは使っていないときに自動的に見えなくなります。マウスのポインターを画面の下の端に置くと、タスクバーが出てきます。富士通の Q&A によると、Windows 11 でこの設定を使えるのは、タスクバーが画面の下にある場合だけです。オフにしておけば、タスクバーは画面の下に表示されたままになります。
    モニターが2台以上だと、タスクバーを出す画面の設定が加わる
    「タスク バーをすべてのディスプレイに表示する」がオンだと、つないでいるすべての画面にタスクバーが出ます。オフだと、タスクバーはメイン ディスプレイに出るのが一般的な動きです（これは AI の説明で、公式情報で確かめたものではありません）。メイン ディスプレイは、「設定」の「ディスプレイ」にある「これをメイン ディスプレイにする」で決めます。今見ていない側のモニターがメインになっていると、手元の画面にはタスクバーが出ません。
    タスクバーの位置は、下以外にもできる
    Windows 10 では、タスクバーを画面の左、上、右、下のどこに置くかを選べます。Windows 11 でも、2026年8月以降の更新プログラムで、下部、上部、左側、右側から選べるようになりました。この機能は段階的に配信されているため、まだ設定が無い PC もあります。下以外になっていると、いつもの場所にタスクバーが見当たりません。
    画面の解像度が合っていないと、端が欠けて見えることがある
    Microsoft は、ふだんは「(推奨)」と書かれた解像度を使うのが最適だと説明しています。モニターに合わない解像度にすると、画面が中央に小さく表示されたり、引き伸ばされたりすることがあります。テレビや一部のモニターでは、画面の端が切れて表示されることもあります。下の端が切れると、そこにあるタスクバーが見えなくなります。最後の2文は AI の一般的な説明です。
    タスクバーを表示するプログラムが止まると、タスクバーごと消える
    タスクバーとデスクトップは、「エクスプローラー」（explorer.exe）というプログラムが表示しています。このプログラムが止まると、タスクバーが表示されなくなることがあります。Microsoft は、画面にマウスのカーソルだけが見えるときの手順として、タスク マネージャーからエクスプローラーを再起動する方法を挙げています。
    ブラウザーの全画面表示では、タスクバーも隠れる
    Microsoft Edge と Google Chrome には、画面全体にページだけを表示する全画面表示があります。Edge は F11 キーで全画面表示のオンとオフが切り替わります。Chrome は F11 キーでオンになり、F11 キーか、Esc キーの長押しでオフになります。全画面表示では、タスクバーに加えて、ブラウザーのタブやアドレス バーも見えなくなります。

    原因の切り分け方

    次の順に試すと、どの原因かの見当がつきます。どれも、Windows とブラウザーに最初からある機能だけで確かめられます。

    ブラウザーのタブやアドレス バーも見えない
    ブラウザーの全画面表示の可能性が高いです。F11 キーを1回押します。タブとタスクバーが出てきたら、全画面表示が原因です。
    マウスを画面の下の端に持っていくと、タスクバーが出てくる
    「タスク バーを自動的に隠す」がオンになっている可能性が高いです。設定でオフにすれば、表示されたままになります。
    Windows キーを押すと、スタート メニューが開く
    タスクバー自体は止まっておらず、見えていないだけの可能性が高いです。隠れる設定、タスクバーの位置、別のモニター、画面からのはみ出しを順に確かめます。スタート メニューが開けば、そこから「設定」と「電源」も使えます。
    Windows キーでは何も出ないが、Ctrl + Shift + Esc でタスク マネージャーが開く
    エクスプローラーが止まっている可能性が高いです。タスク マネージャーからエクスプローラーを再起動すると、直る可能性があります。
    モニターを外したあとから、タスクバーが出なくなった
    表示の設定で、メイン ディスプレイや表示のしかたが前のままになっている可能性が高いです。Windows キー + P で「PC 画面のみ」を選ぶか、「設定」の「ディスプレイ」で確かめます。
    タスクバーが画面の上や左右にある
    タスクバーの位置が下以外に変わっています。「タスク バーの動作」の「タスク バーの位置」で「下」に戻します。
    画面全体が真っ黒で、何も表示されない
    タスクバーだけの問題ではなく、グラフィックス ドライバーや画面の不具合の可能性もあります。Microsoft は、Windows キー + Ctrl + Shift + B でグラフィックス ドライバーをリセットする方法を挙げています。成功すると、ビープ音が鳴るか、画面がちらつくと書かれています。真っ黒な画面の直し方は、お悩み No.029「パソコンの電源を入れても画面が真っ暗。起動しないときにまず確かめること」にまとめています。

    落とし穴

    タスクバーを戻そうとして、かえって困らないために、気をつけたい点があります。

    「タスクバーを直します」という見知らぬソフトを入れる
    広告で出てくる修復ソフトの中には、かえって広告や課金のトラブルにつながるものがあります。この記事の手順は、すべて Windows に最初からある設定と機能でできます。富士通の Q&A には、スタート メニューやタスクバーの見た目を変えるアプリの影響で、スタート メニューが表示されなくなることがあるとも書かれています。
    タスクバーの位置が変わったことに気づかない
    タスクバーが画面の上や横に移っていると、消えたように見えることがあります。富士通の Q&A でも、タスクバーが上部や右端、左端に表示される例が挙げられています。画面の上と左右の端も見て、設定で位置を確かめます。
    インターネットで見つけた「レジストリを書き換える」方法を試す
    レジストリは、Windows の動きを決める大事な設定の集まりです。書き換えを間違えると、パソコンが起動しなくなるおそれがあります。この記事のように、設定アプリとタスク マネージャーを使う公式の手順で直します。
    モニターを外せば、表示の設定も元に戻ると思い込む
    モニターを外しただけでは、表示の設定が1台のときの状態に戻らないことがあります。モニターを外したあとは、設定の「ディスプレイ」で、表示されている画面の数とメイン ディスプレイを確かめます。
    すぐに電源ボタンを長押しして切る
    電源ボタンの長押しで電源を切る方法は、ほかの方法で操作できないときの最後の手段です。富士通の Q&A は、再起動すると、編集中のファイルなど保存されていないデータは失われると注意しています。先に、キーボードで電源を切る方法を試します。

    公式情報で確かめたこと

    次のことを、各社の公式情報と、Windows 11 の画面の表示で確かめました。Windows のバージョンによって、手順や画面の名前が違う場合があります。

    タスクバーの設定（Microsoft サポート「Windows でタスク バーをカスタマイズする」）
    Windows 11 では、タスク バーを右クリックして「タスク バーの設定」を選び、「タスク バーの動作」を展開して、「タスク バーを自動的に隠す」をオンまたはオフにします。非表示になったタスク バーは、画面の下端にマウス ポインターを置くか、タッチすると表示されます。「すべてのディスプレイでタスク バーを表示する」をオンにすると、つないでいるすべてのディスプレイにタスク バーが表示されます。Windows 10 では、「タスク バーの設定」で「デスクトップ モードでタスクバーを自動的に隠す」か「タブレット モードでタスクバーを自動的に隠す」をオンにします。Windows 10 の位置は、「画面上のタスク バーの場所」で「左」「上」「右」「下」から選び、タスク バーの固定が解除されていると変えられます。この記事の Windows 11 の部分には、タスク バーを画面の上部や側面に移動する設定は無いと書かれています。下の更新プログラムの説明とは食い違っていて、記事が新しい機能に追いついていないとみられます。
    Windows 11 のタスクバーの位置（Microsoft サポート「2026 年 8 月 27 日 — KB5120998 プレビュー」）
    Windows 11 バージョン 25H2 と 24H2 向けの更新プログラムです。タスク バーを画面の下部、上部、左側、右側のどこに表示するかを選べるようになったと書かれています。場所は「設定」→「個人用設定」→「タスク バー」→「タスク バーの動作」→「タスク バーの位置」です。検索ボックスと小さいタスク バーは、上部と下部の位置でだけ使えます。機能は段階的に配信され、使えるようになる時期は PC によって違います。
    複数のモニターのタスクバーの設定（Microsoft サポート「2026 年 10 月 28 日 — KB5127936 プレビュー」）
    Windows 11 バージョン 26H2 と 25H2 向けの更新プログラムです。モニターをつないだり外したりしたときに、複数のモニターに関するタスク バーの設定が保たれやすくなったと書かれています。これも段階的に配信される変更です。
    画面が表示されないときの手順（Microsoft サポート「Windows の空白の画面のトラブルシューティング」）
    Windows 11 と Windows 10 が対象の記事です。カーソルのある空白の画面は、多くの場合、Windows のプロセスの停止かドライバーの問題が原因と書かれています。基本の手順として、Windows + Ctrl + Shift + B でグラフィック ドライバーをリセットすること、Windows + P で表示モードを切り替えること、Ctrl + Alt + Del の画面からタスク マネージャーを開いて Windows エクスプローラーを再起動することが挙げられています。エクスプローラーの再起動は、Ctrl + Shift + Esc でタスク マネージャーを開き、Windows エクスプローラーを右クリックして「再起動」を選びます。一覧に無い場合は、「ファイル」→「新しいタスクの実行」で「explorer.exe」と入力して Enter キーを押します。グラフィック ドライバーは、デバイス マネージャーの「ディスプレイ アダプター」から更新し、更新後に問題が出た場合は「ドライバーのロールバック」を選びます。
    複数のモニターの使い方（Microsoft サポート「Windows で複数のモニターを使用する方法」）
    どの番号がどのディスプレイかは、「設定」→「システム」→「ディスプレイ」→「識別」で確かめられます。Windows キー + P で、表示のしかたを「PC 画面のみ」「複製」「拡張」「セカンド スクリーンのみ」から選びます。1つのディスプレイだけに表示するのは「PC 画面のみ」です。
    メイン ディスプレイの決め方（富士通 FMV Q&A「マルチモニター機能を設定する方法を教えてください。」）
    Windows 11 では、「スタート」→「設定」→「システム」→「ディスプレイ」を開き、メインにしたいディスプレイのアイコンをクリックします。「マルチ ディスプレイ」をクリックし、「これをメインディスプレイにする」にチェックを付けて、「適用」を押します。チェックが付いていてクリックできない場合は、そのまま次の手順に進むように書かれています。
    解像度（Microsoft サポート「Windows で画面の解像度とレイアウトを変更する」）
    「設定」→「システム」→「ディスプレイ」の「ディスプレイの解像度」で、ふだんは「(推奨)」と書かれたものを選ぶのが最適と書かれています。ネイティブより低い解像度にすると、文字が鮮明でなくなったり、画面が中央に小さく表示されて周りが真っ暗になったり、引き伸ばされたりすることがあります。解像度が予期せず変わる場合は、Windows Update でグラフィック ドライバーを更新する必要がある場合があります。
    キーボードの操作（Microsoft サポート「Windows のキーボード ショートカット」）
    Windows キーでスタート メニューを開閉し、Windows キー + I で「設定」を開きます。Alt + Tab で開いているウィンドウを切り替えます。Ctrl + Shift + Esc でタスク マネージャーを開きます。Ctrl + Alt + Del は、ロックやサインアウト、タスク マネージャーを開けるセキュリティ画面に切り替えます。Windows キー + X は、スタートボタンを右クリックしたときと同じメニューを開きます。Alt + F4 は作業中のウィンドウを閉じ、開いているウィンドウが無い場合はシャットダウンを求める画面を出します。
    電源の切り方（Microsoft サポート「PC をシャットダウン、スリープ、休止状態にする」、富士通 FMV Q&A「[Windows 11] 電源を切る方法または再起動する方法を教えてください。」「デスクトップのアイコンやタスクバーが表示されなくなりました。」）
    シャットダウンは、「スタート」→「電源」→「シャットダウン」を選びます。Windows キー + X のメニューの「シャットダウンまたはサインアウト」からも操作できます。富士通の Q&A では、Ctrl + Alt + Delete を押して、画面右下に電源ボタンのマークが出たら、マーク→「再起動」とクリックする手順が案内されています。マークが出ない場合だけ、アクセスランプが消えていることを確かめてから、電源ボタンを電源が切れるまで4秒〜10秒以上押し続けます。
    タスクバーが見当たらない例（富士通 FMV Q&A「タスクバー（「スタート」ボタン）の位置やサイズが購入時の状態とは異なります。」「[Windows 11] タスクバーの表示内容を変更する方法を教えてください。」「[Windows 11] タスクバーの位置を変更する方法を教えてください。」）
    タスクバーが上部や右端、左端に表示される、デスクトップ画面で見当たらない、といった例が挙げられています。「タスク バーの設定」が表示されない場合は、Windows キー + I で「設定」を開き、「個人用設定」→「タスク バー」と進みます。「タスク バーを自動的に隠す」は、タスクバーが下部にある場合にだけ使えると書かれています。灰色で設定できない項目は、ディスプレイを2台以上つないでいる場合に使えるようになります。Windows 11 バージョン 26H2 の画面で、「タスク バーの動作」の「タスクバーの位置」から位置を選ぶ手順も載っています。
    ブラウザーの全画面表示（Microsoft サポート「Microsoft Edge のキーボード ショートカット」、Google Chrome ヘルプ「Chrome のキーボード ショートカット」）
    Edge は、F11 キーで全画面表示モードにする（切り替え）と書かれています。Chrome は、F11 キーで全画面表示モードをオンにし、F11 キーか Esc キーの長押しでオフにすると書かれています。
    Windows Update（富士通 FMV Q&A「[Windows 11] スタートメニューが表示されません。」）
    「設定」の「Windows Update」で、「最新の状態です」と表示されている場合は「更新プログラムのチェック」ボタンを押す手順が案内されています。
    Windows 11 の画面の表示
    設定アプリの表記は、「タスク バーの動作」「タスク バーを自動的に隠す」「タスク バーをすべてのディスプレイに表示する」「タスク バーの位置」「マルチ ディスプレイ」「これをメイン ディスプレイにする」「ディスプレイの解像度」です。Microsoft のヘルプの「すべてのディスプレイでタスク バーを表示する」は画面では「タスク バーをすべてのディスプレイに表示する」、ヘルプの「複数のディスプレイ」は画面では「マルチ ディスプレイ」と表示されます。タスク マネージャーの新しい画面には「新しいタスクを実行する」「タスクの再起動」のボタンがあり、右クリックのメニューには「再起動」があります。日本語の Windows では、エクスプローラーの名前は「エクスプローラー」と表示されることがあります。Microsoft のヘルプの「Windows エクスプローラー」と同じものです。

    次のことは、今回の公式情報では確かめられませんでした。「タスク バーをすべてのディスプレイに表示する」がオフのとき、タスクバーがメイン ディスプレイに出るという点は、AI の説明です。画面の端が切れてタスクバーが見えなくなる点、モニターを外したあとも表示の設定が前のままになることがある点も、一般的な説明です。ブラウザーが再起動のあとも全画面表示のまま開くかどうかは、確かめられませんでした。ノートパソコンで Fn キーを使う点、エクスプローラーの再起動で画面が一瞬消える点も、一般的な説明です。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. タスクバーが見えなくなる
    2. 隠れる設定か、別の画面や位置に出ているのか、止まっているのかが分からない
    3. 再起動を繰り返したり、見知らぬ修復ソフトを探したりする
    4. 設定は変わらないので、また消えたままになる

    4のあと、また1に戻ります。

    この流れは、2のところで止められます。マウスを画面の下の端に当てる、F11 キーを押す、Windows キーを押す、Ctrl + Shift + Esc を押す。この4つの結果で、原因の見当がつきます。原因が分かれば、Windows の設定かタスク マネージャーで直せます。

    混同しやすいのは、タスクバーが止まっている場合と、設定で隠れている場合です。止まっている場合は、エクスプローラーの再起動で戻ります。設定で隠れている場合は、再起動しても戻らず、設定を変える必要があります。お悩みのように再起動で直らない場合は、設定を先に確かめます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • Windows のバージョンによって、設定の名前や場所が違うこと
    • 更新プログラムの機能が、PC によって届く時期が違うこと
    • モニターの機種による、画面の端の見え方
    • グラフィックス ドライバーや画面の故障

    変えやすいこと

    • キーボードで、アプリの切り替えと電源の操作をする
    • ブラウザーの全画面表示を F11 キーで切り替える
    • 「タスク バーを自動的に隠す」をオフにする
    • タスクバーの位置を「下」に戻す
    • 解像度を「(推奨)」に戻し、メイン ディスプレイを確かめる
    • エクスプローラーをタスク マネージャーから再起動する
    • モニターをつないだり外したりしたら、表示の設定を見る

    次の行動プランは3段階です。今日は、原因を見分けて、タスクバーを元に戻します。1週間で、モニターをつないだときと外したときの両方を確かめ、自分の使い方に合う設定を決めます。1か月で、同じ設定のまま使えているかを確かめ、再発したときの確かめ方を習慣にします。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。今日の手順は、上から順に進めてください。途中でタスクバーが戻ったら、そこで止めて、最後の「直ったら、その日のうちに確かめる」に進みます。

    手順は、2026年11月時点の Microsoft、Google、富士通の公式情報をもとにしています。手順の名前や画面の表示は、Windows のバージョンによって違います。分からないところは、Microsoft の公式サポートページで確かめてください。

    1. 今日からできる小さな一歩

      目安：15〜30分ほど。お金をかけずにできる設定の見直しだけです

      • 作業中のものを保存してから始める

        ブラウザーで入力中のフォームや、開いている文書があれば、先に保存します。あとの手順でエクスプローラーやパソコンを再起動すると、保存していない内容が消えることがあります。

      • マウスを画面の下の端にゆっくり持っていく

        マウスのポインターを画面の一番下まで動かし、端に当てたまま1秒ほど待ちます。モニターを2台つないでいる場合は、両方の画面の下の端で試します。画面の上と左右の端にタスクバーがないかも見ます。

        タスクバーが出てきたら、自動的に隠す設定が原因です。次の手順でオフにします。

        1. Windows キーを押しながら I キーを押して、「設定」を開きます。出てきたタスクバーの何もないところを右クリックして、「タスク バーの設定」を選んでも構いません。
        2. 「個人用設定」→「タスク バー」を選びます。
        3. 下にスクロールして「タスク バーの動作」を開きます。
        4. 「タスク バーを自動的に隠す」のチェックを外します。

        Windows 10 では、「設定」→「個人用設定」→「タスク バー」で、「デスクトップ モードでタスクバーを自動的に隠す」をオフにします。

      • ブラウザーのタブも見えなければ、F11 キーを押す

        画面いっぱいにページだけが表示されていて、タブやアドレス バーも見えない場合は、ブラウザーの全画面表示になっている可能性があります。キーボードの F11 キーを1回押します。Chrome では、Esc キーを長く押しても全画面表示が終わります。

        ノートパソコンで F11 キーを押しても変わらない場合は、Fn キーを押しながら F11 キーを押します。Fn キーの使い方は機種によって違うので、パソコンのマニュアルで確かめてください。

      • Windows キーを押して、スタート メニューが開くかを確かめる

        スタート メニューが開けば、タスクバー自体は止まっておらず、見えていないだけの可能性が高いです。次の3つを確かめます。

        • タスクバーの位置：「設定」→「個人用設定」→「タスク バー」→「タスク バーの動作」に「タスク バーの位置」があれば、「下」を選びます。この項目が無い Windows 11 では、位置は下のままです。Windows 10 では、「画面上のタスク バーの場所」で「下」を選びます。
        • 解像度：「設定」→「システム」→「ディスプレイ」を開き、「ディスプレイの解像度」で「(推奨)」と書かれたものを選びます。「拡大縮小とレイアウト」の「拡大/縮小」も、「(推奨)」と書かれたものに戻します。Microsoft のヘルプでは「スケールとレイアウト」「スケール」と書かれています。
        • メイン ディスプレイ：同じ「ディスプレイ」の画面で、ディスプレイが2つ以上表示されている場合は、今見ている画面のアイコンを選びます。「マルチ ディスプレイ」を開き、「これをメイン ディスプレイにする」にチェックを付けます。どのアイコンが今見ている画面か分からないときは、「識別」を押すと、各画面に番号が表示されます。

        今はモニターを1台しか使っていない場合は、Windows キーを押しながら P キーを押し、「PC 画面のみ」を選びます。

      • スタート メニューが開かなければ、エクスプローラーを再起動する

        1. Ctrl キーと Shift キーを押しながら Esc キーを押して、タスク マネージャーを開きます。
        2. 小さい画面で開いた場合は、下の「詳細」を押します。左側か上の「プロセス」を選びます。
        3. 一覧の「エクスプローラー」か「Windows エクスプローラー」を右クリックし、「再起動」を選びます。

        画面が一瞬消えて、タスクバーが戻ることがあります。一覧に見つからない場合は、上の「新しいタスクを実行する」を押します。以前の画面では「ファイル」→「新しいタスクの実行」です。「explorer.exe」と入力して Enter キーを押します。

      • それでも戻らなければ、キーボードで再起動する

        Ctrl キーと Alt キーを押しながら Delete キーを押します。画面右下に電源ボタンのマークが出たら、マーク→「再起動」とクリックします。電源ボタンを長く押して切るのは、このマークも出ない場合の最後の手段です。

        画面全体が真っ黒で何も表示されない場合は、Windows キー、Ctrl キー、Shift キーを押しながら B キーを押します。Microsoft は、これでグラフィックス ドライバーがリセットされると説明しています。

      • 直ったら、その日のうちに確かめる

        タスクバーが戻ったら、次の3つが元どおりできるかを確かめます。

        • タスクバーのアイコンや、Alt キーを押しながら Tab キーを押す操作で、アプリを切り替えられる
        • 「スタート」→「電源」から、シャットダウンを選べる
        • 右下に時計が表示されている

        どの手順で直ったかをメモしておきます。また消えたときに、同じ手順から試せます。

    2. 1週間の行動

      目安：モニターの確認に20分ほど。そのあと7日間、ふだんどおり使って様子を見る

      • モニターをつないだときと外したときの両方を確かめる

        もう一台のモニターを使う予定がある場合は、つないだ状態と外した状態の両方で、タスクバーが出るかを確かめます。外したあとは、「設定」→「システム」→「ディスプレイ」で、表示されている画面の数とメイン ディスプレイを見ます。

        2台の画面の使い方は、お悩み No.100「ノートパソコンを2画面にしたいのに、つないでも映らない・同じ画面しか出ない。デュアルディスプレイを広々使うには」にまとめています。

      • 「タスク バーをすべてのディスプレイに表示する」を試す

        2台つないだ状態で、「設定」→「個人用設定」→「タスク バー」→「タスク バーの動作」を開きます。「タスク バーをすべてのディスプレイに表示する」をオンにすると、どちらの画面にもタスクバーが出ます。オフにすると、片方の画面だけになります。両方を試して、自分の使い方に合うほうにします。この項目は、モニターを2台以上つないでいるときだけ選べます。

      • 自動的に隠す設定が原因だった場合は、オフのまま使ってみる

        オフにすると、タスクバーの分だけ画面が狭くなります。しばらく使って、不便がないかを確かめます。画面を広く使いたい場合は、新しい Windows 11 にある「タスク バーのサイズ」を「小」にする方法もあります。この項目が無い PC もあります。

      • モニターを外したあとに再発したら、メイン ディスプレイを見直す

        モニターを外すたびにタスクバーが消える場合は、外す前に、手元の画面をメイン ディスプレイにしておきます。「ディスプレイ」の画面で手元の画面のアイコンを選び、「マルチ ディスプレイ」の「これをメイン ディスプレイにする」にチェックを付けます。

      • 電源の切り方とアプリの切り替え方を覚えておく

        タスクバーが見えないときでも、次のキーで操作できます。紙に書いてパソコンの近くに置いておくと、また消えたときに慌てずに済みます。

        • アプリの切り替え：Alt キーを押しながら Tab キー
        • スタート メニュー：Windows キー
        • 設定：Windows キー + I
        • タスク マネージャー：Ctrl キー + Shift キー + Esc キー
        • 電源の操作：Ctrl キー + Alt キー + Delete キーで出る画面の右下のマーク、または Windows キー + X の「シャットダウンまたはサインアウト」

    3. 1か月の見直し

      目安：月に1回、10分ほど。モニターをつなぎ替えたときに5分ほど

      • 直った設定のまま使い続ける

        1か月のあいだ、タスクバーが消えずに使えたかを振り返ります。消えなければ、そのままの設定で構いません。

      • 再発したら、Windows Update を確かめる

        「設定」→「Windows Update」を開きます。「最新の状態です」と表示されていても、「更新プログラムのチェック」を押して確かめます。Microsoft は、2026年10月28日のプレビューの更新プログラムで、モニターをつないだり外したりしたときに、タスク バーの設定が保たれやすくなったと説明しています。段階的に配信される変更なので、届く時期は PC によって違います。

      • グラフィックス ドライバーの更新が必要かを確かめる

        解像度が勝手に変わる、画面が真っ黒になる、といったことが続く場合は、グラフィックス ドライバーの更新が必要なことがあります。まず Windows Update を確かめます。それでも続く場合は、パソコンのメーカーの公式サポートページで、自分の機種のドライバーを確かめます。ドライバーをダウンロードするのは、メーカーの公式ページからにします。

        更新したあとからおかしくなった場合は、デバイス マネージャーの「ディスプレイ アダプター」から「ドライバーのロールバック」を選ぶ方法があります。

      • モニターをつないだり外したりしたら、そのつど表示の設定を見る

        モニターを増やしたり外したりしたときは、「設定」→「システム」→「ディスプレイ」で、画面の数、メイン ディスプレイ、解像度を確かめます。1分ほどで済みます。先に見ておくと、タスクバーが見えなくなったときに、原因に早く気づけます。

      • エクスプローラーの再起動が何度も必要なら、相談する

        何度もエクスプローラーを再起動しないと戻らない場合は、タスクバーやスタート メニューの見た目を変えるアプリを入れていないかを確かめます。入れている場合は、そのアプリの提供元に相談します。心当たりがなければ、パソコンのメーカーのサポート窓口に相談します。急に固まるときの対処は、お悩み No.020「パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？」にまとめています。

    1か月たったら、タスクバーが消えずに使えたかを振り返ります。消えなければ、今の設定のまま使い続けて構いません。また消えた場合は、今日の手順の順番で確かめ直し、メモしておいた手順から試します。手順の名前や画面の表示は、Windows のバージョンによって違います。分からないところは、Microsoft の公式サポートページで確かめてください。
