お悩み No.120 ・ 2026年11月26日公開

パソコンの写真のファイル名が IMG_0001 ばかりで、探したい写真が見つからない・一括で分かりやすい名前に変えたい

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    写真や書類のファイル名が分かりにくい問題は、Windows に最初からある一括名前変更の機能と、名前の付け方のルールを決めることで、かなり軽くできる見込みが高い。名前を変えるだけなら写真の中身は変わらず、コピーを作ってから試せば元に戻せるので、失敗の心配は小さくできる

    Windows のエクスプローラーでは、複数のファイルをまとめて選んで F2 キーを押すと、1つの名前を入れるだけで全部の名前を変えられます。同じ名前の後ろに、番号が自動で付きます。名前の一部だけを置き換えたいときは、Microsoft の無料ツール PowerToys に入っている PowerRename を使えます。

    ボトルネックは3つです。1つ目は、1枚ずつしか変えられないと思い込んでいることです。2つ目は、名前の付け方のルールが決まっていないことです。3つ目は、間違えて上書きしないか不安なことです。

    名前を変えても、写真の中身や画質は変わりません。先にコピーを作って、コピーのほうで試せば、失敗しても元の写真は残ります。変えた直後なら、Ctrl + Z で元に戻すこともできます。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    写真の名前が IMG_0001 や DSC_0234 のようなものばかりで、探したい写真が見つからない
    カメラやスマホが自動で付けた名前のまま保存している状態です。この名前からは、いつ、どこで撮った写真かが分かりません。探すときは、1枚ずつ開いて確かめることになります。
    「いつ・どこで撮ったか」が分かる名前に変えたい
    名前に日付と行事や場所を入れれば、名前を見るだけで分かるようになります。日付を先頭に置くと、名前の順に並べたときに日付の順にも並びます。
    何百枚もあり、1枚ずつ右クリックで変えるのは無理
    1枚ずつ変える必要はありません。エクスプローラーでは、まとめて選んだファイルの名前を一度に変えられます。
    書類も「最終版」「最終版2」のような名前で、どれが一番新しいか分からない
    「最終版」という言葉には、日付も順番も入っていません。名前の先頭に日付を入れ、最後に v2、v3 のような版の番号を付けると、どれが新しいかが名前だけで分かります。
    一括で変えると、上書きしたり順番がバラバラになったりしないか不安
    名前の変更は、ファイルの中身を書き換える操作ではありません。それでも、思った通りの名前にならないことはあります。コピーを取り、少ない枚数で試してから広げると、失敗しても困らずに済みます。
    中身は変えずに、名前だけを「日付_場所_連番」の形にそろえたい
    エクスプローラーの一括の名前変更と PowerRename は、どちらも名前だけを変えます。写真の中身や画質は変わりません。

    名前を一括で変える仕組み

    名前を一括で変える方法と、分かりやすい名前の付け方について、仕組みを分けて説明します。

    エクスプローラーで、まとめて選んで F2 を押す
    Microsoft の「Windows のキーボード ショートカット」では、F2 は「選択された項目の名前を変更する」キーです。Ctrl + A は「ウィンドウ内のすべてのアイテムを選択する」キーです。複数のファイルを選んだ状態で F2 を押し、名前を1つ入れて Enter を押すと、選んだファイルが全部その名前になります。同じ名前が重ならないように、名前の後ろに (1)、(2) のような番号がかっこ付きで付きます。
    名前は「日付_内容_番号」の順に並べる
    「2026-11-15_運動会_01.jpg」のように、先頭に年月日、次に何の写真か、最後に番号を書きます。名前の順に並べると、日付の順にも並びます。書類なら「20261126_請求書_v2」のように、日付、内容、版の順にします。
    月と日は、0を付けて2けたにそろえる
    4月5日なら「04-05」と書きます。「4-5」と書くと、アプリや並べ方によっては、10月のファイルが4月より前に並ぶことがあります。2けたにそろえておけば、どこで並べても順番が崩れません。
    PowerRename：名前の一部だけを置き換え、変える前に結果を確かめる
    PowerRename は、Microsoft の PowerToys に入っている一括名前変更ツールです。Microsoft Learn の説明では、PowerToys は「無料のオープンソース ユーティリティのセット」です。PowerRename では、名前の中の「IMG_」だけを「2026-11-15_運動会_」に置き換える、といった変え方ができます。変える前に、プレビューで元の名前と変更後の名前を見比べられます。
    写真の撮影日時は、写真のファイルの中に記録されている
    写真には、撮影日時などの情報（EXIF や XMP と呼ばれるメタデータ）が記録されていることがあります。PowerRename では、この撮影日を名前に入れられます。撮影日の年は $DATE_TAKEN_YYYY、月は $DATE_TAKEN_MM、日は $DATE_TAKEN_DD と書きます。
    名前を変えても、写真の中身や画質は変わらない
    名前の変更は、ファイルの名前だけを書き換える操作です。写真を開き直したり、保存し直したりはしないので、中身や画質は変わりません。

    原因の切り分け方

    何に一番困っているかによって、先にやることが違います。次のように切り分けます。

    探したい写真が見つからないだけ
    名前を変える前に、フォルダーを「年」→「行事」の順に分けます。たとえば「写真」→「2026」→「2026-11-15_運動会」です。フォルダーの名前を見るだけで探せるようになり、写真の名前をそろえる作業も1つの行事ずつ進められます。
    名前がバラバラで、どれが最新か分からない
    日付を名前の先頭に入れるルールにします。書類は、日付に加えて最後に v2、v3 のような版の番号を付けます。新しく保存するファイルからこのルールにすると、続けやすくなります。
    名前を変えるのが怖い
    先にフォルダーのコピーを作り、コピーのほうで試します。まず10枚ほどで試し、結果を見てから枚数を増やします。
    写真が何千枚もあって、手作業では無理
    1つの行事ずつ、エクスプローラーの一括の名前変更を使います。名前の一部だけを変えたい、撮影日を名前に入れたい、といった場合は、Microsoft の PowerRename を使います。どちらもプレビューや少ない枚数で確かめてから広げます。
    パソコンの中の写真がどこにあるか分からない
    名前を変える前に、写真の置き場所を決めます。スマホから写真を移す方法は、お悩み No.068「スマホで撮った写真をパソコンに移したい。ケーブルでつないでも表示されないときの取り込み方」にあります。デスクトップに散らばったファイルの片づけ方は、お悩み No.070「パソコンのデスクトップがファイルだらけで、必要なものがすぐ見つからない。探さずに済む整理のコツ」にあります。

    落とし穴

    名前を一括で変えるときに、つまずきやすい点があります。

    写真と動画のように、種類の違うファイルを混ぜて変えると、思った通りの番号にならないことがある
    種類の違うファイルを一緒に選ぶと、番号の付き方や並び順が思った通りにならないことがあります。写真と動画は別のフォルダーに分けるか、片方だけを選んでから変えます。
    直後なら Ctrl + Z で戻せるが、あとから元の名前に戻すのは難しい
    Microsoft の PowerRename の説明には、エクスプローラーの「名前の変更を元に戻す」（Ctrl + Z）で、最後の変更を元に戻せると書かれています。ただし、戻せるのは直前の操作です。ほかの操作を続けたあとで元の名前に戻したくなっても、元の名前を一覧で取り出す方法は、今回確かめた公式情報にはありませんでした。作業の前に、コピーを取っておくことが大事です。
    ファイル名に使えない文字がある
    Microsoft Learn の「ファイル、パス、名前空間の名前付け」では、< > : " / \ | ? * の9つの文字が予約されていて、名前に使えません。名前の最後をスペースやピリオドにすることも勧められていません。日付は「2026/11/15」ではなく、「2026-11-15」や「20261115」のように書きます。
    エクスプローラーの番号は「(1)」の形で、01 のような2けたにはならない
    エクスプローラーでまとめて変えると、「2026-11-15_運動会 (1).jpg」のように、番号がかっこ付きで付きます。番号が10を超えると、アプリによっては (10) が (2) より前に並ぶことがあります。01、02 のように0を付けた番号にしたいときは、PowerRename を使います。
    PowerRename の $YYYY などは、撮影日ではなくファイルの作成日時
    PowerRename の $YYYY、$MM、$DD は、ファイルの作成日時を使う書き方です。コピーしたファイルでは、作成日時がコピーした日になっていることがあります。撮影日を使いたいときは、$DATE_TAKEN_YYYY のような写真のメタデータの書き方を使います。動画や、撮影日時の情報が入っていない画像では、撮影日が名前に入らないことがあります。
    クラウドと同期しているフォルダーで大量に変えると、同期に時間がかかることがある
    OneDrive などと同期しているフォルダーで名前を大きく変えると、変更をクラウドに送るのに時間がかかることがあります。同期が終わるまでは、ほかの端末で古い名前のまま見えたり、一時的に見つけにくくなったりすることがあります。同期のしくみは、お悩み No.047「クラウドのファイルが同期されない。消えたように見えるときの確認と直し方」でも説明しています。
    コピーを作るには、パソコンの空き容量が必要
    写真のフォルダーをまるごとコピーすると、同じ大きさの空き容量を使います。空きが足りないときは、外付けのドライブや USB メモリにコピーします。バックアップの取り方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」にあります。
    名前を変えても、写真そのものは変わらない
    名前を変えても、写真の中身や画質は変わりません。逆に言うと、名前を変えても写真の容量は減りません。容量を空けたい場合は、お悩み No.006「写真が何千枚もたまって容量がいっぱい。大切な写真を失わずに整理するには」を見てください。

    公式情報で確かめたこと

    次のことを、Microsoft の公式サポートと Microsoft Learn で確かめました。手順は Windows 11 を前提にしています。Windows 10 では、表示が多少違う場合があります。

    名前の変更とすべて選択のキー（Microsoft サポート「Windows のキーボード ショートカット」）
    F2 は「選択された項目の名前を変更する」、Ctrl + A は「ウィンドウ内のすべてのアイテムを選択する」、Ctrl + Z は「直前の操作を元に戻す」と書かれています。エクスプローラーは、Windows ロゴ キー + E で開きます。
    右クリックのメニューとチェック ボックス（Microsoft サポート「Windows のエクスプローラー」）
    Windows 11 では、ファイルを右クリックしたメニューの上部に、切り取り、コピー、貼り付け、名前の変更、共有、削除のボタンがあります。アイコンの上にマウス ポインターを置くと、名前が表示されます。ファイルの横にチェック ボックスを出すには、「表示」→「表示」→「項目チェック ボックス」を選びます。Windows 10 では、「表示」タブを選び、「詳細設定」で「チェック ボックスを使用して項目を選択する」を選んで、「OK」を選びます。
    PowerRename の使い方（Microsoft Learn「PowerRename」）
    エクスプローラーでファイルを選んで右クリックし、「Rename with PowerRename」を選びます。この項目は、PowerToys で PowerRename が有効になっている場合にだけ表示されます。「検索対象」に入れた文字を、「置き換える」に入れた文字に置き換えます。プレビューで、元の名前と変更後の名前を確かめられます。「すべての出現箇所を一致させる」をオフにすると、最初に見つかった1か所だけを置き換えます。「適用先」で、ファイル名だけを変えるか、拡張子だけを変えるかを選べます。写真のメタデータ（EXIF または XMP）を選ぶと、撮影日の年・月・日を $DATE_TAKEN_YYYY、$DATE_TAKEN_MM（01〜12）、$DATE_TAKEN_DD（01〜31）で名前に入れられます。$YYYY、$MM、$DD は、ファイルの作成日時を使います。「項目の列挙」を選ぶと、${padding=X} のような書き方で、先頭に0を付けた番号を付けられます。エクスプローラーの「名前の変更を元に戻す」（Ctrl + Z）で、最後の変更を元に戻せます。
    PowerToys のインストール（Microsoft Learn「PowerToys のインストール」「Microsoft PowerToys」）
    PowerToys は、Microsoft Store の PowerToys のページからインストールできます。必要なのは、Windows 11、または Windows 10 バージョン 2004 以降です。64 ビットのプロセッサ（x64 または ARM64）が必要です。PowerToys は、無料のオープンソースのユーティリティのセットです。
    ファイル名に使えない文字（Microsoft Learn「ファイル、パス、名前空間の名前付け」）
    <（より小さい）、>（より大きい）、:（コロン）、"（二重引用符）、/（スラッシュ）、\（円記号）、|（縦棒）、?（疑問符）、*（アスタリスク）が予約されています。CON、PRN、AUX、NUL などの名前も使えません。名前の最後をスペースやピリオドにしないよう書かれています。

    エクスプローラーで複数のファイルをまとめて名前を変える手順を、Windows 11 向けに説明した Microsoft サポートのページは、今回見つけられませんでした。番号の付き方は、行動プランの「今日」の手順で、10枚ほどで試して確かめてください。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. カメラやスマホが付けた名前のまま、写真を保存する
    2. 探すときに、1枚ずつ開いて確かめることになる
    3. 何百枚もあり、1枚ずつ名前を変えるのは無理だと感じる
    4. 失敗が怖くて手を付けられず、意味のない名前の写真がまた増える

    4のあと、また1に戻ります。

    この流れは、どの段階でも止められます。1は、取り込んだその日にルール通りの名前を付ける習慣で止まります。2は、フォルダーを「年」→「行事」に分ければ、探す範囲が狭くなります。3は、エクスプローラーの一括の名前変更を知れば止まります。4は、コピーを取って10枚で試せば、失敗しても元の写真が残るので、手を付けやすくなります。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • カメラやスマホが自動で付ける名前の形
    • エクスプローラーの一括の名前変更で付く番号の形（(1)、(2) のかっこ付き）
    • すでにある何百枚もの写真を、一度に全部整えること
    • クラウドとの同期にかかる時間
    • 撮影日時の情報が入っていない画像があること

    変えやすいこと

    • 作業の前に、写真のコピーを取ること
    • 10枚ほどで試してから、枚数を増やすこと
    • 名前の付け方のルールを決めること
    • フォルダーを「年」→「行事」に分けること
    • 書類の名前に、日付と版の番号を入れること
    • 新しく取り込む写真から、ルール通りの名前にすること
    • PowerToys の PowerRename を入れて使うこと

    次の行動プランは3段階です。今日は、コピーを作って10枚で一括の名前変更を試し、書類を1つ名前を付け直します。1週間で、名前のルールを決めて、1つの行事分の写真をそろえます。1か月で、ルールを全部の写真に広げ、PowerRename で名前の一部の置き換えや撮影日の利用まで進めます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。今日の手順は、上から順に進めてください。

    手順は、2026年11月時点の Microsoft の公式情報をもとに、Windows 11 を前提にしています。Windows 10 では、メニューやボタンの表示が多少違う場合があります。手順の名前や画面の表示は、Windows のバージョンによって変わることがあります。分からないところは、Microsoft の公式サポートページで確かめてください。

    1. 今日からできる小さな一歩

      目安：15〜20分ほど

      • 写真のフォルダーのコピーを作る

        失敗しても元に戻せるように、まずコピーを作ります。元の写真には、今日は手を付けません。

        1. Windows ロゴ キー + E を押して、エクスプローラーを開きます。
        2. 写真が入っているフォルダーを1回クリックして選びます。
        3. Ctrl + C を押し、同じ場所で Ctrl + V を押します。
        4. 「（フォルダー名） - コピー」のような名前のフォルダーができたことを確かめます。

        写真が多くてコピーに時間がかかるときや、空き容量が足りないときは、旅行の写真のフォルダーなど、一部だけをコピーします。

      • コピーの中で、10枚ほどの名前をまとめて変えてみる

        1. コピーしたフォルダーを開き、上部の「新規作成」→「フォルダー」を選んで、「練習」という名前のフォルダーを作ります。
        2. 旅行の写真を10枚ほど選んで、「練習」フォルダーにドラッグして移します。
        3. 「練習」フォルダーを開き、Ctrl + A を押して、全部の写真を選びます。
        4. F2 キーを押します。1つの写真の名前だけが入力できる状態になりますが、そのまま進めます。
        5. 「2026-11-旅行」のような名前を入れて、Enter を押します。

        全部の写真の名前が「2026-11-旅行 (1)」「2026-11-旅行 (2)」のように、番号付きで変わったことを確かめます。1枚開いて、写真の中身が変わっていないことも見ておきます。思った通りにならなかったときは、すぐに Ctrl + Z を押すと、直前の名前の変更を元に戻せます。

        ノートパソコンでは、F2 を押しても名前の変更にならず、画面の明るさなどが変わることがあります。そのときは、Fn キーを押しながら F2 を押してみます。写真を右クリックして、メニューの上部にある「名前の変更」のボタンを選んでも同じです。

      • 書類を1つだけ、日付＋内容＋版の名前に付け直す

        「最終版2」のような名前の書類を1つ選び、F2 を押して「20261126_請求書_v2」のような名前にします。年月日、内容、版の順です。

        書類を開いているときは、名前を変えられないことがあります。先に書類を閉じてから変えます。

    2. 1週間の行動

      目安：ルール決めに15分、そのあとは1日10〜15分

      • 名前の付け方のルールを決めて、メモに書く

        たとえば、次のようなルールにします。

        • 写真：「年月日_場所や行事_番号」。例：2026-11-15_運動会_01.jpg
        • 書類：「年月日_内容_版」。例：20261126_請求書_v2.xlsx
        • 月と日は、04 のように0を付けて2けたにそろえます。
        • 日付の書き方は、「2026-11-15」か「20261115」のどちらかにそろえます。/ や : は名前に使えません。

        エクスプローラーでまとめて変えると、番号は「_01」ではなく「 (1)」の形で付きます。最初はこの形のままで構いません。「_01」の形にしたいときは、1か月の段階で紹介する PowerRename を使います。

      • 写真を「年」→「行事」のフォルダーに分ける

        今日作ったコピーのフォルダーで、「2026」のような年のフォルダーを作ります。その中に、「2026-11-15_運動会」のような行事のフォルダーを作り、写真を移します。

        写真をまとめて選ぶときは、Ctrl キーを押しながら1枚ずつクリックします。「表示」→「表示」→「項目チェック ボックス」を選ぶと、ファイルの横のチェック ボックスでも選べます。写真と動画が混ざっているときは、動画は別のフォルダーに分けておきます。

      • 1つの行事の分だけ、名前をそろえる

        1. 行事のフォルダーを開き、Ctrl + A で写真を全部選びます。
        2. F2 を押し、「2026-11-15_運動会」のように、ルール通りの名前を入れて Enter を押します。
        3. 名前が「2026-11-15_運動会 (1).jpg」のように変わったことを確かめます。番号の順と写真の順が大きくずれていないかも見ます。

        うまくいったら、次の日に別の行事を1つ進めます。1日1つの行事なら、1週間で7つの行事をそろえられます。

      • 書類も、新しく保存するものからルールでそろえる

        「名前を付けて保存」のときに、先頭に日付を入れ、最後に v1、v2 のような版の番号を付けます。「最終版」という言葉は使いません。直したら版の番号を1つ上げ、日付も直した日にします。

        書類の保存場所の決め方は、お悩み No.041「ダウンロードしたファイルが見つからない。保存場所の探し方と、もう迷わない整理のコツ」も参考にしてください。

    3. 1か月の見直し

      目安：PowerToys の準備に20分ほど、そのあと週末に30分ほどを数回

      • 元の写真を別の場所に保存してから、ルールを全部の写真に広げる

        コピーのほうの整理でやり方に慣れたら、元の写真の整理に進みます。その前に、元の写真を外付けのドライブなどに保存しておきます。

        撮った日ごとにフォルダーを分け、1つの行事ずつ、ルール通りの名前にそろえていきます。全部を一度にやろうとせず、週末に数個の行事ずつ進めます。

      • PowerToys を入れて、PowerRename を使えるようにする

        1. スタート メニューから「Microsoft Store」を開きます。
        2. 「PowerToys」を検索し、発行元が Microsoft のものを選んでインストールします。
        3. PowerToys の設定画面を開き、PowerRename が有効（オン）になっていることを確かめます。

        PowerToys は無料です。使えるのは、Windows 11、または Windows 10 バージョン 2004 以降で、64 ビットのプロセッサのパソコンです。会社のパソコンでは、アプリを入れてよいかを先に管理者に確かめます。

      • PowerRename で、名前の一部だけを置き換える

        例として、「IMG_0001.jpg」のような名前の「IMG_」の部分を、「2026-11-15_運動会_」に置き換える手順を書きます。カメラが付けた番号はそのまま残るので、「2026-11-15_運動会_0001.jpg」のような名前になります。

        1. エクスプローラーで、名前を変えたい写真を選びます。
        2. 右クリックして、PowerRename の項目を選びます。英語の表示では「Rename with PowerRename」です。メニューに見つからないときは、メニューの下にある「その他のオプションを確認」の中も見ます。
        3. 「検索対象」に「IMG_」と入れます。
        4. 「置き換える」に「2026-11-15_運動会_」と入れます。
        5. プレビューで、元の名前と変更後の名前を1つずつ見比べます。
        6. 思った通りになっていたら、名前の変更を実行するボタンを押します。

        変えたあとで間違いに気づいたら、すぐにエクスプローラーで Ctrl + Z を押すと、最後の変更を元に戻せます。

      • 撮影日を名前に入れる方法も試す

        PowerRename で写真のメタデータ（EXIF または XMP）を選ぶと、撮影日を名前に入れられます。「置き換える」に「$DATE_TAKEN_YYYY-$DATE_TAKEN_MM-$DATE_TAKEN_DD」と入れると、写真ごとに「2026-11-15」のような撮影日になります。

        • $YYYY、$MM、$DD は、撮影日ではなくファイルの作成日時です。撮影日を使うときは、$DATE_TAKEN_ で始まる書き方を使います。
        • 動画や、撮影日時の情報が入っていない画像では、撮影日が入らないことがあります。
        • 後ろに「_運動会」のような言葉を続けるときも、プレビューで思った通りの名前になっているかを確かめてから実行します。

        「項目の列挙」を選ぶと、01、02 のように0を付けた番号も付けられます。書き方は、Microsoft Learn の PowerRename のページで確かめてください。

      • 新しい写真を取り込むときに、その場でルール通りの名前にする

        スマホやカメラから写真を取り込んだら、その日のうちに行事のフォルダーを作り、ルール通りの名前にそろえます。取り込むたびにそろえておけば、名前のない写真がたまらずに済みます。

      • 1か月の結果を見返す

        探したい写真を、名前やフォルダーからすぐに見つけられるようになったかを確かめます。

        • まだ探しにくい場合は、行事の名前の付け方を見直します。あとで検索するときに入れそうな言葉を使います。
        • 書類で迷うことが残っている場合は、日付と版の番号を付け忘れていないかを見直します。
        • 整理が終わって問題がないと確かめるまで、元の写真のコピーは消さずに残しておきます。

    手順の名前や画面の表示は、Windows のバージョンによって変わることがあります。分からないところは、Microsoft の公式サポートページで確かめてください。

    名前を変える前に、必ずコピーを取ってください。大切な写真の原本は、別の場所に残しておいてください。
