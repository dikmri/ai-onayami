お悩み No.008 ・ 2026年11月22日公開

Excel の関数が覚えられず、集計や転記を手作業でしている。少しずつ使えるようになるには

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    Excel の関数は、覚える量を減らし、試す場所を用意すれば、少しずつ使えるようになる見込みがあります。使いたい場面がすでに分かっていることは、良い出発点です。どの作業を関数に置き換えればよいかを、自分で選べるからです。

    Excel には数百の関数がありますが、全部を覚える必要はありません。仕事で Excel を使う人でも、式の書き方を調べながら使うのは珍しいことではありません。よくある集計や転記には、合計・条件分け・別の表からの取り出しの組み合わせで対応できるものが多くあります。

    関数が使えない理由は、人によって違います。お悩みの文章だけでは原因を決められないので、自分の作業の特徴を確かめながら絞り込みます。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    覚えられない
    仕事で毎日 Excel を使っているのに、関数がなかなか覚えられない。
    調べ直し
    VLOOKUP や SUMIF など、使いたい場面はあるのに式の書き方が分からず、そのたびに検索して調べ直している。
    手作業と残業
    結局、コピー＆ペーストや電卓での計算を手作業で続けていて、残業になることもある。
    聞きづらさ
    今さら同僚や後輩に聞くのが気まずく、自己流のままになっている。
    望んでいること
    関数を少しずつ使えるようになり、集計や転記の手間を減らしたい。

    関数が使えるようにならない原因の候補

    原因は1つとは限らず、いくつかが重なっていることもあります。考えられる候補を挙げ、それぞれに確かめ方を添えました。当てはまるものから、行動プランで手を付ける順番を決めてください。

    関数を暗記しようとしている
    関数の名前と書き方を、まとめて覚えようとしているのかもしれません。使う頻度の低い関数まで覚えようとすると、どれも覚えきれず、使うたびに調べ直すことになりがちです。確かめ方：最近調べた関数を思い出して書き出します。「何をしたかったか」は言えるのに、関数の名前や書き方が出てこない状態になっていないかを見ます。
    引数の順番が分からない
    関数の名前は分かっていても、カッコの中に何をどの順番で書くか（引数）が分からないのかもしれません。たとえば VLOOKUP は、引数が4つあり、3つ目に列の番号を数えて入れる必要があります。確かめ方：前回検索したときに調べたのが、関数の名前だったか、カッコの中の書き方だったかを思い出します。
    場面と関数が結びついていない
    「この作業にはこの関数」という対応が決まっていないのかもしれません。対応が決まっていないと、作業のたびに「関数でできるのか」から考えることになり、急いでいるときは手作業を選びやすくなります。確かめ方：最近手作業で済ませた作業を1つ思い出し、どの関数を使えばよいかがすぐに浮かぶかを見ます。
    エラーが出ると手作業に戻る
    #N/A や #NAME? のようなエラーが出ると、何が起きたのか分からず不安になります。仕事の表を壊しそうで怖くなり、手作業に戻ってしまうのかもしれません。確かめ方：最後に関数をあきらめたときに、エラーの表示が出ていなかったかを思い出します。
    聞ける相手や確かめる場所がない
    聞きづらさから、分からないことを一人で検索して解決しようとしているのかもしれません。検索で見つけた式が自分の表に合っているかを確かめる手段がないと、自己流のままになりやすくなります。確かめ方：分からないときの調べ先が、毎回検索だけになっていないかを見ます。

    ボトルネック

    AIは、関数を使う機会があっても、急いでいて手作業を選んでしまうことが、いちばん大きなボトルネックだと考えます。次の流れが繰り返されている可能性があります。

    1. 仕事で、関数を使いたい場面が来る
    2. 式の書き方が分からず、検索して調べ直す
    3. 時間がないので、結局手作業で済ませる
    4. 関数を使わないので覚えられず、次の場面でも書き方が分からない

    4のあと、また1に戻ります。

    もう一つのボトルネックは、関数を試す場所が仕事の表しかないことです。間違えられない表でいきなり試すと、エラーが出たときに手作業に戻りたくなります。失敗しても困らない練習用の表があれば、急いでいない時間に試せます。

    関数を少しずつ使えるようになるための3つの考え方

    覚えるのではなく、やりたいことから関数を選ぶ
    関数の名前から覚えるのではなく、「合計を出したい」「条件で分けたい」のように、やりたいことから考えます。やりたいことと関数の対応をメモにしておけば、関数の名前を忘れても、メモから選べます。Excel の「関数の挿入」画面でも、やりたいことを入力して関数を探せます。書き方は、そのつど画面のヒントやメモを見て確かめれば十分です。
    まず SUM・IF・XLOOKUP の3つだけに絞る
    最初に使う関数を、合計を出す SUM、条件で分ける IF、別の表から値を引いてくる XLOOKUP の3つに絞ります。お悩みにある VLOOKUP の役割は、XLOOKUP で置き換えられます。SUMIF は、SUM と IF の考え方を組み合わせた関数なので、SUM と IF に慣れておくと書き方を理解しやすくなります。3つに慣れてから次の関数に進むほうが、一度に多くを覚えようとするより続けやすくなります。
    小さな練習用の表で試してから、仕事の表に使う
    5行ほどの小さな表を作り、そこで式を試してから仕事の表に使います。練習用の表なら、結果が正しいかを暗算や電卓ですぐに確かめられます。エラーが出ても、仕事のデータには影響しません。

    3つの考え方は、組み合わせて使います。やりたいことから関数を選び、3つの関数のどれかに当てはめ、練習用の表で確かめてから仕事の表に使います。

    次の行動プランは、メモと練習用の表の準備から始めて、仕事の表で使う回数を少しずつ増やす順番にしています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるものを試してください。

    この記事の画面やボタンの名前は、Windows 版の Excel（Microsoft 365）をもとにしています。Excel のバージョン、Mac 版、Web 版の Excel では、名前や場所が違うことがあります。使っているバージョンは、「ファイル」→「アカウント」の「Excel のバージョン情報」で確かめられます。Google スプレッドシートでも、この記事の関数は同じ名前で使えます。

    式は、半角で入力します。カンマや「"」（ダブルクォーテーション）が全角になっていると、エラーになることがあります。

    1. 今日からできる小さな一歩

      目安：30分ほど

      • 手間がかかっている作業を1つ書き出す

        毎日や毎週の作業のうち、手作業で時間がかかっているものを1つだけ選んで書き出します。たとえば、次のような作業です。

        • 合計を出す：売上や経費の列を、電卓で足している。
        • 条件で分ける：金額や日付を見て、「対象」「対象外」などを1件ずつ手で入力している。
        • 別の表から名前や単価を引いてくる：商品コードや社員番号を見ながら、別の表を探してコピー＆ペーストしている。

        作業の名前と一緒に、1回にかかる時間と、どのくらいの頻度で発生するかも書いておきます。1か月後に、関数に置き換えたときと比べるための記録です。

      • SUM・IF・XLOOKUP を「やりたいこと→関数」の形でメモする

        メモ帳や紙に、次の3行を書きます。カッコの中の引数は、日本語で書いておくと、順番を忘れても確かめられます。

        • 合計を出したい → SUM → =SUM(合計する範囲)（例：=SUM(B2:B6)）
        • 条件で分けたい → IF → =IF(条件, 当てはまるときの値, 当てはまらないときの値)（例：=IF(B2>=1000,"1000円以上","1000円未満")）
        • 別の表から名前や単価を引いてきたい → XLOOKUP → =XLOOKUP(探す値, 探す列, 取り出す列, 見つからないときの表示)（例：=XLOOKUP(A10,E2:E6,F2:F6,"見つかりません")）

        XLOOKUP は、Microsoft 365、Excel 2021 以降、Web 版の Excel、Google スプレッドシートで使えます。Excel 2019 以前では使えないので、代わりに VLOOKUP を使います。VLOOKUP の書き方は、1週間の行動で説明します。

      • 練習用の小さな表を作り、SUM と IF を試す

        新しいブックを作り、次の手順で練習用の表を作ります。仕事のファイルは使いません。

        • A1 に「品名」、B1 に「金額」と入力します。
        • A2〜A6 に品名を5つ、B2〜B6 に金額を入力します。例：ボールペン 1200、コピー用紙 3500、ファイル 800、封筒 600、ホチキス 1500。
        • B7 に =SUM(B2:B6) と入力して Enter キーを押します。例の数字なら、7600 になります。B2:B6 の部分は、式の入力中にマウスで B2 から B6 までをドラッグして選んでも入力できます。
        • C2 に =IF(B2>=1000,"1000円以上","1000円未満") と入力して Enter キーを押します。
        • C2 を選び、セルの右下にある小さな四角（フィルハンドル）を C6 までドラッグして、式をコピーします。C3〜C6 の式は、それぞれ B3〜B6 を見るように自動で変わります。
        • B2〜B6 の金額を書き換えて、B7 の合計と C 列の判定が自動で変わることを確かめます。

        思ったとおりの結果にならなかったら、Ctrl＋Z キーで元に戻してやり直します。練習用の表なので、何度失敗しても構いません。

      • 関数の挿入ボタン（fx）と数式バーの使い方を確かめる

        式の書き方を検索する前に、Excel の画面の中で確かめる方法を覚えておきます。

        • 数式バー：シートの上にある横長の入力欄です。式を入れたセルを選ぶと、セルには計算の結果が、数式バーには式そのものが表示されます。式を直すときは、数式バーをクリックして直します。
        • 関数の挿入ボタン（fx）：数式バーの左にある「fx」のボタンを押すと、「関数の挿入」画面が開きます。「関数の検索」の欄に「合計」「条件」などのやりたいことを入力して「検索開始」を押すと、関数の候補が表示されます。
        • 関数の引数：「関数の挿入」画面で関数を選ぶと、「関数の引数」画面が開きます。引数ごとに入力欄と説明が表示され、下のほうに計算の結果が表示されます。引数の順番を覚えていなくても、この画面の説明を見ながら入力できます。
        • 入力中のヒント：セルに =XLOOKUP( のように関数の名前とカッコまで入力すると、セルの下に引数の一覧が表示されます。今入力している引数は太字になります。
        • Google スプレッドシートの場合：fx のボタンはありませんが、セルに = と関数の名前を入力し始めると、関数の説明と使用例が表示されます。メニューの「挿入」→「関数」からも関数を選べます。

    2. 1週間の行動

      目安：1日10〜15分ほど

      • 毎日1つだけ、関数を使う場面を作る

        仕事の中で、関数を使う場面を1日に1つだけ作ります。全部の作業を関数にしようとせず、1つで十分です。

        • 合計を出す場面では、SUM を使います。
        • 条件で分ける場面では、IF を使います。
        • 別の表から名前や単価を引いてくる場面では、XLOOKUP を使います。

        仕事の表で使う前に、まず練習用の表か、仕事のファイルのコピーで試します。結果が出たら、1〜2件だけ電卓や目視で確かめ、手作業のときと同じ答えになっているかを見ます。

      • 練習用の表で XLOOKUP を試す

        今日作った練習用の表に、別の表の代わりになる一覧を足して試します。

        • E1 に「品名」、F1 に「単価」と入力し、E2〜E6 に品名、F2〜F6 に単価を入力します。
        • A10 に、E2〜E6 にある品名を1つ入力します。
        • B10 に =XLOOKUP(A10,E2:E6,F2:F6,"見つかりません") と入力します。A10 の品名に対応する単価が表示されれば成功です。
        • A10 を、一覧にない品名に書き換えます。B10 に「見つかりません」と表示されることを確かめます。

        この式を下の行にコピーすると、探す範囲の E2:E6 も E3:E7 のようにずれてしまいます。範囲を固定するには、=XLOOKUP(A10,$E$2:$E$6,$F$2:$F$6,"見つかりません") のように「$」を付けます。式の入力中に範囲の部分を選んで F4 キーを押すと、「$」が付きます。ノートパソコンでは、Fn キーと一緒に押す必要がある場合があります。

        XLOOKUP が使えない Excel では、#NAME? のエラーになります。その場合は、VLOOKUP を使って =VLOOKUP(A10,$E$2:$F$6,2,FALSE) と書きます。3つ目の「2」は、範囲の左から2列目の値を取り出すという意味です。4つ目の「FALSE」は、完全に一致するものだけを探す指定です。FALSE を省くと、近い値が選ばれて、間違った結果になることがあります。

      • エラーが出たら、まず表示の意味を確かめ、IFERROR で表示を整える

        エラーは、式のどこに問題があるかを示す表示です。表示を見れば、原因の見当をつけられます。

        • #NAME?：関数の名前のつづりが違うか、その Excel では使えない関数です。
        • #N/A：XLOOKUP や VLOOKUP で、探した値が見つかりません。全角と半角の違いや、文字の前後の空白でも起きます。
        • #VALUE!：文字が入ったセルで計算しようとしているなど、値の種類が合っていません。
        • #DIV/0!：0 か空のセルで割り算をしています。
        • #REF!：式が見ていたセルや列が、削除されています。

        原因を確かめて式が正しいと分かったうえで、見つからないときなどのエラー表示を整えたい場合は、IFERROR を使います。書き方は =IFERROR(元の式,"エラーのときの表示") です。たとえば =IFERROR(VLOOKUP(A10,$E$2:$F$6,2,FALSE),"見つかりません") と書くと、エラーの代わりに「見つかりません」と表示されます。XLOOKUP は、4つ目の引数で同じことができます。

        IFERROR は、すべてのエラーを同じ表示に置き換えます。式そのものが間違っていても気づきにくくなるので、式が正しいことを確かめてから使います。

      • 調べた式を「やりたいこと→式」の形でためていく

        検索したり試したりした式は、その日のうちにメモに追加します。次に同じ作業が来たときは、検索する前にメモを見ます。

        • メモ帳でも、スプレッドシートでも構いません。スプレッドシートにする場合は、「やりたいこと」「関数」「式の例」「気をつけること」「使った日」の列を作ります。
        • 式の例は、数式バーで式を選んでコピーし、そのまま貼ります。スプレッドシートに式を文字として残すときは、先頭の「=」の前に「'」（アポストロフィ）を付けると、計算されずにそのまま表示されます。
        • 「気をつけること」には、「VLOOKUP は最後に FALSE」「範囲は $ で固定」のように、つまずいた点を書きます。

      • 式の意味を確かめる（Excel は数式のヘルプ、Google スプレッドシートは Gemini）

        検索で見つけた式や、メモにためた式の意味が分からないときは、次の方法で確かめます。

        • Excel の「関数の引数」画面：左下の「この関数のヘルプ」を押すと、その関数の説明と使用例のページが開きます。
        • Excel の「数式の検証」：Windows 版の Excel では、式のセルを選び、「数式」タブの「数式の検証」を押すと、式の計算を1段階ずつ確かめられます。どこでエラーになっているかを探すときにも使えます。
        • Google スプレッドシートの数式のヘルプ：式を入力しているときに表示される説明で、引数の意味と使用例を確かめられます。
        • Google スプレッドシートの Gemini：使っているアカウントやプランで Gemini が使える場合は、画面のサイドパネルから Gemini に質問できます。たとえば「B2 から B6 の合計を出す式を教えて」「この式の意味を説明して」と聞きます。使えるかどうかや表示の場所は、アカウントの種類や時期によって変わることがあります。

        AI に聞くときは、顧客の名前や金額など、仕事のデータをそのまま貼り付けないようにします。「A列に品名、B列に金額がある表で」のように、列の内容を言葉で説明して聞きます。仕事で AI を使ってよいかは、勤務先のルールを確かめてください。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • ためたメモを見直し、よく使う式を自分の型にする

        1か月分のメモを見返し、何度も使った式を3〜5個選びます。

        • 選んだ式は、メモの先頭にまとめ、そのまま貼り付けて使える形で残します。
        • 仕事で使う表と同じ列の並びで、式を入れた見本のシートを作っておくと、次からはコピーして使えます。
        • 1回しか使わなかった式は、メモの下のほうに移します。消す必要はありません。

      • 手作業だった集計を1つ関数に置き換え、かかった時間を比べる

        今日の一歩で書き出した作業を、関数に置き換えます。

        • 最初の1回は、手作業と関数の両方でやり、結果が同じになるかを確かめます。
        • 2回目からは関数だけで行い、かかった時間を記録します。
        • 書き出しておいた手作業の時間と比べます。式を作る最初の1回は手作業より時間がかかることもあるので、2回目以降の時間で比べます。

        置き換えた作業が、仕事の重要な表に関わる場合は、ファイルのコピーで試してから元の表に反映します。ほかの人と共有している表の場合は、式を入れてよいか、共有している人に確かめます。

      • 人に聞くときは、自分で作った式を見せて確かめてもらう

        何も分からない状態で聞くより、自分で作った式を見せて「この式で合っていますか」と聞くほうが、短い質問で済みます。聞かれた側も、どこを見ればよいかが分かります。同僚や後輩に聞きづらい場合は、社内の研修や、Microsoft や Google の公式のヘルプとトレーニングのページも使えます。

      • SUMIFS や FILTER など、次の1つに進むかを判断する

        次の2つに当てはまれば、新しい関数を1つだけ増やします。

        • SUM・IF・XLOOKUP を、メモを見れば検索せずに書ける。
        • 手作業だった集計を、1つ以上関数に置き換えられた。

        次の候補は、たとえば次の2つです。

        • SUMIFS：条件に合う行だけを合計します。書き方は =SUMIFS(合計する範囲, 条件の範囲, 条件) です。条件を増やすときは、「条件の範囲, 条件」の組を後ろに足します。お悩みにある SUMIF と同じことができ、条件を2つ以上にもできます。SUMIF とは引数の順番が違うので、メモに書いておきます。
        • FILTER：条件に合う行を、別の場所に抜き出します。Microsoft 365、Excel 2021 以降、Google スプレッドシートで使えます。

        まだ3つの関数を使うたびに調べ直している場合は、新しい関数に進まず、同じ3つをもう1か月続けます。それで構いません。

    1か月たったら、続けられたものと続かなかったものを分けます。続かなかったものはやめて構いません。手作業が1つでも関数に置き換わっていれば、次の1か月も同じ方法で、置き換える作業を1つずつ増やしていきます。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。専門的な助言ではありません。画面やボタンの名前、使える関数は、Excel や Google スプレッドシートのバージョンによって変わることがあります。

    関数の結果や、AI が提案した式は、必ず自分の表で結果を確かめてから使ってください。数件を電卓や手作業で計算し、同じ結果になるかを見るのが確実です。式が正しく見えても、範囲の指定がずれているなど、間違った結果を返すことがあります。
