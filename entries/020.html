お悩み No.020 ・ 2026年11月22日公開

パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    パソコンが固まる悩みや、更新が終わらない悩みは、原因を確かめて設定や置き場所を見直すと、減らせることが多いです。Cドライブの空き容量、起動時に動くアプリ、熱のこもり、更新が始まる時間帯は、自分で確かめて変えられます。固まったときに試す順番を決めておけば、電源を切るかどうかで迷う時間も減らせます。そのため、改善できる見込みがあります。

    ただし、お悩みの文章だけでは、何が原因で固まるのかまでは分かりません。原因は1つとは限らず、いくつかが重なっていることもあります。まず「固まるときの画面とタイミング」を記録し、そこから原因を絞り込みます。

    ハードディスクやSSDの劣化など、部品の不具合が原因の場合は、設定の見直しだけでは直らないことがあります。その場合も、記録があれば、メーカーや修理店に状況を伝えやすくなります。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    急に固まる
    作業の途中で画面が止まり、マウスもキーボードも効かなくなる。
    電源を切ってよいか分からない
    作っていた資料が消えないか心配で、電源ボタンを長押ししてよいのか分からない。そのまま何十分も待ってしまう。
    更新が終わらない
    Windows の更新が始まると、「再起動しています」の画面のまま終わらない。4%のところで止まったまま進まないこともあった。
    更新のあとに起動しない
    更新のあとにパソコンが起動しなくなったことがあり、買い替えるしかないのかと考えている。
    直し方が分からない
    古いパソコンだから仕方ないのか、設定で直せるのかが分からず、こわくて触れずにいる。

    「止まって見える」と「本当に固まっている」は違うことがある

    画面が動かなくても、パソコンの中では処理が続いていることがあります。特に、Windows の更新プログラムを適用している間は、画面が止まって見えても、裏で作業が進んでいることがあります。画面に表示される数字は、一定の速さで進むとは限りません。同じ数字のまま長い時間がたってから、急に進むこともあります。マイクロソフトも、更新にかかる時間は、接続の速さや更新プログラムの大きさなどによって違うと説明しています。

    更新中でなくても、ディスクの読み書きが集中しているときなどは、数分ほど反応が止まることがあります。マウスのカーソルが動く、ファンの音が変わる、本体のランプが点滅する、といった変化があれば、処理が続いている可能性があります。ただし、ランプがない機種もあります。

    固まる原因の候補

    固まる原因は、1つに決めつけられません。いくつかが重なっていることもあります。考えられる候補を挙げ、それぞれに確かめ方を添えました。確かめる手順は、下の行動プランに書いています。

    メモリの不足
    開いているアプリやブラウザのタブが多いと、作業用の記憶領域であるメモリが足りなくなります。足りなくなると、動きが遅くなったり、止まったように見えたりします。確かめ方：重いと感じたときに、タスクマネージャーの「パフォーマンス」でメモリの使用率を見ます。
    ディスクの空き容量の不足
    Cドライブの空き容量が少ないと、Windows が作業用のファイルを置く場所が足りなくなり、動作が遅くなることがあります。マイクロソフトは、空き領域が足りないと、更新が遅くなったり、インストールできなくなったりすることがあると説明しています。確かめ方：エクスプローラーで「PC」を開き、Cドライブの空き容量を見ます。
    起動時に動くアプリの多さ
    パソコンの起動と同時に、いくつものアプリが自動で立ち上がる設定になっていることがあります。使わないアプリもメモリを使うため、起動の直後に重くなったり固まったりする原因になります。確かめ方：タスクマネージャーの「スタートアップ アプリ」で、自動で立ち上がるアプリの数を見ます。
    ほこりによる熱のこもり
    放熱口やファンにほこりがたまると、本体の中の熱が逃げにくくなります。パソコンは、熱くなりすぎると、部品を守るために処理の速さを落とすことがあります。その結果、動きが重くなったり止まったりします。確かめ方：ファンの音が大きくないか、本体が熱くないか、放熱口にほこりがたまっていないかを見ます。
    ハードディスクやSSDの劣化
    ハードディスクやSSDは、長く使ううちに劣化することがあります。劣化すると、データの読み書きに時間がかかったり失敗したりして、固まる原因になることがあります。ただし、劣化の進み方は、使い方や製品によって違います。古いから劣化していると決めつけずに、状態を確かめます。確かめ方：無料のツール（CrystalDiskInfo など）で、健康状態の表示を見ます。
    ドライバーの不具合
    ドライバーは、パソコンの部品や周辺機器を Windows から動かすためのソフトです。ドライバーに不具合があったり、Windows の更新のあとに古いドライバーと合わなくなったりすると、固まることがあります。確かめ方：固まるようになった時期と、更新や新しい機器をつないだ時期が重なっていないかを見ます。

    更新のあとに起動しなくなる理由

    更新のあとにパソコンが起動しなくなる理由として、次の2つが考えられます。

    更新の適用が途中で止まった
    更新プログラムの適用中に電源が切れたり、強制終了したりすると、Windows のファイルが書き換えの途中のまま残ることがあります。空き容量が足りずに、適用が失敗することもあります。
    古い部品との相性
    更新で Windows の中身が変わると、古い部品やドライバーとの組み合わせで不具合が出ることがあります。

    起動しなくなったときも、すぐに買い替えが必要とは限りません。Windows には、起動しないときに使える回復の機能（Windows 回復環境）があります。マイクロソフトの案内では、最近の更新のあとに問題が起きた場合は、その更新をアンインストールすると直る可能性があるとしています。

    ただし、回復環境の多くの操作では、BitLocker の回復キー（48桁の数字）を求められることがあります。項目によっては、ファイルやアプリが消えるものもあります。操作に自信がないときは、メーカーのサポートや修理店に相談してください。

    ボトルネック

    AIは、「固まったときに何が起きているのかが分からないまま、電源を切るかどうかで迷い、原因も確かめられずにいること」が、いちばん大きなボトルネックだと考えます。

    何が起きているのかが分からないと、待つべきか、電源を切るべきかを決められません。原因の候補も確かめていないため、どの設定を変えればよいかも分かりません。その結果、固まるたびに同じように迷い、こわくて触れない状態が続きます。

    そこで、固まったときに試す順番を先に決めておきます。そのうえで、「固まるときの画面とタイミング」を記録し、原因の候補を1つずつ確かめます。修理や買い替えは、確かめたあとに考えます。

    固まったときの4つの考え方

    1. 更新中は電源を切らない
    2. 固まったら、まず10〜15分待つ
    3. Ctrl+Alt+Delete でタスクマネージャーを開き、止まっているアプリを終わらせる
    4. どうしても動かないときだけ、最後の手段として電源ボタンの長押しで強制終了する
    更新中は電源を切らない
    「再起動しています」「更新プログラムを構成しています」「電源を切らないでください」などの画面は、更新プログラムを適用している途中に表示されます。この間に電源を切ると、適用が途中で止まり、起動しなくなるおそれがあります。数字が進まなくても、電源を切らずに待つのが基本です。ノートパソコンは、途中で電池が切れないように、電源アダプターをつないでおきます。
    まず10〜15分待つ
    一時的に処理が集中しているだけなら、待つと動き出すことがあります。慌ててキーを何度も押したり、クリックを繰り返したりすると、動き出したときに思わぬ操作が実行されることがあります。待つ間は、カーソルが動くか、画面の表示が変わるかを見ます。
    止まったアプリを終わらせる
    パソコン全体ではなく、1つのアプリだけが止まっていることがあります。その場合は、そのアプリだけを終わらせれば、ほかのアプリの作業は残ります。ただし、終わらせたアプリの保存していない内容は、消えることがあります。
    最後の手段の強制終了
    待っても動かず、Ctrl+Alt+Delete も効かないときだけ、電源ボタンの長押しで強制終了します。強制終了すると、保存していない作業は消えることがあります。更新の途中であれば、起動しなくなるおそれもあります。そのため、強制終了はあくまで最後の手段です。更新の画面が出ているときは、電源を切らずに待つのが基本です。数時間たっても数字が変わらず、ランプなどの変化もない場合にだけ、強制終了を検討します。

    修理と買い替えについて

    「古いパソコンだから仕方ない」とは限りません。空き容量や起動時のアプリ、熱のこもりが原因であれば、お金をかけずに改善できることがあります。まず行動プランの見直しを試し、それでも固まるかを確かめます。

    ハードディスクやSSDの劣化が疑われる場合や、見直しても固まり続ける場合は、部品の交換や修理が必要なことがあります。修理と買い替えのどちらがよいかは、パソコンの年数や状態、修理にかかる費用によって変わります。費用は機種や修理の内容によって違うため、この記事では断定しません。特定の店やサービス、製品も勧めません。メーカーのサポートや修理店で見積もりを聞いてから比べます。

    パソコンが Windows 10 の場合は、マイクロソフトのサポートが2025年10月14日に終了しています。拡張セキュリティ更新プログラム（ESU）に登録していなければ、セキュリティ更新プログラムは届きません。使っている Windows の種類は、行動プランの「1か月の見直し」で確かめます。修理と買い替えを比べるときの材料にしてください。

    次の行動プランは、固まったときに試す順番を確かめることから始め、お金をかけずにできる見直しを先に並べています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるものを試してください。

    画面の名前は Windows 11 のものです。Windows 10 で名前が違うところは、あわせて書いています。設定の名前や場所は、パソコンの機種や Windows のバージョンによって変わることがあります。見つからないときは、スタートメニューの検索欄に項目名を入れて探してください。公式のヘルプ（Microsoft サポート、パソコンのメーカーのサポートページ）でも確かめられます。各ヘルプへのリンクは、注意書きにまとめています。

    1. 今日からできる小さな一歩

      目安：手順を確かめるのに15分ほど。メモは固まるたびに1〜2分

      • 固まったら、まず落ち着いて10〜15分待つ

        • 固まったと気づいたら、時計やスマホで時刻を見ます。待った時間が分かると、慌てずに済みます。
        • 待つ間は、キーを何度も押したり、クリックを繰り返したりしないようにします。
        • マウスを少し動かして、カーソルが動くかを見ます。画面の表示が変わるか、ファンの音や本体のランプに変化があるかも見ます。
        • 動き出したら、まず作業中のファイルを保存します（Ctrl + S）。そのあと、使っていないアプリを閉じます。

      • 動かないときは、Ctrl+Alt+Delete でタスクマネージャーを開く

        Ctrl + Alt + Delete を同時に押します。画面が切り替わったら、「タスク マネージャー」を選びます。Ctrl + Shift + Esc を同時に押しても、タスクマネージャーを直接開けます。

        • 小さい画面で開いた場合は、「詳細」を押します。
        • 「プロセス」の一覧で、状態の欄に「応答なし」と出ているアプリを探します。
        • そのアプリを右クリックし、「タスクの終了」を選びます。版によっては、画面の上のほうに同じ働きのボタンもあります。
        • 終わらせたアプリの、保存していない内容は消えることがあります。ほかのアプリの作業は残ります。
        • 名前を見ても何か分からないものは、終了させないでください。Windows の動作に必要なものが含まれていることがあります。

      • 更新中の画面が出ているときは、電源を切らずに待つ

        • 「再起動しています」「更新プログラムを構成しています」「電源を切らないでください」などの画面は、更新プログラムを適用している途中の表示です。電源を切らずに待ちます。
        • ノートパソコンは、電源アダプターをつなぎます。更新の途中で電池が切れると、強制終了したのと同じ状態になるためです。
        • 数字が同じところで止まって見えても、すぐには電源を切りません。
        • 数時間たっても数字が変わらず、ランプなどの変化もない場合にだけ、下の強制終了を検討します。その前に、画面の表示をスマホで撮っておきます。

      • 最後の手段の、強制終了のやり方を知っておく

        待っても動かず、Ctrl + Alt + Delete も効かないときだけ行います。

        • 電源ボタンを、電源が切れるまで押し続けます。多くの機種では、数秒から10秒ほどで切れます。
        • 切れたら10秒ほど待ってから、電源ボタンを押して起動します。
        • Word や Excel には、作業中の内容を一定の間隔で保存しておく「自動回復」の機能があります。強制終了のあとにアプリを開くと、回復できるファイルが表示されることがあります。ただし、すべてが元に戻るとは限りません。
        • 強制終了は、保存していない作業が消えたり、更新中であれば起動しなくなったりするおそれがあります。毎回の対処にはしないでください。

      • 固まったときのメモをとる

        固まったら、元に戻ったあとで次のことをメモします。スマホのメモ帳で構いません。1週間の行動で、原因を絞り込むのに使います。

        • 日時
        • 何をしていたか（使っていたアプリ、開いていたファイルやタブの数）
        • 画面に何と出ていたか（メッセージが出ていたら、スマホで撮っておきます）
        • どれくらい待ったか、どうやって元に戻ったか（待った、アプリを終わらせた、強制終了した）
        • パソコンを起動してからどれくらいたっていたか、本体が熱かったか

      • 作業中のファイルを、こまめに保存する

        • 作業の区切りごとに、Ctrl + S を押して保存する習慣をつけます。たとえば、段落を書き終えたとき、表を1つ作り終えたとき、席を立つ前などです。
        • 新しく作ったファイルは、最初に名前を付けて保存しておきます。一度保存しておけば、そのあとは Ctrl + S だけで上書き保存できます。
        • Microsoft 365 の Word や Excel では、OneDrive に保存したファイルの変更を自動で保存する「自動保存」の機能を使えることがあります。

    2. 1週間の行動

      目安：1日10〜20分。原因の候補を1日に1つずつ確かめます

      • Cドライブの空き容量を確かめ、一時ファイルを消す

        エクスプローラーで「PC」を開くと、Cドライブの空き容量が表示されます。残りが少ない場合は、不要なファイルを消します。

        • 「設定」→「システム」→「ストレージ」を開き、「一時ファイル」を選びます。Windows 10 では「設定」→「システム」→「記憶域」です。
        • 消してよい項目にチェックを入れ、「ファイルの削除」を押します。
        • 一覧の「ダウンロード」にチェックを入れると、ダウンロードフォルダの中身がすべて消えます。中身を確かめるまでは、チェックを外したままにしてください。
        • マイクロソフトは、Windows の大きな更新（アップグレード）には、64ビット版で20GB以上の空き領域が必要だと案内しています。
        • 空き容量を増やすほかの方法は、お悩み No.002「パソコンが遅くて容量もいっぱい、買い替える前にできること」にまとめています。

      • 起動時に動くアプリを減らす

        タスクマネージャーを開き、左側の「スタートアップ アプリ」を選びます。Windows 10 では、上の「スタートアップ」タブです。パソコンの起動と同時に立ち上がるアプリの一覧が表示されます。

        • 毎回すぐには使わないアプリを右クリックし、「無効にする」を選びます。版によっては「無効化」という名前です。
        • 無効にしても、アプリは削除されません。自分で開けば使えます。
        • 「スタートアップへの影響」が「高」のものから見直すと、効果が出やすくなります。
        • ウイルス対策ソフトや、パソコンのメーカー名が付いたソフト、何のためのものか分からないものは、有効のままにしておきます。

      • Windows Update の「アクティブ時間」を設定する

        アクティブ時間は、ふだんパソコンを使う時間帯を Windows に伝える設定です。マイクロソフトの案内では、アクティブ時間を設定すると、都合の悪いときに更新のための再起動が行われるのを防げます。

        • 「設定」→「Windows Update」→「詳細オプション」→「アクティブ時間」を開きます。
        • 「アクティブ時間の調整」で「手動」を選び、仕事でパソコンを使う時間帯の開始時刻と終了時刻を選びます。使う時間帯が日によって違う場合は、「自動」を選ぶと、使い方に合わせて Windows が調整します。
        • Windows 10 では、「設定」→「更新とセキュリティ」→「Windows Update」→「アクティブ時間の変更」です。
        • 更新の準備ができると、再起動を求める表示が出ます。仕事の終わりなど区切りのよいときに作業を保存し、自分で再起動します。ノートパソコンは、再起動の前に電源アダプターをつなぎます。

      • 放熱口のほこりを確かめ、風通しのよい場所に置く

        • 電源を切り、電源ケーブルを抜いてから作業します。ノートパソコンは電源アダプターも外します。
        • 本体の外から見える放熱口やファンの吹き出し口に、ほこりがたまっていないかを見ます。たまっていたら、エアダスターや柔らかいブラシで取ります。本体のねじは外しません。
        • ノートパソコンを布団やクッションの上で使うと、放熱口がふさがります。机の上など、平らで硬い場所に置いて使います。
        • デスクトップパソコンは、壁や家具との間を少し空けて、放熱口をふさがないように置きます。

      • SSDやハードディスクの健康状態を確かめる

        CrystalDiskInfo は、SSDやハードディスクの状態を表示する無料のツールです。公式サイト（Crystal Dew World）からダウンロードします。

        • 起動すると、「健康状態」の欄に「正常」「注意」「異常」「不明」のいずれかが表示されます。「正常」かどうかを見ます。
        • 「正常」と表示されていても、この先も壊れないという保証にはなりません。公式サイトの説明でも、そう書かれています。また、ほかの原因で固まっている可能性も残ります。
        • 「注意」や「異常」と表示された場合は、劣化している可能性があります。公式サイトの説明では、「注意」は今すぐ必ず故障するという意味ではないとしています。ただし、早めに大切なデータをコピーし、メーカーのサポートや修理店に相談してください。データのコピーのしかたは、1か月の見直しに書いています。
        • 「不明」は、判定に必要な情報を取得できない場合の表示です。
        • ソフトを入れるのが不安な場合は、無理に入れなくて構いません。メーカーのサポートに相談するときに、ディスクの状態を確かめてもらう方法もあります。

      • 固まったときのメモと、Windows の記録を見比べる

        Windows には、エラーや問題が起きた日を記録する「信頼性モニター」があります。スタートメニューの検索欄に「信頼性」と入れ、「信頼性の履歴の表示」を開きます。

        • グラフの下に、問題が起きた日の印（赤い×など）が並びます。その日を選ぶと、どのアプリで、どんな問題が起きたかが表示されます。
        • 今日の一歩でとったメモと見比べて、固まった日に同じアプリや同じ問題が出ていないかを確かめます。
        • 重いと感じたときは、タスクマネージャーの「パフォーマンス」を開き、メモリとディスクの使用率を見ます。高い状態が続いていれば、メモリの不足や、ディスクの読み書きの集中が関わっている可能性があります。
        • 固まるようになった時期が、Windows の更新や新しい機器をつないだ時期と重なる場合は、ドライバーが関わっている可能性があります。パソコンのメーカーのサポートページで、機種名からドライバーの更新が出ていないかを確かめます。

    3. 1か月の見直し

      目安：1か月後に30分〜1時間（バックアップするデータの量によって変わります）

      • 固まる回数と、更新の様子を確かめる

        • 今日の一歩から続けてきたメモを見返し、固まる回数が減ったかを確かめます。
        • 「設定」→「Windows Update」→「更新の履歴」を開き、更新プログラムが正しくインストールされているかを見ます。失敗したものがあれば、その名前をメモしておきます。Windows 10 では、「設定」→「更新とセキュリティ」→「Windows Update」→「更新の履歴を表示する」です。
        • 固まる回数が減り、更新も無事に終わっていれば、今の見直しを続けます。

      • バックアップがまだなら、大切なデータをコピーする

        固まったり起動しなくなったりするトラブルに備えて、大切なデータを本体の外にもコピーしておきます。

        • 写真や仕事の書類など、なくなると困るファイルを、外付けハードディスクやクラウド（OneDrive など）にコピーします。
        • コピーしたら、コピー先でいくつかのファイルを開き、きちんと見られることを確かめます。
        • バックアップの始め方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」にまとめています。
        • パソコンによっては、起動しないときの回復の画面で、BitLocker の回復キーを求められることがあります。回復キーが Microsoft アカウントに保存されている場合は、別の端末から確かめられます。確かめ方は、注意書きにあるマイクロソフトの案内を見てください。起動できるうちに、回復キーがどこにあるかを確かめておきます。

      • 症状が続くときは、メーカーのサポートや修理店に相談する

        次のような場合は、自分で直そうとせずに、パソコンのメーカーのサポートや修理店に相談します。保証期間中は、まずメーカーに相談します。

        • 見直しをしても、何度も固まる
        • 更新のたびに起動しなくなる
        • CrystalDiskInfo で「注意」や「異常」と表示された

        相談するときは、次のものを用意しておくと、状況を伝えやすくなります。

        • 固まったときのメモと、画面の写真
        • パソコンのメーカー名と型番（本体の裏のシールや、購入時の書類に書かれています）
        • Windows の種類とバージョン（Windows + R を押し、「winver」と入れて「OK」を押すと表示されます）
        • CrystalDiskInfo の画面の写真（使った場合）

      • 古いパソコンは、修理と買い替えを相談のうえで比べる

        • パソコンが古い（10年近い）場合は、修理と買い替えのどちらがよいかを、相談先で聞いてから比べます。
        • 修理の費用や、部品が手に入るかどうかは、機種や修理の内容によって違います。見積もりを聞いてから決めます。
        • Windows 10 のパソコンは、2025年10月14日にマイクロソフトのサポートが終了しています。Windows 11 に上げられるかどうかは、パソコンの部品によって決まります。上げられるかどうかも、相談のときに確かめます。
        • 買い替える場合も、今のパソコンのデータを先にコピーしておくと、新しいパソコンへ移しやすくなります。

      • 月に一度、点検の日を決める

        • 毎月の日付を1つ決めて、カレンダーやスマホの予定に書き込みます。
        • その日には、Cドライブの空き容量と、Windows Update の更新の履歴を確かめます。CrystalDiskInfo を使っている場合は、健康状態の表示も見ます。
        • あわせて、バックアップが最近の日付で取れているかも確かめます。

    まず今日、固まったときに試す順番を確かめ、固まったときのメモをとり始めます。次の1週間で、空き容量、起動時のアプリ、更新の時間帯、熱、ディスクの状態を1つずつ確かめます。1か月後に、固まる回数と更新の様子を見直し、バックアップを取ります。症状が続くときは、メーカーのサポートや修理店に相談します。手順の名前や場所は、機種や Windows のバージョンで変わることがあります。分からないところは、メーカーやマイクロソフトのサポートページで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理や保守についての専門的な助言ではありません。

    強制終了や設定の変更は、ご自身の判断と責任で行ってください。強制終了をすると、保存していない作業が消えることがあります。更新の途中に強制終了すると、パソコンが起動しなくなるおそれがあります。ファイルを削除するときは、必要なファイルが含まれていないかを先に確かめてください。

    修理や部品の交換、買い替えには、費用がかかる場合があります。費用は、機種や修理の内容、依頼先によって違います。依頼する前に、見積もりを確かめてください。保証期間中は、まずメーカーに相談してください。本体を自分で開けると、保証が受けられなくなることがあります。

    設定の名前や場所は、パソコンの機種や Windows のバージョンによって変わることがあります。この記事の手順と画面が違うときは、スタートメニューの検索欄で探すか、公式のヘルプで確かめてください。

    会社から貸与されたパソコンは、管理者の決まりで、更新の設定やソフトの追加が制限されていることがあります。その場合は、管理している担当者に確かめてください。
