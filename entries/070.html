    AIの見立て

    デスクトップは作業机の天板と同じで、置き場所ではなく一時置き場と割り切り、フォルダ分けのルールを決めてダウンロード直後に振り分ければ、探す時間の多くは減らせる見込みあり

    作業机の天板には、今使っている書類だけを置き、終わったら引き出しにしまいます。デスクトップも同じように、作業中のファイルを一時的に置く場所と決めます。そのうえで、フォルダー分けのルールを先に決めておきます。ダウンロードしたファイルをその直後に振り分ければ、探す時間の多くは減らせる見込みがあります。

    ボトルネックは、保存するときに行き先を決めていないことです。行き先がないので、とりあえずデスクトップに置き、ファイルが増えていきます。フォルダーの分け方に正解を求めすぎると、整理を始められません。その間にも、新しいファイルはデスクトップにたまっていきます。

    どんな分け方が使いやすいかは、人によって違います。この記事の分け方は一例です。使いながら、自分に合う形に直していきます。

    この記事の手順とメニュー名は、2026年11月時点の Microsoft と Apple の公式ヘルプをもとにした、Windows 11 と Mac の例です。設定名やメニューの場所は、Windows や macOS のバージョンによって変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    デスクトップが、ファイルやスクリーンショットでいっぱいになっている
    保存したファイルや撮ったスクリーンショットが、デスクトップに残ったままになっている。必要なものとそうでないものが、同じ場所に混ざっている。
    保存したはずのファイルが見つからず、探すのに毎回時間がかかる
    どこに保存したかを覚えておらず、そのたびにデスクトップやフォルダーを順に見ている。
    画面共有のとき、デスクトップが見えるのが恥ずかしい
    会議などで画面を共有すると、デスクトップのファイル名がほかの人に見えてしまう。慌ててファイルをどかしたこともある。
    ダウンロードしたものが置きっぱなしで、どれが最新版か分からない
    ダウンロードしたファイルが、片付けられないまま残っている。似た名前のファイルが増えて、どれを使えばよいか見分けられない。
    フォルダーの分け方が分からず、結局またデスクトップに置いてしまう
    整理しようという気持ちはあるが、分け方を決められない。決められないまま、新しいファイルもデスクトップに置いている。

    考えられる原因

    デスクトップがファイルだらけになる原因として、次のことが考えられます。

    保存するときに行き先を決めず、とりあえずデスクトップに置いてしまう
    デスクトップはいつも画面に見えているので、保存先に選びやすい場所です。保存のたびに行き先を考えるのは手間なので、とりあえずデスクトップに置くことが続きます。その結果、ファイルが少しずつ増えていきます。
    ダウンロードしたファイルやスクリーンショットが、そのまま残っていく
    ブラウザーでダウンロードしたファイルは、多くの場合「ダウンロード」フォルダーに保存されます。Mac では、スクリーンショットは「スクリーンショット[日付][時刻]」という名前で、デスクトップに保存されるのが初期設定です。Windows では、Windows + PrtScn で撮った画面が「スクリーンショット」フォルダーに保存されます。どれも、自分で移したり消したりしない限り、同じようなファイルが増え続けます。
    「最新版」「最終」といった名前で保存し、どれが本物か分からなくなる
    「最新」と付けたファイルも、あとで直すと最新ではなくなります。「最終」のあとに「最終2」「最終_修正」が増えることもあります。同じ名前のファイルをもう一度ダウンロードすると、名前の後ろに「(1)」などの番号が付いて、別のファイルとして保存されることもあります。こうなると、名前からどれが新しいかを判断できません。
    フォルダーの分け方に正解を求めすぎて、整理そのものを先延ばしにしてしまう
    最初から完璧な分け方を決めようとすると、なかなか決められません。決められない間も、新しいファイルは増えていきます。分け方は、使いながら直せば十分です。
    デスクトップに置いたファイルもパソコンの容量を使うことを知らず、置きっぱなしにしている
    デスクトップは画面の背景のように見えますが、中身は「デスクトップ」という名前のフォルダーです。Windows では、エクスプローラーの左側で「デスクトップ」を選ぶと、置いてあるファイルを一覧で見られます。デスクトップのファイルも、ほかのフォルダーのファイルと同じように保存容量を使います。置きっぱなしにすると、気づかないうちに空き容量が減っていきます。

    どこが原因かを切り分ける方法

    次のことを確かめると、どこから手を付ければよいかが分かります。具体的な手順は、行動プランで説明します。

    デスクトップのアイコンが何個あるか数えて、3個以内にできるか確かめる
    まず、今のアイコンの数を数えます。そのうち、今日使うものが何個あるかも数えます。今日使うものが3個以内なら、残りはすべてフォルダーへ移せます。
    探すのに30秒以上かかるファイルがあるか確かめる
    よく使うファイルを3つ思い浮かべ、開くまでの時間を測ります。30秒以上かかるものは、置き場所か名前を見直す候補です。
    ダウンロードフォルダーに何日分のファイルがたまっているか確かめる
    「ダウンロード」フォルダーを開き、更新日時の順に並べます。いちばん古いファイルの日付を見れば、何日分たまっているかが分かります。何か月も前のファイルが残っていれば、ダウンロードしたあとに片付ける習慣がまだないと分かります。
    同じ内容のファイルが「(1)」「コピー」付きで何個あるか確かめる
    デスクトップや「ダウンロード」フォルダーを名前の順に並べると、似た名前のファイルが隣り合って並びます。「(1)」や「コピー」が付いたファイルが多いときは、同じファイルを何度も保存しています。どれを残すかを決めれば、ファイルの数を減らせます。

    直る見込み

    デスクトップに「作業中のものだけ」を置くルールにすれば、画面がすっきりする
    作業が終わったファイルをフォルダーへ移すルールにすれば、デスクトップに残るのは数個だけです。画面共有のときに見えるものも減ります。Windows には、デスクトップのアイコンを一時的に隠す設定もあります。
    フォルダーを用途で3つ程度に分けるだけでも、探す場所が絞れる
    「写真」「仕事」「学校」のように、用途で3つ程度に分けます。ファイルを探すときは、まず用途を思い出し、そのフォルダーだけを見れば済みます。
    ファイル名を「日付＋内容」に統一すれば、並べ替えで新しいものがすぐ分かる
    「2026-11-24_見積書」のように、先頭に日付を付けます。名前の順に並べると日付の順にもなるので、いちばん新しいファイルがすぐ分かります。「最新」「最終」と付ける必要もなくなります。
    スクリーンショットは週に1回まとめて移す習慣にすれば、たまりにくくなる
    決まった曜日に、スクリーンショットをまとめて見直します。いらないものは消し、残すものはフォルダーへ移します。Mac では、スクリーンショットの保存先をデスクトップ以外に変えることもできます。
    よく使うフォルダーを登録すれば、1クリックで開ける
    Windows のエクスプローラーでは「クイック アクセス」に、Mac の Finder ではサイドバーの「よく使う項目」に、フォルダーを登録できます。フォルダーを順にたどる手間が減ります。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 保存するとき、行き先を決めずにデスクトップや「ダウンロード」フォルダーに置く
    2. ファイルが増えて、必要なものが見つからなくなる
    3. 整理しようとしても分け方を決められず、先延ばしにする
    4. 新しいファイルも、またデスクトップに置く

    4のあと、また1に戻ります。

    この循環は、1のところで止められます。用途のフォルダーを先に3つだけ作っておけば、保存するときに行き先を選べます。分け方は完璧でなくて構いません。使いにくいところは、1か月後の見直しで直します。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 仕事や学校で受け取るファイルの量
    • ほかの人が付けたファイル名
    • 会議で画面共有を求められる場面
    • Windows や macOS のバージョンによる、手順やメニュー名の違い

    変えやすいこと

    • 保存するときに、行き先のフォルダーを選ぶこと
    • フォルダーの数と分け方
    • ファイル名の付け方
    • ダウンロードしたファイルを片付けるタイミング
    • スクリーンショットの保存先と、片付ける頻度
    • よく使うフォルダーを、クイック アクセスやよく使う項目に登録すること
    • 画面共有の前に、デスクトップが見えないようにしておくこと

    次の行動プランは3段階です。今日は、デスクトップのファイルを「あとで整理」フォルダーへいったん移します。1週間で、用途のフォルダーと保存のルールを決めて、習慣にします。1か月後には、「あとで整理」フォルダーの中身を振り分け、ルールが続いているかを確かめます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は Windows 11 と Mac の例です。メニューやボタンの名前と場所は、機種や Windows、macOS のバージョンによって違うことがあります。この記事と画面が違うときは、使っているパソコンの公式ヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分ほど。迷ったファイルは消さずに「あとで整理」へ入れます

      • デスクトップを一度だけ見渡して、「今日使うもの」と「それ以外」に分ける

        1つずつ開いて中身を確かめる必要はありません。名前とアイコンを見て、今日使うかどうかだけで分けます。迷ったものは「それ以外」にします。

      • Windows の場合：「あとで整理」フォルダーを1つだけ作り、「それ以外」をいったん全部移す

        1. アプリで開いているファイルがあれば、先に閉じます。
        2. Windows + E を押して、エクスプローラーを開きます。左側の「デスクトップ」を選ぶと、デスクトップに置いてあるファイルが一覧で表示されます。
        3. 上部の「新規作成」→「フォルダー」を選びます。Ctrl + Shift + N を押しても作れます。
        4. 名前に「あとで整理」と入力して、Enter を押します。
        5. 「それ以外」に分けたファイルを選びます。Ctrl を押しながらクリックすると、複数のファイルを選べます。
        6. 上部の「切り取り」を選びます。続けて「あとで整理」フォルダーを開き、上部の「貼り付け」を選びます。
        • ファイルを「あとで整理」フォルダーへドラッグしても移せます。
        • デスクトップに新しく作るフォルダーは、「あとで整理」の1つだけにします。

      • Mac の場合：「あとで整理」フォルダーを1つだけ作り、「それ以外」をいったん全部移す

        1. アプリで開いているファイルがあれば、先に閉じます。
        2. デスクトップで、「それ以外」に分けたファイルを選びます。Command を押しながらクリックすると、複数のファイルを選べます。
        3. Control を押しながら、選んだファイルのどれか1つをクリックします。
        4. 「選択項目から新規フォルダ」を選びます。選んだファイルが、新しいフォルダーにまとめて入ります。
        5. 名前に「あとで整理」と入力して、Return を押します。
        • 先に空のフォルダーを作るときは、デスクトップをクリックしてから「ファイル」＞「新規フォルダ」を選びます。Shift + Command + N でも作れます。作ったフォルダーへファイルをドラッグすると、ファイルが移ります。

      • ダウンロードフォルダーを開いて、今日いらないものをゴミ箱へ移す

        • Windows：エクスプローラーの左側で「ダウンロード」を選びます。上部の「並べ替え」→「更新日時」を選ぶと、日付の順に並びます。いらないファイルを選んで Delete を押すと、「ごみ箱」に移ります。
        • Mac：Finder のサイドバーで「ダウンロード」を選びます。いらないファイルを、Dock の「ゴミ箱」へドラッグします。
        • いるかどうか迷ったファイルは消さずに、「あとで整理」フォルダーへ移します。
        • ゴミ箱に移したファイルは、ゴミ箱を空にするまでは元に戻せます。今日は、ゴミ箱を空にしなくて構いません。

      • ファイル名に「最新」「最終」と付けないと決める

        「最新」と付けても、あとで直せば最新ではなくなります。今日からは、名前に日付を付けます。付け方は、1週間の行動で説明します。

    2. 1週間の行動

      目安：1回10〜15分ほどを、数日に分けて。スクリーンショットの片付けは週に1回

      • 用途でフォルダーを3つまでに分ける

        よく扱うファイルの用途を思い浮かべ、フォルダーを3つまで作ります。たとえば「写真」「仕事」「書類」です。名前は、自分の使い方に合うものに変えて構いません。

        • 作る場所は、Windows ならエクスプローラーの「ドキュメント」、Mac なら Finder の「書類」が分かりやすいです。
        • どれにも当てはまらないファイルは、「あとで整理」フォルダーに入れます。4つ目のフォルダーは、1か月後の見直しまで作りません。
        • フォルダーの中にさらにフォルダーを作るのは、必要になってからにします。

      • 新しいファイルは、保存するときに行き先のフォルダーを選ぶ

        • Word や Excel などで保存するときは、「名前を付けて保存」の画面で用途のフォルダーを選んでから保存します。
        • ブラウザーでダウンロードしたファイルは、「ダウンロード」フォルダーに入ります。ダウンロードしたら、すぐに用途のフォルダーへ移します。一度だけ見ればよいファイルは、見終わったら消します。
        • Edge でダウンロードの保存先を確かめるときは、右上の「設定など」（…）→「設定」→「ダウンロード」を選び、「場所」を見ます。

      • スクリーンショットは週に1回、専用のフォルダーへ移す

        曜日を1つ決めて、スクリーンショットをまとめて見直します。いらないものは消し、残すものは用途のフォルダーか、スクリーンショット専用のフォルダーへ移します。

        • Windows：Windows + PrtScn で撮った画面は、「画像」（バージョンによっては「ピクチャ」）フォルダーの中の「スクリーンショット」フォルダーに保存されます。Windows 11 の Snipping Tool で撮った画面も、自動で「スクリーンショット」フォルダーに保存されます。
        • Mac：初期設定では、スクリーンショットはデスクトップに保存されます。保存先を変えると、デスクトップにたまらなくなります。

      • Mac の場合：スクリーンショットの保存先をデスクトップ以外に変える

        1. Finder の「書類」の中に、「スクリーンショット」という名前のフォルダーを作ります。
        2. Shift + Command + 5 を押して、スクリーンショットアプリを開きます。
        3. 「オプション」メニューの保存先で、作ったフォルダーを選びます。
        • スクリーンショットアプリは、「アプリケーション」フォルダーの中の「ユーティリティ」フォルダーからも開けます。

      • よく使うフォルダーを、1クリックで開けるように登録する

        • Windows：エクスプローラーで、登録したいフォルダーを右クリックし、「クイック アクセスにピン留めする」を選びます。登録したフォルダーは、エクスプローラーの「ホーム」と、左側のクイック アクセスに表示されます。外すときは、右クリックして「クイック アクセスからピン留めを外す」を選びます。
        • Mac：Finder を開き、登録したいフォルダーをサイドバーの「よく使う項目」へドラッグします。「よく使う項目」が表示されていないときは、「Finder」＞「設定」を選び、「サイドバー」で「よく使う項目」の項目を1つ以上選びます。外すときは、項目をサイドバーの外へドラッグし、削除の記号が出たら放します。
        • 登録しても、フォルダーそのものの場所は変わりません。Apple の案内では、サイドバーの項目は元のフォルダーのエイリアス（別の場所から開くための目印）です。

      • ファイル名を「日付＋内容」でそろえる

        「2026-11-24_見積書」のように、先頭に日付、続けて内容を書きます。名前の順に並べると、日付の順にも並びます。

        • 月と日は、「11-04」のように2けたで書きます。「11-4」のように書くと、並べ替えたときに順番がずれることがあります。
        • 内容には、あとで検索するときに入れそうな言葉を使います。
        • 名前の変え方：Windows では、ファイルを選んで F2 を押すか、右クリックして「名前の変更」を選びます。Mac では、ファイルを選んで Return を押します。
        • これまでのファイルの名前を、全部変える必要はありません。新しく保存するファイルから始めます。

      • 画面共有の前に、デスクトップが見えないようにする

        • Windows：デスクトップの何もないところを右クリックし、「表示」→「デスクトップ アイコンの表示」のチェックを外します。アイコンが一時的に隠れます。もう一度チェックを入れると、元に戻ります。隠している間も、エクスプローラーの左側で「デスクトップ」を選べば、中身を見られます。
        • 会議アプリ：Microsoft Teams では、共有を始めるときに、画面全体かウィンドウかを選べます。ウィンドウを選ぶと、そのウィンドウだけが相手に見えます。ほかの会議アプリは、そのアプリの公式ヘルプで確かめてください。
        • Mac：デスクトップをクリックし、「表示」＞「スタックを使用」を選ぶと、デスクトップのファイルがグループにまとまります。Control + Command + 0 でも切り替えられます。まとめ方は、「表示」＞「スタックのグループ分け」で、種類・日付・タグなどから選べます。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • 「あとで整理」フォルダーの中身を見直す

        この1か月に「あとで整理」フォルダーから一度も取り出さなかったファイルは、使わなかったファイルと考えられます。

        • 必要なものは、用途のフォルダーへ移します。
        • 1か月使わなかったもののうち、残しておきたいものは、外付けのドライブやクラウドのストレージなど、パソコンの外に保存します。
        • いらないものは削除します。大切なファイルを削除する前には、必ずバックアップを取ります。
        • 3つの用途に入らないファイルが多いときは、ここで4つ目のフォルダーを作るか、分け方を変えます。

      • デスクトップのアイコンが3個以内に収まっているか確かめる

        数が増えているときは、どんなファイルが置かれているかを見ます。同じ種類のファイルが多いなら、その種類のファイルの行き先がまだ決まっていません。行き先のフォルダーを決めて、次からはそこへ保存します。

      • 探すのに30秒以上かかるファイルが残っていないか振り返る

        この1か月で、探すのに時間がかかったファイルを思い出します。フォルダーの名前が分かりにくいなら、名前を変えます。何度も開くフォルダーは、クイック アクセスやよく使う項目に登録します。

      • フォルダーが深くなりすぎていないか確かめる

        フォルダーの中のフォルダーは、3階層以内を目安にします。たとえば「仕事」→「2026年」→「見積書」で3階層です。それより深いと、目当てのファイルにたどり着くまでに時間がかかります。深くなったフォルダーは、1つ上の階層にまとめます。

    1か月たったら、続けられたルールと続かなかったルールを分けます。続かなかったルールは、やめるか、もっと簡単なものに変えて構いません。続けられたルールを残して、次の1か月も同じように見直します。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの操作についての専門的な助言ではありません。操作は、ご自身の判断と責任で行ってください。

    大切なファイルを削除する前には、必ずバックアップを取ってください。外付けのドライブやクラウドのストレージに、コピーを保存しておきます。ゴミ箱を空にすると、削除したファイルは元に戻せなくなります。

    ファイルやフォルダーを移動するときは、アプリから開いているファイルを閉じてから行ってください。開いたまま移そうとすると、移動できなかったり、作業中の内容を保存できなかったりすることがあります。

    OneDrive や iCloud Drive などで、デスクトップのフォルダーをクラウドと同期している場合は、パソコンでの移動や削除がクラウド側にも反映されることがあります。同期の設定は、それぞれのサービスの公式ヘルプで確かめてください。

    会社や学校から貸し出されたパソコンでは、ファイルの保存場所が決められていることがあります。その場合は、職場や学校のルールに従ってください。

    手順やメニューの名前は、機種や Windows、macOS のバージョンによって変わることがあります。この記事は、2026年11月時点の公式ヘルプをもとにしています。分からない操作は、使っているパソコンの公式ヘルプで確かめてください。
