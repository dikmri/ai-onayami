お悩み No.082 ・ 2026年11月24日公開

パソコンが急に青い画面になって再起動する。仕事中のデータが消えたときの切り分けと直し方

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    青い画面（ブルースクリーン）は Windows が深刻な問題を検知して自分を守るために再起動する仕組みで、原因の多くはドライバーや Windows Update、メモリなどの不具合にあり、エラーコードと発生パターンを確かめることで切り分けができる見込みあり。たまに起きるだけなら様子見でよいことも多いが、繰り返し起きる場合は原因の特定と対処が必要

    青い画面は、Windows が安全に動き続けられない状態を見つけたときに出ます。そのまま動かし続けると、データが壊れるおそれがあるためです。Windows は動作を止めて、自動で再起動します。Microsoft は、これを「停止コード エラー」や「ブルースクリーン エラー」と呼んでいます。

    原因は、パソコンの部品や周辺機器、それを動かすドライバー、ソフトウェアのどれかにあります。画面に出る「停止コード」と、起きたときの状況を記録すれば、原因を絞り込めます。

    Microsoft のヘルプでは、多くの場合は再起動するだけで済むと案内されています。今回のお悩みのように何度も繰り返す場合は、原因を探して対処する必要があります。

    ボトルネックは2つあります。1つは、原因を探す手がかり（停止コードと起きたときの状況）が残っていないことです。もう1つは、保存していない書類が、再起動のたびに消えてしまうことです。

    この記事の手順は、2026年11月時点の Microsoft の公式サポートをもとにしています。設定の名前や場所は、Windows のバージョンによって変わることがあります。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    仕事中に突然、画面が青くなって再起動する
    自分で何かを操作したわけではないのに、パソコンが止まり、勝手に再起動する。
    保存していなかった書類の内容が消えた
    再起動の前に保存する時間はない。最後に保存したときから後の作業が、なくなってしまう。
    何度も繰り返し起きている
    1回だけの偶然ではない。何かの原因が、パソコンに残っている可能性が高い。
    エラーコードが毎回違う気がする
    停止コードを控えていないので、同じなのか違うのかを確かめられていない。
    再起動を繰り返して、使えない時間がある
    仕事に使えない時間が出ていて、影響が大きくなっている。
    故障なのか、設定で直るのか分からない
    修理に出すべきかを決めるための材料が、まだそろっていない。

    考えられる原因

    青い画面が出る原因として、次のことが考えられます。

    ドライバー（周辺機器を動かすソフト）の不具合
    ドライバーは、グラフィックス（画面の表示）やネットワーク、プリンターなどの機器を動かすためのソフトです。ドライバーが古い、壊れている、Windows と合っていない、といった場合に、停止コード エラーが起きます。停止コードの画面に「〇〇.sys」というファイル名が出ていれば、問題のドライバーを探す手がかりになります。
    Windows Update の直後なら、更新内容との相性
    更新の直後から起きるようになった場合は、更新の内容と、パソコンの機器やドライバーの組み合わせが合っていない可能性があります。反対に、まだ入れていない更新に、問題を直す修正が入っていることもあります。
    メモリ（RAM）の故障や接触不良
    メモリは、作業中のデータを一時的に置いておく部品です。メモリに異常があると、停止コード エラーが起きます。Microsoft のヘルプでも、メモリを調べる手段として「Windows メモリ診断」が案内されています。
    ハードディスク・SSD の劣化や、空き容量の不足
    データを保存する装置が劣化すると、Windows のファイルを正しく読めなくなり、停止コード エラーが起きることがあります。空き容量が少なすぎる場合も原因になります。Microsoft は、全体の10〜15%ほどの空き容量を残しておくよう勧めています。
    最近つないだ USB 機器や、新しく入れたソフト
    新しい機器やソフトを入れた時期と、青い画面が出始めた時期が近ければ、それが原因の候補になります。Microsoft のヘルプでも、最初の手順として、新しく追加したハードウェアを取り外すよう案内しています。
    パソコン内部の熱
    通気口やファンにホコリがたまると、パソコンの中の温度が上がります。熱で部品の動きが不安定になると、突然の停止や再起動が起きることがあります。
    ウイルス対策ソフトなど、常に動いているソフトの干渉
    ウイルス対策ソフトのように、Windows の深いところで動くソフトは、停止コード エラーの原因になることがあります。また、ウイルスによって Windows のファイルが壊れると、停止コード エラーが起きることもあります。
    エラーコードが毎回違うなら、ハードウェアの可能性が高まる
    同じ停止コードが続く場合は、特定のドライバーやソフトが原因のことがあります。停止コードが毎回違う場合は、メモリや電源など、ハードウェアの側の不具合の可能性が高まります。部品の不具合は、どの処理をしているときにも起きうるため、止まる場所とコードが毎回変わるからです。

    どこが原因かを切り分ける方法

    次のことを確かめると、原因を絞り込めます。具体的な手順は、行動プランで説明します。

    まず、画面の「停止コード」を写真に撮って控える
    停止コードは、英語の大文字と「_」でできた名前です。たとえば「CRITICAL_PROCESS_DIED」や「DRIVER_POWER_STATE_FAILURE」です。原因になったファイルの名前（〇〇.sys）が出ていれば、それも控えます。Windows 11 バージョン 24H2 以降では、画面が2秒ほどで消えることが多いため、撮れなかったときはイベント ビューアーで確かめます。
    いつ起きるかをメモする
    特定のソフトを使っているとき、起動の直後、スリープから戻ったとき、などを書き留めます。決まったソフトを使っているときに起きるなら、そのソフトか、関係するドライバーが疑わしくなります。スリープから戻ったときに起きるなら、電源の切り替えに関わるドライバーが疑わしくなります。
    最近入れたソフトやつないだ機器を外して、起きなくなるか確かめる
    外したあとで起きなくなれば、それが原因です。機器は、パソコンの電源を切ってから外します。
    Windows Update を確かめ、保留中の更新を入れる
    更新を入れたあとで起きなくなれば、更新で直る種類の問題だったと考えられます。更新の直後から起きるようになった場合は、その更新を一度アンインストールする方法もあります。
    セーフ モードで起動して、普通に使えるか確かめる
    セーフ モードでは、Windows が最低限のドライバーとサービスだけで起動します。セーフ モードで起きないなら、追加のドライバーや常に動いているソフトが原因の可能性が高まります。セーフ モードでも起きるなら、部品の故障や Windows そのものの問題を疑います。
    Windows メモリ診断を実行する
    Windows に最初から入っている、メモリを調べるツールです。異常が見つかれば、メモリの交換を考えます。
    イベント ビューアーで、エラーの記録を確かめる
    イベント ビューアーは、Windows に起きた出来事を記録しているツールです。「Windows ログ」→「システム」を開き、再起動の直前の時刻に「重大」や「エラー」の記録がないかを探します。写真に撮れなかった停止コードも、ここで確かめられることがあります。

    直る見込み

    ドライバーの更新や Windows Update で直ることが多い
    停止コード エラーの原因の多くは、ドライバーや Windows の不具合です。メーカーや Microsoft が修正を出していれば、更新を入れるだけで止まります。
    原因のソフトや機器を外すだけで止まることもある
    最近入れたソフトやつないだ機器が原因なら、外すだけで起きなくなります。その機器を使い続けたい場合は、メーカーのサイトで新しいドライバーが出ていないかを確かめます。
    メモリ診断で異常が見つかれば、メモリの交換で直る見込みがある
    メモリは、パソコンの部品の中では交換しやすいものです。ただし、ノートパソコンには、メモリが基板に固定されていて交換できない機種もあります。その場合は、メーカーの修理に出すことになります。
    画面が青ではなく黒でも、同じ対処でよい
    Windows 11 バージョン 24H2 以降では、停止コード エラーの画面が黒に変わりました。顔文字と QR コードがなくなり、停止コードと原因のドライバーの情報が短く表示されます。画面の色が違っても、起きていることと対処の方法は同じです。
    起動できなくなったときに、自動で回復する仕組みもある
    Windows 11 には「クイック マシン回復」という仕組みが加わりました。起動の失敗が何度か続くと、Windows は回復用の画面（Windows 回復環境）に入ります。そこでインターネットにつなぎ、Microsoft が出している修正を探して、見つかれば自動で適用し、再起動します。ただし、対象は多くのパソコンで起きている既知の起動の問題です。部品の故障などは、この仕組みでは直りません。
    何をしても繰り返す場合は、記録が修理の相談に役立つ
    停止コード、起きた日時と回数、試したことを控えておくと、修理店やメーカーのサポートに相談するときに話が早く進みます。修理に出すか、買い替えるかを決める材料にもなります。

    公式情報で確かめたこと

    次のことを、Microsoft の公式サポートと公式ブログで確かめました。Windows のバージョンによっては、画面や名前が違うことがあります。

    停止コード エラーの基本の手順
    Microsoft サポートの「Windows の予期しない再起動および停止コード エラーのトラブルシューティング」では、多くの場合は再起動だけで済み、同じ停止コードで何度も再起動する場合に次の手順を試すよう案内されています。新しいハードウェアを取り外す、セーフ モードで起動する、デバイス マネージャーを確かめる、空き容量を確かめる、Windows Update で最新の更新を入れる、Windows を復元する、の6つです。
    画面の色と QR コード
    Windows 10 と、Windows 11 バージョン 23H2 までは、青い画面に停止コードと QR コード、「https://www.windows.com/stopcode」のアドレスが表示されます。このアドレスは、Microsoft サポートの停止コード エラーのトラブルシューティングのページにつながります（2026年11月に転送先を確かめました）。Windows 11 バージョン 24H2 以降は黒い画面になり、顔文字と QR コードはなくなりました。代わりに、停止コードの16進数の番号と、原因のドライバーの情報が表示されます。多くのパソコンでは、この画面は2秒ほどで再起動に進みます。
    デバイス マネージャーとドライバー
    「スタート」ボタンを右クリックして「デバイス マネージャー」を開き、「!」の付いた機器を右クリックして「ドライバーの更新」を選びます。Microsoft は、ドライバーを入手するいちばんよい方法は Windows Update だとしています。手動で入れる場合は、機器の製造元の公式サイトから入れ、ほかのサイトからはダウンロードしないよう案内しています。更新したあとで調子が悪くなった場合は、機器の「プロパティ」→「ドライバー」タブ→「ドライバーを元に戻す」で、前のドライバーに戻せます。
    Windows メモリ診断
    Microsoft のヘルプでは、Windows キー + R で「ファイル名を指定して実行」を開き、「mdsched」と入力して「OK」を選ぶ方法が案内されています。開いた画面で「今すぐ再起動して問題がないかチェックする (推奨)」を選ぶと、再起動したあとに診断が自動で始まります。終わると Windows が起動し、サインインのあとで結果が通知されます。通知が出るまで数分かかることがあります。
    セーフ モード
    「設定」→「システム」→「回復」の「今すぐ再起動」から、または、サインイン画面で Shift キーを押しながら「電源」→「再起動」を選ぶと、「オプションの選択」の画面が出ます。そこから「トラブルシューティング」→「詳細オプション」→「スタートアップ設定」→「再起動」と進み、4 か F4 キーでセーフ モード、5 か F5 キーでネットワークありのセーフ モードを選びます。セーフ モードでは PIN や顔・指紋でのサインインが使えないため、アカウントのパスワードが必要です。もう一度再起動すると、通常の状態に戻ります。
    イベント ビューアー
    「スタート」ボタンを右クリックして「イベント ビューアー」を選びます。Microsoft の技術資料では、停止コード エラーと同じ時間帯に起きた重大なエラーを、システム ログで探すよう案内しています。原因のドライバーや機器を見つける手がかりになることがあります。
    更新プログラムのアンインストール
    Windows 11 では、「設定」→「Windows Update」→「更新履歴」→「更新プログラムのアンインストール」で外せます。Microsoft は、セキュリティの更新を外す前に、そのリスクを理解しておくよう注意しています。外せない更新もあります。
    クイック マシン回復
    Windows 11 の機能で、起動の失敗が繰り返されたときに、Windows 回復環境から Microsoft の修正を探して自動で適用します。設定は「設定」→「システム」→「回復」→「クイック マシン リカバリ」にあります。Microsoft の Windows IT Pro Blog によると、Windows 11 Home では最初からオンになっています。Pro などのエディションでは、最初はオフです。
    Office の自動保存と自動回復
    自動保存は、Microsoft 365 を契約している人が使える Word、Excel、PowerPoint の機能です。OneDrive か SharePoint に保存したファイルで働き、数秒ごとに変更を保存します。パソコンの中（C ドライブなど）に保存したファイルでは自動保存は働きませんが、自動回復が最初からオンになっていて、10分ごとに作業内容を記録します。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 仕事中に突然、青い画面になって再起動する
    2. 停止コードを控えないまま、作業に戻る
    3. 原因が分からないまま、同じことがまた起きる
    4. 保存していない書類が消え、修理に出すべきかも決められない

    4のあと、また1に戻ります。

    この循環は、2か所で止められます。1つは2のところです。停止コードと起きたときの状況を記録すれば、原因を探す手がかりが残ります。記録がたまれば、設定で直せるのか、修理が必要なのかも判断しやすくなります。

    もう1つは4のところです。こまめに保存し、自動保存や自動回復を使えば、原因を探している間も、消える作業の量を小さくできます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • パソコンの部品（メモリ、SSD、電源など）の故障そのもの
    • ドライバーや Windows Update の中身
    • メモリを交換できない機種の作り
    • 職場のパソコンで、会社が決めている設定や管理の方法

    変えやすいこと

    • 停止コードと、起きたときの状況の記録
    • こまめに保存する習慣と、自動保存の設定
    • 最近入れたソフトや、つないだ機器の取り外し
    • Windows Update とドライバーの更新
    • バックアップの仕組み
    • 修理に相談するタイミングの判断

    次の行動プランは3段階です。今日は、停止コードを控える準備と、こまめに保存する設定をして、最近入れたソフトや機器を外し、Windows Update を確かめます。1週間で、起きたときの記録をつけ、ドライバー、メモリ、ウイルスを順に確かめます。1か月後には、記録を見て様子見でよいか、修理に相談するかを決め、バックアップの仕組みを整えます。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、できるところまで試してください。

    手順は、Windows 11 での例です。設定の名前や場所は、Windows の機種やバージョンによって変わることがあります。画面がこの記事と違うときは、Microsoft の公式サポートで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分〜1時間ほど

      • 消えた書類が残っていないか確かめる

        Word や Excel は、突然の再起動のあとで開き直すと、「ドキュメントの回復」の一覧を出すことがあります。消えたと思った書類の、途中までの内容が残っている場合があるので、まず確かめます。

      • 青い画面が出たら、停止コードを写真に撮る

        仕事中は、スマホをすぐ手に取れる場所に置いておきます。青い画面が出たら、画面全体を写真に撮ります。控えたいのは次の3つです。

        • 停止コード（例：CRITICAL_PROCESS_DIED、DRIVER_POWER_STATE_FAILURE）
        • 原因になったファイルの名前（〇〇.sys）。表示されていれば撮ります
        • 「0x」で始まる番号（16進数の停止コード）。表示されていれば撮ります

        Windows 10 や、Windows 11 バージョン 23H2 までの青い画面には、QR コードが出ます。スマホで読み取ると、Microsoft の停止コード エラーのトラブルシューティングのページが開きます。画面に出ている「https://www.windows.com/stopcode」も、同じページにつながります。

        Windows 11 バージョン 24H2 以降の黒い画面は、2秒ほどで消えることが多く、QR コードもありません。撮れなかったときは、1週間の行動で説明するイベント ビューアーで確かめます。

      • 作業中の書類を、こまめに保存する

        • Ctrl + S を習慣にします。区切りのよいところや、席を立つ前に押します。
        • Microsoft 365 を契約している場合は、書類を OneDrive に保存し、Word や Excel の左上にある「自動保存」のスイッチをオンにします。数秒ごとに自動で保存されます。
        • パソコンの中に保存している場合は、「ファイル」→「オプション」→「保存」で、自動回復用のデータを保存する間隔を確かめます。最初は10分です。5分などに短くすると、消える作業の量を減らせます。ただし、自動回復は手で保存する代わりにはなりません。

      • 最近入れたソフトや、つないだ機器を外す

        青い画面が出始める少し前に、新しく入れたソフトや、つないだ USB 機器（プリンター、外付けの HDD、ドックなど）がないかを思い出します。

        • 機器：パソコンの電源を切ってから外し、もう一度電源を入れます。
        • ソフト：「設定」→「アプリ」→「インストールされているアプリ」で、最近入れたソフトを確かめます。仕事で使っていないものなら、アンインストールします。

      • Windows Update を確かめる

        「スタート」→「設定」→「Windows Update」を開き、「更新プログラムのチェック」を選びます。保留中の更新があれば入れて、パソコンを再起動します。

      • 再起動のあと、しばらく普通に使ってみる

        30分から1時間ほど、いつもの作業をして、すぐに再発するかを確かめます。作業中は、こまめに保存します。

      • 再起動が止まらず、使えないときは

        起動の失敗が続くと、「オプションの選択」という回復用の画面が出ることがあります。その場合は、次の順に試します。

        1. 「トラブルシューティング」→「詳細オプション」→「スタートアップ設定」→「再起動」を選び、4 か F4 キーでセーフ モードで起動します。セーフ モードで使えれば、大事なファイルを USB メモリなどにコピーしておきます。
        2. Windows Update の直後から起きるようになった場合は、「トラブルシューティング」→「詳細オプション」→「更新プログラムのアンインストール」で、最新の更新を外す方法もあります。

        途中で BitLocker の回復キーを求められることがあります。回復キーは、Microsoft アカウントに保存されている場合があり、別のパソコンやスマホから確かめられます。分からない場合や、会社のパソコンの場合は、無理に進めず、メーカーや社内の担当者に相談してください。

    2. 1週間の行動

      目安：記録は1回1〜2分。点検に1〜2時間ほど（メモリ診断はパソコンを使わない時間に）

      • 起きたときの記録をつける

        青い画面が出るたびに、次のことをメモ帳やスマホのメモに書き留めます。

        • 日時
        • そのとき使っていたソフト
        • 停止コード（写真を撮っていれば、その写真）
        • 直前にしたこと（スリープから戻った、機器をつないだ、など）

        3回以上たまったら見比べます。同じ停止コードが続いていれば、特定のドライバーやソフトを疑います。毎回違うなら、メモリなどのハードウェアを疑います。3回以上続くようなら、修理の相談のときにもこの記録が役に立ちます。

      • 撮り逃した停止コードを、イベント ビューアーで確かめる

        1. 「スタート」ボタンを右クリックして、「イベント ビューアー」を選びます。
        2. 左側の「Windows ログ」→「システム」を選びます。
        3. 再起動した時刻の少し前の記録を見ます。レベルが「重大」や「エラー」になっている記録を探します。

        ソースが「BugCheck」の記録があれば、そこに停止コードの番号（「0x」で始まる16進数）が書かれていることがあります。ソースが「Kernel-Power」でイベント ID が 41 の記録は、正常に終了しないまま再起動したことを示します。見慣れない画面ですが、記録を見るだけなら、パソコンに変更は加わりません。

      • デバイス マネージャーで、「!」の付いた機器を確かめる

        1. 「スタート」ボタンを右クリックして、「デバイス マネージャー」を選びます。
        2. 各項目の横の矢印を選んで開き、「!」の付いた機器がないかを見ます。
        3. 「!」の付いた機器があれば、右クリックして「ドライバーの更新」を選び、自動で検索する項目を選びます。

        見つからない場合は、パソコンか機器のメーカーの公式サイトから、自分の機種と Windows のバージョンに合ったドライバーを入れます。グラフィックス（画面の表示）やネットワークのドライバーは、停止コード エラーの原因になりやすいため、「!」がなくても、メーカーのサイトで新しいものが出ていないか確かめます。

        ドライバーを更新してから調子が悪くなった場合は、機器を右クリックして「プロパティ」→「ドライバー」タブ→「ドライバーを元に戻す」を選びます。

      • Windows メモリ診断を実行する

        1. 作業中のファイルをすべて保存し、アプリを閉じます。
        2. スタートメニューで「Windows メモリ診断」と検索して開きます。Windows キー + R を押して「mdsched」と入力し、「OK」を選んでも開けます。
        3. 「今すぐ再起動して問題がないかチェックする (推奨)」を選びます。
        4. 再起動すると、診断が自動で始まります。終わるまで、しばらく時間がかかります。
        5. 終わると Windows が起動します。サインインしたあと、数分以内に結果が通知されます。

        異常が見つかった場合は、メモリの交換が必要な可能性があります。自分でメモリを抜き差しせず、メーカーか修理店に相談してください。

      • ウイルス対策ソフトでスキャンする

        Windows に最初から入っている「Windows セキュリティ」を使っている場合は、「ウイルスと脅威の防止」を開き、「クイック スキャン」を選びます。ほかのウイルス対策ソフトを使っている場合は、そのソフトでスキャンします。

      • 空き容量と、通気口のホコリを確かめる

        • 空き容量：「設定」→「システム」→「ストレージ」で確かめます。全体の10〜15%より少なければ、使っていないファイルやアプリを整理します。
        • 通気口：パソコンの電源を切り、電源ケーブル（ノートパソコンなら AC アダプター）を抜いてから、外から見える通気口のホコリを取ります。パソコンのケースは開けないでください。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • 再発していなければ、様子見でよい

        1か月たっても青い画面が出ていなければ、様子を見て構いません。たまに起きるだけなら、Windows やドライバーの更新で、そのまま収まることも多いです。

      • 週に1回、Windows Update を確かめる

        曜日を決めて、「設定」→「Windows Update」で「更新プログラムのチェック」を選びます。問題を直す修正を、早めに受け取れます。

      • 再発しているなら、記録を整理して相談する

        1週間の行動でつけた記録を、次の形にまとめます。修理店やメーカーのサポートに相談するときに、そのまま見せられます。

        • パソコンのメーカー名と機種名
        • 停止コードの一覧と、それぞれが起きた日時と回数
        • 起きたときに使っていたソフトや、直前にしたこと
        • 試したこと（機器を外した、更新を入れた、ドライバーを更新した、メモリ診断の結果、など）

        再起動を繰り返して使えない時間が長い場合や、作業中のデータが何度も消える場合は、1か月を待たずに、早めにバックアップを取って相談してください。

      • バックアップの仕組みを整える

        突然の再起動や故障でも大事なデータが消えないように、ふだんから別の場所にもデータを置いておきます。

        • 仕事の書類は OneDrive などのクラウドに保存し、自動保存を使う。
        • 外付けの HDD や SSD に、週に1回など日を決めてコピーする。

        会社のパソコンの場合は、会社が決めている保存場所やバックアップの方法に従ってください。

      • 1か月を振り返る

        青い画面の回数が減ったか、保存の習慣が続いているかを振り返ります。減っていない場合は、記録を持って相談する時期です。

    1か月たったら、続けられたものと続かなかったものを分けます。続かなかったものはやめて構いません。続けられたものを残して、次の1か月の計画を立て直します。手順の名前や場所は Windows の機種やバージョンで変わることがあるので、分からないところは、Microsoft の公式サポートで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理やデータの復旧についての専門的な助言ではありません。

    メモリの抜き差しやパソコンの中の掃除は、無理をしないでください。パソコンを分解すると、メーカーの保証が受けられなくなる場合があります。作業の前に、メーカーの保証の内容を確かめてください。

    ドライバーは、必ずパソコンや機器のメーカーの公式サイトか、Windows Update から入れてください。Microsoft も、製造元の公式サイト以外のサイトからドライバーをダウンロードしないよう案内しています。怪しいサイトで配られている「ドライバー更新ツール」などは使わないでください。

    青い画面が出て再起動を繰り返し、パソコンが使えない状態が続く場合は、無理に操作を続けないでください。早めにバックアップを取って、修理店やメーカーに相談してください。

    消えたデータの復旧が必要な場合は、データ復旧の専門業者に相談してください。自分で復旧ソフトを試すと、かえってデータが取り出せなくなる場合があります。

    更新プログラムのアンインストールは、Windows Update の直後から起きるようになった場合に限って試してください。セキュリティの更新を外したままにすると、パソコンが危険にさらされます。職場のパソコンでは、会社の設定によって、更新やドライバーを自分で変えられないことがあります。その場合は、社内の情報システムの担当者に相談してください。

    設定の名前や場所は、Windows のバージョンで変わることがあります。この記事は、2026年11月時点の Microsoft の公式サポートと公式ブログをもとにしています。分からない操作は、Microsoft の公式サポートで確かめてください。
