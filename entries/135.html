    AIの見立て

    1回のクリックが2回分として伝わる現象は『チャタリング』と呼ばれ、多くの場合、マウスのボタンの中のスイッチの接点がすり減ったことが原因で、設定だけでは直りにくい。ただしダブルクリックの速さの設定やドライバー、USBの接続が原因のこともあり、切り分けをすれば買い替えなくても直る場合もある。保証期間内なら、自分で開けずにメーカーに相談すること

    1回のクリックが2回分としてパソコンに伝わる現象は、「チャタリング」と呼ばれます。多くの場合、マウスのボタンの中にある小さなスイッチ（マイクロスイッチ）の接点がすり減ったことが原因です。接点がすり減ると、1回押しただけで電気の信号が何度も跳ね返り、パソコンに2回分の信号が届きます。この場合は、設定を変えるだけでは直りにくいです。

    ただし、原因はスイッチだけとは限りません。ダブルクリックの速さの設定、ドライバーの不具合、USB の接続の不安定さが原因のこともあります。順番に切り分ければ、買い替えなくても直る場合があります。お悩みの方は、ほかのパソコンでも同じ症状が出ているので、マウス本体のスイッチが原因の可能性が高いと考えます。

    ボトルネックは3つです。1つ目は、設定の問題なのか、マウス本体の寿命なのか分からないことです。2つ目は、スイッチの劣化は外からは見えず、確かめる方法が分かりにくいことです。3つ目は、直す方法として分解や部品の交換の話も出てきますが、どこまで自分でやってよいか分かりにくいことです。

    マウスが保証期間内なら、自分で開けずに、買った店かメーカーに相談してください。

    この記事は、2026年11月時点の Microsoft と Logicool の公式情報と、Windows 11 の画面の表示をもとにしています。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    1回クリックしたつもりなのに、フォルダが勝手に開く、ファイルが開いてしまう
    Windows では、フォルダやファイルは、1回のクリックで選び、ダブルクリックで開くのが標準の設定です。1回押しただけでパソコンに2回分の信号が届くと、パソコンはダブルクリックとして受け取り、フォルダやファイルを開きます。
    ドラッグして範囲を選ぶと、途中で切れる、違う場所が選ばれる
    ドラッグは、ボタンを押したままマウスを動かす操作です。押している間にスイッチの接点が一瞬離れると、パソコンはボタンが離されたと受け取ります。そのため、選択が途中で切れたり、離れた場所でもう一度押されたことになったりします。
    買って3年ほどたち、ほかのパソコンにつないでも同じように起きる
    2台のパソコンで同じ症状が出るなら、パソコン側よりマウス本体が原因の可能性が高いです。Microsoft は、別の PC でもデバイスが動作しない場合は、デバイスの交換が必要な可能性があると説明しています。Logicool も、最近までは正常だったのにダブルクリックになった場合は、カスタマーケアに問い合わせるよう案内しています。
    クリックの速さの設定を変えても、あまり変わらなかった
    Windows の「ダブルクリックの速度」は、2回のクリックをどのくらいの間隔までダブルクリックとみなすかを決める設定です。スイッチの接点が跳ねて出る2回目の信号は、ごく短い間に送られます。そのため、速度の設定を変えても止まりにくいです。設定を変えても変わらなかったことは、スイッチの劣化を疑う手がかりの1つになります。
    買い替えた方がいいのか、直す方法があるのか知りたい
    設定、接続、ドライバーは、自分で確かめられます。これらを確かめても直らなければ、スイッチの寿命と考えて買い替えを検討します。マウスを分解してスイッチを交換する方法もありますが、保証の対象外になるなどの注意点があります。

    1回のクリックが2回分になる仕組み

    マウスのクリックが2回分になる原因を、1つずつ説明します。

    マウスのボタンの中には、小さなスイッチがある
    マウスのボタンの下には、マイクロスイッチと呼ばれる小さなスイッチがあります。ボタンを押すと、中の金属の接点が触れて、「押した」という信号がパソコンに伝わります。指を離すと接点が離れて、「離した」という信号が伝わります。
    接点がすり減ると、1回押しても信号が何度も送られる
    スイッチは、押した回数が増えるほど、接点が少しずつすり減ります。すり減った接点は、1回押しただけでも細かく跳ねて、触れたり離れたりを繰り返します。そのたびに「押した」「離した」の信号が送られ、パソコンは2回押されたと受け取ります。これがチャタリングです。Logicool も、シングルクリックするとダブルクリックになる症状の原因の1つに、ハードウェアの問題を挙げています。
    ダブルクリックの速度の設定は、2回のクリックの間隔を決める
    Windows は、2回のクリックの間隔が設定より短いと、ダブルクリックとみなします。「ダブルクリックの速度」のつまみを「遅く」の側に動かすほど、間が空いた2回のクリックもダブルクリックとみなされます。Windows の設定画面にも、試しのフォルダをダブルクリックして開いたり閉じたりしない場合は、速度を遅くするよう書かれています。つまみが「遅く」の側に寄りすぎていると、選ぶつもりで2回クリックしただけで、ファイルが開いてしまうことがあります。
    「シングルクリックで開く」設定だと、1回のクリックで開く
    Windows には、フォルダやファイルを1回のクリックで開く設定があります。Logicool は、この設定が有効だと、シングルクリックがダブルクリックの動作になると説明しています。
    ワイヤレスマウスは、電池が少ないと信号が不安定になることがある
    ワイヤレスマウスは、電池の電力で信号を送ります。電池の残りが少ないと、信号が不安定になることがあります。Microsoft は、電池で動く機器は、完全に充電されているか、新しい電池が入っているかを確かめるよう案内しています。
    USB の差し込み口やハブの接続が不安定だと、クリックの信号がおかしくなることがある
    Logicool は、ボタンが正しく動かない原因の1つに、USB ポートの問題を挙げています。Microsoft と Logicool はどちらも、別の USB の差し込み口を試すことと、USB ハブを通さずパソコンに直接つなぐことを案内しています。
    ドライバーの不具合でも、マウスの動きがおかしくなることがある
    ドライバーは、Windows がマウスを動かすために使うプログラムです。Microsoft は、マウスとキーボードの問題の対処として、ドライバーの更新を挙げています。Windows Update のあとに問題が起きた場合は、以前のドライバーに戻すと解決することがよくあるとも説明しています。

    原因の切り分け方

    次の順に確かめます。どれも、マウスを開けずに確かめられます。

    ほかのパソコンにつないでも起きるか
    ほかのパソコンでも同じ症状が出るなら、マウス本体のスイッチの劣化の可能性が高いです。お悩みの方は、すでにこの状態です。Microsoft は、別の PC でテストするときは、そのデバイスに合うドライバーが入っているかを確かめるよう書いています。
    今のパソコンに別のマウスをつなぐと起きるか
    別のマウスでは起きないなら、今のマウスが原因の可能性が高いです。別のマウスでも同じように起きるなら、パソコン側の設定やドライバーの問題を疑います。
    左のボタンだけで起きるか、左右どちらのボタンでも起きるか
    左のボタンだけで起きるなら、左のボタンのスイッチの劣化の可能性が高いです。Logicool は、左右のボタンを設定で入れ替えて試す方法を案内しています。問題が同じボタンに残るならハードウェアの問題、新しいボタンに移るならソフトウェアの設定やアプリの問題です。左右どちらのボタンでも起きるなら、設定や接続の問題も疑います。
    ダブルクリックの速度を「速く」の側に戻すと、症状が消えるか
    つまみが「遅く」の側に寄っていて、真ん中あたりに戻すと症状が消えるなら、設定の問題だった可能性が高いです。設定の画面の試しのフォルダを1回だけクリックして、開いたり閉じたりするなら、つまみの位置に関係なく、ボタンから2回分の信号が送られている可能性が高いです。
    USB の差し込み口を変えると、違いがあるか
    差し込み口を変えて直るなら、元の差し込み口の接続が原因です。Logicool は、差し込み口によって違いがある場合は、パソコンの USB のチップセットのドライバーを更新してみるよう案内しています。
    ワイヤレスマウスなら、電池を替えると直るか
    電池を新しくして直るなら、電池の残りが原因です。新しい電池に替えても直らないなら、スイッチの劣化の可能性が高くなります。

    落とし穴

    直そうとして、かえって悪くしたり、保証を受けられなくなったりしないために、気をつけたい点があります。

    ダブルクリックの速度を「遅く」の側に動かす
    「遅く」の側に動かすと、間が空いた2回のクリックもダブルクリックとみなされます。勝手に開く症状は、かえって起きやすくなります。「遅く」の側に動かすのは、ダブルクリックしてもフォルダが開かないときです。
    保証期間内のマウスを分解する、慣れないままスイッチを交換する
    マウスを分解して、スイッチを新しい部品に交換する方法もあります。ただし、はんだ付けなどの作業が必要で、慣れていないと、マウスを壊してしまうことがあります。Logicool の保証の規定では、許可のない修理、改造、分解から生じた問題は、保証の対象外です。保証期間内のマウスは、自分で開けずに、買った店やメーカーに相談します。
    無料の「チャタリングを直す」ソフトを入れる
    チャタリングを防ぐとうたう無料のソフトの中には、クリックの信号を少し遅らせたり、すぐあとの2回目の信号を無視したりする仕組みのものがあります。この仕組みだと、ゲームなどでは反応が遅く感じられることがあります。速いダブルクリックが効きにくくなることもあります。配布元がはっきりしないソフトは入れません。スイッチの劣化そのものは、ソフトでは直りません。
    ドライバーを公式サイト以外から入れる
    Microsoft は、ドライバーを製造元の公式サイト以外の Web サイトからダウンロードしないよう案内しています。ドライバーは、Windows Update か、マウスのメーカーの公式サイトから入手します。
    電池を替えても直らないのに、電池のせいだと考え続ける
    ワイヤレスマウスで、電池を新品に替えたり、しっかり充電したりしても直らない場合は、スイッチの劣化の可能性が高いです。電池を何度も替えるより、ほかの切り分けに進みます。
    買い替えるときに、仕様と保証を見ずに選ぶ
    スイッチは消耗する部品です。買い替えるときは、ボタンが何回のクリックに耐えるかの数字や、保証期間を見て選ぶと、長持ちしやすく、壊れたときにも相談しやすくなります。

    公式情報で確かめたこと

    次のことを、Microsoft と Logicool の公式情報と、Windows 11 の画面の表示で確かめました。機種や Windows のバージョンによって、手順や画面の名前が違う場合があります。

    Windows のマウスの設定（Microsoft サポート「マウスの設定を変更する」）
    Windows 11 では、「スタート」→「設定」→「Bluetooth とデバイス」→「マウス」を選び、「関連設定」の項目から「マウスのプロパティ」を開きます。この項目は、Microsoft のヘルプでは「その他のマウス設定」と書かれ、Windows 11 の画面では「マウスの追加設定」と表示されます。「ボタン」タブの「ダブルクリックの速度」の「速度」のつまみで、ダブルクリックの速度を調整します。「マウスの主ボタン」のメニューで、主ボタンを「左」か「右」に設定できます。ボタンを押し続けなくてもドラッグできる ClickLock も、「ボタン」タブで設定します。Windows 10 では、「スタート」→「設定」→「デバイス」→「マウス」→「追加のマウス オプション」で「マウスのプロパティ」を開きます。
    「マウスのプロパティ」の画面の表示（Windows 11）
    「ダブルクリックの速度」には、「右側のフォルダーをダブルクリックして、設定をテストしてください。フォルダーが開いたり閉じたりしない場合は、速度を遅くしてください。」と表示されます。ClickLock は、画面では「クリックロック」と表示されます。「クリックロックをオンにする」の説明には、項目をクリックし、マウスのボタンを少しの間押したままにしてから離すと、ボタンを押したままでなくても強調表示やドラッグができると書かれています。
    マウスの問題の確かめ方（Microsoft サポート「Windows でのマウス、キーボードの問題」）
    最初にハードウェアを確かめるよう書かれています。USB ケーブルを抜き、Windows がドライバーを外すまでしばらく待ってから、つなぎ直します。別の USB ポートも試します。USB ハブを使っている場合は、ハブに電源があるかを確かめ、それでも動かなければハブを外して直接つなぎます。ケーブルが傷んでいないか、電池が新しいか、キーやセンサーをふさぐ汚れがないかも確かめます。ワイヤレスの機器は、底にあるリセットボタンを押すか、USB の受信機を抜いて約10秒待ってから差し直すと、ワイヤレス接続がつなぎ直されます。別の PC でも動作しない場合は、デバイスの交換が必要な可能性があります。ドライバーは、Windows Update の「更新プログラムのチェック」か、デバイス マネージャーで更新します。
    ドライバーの更新と入れ直し（Microsoft サポート「Windows のデバイス マネージャーを使用してドライバーを更新する」）
    ドライバーの更新は、Windows Update で自動的に受け取るのがいちばんよい方法だと書かれています。デバイス マネージャーでは、デバイスを右クリックして「ドライバーの更新」→「ドライバー ソフトウェアの最新版を自動的に検索」を選びます。入れ直すときは、作業を保存してアプリを閉じ、デバイスを右クリックして「デバイスのアンインストール」を選び、パソコンを再起動します。再起動のあと、Windows がドライバーを入れ直そうとします。最近の更新のあとに問題が起きた場合は、デバイスの「プロパティ」の「ドライバー」タブで「ドライバーを元に戻す」を選びます。これには管理者の権限が必要です。製造元の公式サイト以外からドライバーをダウンロードしないよう書かれています。
    エクスプローラーの設定の開き方（Microsoft サポート「Windows のエクスプローラー」）
    Windows 11 では、エクスプローラーの上の「詳細を表示」（「…」のボタン）から「オプション」を選ぶと、フォルダーの設定の画面が開きます。
    シングルクリックがダブルクリックになるとき（Logicool サポート「マウスのシングル クリックがダブルクリックになる」）
    使い始めた日からダブルクリックになる場合は、Windows の「ポイントして選択し、シングル クリックで開く」の設定を確かめるよう書かれています。この設定が有効だと、シングルクリックがダブルクリックの動作になります。「全般」タブで「シングルクリックで選択し、ダブルクリックで開く」を選びます。最近までは正常に動いていたのにダブルクリックになった場合や、設定を確かめても直らない場合は、Logicool のカスタマーケアに問い合わせるよう書かれています。
    ボタンが正しく動かないとき（Logicool サポート「キーボード／マウス - ボタンまたはキーが正しく動作しない」）
    考えられる原因に、ハードウェアの問題、OS やソフトウェアの設定、USB ポートの問題が挙がっています。症状の例に、シングルクリックするとダブルクリックになることがあります。対処には、エアダスターでのボタンの掃除と、ハブや延長器を通さない直接の接続が挙がっています。ペアリングの解除とつなぎ直し、ファームウェアの更新、別の USB ポートや別のコンピューターでの確認も挙がっています。左右のボタンを入れ替えて、問題が同じボタンに残ればハードウェアの問題、新しいボタンに移ればソフトウェアの設定やアプリの問題と書かれています。ボタンが「シングルクリックはダブルクリック」に設定されていないかを、Windows のマウスの設定やメーカーのソフトで確かめるよう書かれています。
    Logicool のマウスのファームウェア（Logicool サポート「マウスのファームウェアを更新するにはどうすればよいですか？」「Logi Options+」）
    Logi Options+ でマウスを選び、ウィンドウの左側の「設定」を選ぶと、「概要」の下にファームウェアのバージョンが表示されます。「更新を確認」を選ぶと、ファームウェア更新ツールが開き、更新があるかを知らせます。ファームウェアの更新の目的に、バグの修正が挙がっています。Logi Options+ は、対応するマウスとキーボードを管理するためのソフトです。ダウンロードのページには、対応 OS として Windows 11 と Windows 10 が書かれています。
    Logicool の保証（Logicool「期間限定保証」）
    保証期間は、製品のパッケージや、Logicool の公式サイトの製品の仕様に書かれた期間です。保証の請求は、まず support.logi.com で解決策を探し、見つからない場合は買った店に問い合わせます。購入後の最初の30日間は、通常は買った店を通して処理されます。修理や交換を受けるには、日付の入ったレシートか領収書の写しが必要です。事故、誤用、許可のない修理、改造、分解などから生じた問題は、保証の対象外と書かれています。

    「チャタリング」という言葉と、接点が跳ねて信号が何度も送られる仕組みは、Microsoft と Logicool の公式情報には書かれていませんでした。この記事の仕組みの説明は、マウスのスイッチの一般的な説明をもとにしています。チャタリングを防ぐソフトについての説明も、一般的な説明です。Logicool 以外のメーカーのソフトや保証の内容は、今回は確かめていません。自分のマウスについては、メーカーの公式サポートページで確かめてください。

    ボトルネック

    AIは、次の流れがいちばん大きなボトルネックだと考えます。

    1. 1回のクリックが2回分になり、フォルダが勝手に開く
    2. 設定の問題なのか、マウスの寿命なのか分からない
    3. クリックの速さの設定を少し変えてみるが、変わらない
    4. 直すか買い替えるか決められないまま、使い続ける

    4のあと、また1に戻ります。

    この流れは、2のところで止められます。左右のボタンの入れ替え、別のマウスや別のパソコンでの確認、USB の差し込み口の変更で、原因がマウス本体にあるかを確かめられます。原因がマウス本体にあると分かれば、保証の確認と買い替えに進めます。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • スイッチの接点は、使ううちに少しずつすり減ること
    • スイッチの劣化は、外からは見えないこと
    • 分解して直すには、はんだ付けなどの作業が必要で、保証の対象外になること
    • 保証期間は、メーカーや機種によって決まっていること
    • 機種や Windows のバージョンで、設定の名前や場所が違うこと

    変えやすいこと

    • ダブルクリックの速度とクリック方法の設定を確かめる
    • 左右のボタンを入れ替えて、原因がボタンにあるかを確かめる
    • USB の差し込み口を変える、USB ハブを外す
    • 電池を新しくする、しっかり充電する
    • ボタンのすき間のホコリを取る
    • ドライバーとファームウェアを更新する
    • 買い替えるときに、耐久回数と保証期間を比べる

    次の行動プランは3段階です。今日は、設定、接続、電池、ホコリを確かめ、原因がマウス本体にあるかを切り分けます。1週間で、ドライバーとメーカーのソフトを確かめ、数日使って様子を見ます。1か月で、直らなければ保証を確かめて相談するか、買い替えを検討します。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。今日の手順は、上から順に進めてください。最初の3つは、Windows の設定の画面で確かめられます。

    手順は、2026年11月時点の Microsoft と Logicool の公式情報と、Windows 11 の画面の表示をもとにしています。手順の名前や画面の表示は、機種や Windows のバージョンによって変わることがあります。分からないところは、Microsoft やマウスのメーカーの公式サポートページで確かめてください。

    1. 今日からできる小さな一歩

      目安：20〜30分ほど

      • ダブルクリックの速度とクリックロックを確かめる

        Windows 11 では、次の順に「マウスのプロパティ」を開きます。

        1. 「スタート」→「設定」→「Bluetooth とデバイス」→「マウス」を選びます。
        2. 画面の下のほうの「関連設定」にある「マウスの追加設定」を選びます。Microsoft のヘルプでは「その他のマウス設定」と書かれています。
        3. 「マウスのプロパティ」が開いたら、「ボタン」タブを選びます。

        「ダブルクリックの速度」の「速度」のつまみを見ます。つまみが「遅く」の側にあるほど、2回のクリックの間が空いていても、ダブルクリックとみなされます。つまみが「遅く」の端に近いときは、真ん中あたりまで「速く」の側に戻して、「OK」を押します。

        同じ画面の右側にあるフォルダのアイコンで試せます。いつもの速さでダブルクリックして、フォルダが開いたり閉じたりすれば、その位置で使えます。開かないときは、つまみを「遅く」の側に少し戻します。次に、このフォルダを1回だけクリックしてみます。1回だけで開いたり閉じたりするなら、つまみの位置に関係なく、ボタンから2回分の信号が送られている可能性が高いです。

        同じ「ボタン」タブの「クリックロック」も見ます。クリックロックは、ボタンを押し続けなくてもドラッグできるようにする機能です。Windows の説明では、ボタンを少しの間押したままにしてから離すと、押した状態が続きます。オンにした覚えがないのに「クリックロックをオンにする」にチェックが入っていたら、チェックを外して「OK」を押し、ドラッグの様子を比べます。

        Windows 10 では、「スタート」→「設定」→「デバイス」→「マウス」→「追加のマウス オプション」で、同じ「マウスのプロパティ」が開きます。

      • 「シングルクリックで開く」設定になっていないかを確かめる

        1. エクスプローラーを開き、上のほうにある「…」（詳細を表示）を選んで、「オプション」を選びます。
        2. 「全般」タブで、「シングルクリックで選択し、ダブルクリックで開く」が選ばれているかを見ます。
        3. 「ポイントして選択し、シングルクリックで開く」が選ばれていたら、「シングルクリックで選択し、ダブルクリックで開く」に変えて、「OK」を押します。

        Logicool は、使い始めた日からダブルクリックになる場合に、まずこの設定を確かめるよう案内しています。最近になって起き始めた場合も、1分ほどで確かめられるので、ここで見ておきます。

      • 左右のボタンを入れ替えて、原因がボタンにあるかを確かめる

        1. 「スタート」→「設定」→「Bluetooth とデバイス」→「マウス」を選びます。
        2. 「マウスの主ボタン」を「右」に変えます。これで、右のボタンで選んだり開いたりするようになります。
        3. 右のボタンで、デスクトップやエクスプローラーのフォルダを1回クリックします。何回か試して、勝手に開くかを見ます。

        右のボタンでは勝手に開かないなら、問題は左のボタンに残っています。Logicool の説明では、問題が同じボタンに残る場合はハードウェアの問題です。左のボタンのスイッチが劣化している可能性が高いです。右のボタンでも同じように勝手に開くなら、問題は新しい主ボタンに移っています。Logicool は、この場合はソフトウェアの設定やアプリの問題だと説明しています。設定や接続の問題も疑って、次の手順に進みます。

        確かめ終わったら、「マウスの主ボタン」を「左」に戻します。入れ替えている間は、右のボタンで選ぶことに気をつけます。

      • USB の差し込み口を変える。USB ハブを使っていたら外す

        • パソコン本体の、別の USB の差し込み口に差し替えます。
        • USB ハブを通している場合は、ハブを外し、パソコン本体の差し込み口に直接差します。
        • ケーブルでつなぐマウスは、ケーブルを抜いて少し待ってから、差し直します。ケーブルに傷がないかも見ます。
        • USB の受信機（レシーバー）を差すワイヤレスマウスは、受信機を抜いて10秒ほど待ってから、差し直します。Microsoft は、これでワイヤレス接続がつなぎ直されると説明しています。
        • Bluetooth でつなぐマウスは、Logicool の案内のとおり、いったんペアリングを解除してから、つなぎ直します。つなぎ方は、お悩み No.043「パソコンのマウスが動かない。カーソルが止まる・見つからないときの切り分けと直し方」で説明しています。

      • ワイヤレスマウスは、電池を新しくするか、しっかり充電する

        電池で動くマウスは、新しい電池に替えます。充電式のマウスは、しっかり充電してから試します。マウスの底にリセットボタンがある機種では、押すとワイヤレス接続がいったん切れてから、つながり直します。

        電池を新しくしても直らないなら、電池が原因ではありません。次の手順に進みます。

      • ボタンのすき間のホコリを取る

        ケーブルでつなぐマウスはケーブルを抜き、ワイヤレスマウスは電源を切ってから行います。ボタンのすき間を、やわらかいブラシで軽くなでるか、エアダスターで吹きます。Logicool は、エアダスターでボタンを掃除する方法を挙げています。

        水や洗剤をかけたり、すき間に細い物を差し込んだりはしません。マウスのねじを外して開けることもしません。

      • 別のマウスと、別のパソコンで比べる

        • 今のパソコンに、別のマウスをつないで試します。家族のマウスや、ノートパソコンのタッチパッドでも構いません。別のマウスでは起きないなら、今のマウスが原因の可能性が高いです。別のマウスでも起きるなら、パソコン側の設定やドライバーを疑います。
        • 今のマウスを、ほかのパソコンにつないで試します。お悩みの方のように、ほかのパソコンでも同じ症状が出るなら、マウス本体のスイッチの劣化の可能性が高いです。

        今日わかったことを、メモ帳などに書いておきます。1か月の見直しで、買い替えや相談を決めるときに使います。

    2. 1週間の行動

      目安：ドライバーとソフトの確認に30分ほど。そのあと数日、様子を見る

      • Windows Update とデバイス マネージャーで、ドライバーを更新する

        今日の手順で直らなかった場合に行います。Microsoft は、ドライバーは Windows Update で自動的に受け取るのがいちばんよい方法だと説明しています。

        1. タスクバーの検索ボックスに「更新プログラムの確認」と入力し、出てきた「更新プログラムの確認」を選びます。「更新プログラムのチェック」を選び、更新があれば入れます。ドライバーの更新が無いこともあります。
        2. 「スタート」ボタンを右クリックし、「デバイス マネージャー」を選びます。
        3. 「マウスとそのほかのポインティング デバイス」の横の矢印を選んで、一覧を開きます。
        4. マウスの名前（「HID 準拠マウス」などと表示されます）を右クリックし、「ドライバーの更新」を選びます。
        5. 「ドライバー ソフトウェアの最新版を自動的に検索」を選びます。新しいドライバーが見つかれば、Windows がインストールします。

        Windows Update のあとから症状が出始めた場合は、マウスの名前を右クリックして「プロパティ」を選び、「ドライバー」タブの「ドライバーを元に戻す」を選ぶ方法もあります。この操作には、管理者の権限が必要です。

      • 直らなければ、ドライバーを入れ直す

        1. 作業中のファイルを保存して、アプリを閉じます。
        2. デバイス マネージャーで、マウスの名前を右クリックし、「デバイスのアンインストール」を選びます。確認の画面で「アンインストール」を選びます。
        3. 「スタート」ボタンを右クリックし、「シャットダウンまたはサインアウト」→「再起動」を選びます。再起動のあと、Windows がドライバーを入れ直そうとします。

        アンインストールしたあと、再起動するまでマウスが動かなくなることがあります。そのときは、キーボードで再起動します。Windows キーを押しながら D キーを押してデスクトップを表示し、Alt キーを押しながら F4 キーを押します。「Windows のシャットダウン」の画面で、矢印キーで「再起動」を選び、Enter キーを押します。キーボードでの操作は、お悩み No.043「パソコンのマウスが動かない。カーソルが止まる・見つからないときの切り分けと直し方」でも説明しています。

      • メーカーのソフトで、ボタンの設定とファームウェアを確かめる

        Logicool のマウスで、Logi Options+ に対応している機種なら、次の手順でファームウェアの更新を確かめられます。Logi Options+ は、Logicool の公式サイトから入手します。

        1. Logi Options+ を開き、マウスを選びます。
        2. ウィンドウの左側の「設定」を選びます。「概要」の下に、ファームウェアのバージョンが表示されます。
        3. 「更新を確認」を選びます。ファームウェア更新ツールが開き、更新があるかを知らせます。更新があれば、画面の指示に従います。

        Logicool は、ボタンが「シングルクリックはダブルクリック」のような設定になっていないかを確かめるよう案内しています。メーカーのソフトでボタンに別の動作を割り当てた覚えがあれば、割り当てを元に戻して比べます。

        ほかのメーカーのマウスは、そのメーカーの公式サイトで、専用のソフトやファームウェアの更新があるかを調べます。ソフトやドライバーは、メーカーの公式サイトから入手します。

      • 数日使って、症状が出る回数を比べる

        設定、接続、ドライバーを確かめたら、数日そのまま使います。1日に何回くらいフォルダが勝手に開いたか、ドラッグが途中で切れたかを、メモ帳などに書いておきます。今日の手順の前より減ったか、変わらないかで、1か月の見直しで何をするかを決めます。

    3. 1か月の見直し

      目安：保証の確認と相談に30分ほど。買い替える場合は、選ぶ時間も含めて1〜2時間ほど

      • 直らないときは、スイッチの寿命と考えて買い替えを検討する

        次の3つに当てはまるなら、マウス本体のスイッチの寿命の可能性が高いです。

        • 設定、ドライバー、接続を確かめても直らない
        • ほかのパソコンにつないでも、同じ症状が出る
        • 左右のボタンを入れ替えても、問題が同じボタンに残る

        Microsoft も、別の PC でも動作しない場合は、デバイスの交換が必要な可能性があると説明しています。

      • 保証期間内なら、自分で開けずに、買った店かメーカーに相談する

        保証期間は、メーカーや機種によって違います。パッケージ、保証書、メーカーの公式サイトの製品の仕様で確かめます。買ってから3年ほどたっている場合は、保証期間が過ぎていることもあります。

        Logicool の場合は、保証期間が製品のパッケージや、公式サイトの製品の仕様に書かれています。保証の規定では、購入後の最初の30日間は、通常は買った店を通して保証の請求を受け付けます。この期間は店によって違う場合があります。修理や交換を受けるには、日付の入ったレシートか領収書の写しが必要です。最近になってダブルクリックになった場合は、Logicool のカスタマーケアに問い合わせるよう案内されています。

        許可のない分解から生じた問題は、保証の対象外になります。保証期間内のマウスは、自分で開けずに相談してください。

      • 買い替えるときは、耐久回数と保証期間を比べる

        • クリックの耐久回数：製品の仕様に、ボタンが何回のクリックに耐えるかが書かれていることがあります。数字が大きいほど、スイッチが長持ちする目安になります。
        • 保証期間：長いものを選ぶと、スイッチが早く傷んだときにも相談しやすくなります。
        • レシートや納品書：保証の請求に、買った日の分かる書類が必要です。箱と一緒に、すぐ出せる場所に保管します。

      • 新しいマウスに合わせて、ダブルクリックの速度を調整する

        新しいマウスを使い始めたら、今日と同じ手順で「マウスのプロパティ」の「ボタン」タブを開きます。右側のフォルダのアイコンを、いつもの速さでダブルクリックして、開いたり閉じたりする位置につまみを合わせます。「遅く」の側に寄せすぎると、選ぶつもりの2回のクリックで開いてしまうことがあるので、ダブルクリックが効くいちばん「速く」に近い位置を選びます。

      • 分からないところは、公式サポートで確かめる

        Windows の設定の場所は Microsoft サポート、マウスのソフト、ファームウェア、保証は、マウスのメーカーの公式サポートページで確かめます。

    1か月たったら、勝手に開く回数やドラッグが切れる回数が減ったかを振り返ります。減っていれば、そのまま使い続けて構いません。減らなければ、保証を確かめて相談するか、買い替えます。手順の名前や画面の表示は、機種や Windows のバージョンによって変わることがあります。分からないところは、Microsoft やマウスのメーカーの公式サポートページで確かめてください。
