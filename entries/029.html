お悩み No.029 ・ 2026年11月23日公開

パソコンの電源を入れても画面が真っ暗。起動しないときにまず確かめること

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    画面が真っ暗になる原因には、ケーブルのゆるみや映す先の切り替えのように、本人がすぐ確かめられるものが多くあります。青い画面や英語のメッセージにも、画面に出ている文字やエラーコードという手がかりがあります。順番に確かめれば、本体の問題か画面の問題かを分けられると考えます。

    画面が映らなくても、写真や書類のデータは、本体の記憶装置（SSD やハードディスク）に残っていることが多くあります。画面が真っ暗というだけで、データがすぐに消えるわけではありません。修理に出す前に、自分で確かめられることもいくつかあります。そのため、改善できる見込みがあります。

    一方で、記憶装置や部品そのものが故障している場合は、自分では直せません。異音がする、焦げ臭い、煙が出るといった場合は、すぐに電源を切って、それ以上触らないでください。自分で分解したり、内部を触ったりすると、保証が受けられなくなったり、かえって壊れたりすることがあります。修理と買い替えのどちらがよいかは、確かめた結果とメーカーの診断をもとに決めます。

    悩みの分解

    お悩みの文章から、困っていることを6つに分けました。

    画面が真っ暗のまま
    電源のランプはつき、ファンの音が聞こえることもあるのに、画面に何も表示されない。昨日までは普通に使えていた。
    青い画面に英語のメッセージが出る
    「パソコンが正しく起動できませんでした」という表示が出て、何度入れ直しても同じ画面に戻る。
    入れ直しても直らない
    電源ボタンを長押しして入れ直しても、様子が変わらない。
    どこが壊れたのか分からない
    修理に出すしかないのかどうかも分からない。
    データが消えたのではないかと不安
    写真や書類のデータが消えたのではないかと心配している。むやみに触ると、余計に悪くなりそうで怖い。
    何から確かめればよいか分からない
    買い替えるべきか、直せるのかを決める材料がない。

    画面が真っ暗になる原因

    電源のランプがついている、ファンの音が聞こえるという場合は、本体は動いていて、画面の側に問題があることが多くあります。よくある原因は次の5つです。

    ケーブルや電源がゆるんでいる
    デスクトップでは、本体とモニターをつなぐケーブル（HDMI、DisplayPort など）や、モニターの電源ケーブルが抜けかけていることがあります。モニターの入力の切り替え（「HDMI1」と「HDMI2」など）が、つないだ端子と合っていないと、本体が動いていても画面は映りません。ノートパソコンでは、ACアダプターが抜けかけていて、バッテリーが切れかけていることもあります。
    映す先が外部モニターになっている
    ノートパソコンを外部モニターやテレビにつないだことがあると、映す先がそちらだけになっていることがあります。この場合、ノートパソコン本体の画面には何も映りません。
    画面の明るさが下がっている
    ノートパソコンでは、明るさを変えるキーを押して、画面がいちばん暗くなっていることがあります。暗い部屋で画面に顔を近づけると、かすかに映っているのが分かる場合もあります。
    スリープから戻っていない
    電源のランプが点滅している場合は、スリープ（作業の途中で一時的に休んでいる状態）のことがあります。ランプの色や点滅の意味は、機種によって違います。
    画面を表示する仕組み（グラフィック ドライバー）が止まっている
    Windows には、画面を表示する仕組みをリセットするキー操作があります。マイクロソフトの案内では、Windows ロゴ キー + Ctrl + Shift + B を押すと、グラフィック ドライバーがリセットされます。

    電源のランプもつかず、ファンの音もしない場合は、電源そのものが入っていません。コンセントや電源タップ、ACアダプターの確認と、下で説明する「放電」を先に試します。

    青い画面が出る原因

    青い画面にメッセージが出る場合は、本体は動いていますが、Windows が起動できていない状態です。出ている画面によって、意味が変わります。

    「Your PC did not start correctly」などと出る
    「PC が正しく起動しませんでした」という意味です。Windows は、起動がうまくいかないと、自動で修復を試みます。直せなかった場合に、このような画面が出ます。「再起動」を押しても同じ画面に戻る場合は、「詳細オプション」から Windows の回復の機能（Windows 回復環境）に進めます。
    エラーコードが出る
    「Your PC/Device needs to be repaired」のような文と一緒に、「0xc」から始まる英数字などのエラーコードが出ることがあります。エラーコードは、原因の手がかりです。コードによって、起動に必要な情報が見つからない、記憶装置につながらない、といった違いがあります。
    停止コードが出て、自動で再起動する
    「Your device ran into a problem and needs to restart」（デバイスで問題が発生したため、再起動が必要です）と出て、自動で再起動する画面もあります。画面の下に、「MEMORY_MANAGEMENT」のような停止コードが出ます。マイクロソフトの案内では、Windows 11 24H2 以降、この画面は青ではなく黒になります。黒い画面に文字が出ている場合は、この画面の可能性があります。
    回復キーを求められる
    「BitLocker 回復」と書かれた画面で、48桁の回復キーの入力を求められることがあります。記憶装置を暗号化する機能（BitLocker やデバイスの暗号化）が有効なパソコンで出ます。回復キーは Microsoft アカウントに保存されている場合があり、別のスマホやパソコンから確かめられます。

    英語のメッセージで「起動する場所が見つからない」と出る原因

    黒い画面に、次のような英語のメッセージが出ることがあります。

    • Start PXE over IPv4
    • No bootable device
    • Boot device not found

    「PXE」や「IPv4」は、ネットワークから起動しようとしていることを示す言葉です。パソコンは電源を入れると、決められた順番で、起動に使う場所（SSD やハードディスク、USB メモリ、ネットワークなど）を探します。SSD などから起動できないと、ネットワークから起動しようとして失敗し、このようなメッセージが出ます。パソコンが、起動する場所を見失っている状態のことが多くあります。

    原因には、次のようなものがあります。

    • USB メモリや外付けハードディスク、SD カードなどがつながっていて、そちらから起動しようとしている
    • 起動の順番の設定（BIOS や UEFI の設定）が変わっている
    • SSD やハードディスクの故障や、中の接続の不良

    つないでいる機器を外して入れ直すだけで、起動することもあります。BIOS や UEFI の設定は、意味の分からない項目を変えると、起動できなくなることがあります。設定を変える前に、メーカーのサポートに相談してください。

    「放電」で直ることがある理由

    パソコンの中には、電源を切ってもわずかに電気が残っています。この電気がたまると、部品の動きが不安定になり、電源が入らない、画面が映らないといった状態になることがあります。電源ケーブルやバッテリーを外して、たまった電気を逃がす操作を「放電」と呼びます。国内の多くのパソコンメーカーが、電源が入らないときや画面が映らないときに、まず試す方法として案内しています。

    手順は機種によって違います。バッテリーを外せないノートパソコンでは、メーカー独自の手順がある場合もあります。メーカーのサポートページで確かめてください。

    データは残っていることが多い

    画面が映らない、Windows が起動しないという状態でも、写真や書類のデータは、本体の記憶装置に残っていることが多くあります。画面に何も出ないというだけで、データがすぐに消えるわけではありません。

    一方で、次のような操作や状態は、データに影響することがあります。

    • 回復の機能のうち、「この PC を初期状態に戻す」や「クラウドの再構築」などの操作。マイクロソフトの案内では、項目や選び方によって、個人用のファイルが削除されます。
    • 記憶装置そのものの故障。ハードディスクから、カチカチ、カリカリという音が続く場合は、電源の入れ直しをくり返すと、状態が悪くなることがあります。
    • 修理のときの記憶装置の交換や初期化。修理の内容によっては、データが消えた状態で戻ってくることがあります。

    そのため、入れ直しをくり返すより、データに影響しない確認から順番に試すことが大切です。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 画面が真っ暗、または青い画面が出て、どこが悪いのか分からない
    2. 電源ボタンの長押しで入れ直すことを、何度もくり返す
    3. 様子が変わらず、データが消えたのではないかという不安が大きくなる
    4. 何を確かめればよいか分からないまま、修理か買い替えかで迷う

    4のあと、また1に戻ります。

    この循環は、2のところで止められます。入れ直しをくり返す前に、電源とケーブル、放電、別のモニターという順番で確かめれば、本体の問題か画面の問題かを分けられます。画面に出た文字やエラーコードを控えておけば、メーカーの窓口でも原因を絞り込みやすくなります。

    画面の名前やボタンの場所、キーの組み合わせは、パソコンの機種や Windows のバージョンによって違います。この記事で挙げる名前は一例です。分からないときは、メーカーやマイクロソフトのサポートページなど、公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • 部品や記憶装置そのものの故障
    • 機種ごとの電源ランプの意味や、キーの割り当て
    • 回復の画面の作りや、項目の名前
    • 修理の内容と、修理にかかる費用や期間
    • 保証の条件

    変えやすいこと

    • 電源ケーブル、コンセント、電源タップの確認
    • 放電を試すこと
    • 別のモニターやテレビにつないで確かめること
    • つないでいる USB 機器を外すこと
    • 画面に出た文字やエラーコードを写真に撮ること
    • 日ごろのバックアップ
    • 相談する前に、症状を整理しておくこと

    次の行動プランは、今日「電源とケーブルの確認」「放電」「別の画面での確認」から始め、1週間でデータのバックアップと公式の情報での確認を進め、1か月後にバックアップの習慣と、修理や買い替えを決める材料を見直す順番にしています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すたびに、画面の様子が変わったかを確かめます。

    ボタンの名前や場所、キーの組み合わせ、回復の画面の項目の名前は、パソコンの機種や Windows のバージョンによって違います。この記事の手順と画面が違うときは、メーカーやマイクロソフトのサポートページなど、公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：30分ほど。データに影響しない確認から順に試します

      • 異音、焦げ臭いにおい、煙があれば、電源を切ってそれ以上触らない

        次のような様子があるときは、ここから先の手順は試さないでください。

        • 焦げ臭いにおいがする、煙が出ている
        • 本体から、ふだん聞かない音（カチカチ、カリカリ、ジーという音など）が続く
        • 本体や ACアダプターが、触れないほど熱い
        • ノートパソコンの底やキーボードが、ふくらんで浮き上がっている

        電源を切り、電源ケーブルや ACアダプターをコンセントから抜きます。煙が出ているなど危ないときは、本体に近づかず、身の安全を優先します。そのうえで、メーカーのサポート窓口に相談します。

      • 電源ケーブルとコンセントを確かめる

        • 電源タップを使っている場合は、タップのスイッチが入っているかを見ます。壁のコンセントに直接さして試すと、タップの問題かどうかが分かります。
        • デスクトップは、本体とモニターの両方の電源ケーブルが、奥までささっているかを確かめます。本体の背面に電源のスイッチがある機種もあります。
        • 本体とモニターをつなぐケーブル（HDMI、DisplayPort など）を、両側ともさし直します。モニターの入力の切り替え（「HDMI1」「HDMI2」など）が、つないだ端子と合っているかも見ます。
        • ノートパソコンは、ACアダプターがコンセントと本体の両方にささっているかを確かめます。ACアダプターや本体に充電のランプがある機種では、ランプがつくかも見ます。

      • 画面を表示させるキー操作を試す

        キー操作は、Windows が起動していて、画面だけが映っていない場合に使えます。

        • 電源のランプが点滅している場合は、スリープのことがあります。電源ボタンを短く1回押すか、キーボードのキーを押します。ランプの意味は、取扱説明書で確かめます。
        • Windows + Ctrl + Shift + B を同時に押します。Windows は、Windows のロゴが書かれたキーです。マイクロソフトの案内では、うまくいくと、ビープ音が鳴るか、画面がちらつきます。
        • ノートパソコンでは、明るさを上げるキー（太陽のマークのキーなど）を何回か押します。Fn キーと一緒に押す機種もあります。
        • 外部モニターやテレビにつないだことがある場合は、映す先を切り替えます。マイクロソフトの案内では、Windows + P を押したあと、もう一度 P を押してから Enter を押すと、表示のモードが切り替わります。画面が見えないままの操作なので、何回かくり返して試します。

      • 放電を試す

        電源ボタンの長押しでの入れ直しをくり返す前に、放電を1回試します。

        ノートパソコンの場合：

        1. 電源を切ります。画面が映らず操作できないときは、電源ボタンを長押しして切ります。
        2. ACアダプターを本体から外します。USB 機器や SD カード、外部モニターのケーブルも外します。
        3. バッテリーを外せる機種は、バッテリーを外します。
        4. 電源ボタンを10秒ほど長押しします。
        5. 数分置いてから、バッテリーと ACアダプターをつなぎ直し、電源を入れます。

        デスクトップの場合は、電源を切り、電源ケーブルをコンセントから抜きます。周辺機器のケーブルも外します。電源ボタンを10秒ほど長押しし、数分置いてから電源ケーブルをつなぎ直して、電源を入れます。

        バッテリーを外せないノートパソコンでは、メーカーが決まった手順を用意していることがあります。メーカーのサポートページで、機種名と「放電」で調べて確かめます。

      • テレビや別のモニターにつないで、画面が出るか確かめる

        • パソコンに HDMI などの映像の端子があれば、家のテレビや別のモニターにつなぎます。テレビの入力の切り替えを、つないだ端子に合わせます。
        • 別の画面に映れば、本体は動いています。元の画面（ノートパソコンの画面、またはモニターやケーブル）の側に問題がある可能性が高いと考えられます。
        • デスクトップでは、ケーブルを別のものに替えて試すと、ケーブルの問題かどうかが分かります。
        • 別の画面にも映らない場合は、本体の側に問題がある可能性があります。

      • 英語のメッセージが出る場合は、つないでいる機器を外して入れ直す

        • USB メモリ、外付けハードディスク、SD カード、CD や DVD を外してから、電源を入れ直します。
        • 「Start PXE over IPv4」「No bootable device」などのメッセージが続く場合は、BIOS や UEFI の設定は変えずに、メーカーのサポート窓口に相談します。

      • 画面に出た文字やエラーコードを写真に撮って控える

        • 青い画面や黒い画面に文字が出たら、スマホで画面全体を写真に撮ります。エラーコード（「0xc」から始まる英数字など）や停止コード（「MEMORY_MANAGEMENT」のような英語）が写るようにします。
        • 電源のランプの色と点滅のしかた、ファンの音がするか、起動のときにピーという音が鳴るか（鳴る場合は回数）もメモします。メーカーによっては、ランプの点滅や音の回数で、故障の場所を知らせる仕組みがあります。
        • BitLocker の回復キーを求められた場合は、別のスマホやパソコンで Microsoft アカウントにサインインし、回復キーが保存されていないかを確かめます。確かめ方は、注意書きにあるマイクロソフトの案内を見てください。会社や学校から渡されたパソコンは、その管理者に相談します。
        • 撮った写真は、メーカーなど公式の窓口に相談するときだけ使い、SNS などには載せません。

    2. 1週間の行動

      目安：画面が出るようになったら、まずデータを守ります。起動しないままなら、メーカーの窓口に相談します

      • 画面が出るようになったら、まず大切なデータをコピーする

        • 写真や書類など、失いたくないデータを、USB メモリや外付けハードディスク、クラウドストレージ（OneDrive、Google ドライブなど）にコピーします。
        • 量が多い場合は、いちばん大切なフォルダー（「ピクチャ」「ドキュメント」など）から先にコピーします。
        • Windows には「Windows バックアップ」というアプリがあり、フォルダーや設定を OneDrive にバックアップできます。手順は、注意書きにあるマイクロソフトの案内を見てください。
        • コピーしたら、コピー先でファイルが開けるかを確かめます。

        バックアップの始め方は、お悩み No.017「パソコンが壊れたらデータはどうなる？バックアップの始め方が分からない」にもまとめています。

      • Windows Update と、画面や音などのドライバーの更新を確かめる

        • 「設定」アプリの「Windows Update」を開き、更新プログラムがあるかを確かめます。
        • 画面や音などのドライバーの更新は、「Windows Update」の「詳細オプション」にある「オプションの更新プログラム」に表示されることがあります。
        • パソコンのメーカーが、ドライバーを更新するためのアプリを用意していることもあります。メーカーのサポートページで確かめます。
        • ドライバーの更新のあとに画面が映らなくなった場合は、ドライバーを前の版に戻す（ロールバックする）方法があります。手順は、注意書きにある「Windows の空白の画面のトラブルシューティング」を見てください。

        更新の途中で電源を切ってよいか迷うときは、お悩み No.020「パソコンが急に固まる・Windows Update が終わらない。電源を切っても大丈夫？」も参考にしてください。

      • エラーコードを、公式のサポートページで調べる

        • 写真に撮ったエラーコードや停止コードを、メーカーのサポートページや、マイクロソフトのサポートページで調べます。
        • 停止コードが出る場合は、注意書きにある「Windows の予期しない再起動および停止コード エラーのトラブルシューティング」に、確かめる順番が載っています。
        • 検索結果の広告や、知らないサイトの「修復ツール」は使いません。公式のページからたどります。

      • 回復の機能を使う前に、データへの影響を確かめる

        起動しないときは、Windows の回復の機能（Windows 回復環境）から、修復を試せる場合があります。「トラブルシューティング」や「詳細オプション」から、次のような項目を選べます。マイクロソフトの案内に沿って、データへの影響をまとめました。

        • スタートアップ修復：Windows の起動を妨げている問題の修復を試みます。
        • 更新プログラムのアンインストール：最近の更新のあとに起動しなくなった場合に使います。ファイルとアプリは影響を受けません。
        • システムの復元：個人用のファイルは残りますが、復元ポイントのあとに入れたアプリやドライバー、設定の変更は元に戻ります。
        • ポイントインタイム リストア：個人用のファイルも含めて、パソコン全体が復元ポイントの時点に戻ります。その時点のあとに作ったファイルは失われます。
        • この PC を初期状態に戻す：選び方によっては、個人用のファイルがすべて削除されます。アプリと設定は削除されます。

        どの項目も、操作の前に大切なデータをバックアップしておきます。押し間違いや、途中で失敗したときに備えるためです。画面が出ずバックアップができない場合は、データが消える項目は選ばず、先にメーカーの窓口に相談します。BitLocker が有効なパソコンでは、ほとんどの項目で回復キーが必要になります。

      • 起動しないままなら、メーカーのサポート窓口に相談する

        • パソコンの底面や背面のシール、保証書などで、型番と製造番号（シリアル番号）を控えます。
        • 保証期間が残っているかを、保証書やメーカーのサイトで確かめます。
        • 窓口には、エラーコードの写真、電源ランプの色と点滅、ファンの音、ピーという音の回数、いつから起きたか、試したこと（放電、別のモニターなど）を伝えます。
        • メーカーによっては、パソコンの部品の状態を調べる診断ツールを用意しています。Windows が起動しない状態でも使えるものもあります。使えるかどうかと使い方を、窓口やサポートページで確かめます。
        • 修理に出す場合は、データがどうなるか（記憶装置の交換や初期化があるか）を、申し込む前に確かめます。データを残したい場合は、その希望を伝えます。

    3. 1か月の見直し

      目安：1か月後に20〜30分。その後は月に一度、バックアップを取ります

      • 月に一度、バックアップを取る習慣にする

        • バックアップを取る日を決めます。たとえば、月の初めの週末など、忘れにくい日にします。
        • 外付けハードディスクにコピーしている場合は、前回のあとに増えたファイルもコピーします。OneDrive などで自動でバックアップしている場合は、同期が止まっていないかを確かめます。
        • バックアップ先が壊れることもあります。特に大切なデータは、2か所以上に置いておくと安心です。

      • ファンの音が大きい、熱いときは、メーカーの案内に沿って通気口のホコリを確かめる

        • ファンの音が大きい、本体が熱いといった様子が続く場合は、通気口（空気の出入り口）にホコリがたまっていないかを見ます。
        • 掃除は、取扱説明書やメーカーのサポートページの案内に沿って、外側の通気口だけにします。自分で分解して、中を掃除するのはやめます。
        • 布団やクッションの上で使うと、通気口がふさがれます。机などの平らな場所で使います。

      • 起動が遅い、固まるときは、記憶装置の空き容量と寿命の目安を確かめる

        • 「設定」アプリの「システム」>「ストレージ」で、空き容量を確かめます。マイクロソフトの案内では、空き容量を10〜15％ほど残しておくことが勧められています。
        • Windows 11 では、「ストレージ」>「ストレージの詳細設定」>「ディスクとボリューム」でディスクの「プロパティ」を開くと、「ドライブの正常性」に推定残り寿命などが表示される場合があります。表示されるのは NVMe という種類の SSD だけです。項目の名前は、Windows のバージョンによって違います。
        • 寿命が少なくなっている、警告が出ているといった場合は、まずバックアップを取ってから、メーカーの窓口に相談します。

        空き容量の増やし方は、お悩み No.002「パソコンが遅くて容量もいっぱい、買い替える前にできること」にもまとめています。

      • 修理か買い替えかは、メーカーの窓口で相談してから決める

        • 修理の費用と期間の見積もり、保証が使えるか、使っている年数を並べて比べます。
        • Windows 10 のパソコンは、マイクロソフトのサポートが2025年10月14日に終わっています。買い替えを考えるときの材料の1つになります。
        • 買い替える場合は、データの移し方を先に確かめておきます。Windows バックアップでバックアップした内容は、新しいパソコンの初期設定のときに復元できます。
        • 古いパソコンを処分する場合は、データの消し方をメーカーの案内で確かめてから処分します。

      • 「パソコンが壊れています」「今すぐ電話してください」と出ても、電話しない

        パソコンの調子が悪いときに、ブラウザーの画面いっぱいに「ウイルスに感染しました」「パソコンが壊れています」「今すぐ電話してください」と、電話番号つきの警告が出ることがあります。IPA（情報処理推進機構）は、このような警告を「偽のセキュリティ警告」（サポート詐欺）として注意を呼びかけています。

        • 表示された番号には電話しません。IPA の案内では、電話をかけなければ被害にあうことはありません。
        • IPA の案内では、Esc キーを2〜3秒長押しすると全画面の表示が解除され、閉じるボタンが出ます。
        • 心配なときは、メーカーやマイクロソフトの公式の窓口に、自分から連絡して確かめます。

    まず今日、異音や焦げ臭いにおいがないかを確かめ、電源ケーブルとコンセント、電源タップのスイッチを見ます。画面を表示させるキー操作を試し、放電を1回試します。テレビや別のモニターにつないで、画面が出るかも確かめます。英語のメッセージが出る場合は、USB 機器を外して入れ直します。青い画面が出る場合は、エラーコードを写真に撮って控えます。次の1週間は、画面が出るようになったら、まず大切なデータをコピーし、Windows Update とドライバーの更新を確かめます。回復の機能を使う前には、データへの影響を確かめます。起動しないままなら、写真とメモを持って、メーカーの窓口に相談します。1か月後に、月に一度のバックアップを習慣にし、記憶装置の空き容量と寿命の目安を確かめて、修理か買い替えかを窓口で相談して決めます。手順の名前や場所は、機種や Windows のバージョンで変わることがあります。分からないところは、メーカーやマイクロソフトのサポートページなど、公式のヘルプで確かめてください。
