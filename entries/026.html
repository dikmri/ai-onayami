パソコンから音が出ない。動画は映るのに声も音楽も聞こえないときの確認順番

    AIの見立て

    改善できる見込みあり

    パソコンから音が出ないトラブルは、故障ではないことが多くあります。多くは、音の出口（出力先）が別の機器になっている、ミュートになっている、といった設定の問題です。確かめる場所はある程度決まっています。順番に確かめれば、本人の手で直せることが多いと考えます。そのため、改善できる見込みがあります。

    お悩みの文章には、故障か設定かを見分ける手がかりが2つ書かれています。「動画の映像は映る」ことと、「ヘッドホンをつなぐと聞こえる」ことです。この2つから、パソコンは音を出せていて、その音がスピーカーまで届いていない可能性が高いと考えます。

    一方で、Windows Update のあとや、ドライバー（機器を動かすためのソフト）の不具合で、急に音が出なくなることもあります。部品が故障している場合もあります。これらは、設定を確かめるだけでは直らないことがあります。その場合の相談先は、行動プランの「1か月の見直し」に書いています。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    映像は映るのに音だけ出ない
    動画を見ようとしたら、映像は映るのに、声も音楽もまったく聞こえない。
    ヘッドホンでは聞こえるのに、スピーカーから出ない
    ヘッドホンをつなぐと聞こえるのに、スピーカーからは音が出ないことがある。
    音量は上がっているのに無音
    画面の右下のスピーカーのマークを見ると、音量は上がっているはずなのに、無音のままになっている。
    どこを直せばいいか分からない
    ある日急に出なくなり、設定をあちこち触ってみたが、どこを直せばいいのか分からない。
    買い直すべきか迷っている
    新しいスピーカーを買えば直るのか、買い直しても同じだったらどうしようと迷っている。壊れたのか設定の問題なのかを自分で見分けたい。

    音が出ない原因

    パソコンから音が出ない原因の多くは、次の4つのどれかです。どれも故障ではなく、設定を確かめるだけで直ることが多いものです。

    音の出口（出力先）が別の機器になっている
    パソコンは、音を出す機器を1つ選んで、そこへ音を送ります。この出力先が、スピーカーではなく、モニター（HDMI でつないだ画面）やヘッドホンになっていることがあります。スピーカーの付いていないモニターが選ばれていると、音はどこからも聞こえません。
    ミュートになっているか、音量がゼロ
    スピーカーのマークに×印が付いているときは、ミュート（消音）の状態です。キーボードの消音のキーを押すと、気づかないうちにミュートになることがあります。外付けのスピーカーには、スピーカー本体にも電源や音量のつまみがあります。
    ヘッドホンや Bluetooth のイヤホンがつながったまま
    ヘッドホンをつないでいると、スピーカーから音が出ない機種があります。Bluetooth のイヤホンは、見えないところでパソコンとつながったままになり、音がイヤホンの方へ送られていることがあります。
    アプリごとの音量が下がっている
    Windows では、パソコン全体の音量とは別に、アプリごとに音量を決められます。ブラウザや動画アプリの音量だけがゼロになっていると、全体の音量が上がっていても、そのアプリの音は聞こえません。動画の再生画面にあるスピーカーのマークが消音になっている場合も、同じように聞こえません。

    このほか、Windows Update のあとや、ドライバーの不具合で、急に音が出なくなることもあります。この場合は、設定を確かめても直らないことがあります。行動プランの「1週間の行動」と「1か月の見直し」で扱います。

    故障か設定かを見分ける手がかり

    お悩みの文章にある様子から、次のように切り分けられます。

    動画の映像は映るが、音だけ出ない
    パソコンは動いていて、動画も再生できています。音だけが別の機器に送られているか、どこかで消音になっている可能性が高いと考えます。
    ヘッドホンをつなぐと聞こえる
    パソコンは音を出せています。パソコンの中で音を作る部分は、壊れていない可能性が高いと考えます。疑うのは、出力先の選び方と、スピーカーの側（電源、ケーブル、音量のつまみ）です。
    別のアプリでは音が出る
    パソコン全体ではなく、そのアプリの音量や設定の問題です。
    どのアプリでも、ヘッドホンでも聞こえない
    パソコン全体の設定や、ドライバー、部品の問題の可能性があります。「出力デバイスが見つかりません」と表示される場合も、この種類です。設定を確かめるだけでは直らないことがあります。

    このように切り分けると、故障か設定の問題かを、ある程度は自分で見分けられます。ただし、手がかりから分かるのは「どこが怪しいか」までです。故障かどうかを確実に決めるには、お店やメーカーでの点検が必要な場合があります。

    ボトルネック

    AIは、次の循環がいちばん大きなボトルネックだと考えます。

    1. 音が出ないので、設定をあちこち触ってみる
    2. どこを変えたのか分からなくなり、何が原因なのかも分からないままになる
    3. 「壊れたのでは」と不安になり、スピーカーの買い直しを考える
    4. 「買い直しても同じだったら」と迷って手が止まり、無音のまま過ごす

    4のあと、また1に戻ります。

    この循環は、1のところで止められます。あちこち触る代わりに、確かめる順番を決めて、上から1つずつ確かめます。1つ確かめるごとに、音が出るかを試します。変えた設定はメモに残します。そうすれば、どこで直ったのかが分かります。直らなかったときも、どこまで確かめたかを相談先に伝えられます。

    スピーカーの買い直しは、順番に確かめても直らず、スピーカー本体が怪しいと分かってから考えても遅くありません。

    画面の名前やボタンの場所は、パソコンの機種や Windows のバージョンによって違います。この記事で挙げる名前は一例です。分からないときは、Microsoft サポートやパソコンのメーカーなどの公式のヘルプで確かめてください。

    本人が変えやすいこと・変えにくいこと

    変えにくいこと

    • Windows の画面の作りや、設定の名前と場所
    • Windows Update で変わる内容
    • ドライバーの不具合や、部品の故障
    • パソコンの機種ごとの作り（ヘッドホンをつなぐとスピーカーが止まる、など）

    変えやすいこと

    • 音の出口（出力先）の選び方
    • ミュートとパソコン全体の音量
    • アプリごとの音量
    • ヘッドホンや Bluetooth のイヤホンを外すこと
    • 確かめる順番を決めて、1つずつ試すこと
    • 変えた設定や、起きたことをメモすること
    • 困ったときに相談する先を決めておくこと

    次の行動プランは、今日「音の出口」を確かめることから始め、1週間で設定画面をじっくり見直し、1か月後に再発のパターンを振り返る順番にしています。

    3具体的な行動プラン

    一度にすべてをやる必要はありません。上から順に、1つずつ試してください。1つ試すごとに、動画を再生して音が出るかを確かめます。

    お悩みの文章に「画面の右下のスピーカーのマーク」とあるので、この記事では Windows のパソコンで説明します。ボタンの名前や場所、設定の項目の名前は、パソコンの機種や Windows のバージョン（Windows 11 か Windows 10 か、など）によって違います。画面が違うときは、Microsoft サポートやパソコンのメーカーなどの公式のヘルプで確かめてください。

    1. 今日からできる小さな一歩

      目安：10〜15分。音が出ない今のうちに、上から順に試します

      • スピーカーのアイコンで、音量とミュートを確かめる

        画面の右下にあるスピーカーのアイコンを押します。

        • 音量のつまみ（スライダー）が、ゼロや小さすぎる位置になっていないかを見ます。
        • スピーカーのアイコンに×印が付いていたら、ミュート（消音）の状態です。アイコンを押して×印を外します。
        • キーボードに音量や消音のキーがある機種では、そのキーで音量を上げたり、消音を外したりすることもできます。

        スピーカーのアイコンが見つからないときは、画面の右下の「^」のマーク（隠れているアイコンを表示するボタン）を押すと、出てくることがあります。

      • 音の出口（出力先）が「スピーカー」になっているかを確かめる

        スピーカーのアイコンを押すと、音量のつまみが出ます。つまみの右にある小さな矢印（「>」など）を押すと、音を出す機器の一覧が出ます。今選ばれている機器が、音の出口です。

        • 「スピーカー」が選ばれているかを見ます。名前は機種によって違い、「スピーカー」の後ろにメーカーの名前などが付くことがあります。
        • 「モニター」「HDMI」や、モニターの製品名が選ばれていたら、音は画面の方へ送られています。スピーカーの付いていないモニターでは、音は聞こえません。一覧から「スピーカー」を選び直します。
        • ヘッドホンやイヤホンの名前が選ばれていたら、音はそちらへ送られています。同じように「スピーカー」を選び直します。

      • ヘッドホンや Bluetooth のイヤホンを、一度外す

        • ヘッドホンのケーブルがパソコンに差さっていたら、抜きます。ヘッドホンをつないでいる間は、スピーカーから音が出ない機種があります。
        • Bluetooth のイヤホンやスピーカーを使ったことがあれば、イヤホンをケースにしまうか、電源を切ります。それでも出力先が切り替わらないときは、「設定」→「Bluetooth とデバイス」で、その機器の接続を切ります（Windows 10 では「設定」→「デバイス」→「Bluetooth とその他のデバイス」）。

        外したあとで、もう一度スピーカーのアイコンから出力先を見て、「スピーカー」が選ばれているかを確かめます。

      • 外付けのスピーカーなら、電源とケーブルを確かめる

        パソコンとは別に置くスピーカーを使っている場合は、スピーカーの側も確かめます。

        • スピーカーの電源が入っているか（電源のランプが付いているか）を見ます。
        • スピーカー本体に音量のつまみがあれば、ゼロになっていないかを見ます。
        • ケーブルが、パソコンとスピーカーの両方にしっかり差さっているかを見ます。差し込む穴が合っているかも見ます。音を出す穴には、ヘッドホンのマークや緑色の印が付いていることがあります。印は機種によって違います。
        • USB でつなぐスピーカーなら、パソコンの別の USB の差し込み口に差し替えてみます。

      • 別の動画や音楽のアプリでも試す

        今見ている動画だけの問題か、パソコン全体の問題かを切り分けます。

        • 別のサイトの動画や、パソコンに入っている音楽や動画のアプリで、音が出るかを試します。
        • 動画の再生画面にも、スピーカーのマークがあることが多くあります。そこが消音になっていないか、音量が下がっていないかも見ます。
        • ほかのアプリでは音が出るなら、問題はそのアプリだけです。「1週間の行動」の音量ミキサーで、そのアプリの音量を確かめます。

      • どうしても直らないときは、パソコンを再起動する

        上の確かめ方で直らないときは、開いている作業を保存してから、「スタート」→「電源」→「再起動」を選びます。再起動したら、もう一度、音量と出力先を確かめます。

        「更新して再起動」と表示されていたら、そちらを選びます。途中になっている Windows Update が終わると、音が戻ることがあります。

      • 試したことと結果を、一言メモする

        試したことと、音が出たかどうかを、紙やスマホのメモに一言ずつ書きます。たとえば「出力先がモニターだった。スピーカーに変えたら直った」のように書きます。直らなかった場合も、どこまで確かめたかが分かるようにしておきます。

    2. 1週間の行動

      目安：30分ほどを1回。音が出なくなったときにも見直します

      • 「設定」の画面で、出力デバイスを確かめる

        「スタート」→「設定」→「システム」→「サウンド」を開きます。

        • 「出力」の欄で、音を出す機器（出力デバイス）に「スピーカー」が選ばれているかを見ます。ほかの機器が選ばれていたら、「スピーカー」を選び直します。ここで選んだ機器が、ふだん使う出力先になります。
        • 同じ画面で、出力の音量がゼロになっていないかも見ます。
        • 一覧に「スピーカー」が出てこないときや、「出力デバイスが見つかりません」と表示されるときは、メモしておきます。「1か月の見直し」で扱います。

      • 「音量ミキサー」で、アプリごとの音量を確かめる

        「設定」→「システム」→「サウンド」→「音量ミキサー」を開きます。Windows 10 では、「サウンド」の画面の「アプリの音量とデバイスの設定」などから開きます。

        • パソコン全体の音量だけでなく、使っているアプリ（ブラウザや動画アプリ）の音量が、ゼロや小さすぎる位置になっていないかを見ます。
        • アプリごとに出力先を選べる画面もあります。使っているアプリの出力先に、別の機器が選ばれていないかも見ます。
        • アプリは、音を出している間だけ一覧に出ることがあります。動画を再生しながら開くと、見つけやすくなります。

      • 「オーディオ」のトラブルシューティングを実行する

        Windows には、音の問題を自動で調べて直そうとする機能（トラブルシューティング ツール）があります。

        • 「設定」→「システム」→「トラブルシューティング」→「その他のトラブルシューティング ツール」を開きます。「オーディオ」の横の「実行」を押します。
        • Windows のバージョンによっては、「問い合わせ」というアプリが開きます。画面の質問に答えながら進めます。
        • 途中で、どの機器を調べるかを聞かれたら、「スピーカー」を選びます。

        項目の名前や場所は、Windows のバージョンによって違います。見つからないときは、下の「公式のヘルプ」にある Microsoft サポートのページで確かめてください。

      • 音が出なくなったのが、Windows Update の直後だったかをメモする

        「設定」→「Windows Update」→「更新の履歴」を開くと、更新が入った日付を見られます（Windows 10 では「設定」→「更新とセキュリティ」→「Windows Update」→「更新の履歴を表示する」）。

        音が出なくなった日と、更新が入った日が近いかどうかをメモします。近い場合は、更新が原因の可能性があります。相談するときに伝えると、話が早く進みます。Microsoft サポートにも、Windows Update のあとに音が出なくなった場合のページがあります（下の「公式のヘルプ」を見てください）。

    3. 1か月の見直し

      目安：1か月後に20〜30分

      • 再発のパターンをメモにまとめる

        音がまた出なくなったことがあれば、そのときの様子をメモにまとめます。次のことを書き留めておくと、自分で直すときにも、相談するときにも役に立ちます。

        • 音が出なくなるのは、特定のアプリだけか、パソコン全体か
        • ヘッドホンや Bluetooth のイヤホンをつないだ後だけか
        • モニターをつないだ後や、Windows Update の後だけか
        • どうしたら直ったか（出力先を選び直した、再起動した、など）

        同じ原因で何度も起きているなら、その確かめ方を「今日からできる小さな一歩」の順番の先頭に書き足しておきます。

      • ドライバーの更新が必要なら、パソコンメーカーの公式サイトから入手する

        ここまでの確かめ方で直らない場合、ドライバー（音を出す部品を動かすためのソフト）の更新が必要なことがあります。

        • ドライバーは、パソコンメーカーの公式サイトのサポートページからだけ入手します。パソコンの機種名や型番で探します。型番は、パソコンの底面のシールや保証書などに書かれていることが多くあります。
        • 検索で出てきた見知らぬサイトの「ドライバー更新ツール」や「無料の修復ツール」は使いません。関係のないソフトや、不正なソフトが一緒に入ることがあります。
        • ドライバーの入れ替えに自信がないときは、無理に自分で行わず、下の窓口に相談します。

      • スピーカーを買い直す前に、確かめること

        買い直しを考えるのは、次のことをすべて確かめた後にします。

        • ヘッドホンでは聞こえる（パソコンは音を出せている）
        • 出力先に「スピーカー」が選ばれている
        • ミュートが外れていて、全体とアプリの音量が上がっている
        • 外付けのスピーカーなら、電源、音量のつまみ、ケーブルを確かめた

        これでもそのスピーカーだけ鳴らない場合は、スピーカー本体が故障している可能性があります。外付けのスピーカーをほかの機器につなげる場合は、つないで鳴るかを試すと、スピーカーの側の問題かを確かめられます。ノートパソコンの内蔵のスピーカーは自分で交換できないことが多いので、下の窓口に相談します。

      • 直らないときは、パソコンショップやメーカーの窓口に相談する

        「出力デバイスが見つかりません」と表示され続ける場合や、どの方法でも音が戻らない場合は、設定を確かめるだけでは直らないことがあります。次のような窓口に相談します。

        • パソコンを買ったお店や、パソコンショップの相談窓口（内容によって有料の場合があります。前もって確かめます）
        • パソコンのメーカーの公式サイトや、保証書に書かれた相談窓口
        • 外付けのスピーカーの場合は、そのスピーカーのメーカーの相談窓口

        パソコンを買ってから日が浅い場合は、保証期間の中かどうかを保証書で確かめておきます。相談するときは、上でまとめたメモを見せると、状況を伝えやすくなります。

    まず今日、画面の右下のスピーカーのアイコンで、音量とミュート、音の出口（出力先）を確かめます。ヘッドホンや Bluetooth のイヤホンを一度外し、別のアプリでも音が出るかを試します。直らないときは再起動します。次の1週間は、「設定」→「システム」→「サウンド」で出力デバイスを確かめ、音量ミキサーでアプリごとの音量を見て、オーディオのトラブルシューティングを実行します。音が出なくなったのが Windows Update の直後だったかもメモします。1か月後に、再発のパターンをメモにまとめ、直らない場合はメーカーの公式サイトや相談窓口を使います。手順の名前や場所は、機種や Windows のバージョンで変わることがあります。分からないところは、Microsoft サポートやパソコンのメーカーのサポートページで確かめてください。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの操作や修理についての専門的な助言ではありません。

    パソコンの設定の変更は、ご自身の判断と責任で行ってください。設定を変える前に、今の設定の画面をスクリーンショットで残しておくと、元に戻しやすくなります。勤務先から貸し出されたパソコンでは、設定を変える前に勤務先の担当者に確かめてください。

    設定の名前や場所、ボタンの形は、パソコンの機種や Windows のバージョンによって変わることがあります。この記事の手順と画面が違うときは、Microsoft サポートやパソコンのメーカーの公式のヘルプで確かめてください。

    ドライバーやソフトは、必ずパソコンメーカーや Microsoft などの公式サイトから入手してください。検索や広告で出てきた見知らぬサイトの「無料の修復ツール」「ドライバー更新ツール」は入れないでください。関係のないソフトや、不正なソフトが一緒に入ることがあります。

    「音が出ないのを直します」「パソコンに問題が見つかりました」などと名乗る電話やメッセージで、パソコンの操作や、遠隔操作のソフトのインストールを指示されることがあります。その場で従わないでください。いったん電話やメッセージを終えて、メーカーの公式サイトや保証書に書かれた窓口に、自分から連絡して確かめます。画面に「ウイルスに感染しました」などの警告と電話番号が出た場合も、その番号には電話しないでください。

    知らない相手の指示でソフトを入れてしまった場合や、お金を払ってしまった場合は、早めに下の相談先に相談してください。

    公式のヘルプ

    • Windows のサウンドまたはオーディオの問題を修正する（Microsoft サポート）
    • Windows でスピーカーまたはヘッドホンからサウンドが再生されない場合のオーディオの問題を修正する（Microsoft サポート）
    • Windows でシステム サウンドは動作するがアプリ オーディオが動作しない問題を解決する（Microsoft サポート）
    • Windows で Windows Update を実行した後にオーディオが動作しなくなる問題を修正する（Microsoft サポート）
    • Windows でオーディオ出力デバイスが見つからない、または検出されない問題を修正する（Microsoft サポート）
    • Windows で Bluetooth 接続時に音が出ない問題を修正する（Microsoft サポート）
