お悩み No.002 ・ 2026年11月22日公開

パソコンが遅くて容量もいっぱい、買い替える前にできること

カテゴリ

    1お悩み

    2AIによる検証

    AIの見立て

    改善できる見込みあり

    空き容量の不足や、自動で起動するアプリの多さは、本人の操作で改善できることが多い原因です。お悩みの症状には、これらと当てはまる点がいくつもあります。そのため、買い替える前に試せることがあります。

    ただし、パソコンの部品の性能が足りない場合は、設定の見直しだけでは十分に速くならないこともあります。その場合は、部品の交換や買い替えを考えます。

    悩みの分解

    お悩みの文章から、困っていることを5つに分けました。

    起動
    電源を入れてから、使えるようになるまでに時間がかかる。
    アプリ
    アプリの立ち上がりが遅い。写真や動画の編集アプリは、特に重い。
    夕方
    仕事の終わり頃になると、さらに重くなる。
    容量
    Cドライブの空き容量が残りわずかで、「容量不足」の警告が出ることがある。
    買い替え
    費用とデータを移す手間が気になり、踏み切れない。自分でできることを先に試したい。

    遅さの原因の候補

    パソコンが遅くなる原因は1つとは限らず、いくつかが重なっていることもよくあります。症状だけでは原因を決められないので、考えられる候補を分けて挙げます。それぞれに確かめ方を添えました。

    空き容量
    Windows は、メモリが足りなくなると、Cドライブの一部をメモリの代わりに使います。写真や動画の編集アプリも、作業中にCドライブへ一時的なファイルを書き込みます。空き容量が少ないとこれらがうまく働かず、動作が遅くなることがあります。「容量不足」の警告が出ているので、最初に確かめたい候補です。確かめ方：「設定」→「システム」→「ストレージ」で、空き容量と、何が容量を使っているかを見ます。
    自動起動
    パソコンの起動と同時に、自動で立ち上がるアプリが多いと、起動に時間がかかります。立ち上がったアプリは、その後も裏でメモリを使い続けます。「起動が遅い」という症状に当てはまります。確かめ方：タスクマネージャーの「スタートアップ アプリ」で、自動で立ち上がるアプリの数を見ます。
    開きっぱなし
    ブラウザのタブやアプリを開いたままにしていると、使うメモリが少しずつ増えていきます。「仕事の終わり頃にさらに重くなる」という症状に当てはまります。確かめ方：重いと感じたときに、タスクマネージャーでメモリの使用率を見ます。
    発熱
    本体にほこりがたまると、熱をうまく逃がせなくなります。パソコンは熱くなりすぎると、自動で性能を下げて温度を抑えます。長い時間使うほど重くなる場合は、この候補も当てはまります。確かめ方：ファンの音が大きくないか、本体が熱くないか、通気口にほこりが見えないかを確かめます。
    部品の性能
    データを保存する部品がHDD（ハードディスク）の場合や、メモリの量が少ない場合は、ほかの対策をしても速くなりにくいことがあります。写真や動画の編集アプリは、多くのメモリを使います。確かめ方：タスクマネージャーの「パフォーマンス」で、ディスクの種類（SSD か HDD か）と、メモリの量を見ます。

    このほか、Windows の更新が途中で止まっている場合や、ウイルスなどの不正なソフトが動いている場合にも、動作が遅くなることがあります。

    ボトルネック

    AIは、空き容量の不足がいちばん先に対処すべきボトルネックだと考えます。警告が出ていることに加えて、空き容量が少ないと Windows の更新やアプリの作業にも差し支えるためです。

    ただし、これだけが原因だと決めつけず、確かめやすく元に戻しやすいものから順に試していきます。

    1. 空き容量を確かめ、増やす（警告が出ていて、すぐに確かめられる）
    2. 自動起動と開きっぱなしのアプリを減らす（設定を変えるだけで試せて、元にも戻せる）
    3. 発熱を確かめる（音と温度とほこりを見れば分かる）
    4. 部品の性能を見直す（費用がかかるので、1〜3を試したあとに判断する）

    1つ試すごとに動作の変化を見ると、どれが効いたのかが分かります。

    買い替えが必要かどうかの見分け方

    次のどちらに当てはまるかで、買い替えが必要かどうかを判断できます。

    まだ買い替えなくてよい場合

    • 空き容量を増やしたり、自動起動のアプリを減らしたりしたら速くなった
    • ほこりを掃除したら、ファンの音や熱がおさまった
    • 保存用の部品がHDDで、SSDに交換できる機種である
    • メモリが足りないが、増設できる機種である

    買い替えを考えてよい場合

    • このページの対策をひととおり試しても、遅さがほとんど変わらない
    • メモリや保存用の部品が本体に固定されていて、交換や増設ができない
    • Windows 10 のままで、Windows 11 に更新できない（Windows 10 のサポートは2025年10月に終了しています）
    • 使いたい編集アプリが求める性能（必要なメモリの量など）を満たしていない
    • 修理や部品交換の費用が、買い替えの費用に近い

    お悩みの症状からは、まず「まだ買い替えなくてよい場合」に当てはまるかどうかを確かめる価値があります。次の行動プランは、無料で試せることから順に並べています。

    3具体的な行動プラン

    作業を始める前に、必ず大事なデータのバックアップを取ってください。このプランには、ファイルの削除や移動が含まれます。間違えて消したファイルは、元に戻せないことがあります。

    一度にすべてをやる必要はありません。上から順に、できるものを試してください。画面の名前は Windows 11 のものです。Windows 10 では、項目の名前や場所が少し違うことがあります。

    1. 今日からできる小さな一歩

      目安：30分〜1時間（バックアップするデータの量によって変わります）

      • 最初に、大事なデータのコピーがあるかを確かめる

        写真、動画、仕事の書類など、なくなると困るファイルが、パソコン本体にしかない状態になっていないかを確認します。

        • 本体にしかないファイルは、外付けのHDD・SSDやUSBメモリにコピーします。OneDrive などのクラウドに保存する方法もあります。
        • コピーしたら、コピー先でいくつかのファイルを開き、きちんと見られることを確かめます。
        • このあとの作業で何かを削除するときは、その前に「コピーが別の場所にあるか」を毎回確認します。

      • 今の状態を記録しておく

        あとで効果を比べるために、次の2つをメモします。

        • 電源を入れてから、デスクトップが表示されてアプリを使えるようになるまでの時間（スマホのストップウォッチで計ります）
        • Cドライブの空き容量（エクスプローラーで「PC」を開くと表示されます）

      • タスクマネージャーで、重いアプリを確かめて閉じる

        Ctrl + Shift + Esc を同時に押すと、タスクマネージャーが開きます。小さい画面で開いた場合は、「詳細」を押します。

        • 「プロセス」の画面で、「メモリ」や「ディスク」の列の見出しを押すと、使っている量が多い順に並びます。
        • 使っていないアプリが上のほうにあれば、そのアプリの画面に戻り、作業を保存してから閉じます。
        • 名前を見ても何か分からないものは、終了させないでください。Windows の動作に必要なものが含まれていることがあります。

      • ブラウザのタブを減らす

        開いたままのタブは、1つずつメモリを使います。あとで読むページはブックマークに入れてから閉じます。

        Chrome や Edge には、しばらく使っていないタブのメモリを自動で減らす機能があります。ブラウザの設定画面で「パフォーマンス」と検索すると、オンになっているかを確かめられます。

      • ごみ箱を空にする

        デスクトップの「ごみ箱」を開き、残しておきたいファイルが入っていないかを確かめます。そのあと「ごみ箱を空にする」を押します。空にすると、中のファイルは元に戻せません。

      • 何が容量を使っているかを確かめる

        「設定」→「システム」→「ストレージ」を開くと、Cドライブの使用量が、アプリ、一時ファイル、写真、動画などの種類別に表示されます。

        どの種類が大きいかをメモしておきます。1週間の行動で、大きいものから順に減らします。

    2. 1週間の行動

      目安：1日15〜30分ほど。数日に分けて進めます

      • ストレージセンサーをオンにする

        「設定」→「システム」→「ストレージ」にある「ストレージ センサー」をオンにします。オンにすると、一時ファイルやごみ箱の古いファイルを、Windows が自動で削除するようになります。

        • 「ストレージ センサー」の文字を押すと、細かい設定を変えられます。ごみ箱のファイルを何日たったら消すか、などを選べます。
        • 「ダウンロード」フォルダのファイルを自動で消す項目は、中身を確かめるまでは、削除しない設定のままにしておきます。
        • 同じ「ストレージ」の画面の「一時ファイル」からも、不要なファイルをまとめて削除できます。ただし、一覧の「ダウンロード」にチェックを入れると、ダウンロードフォルダの中身がすべて消えます。中身を確かめるまでは、チェックを外したままにしてください。

      • 使っていないアプリをアンインストールする

        「設定」→「アプリ」→「インストールされているアプリ」を開きます。並べ替えでサイズの大きい順を選ぶと、容量を多く使っているアプリから順に表示されます。Windows 10 では「設定」→「アプリ」→「アプリと機能」です。

        • 使っていないと分かっているアプリだけを、アンインストールします。
        • パソコンのメーカー名が付いたものや、「ドライバー」と付いたもの、何のためのものか分からないものは、消さずに残します。
        • 使うかどうか迷うものは、残しておいて構いません。

      • 写真や動画を、本体の外に移す

        写真や動画は容量が大きいので、本体の外に移すと空き容量を大きく増やせます。移す先は、外付けのHDD・SSDか、Google フォトや OneDrive などのクラウドです。

        • 外付けのドライブに移すときは、まずコピーします。コピー先で開けることを確かめてから、本体のファイルを削除します。
        • クラウドは、無料で使える容量に上限があります。移す前に、空き容量と料金を確認します。
        • OneDrive に入れたファイルは、右クリックして「空き容量を増やす」を選ぶと、本体からは消えてクラウドだけに保存されます。開くときはインターネットへの接続が必要です。
        • 大事な写真や動画は、1か所だけに置かず、外付けのドライブとクラウドのように2か所以上に保存しておくと安全です。
        • 編集中の写真や動画を移すと、編集アプリがファイルを見つけられなくなることがあります。編集が終わったものから移します。

      • 起動時に自動で開くアプリを減らす

        「設定」→「アプリ」→「スタートアップ」を開くと、パソコンの起動と同時に立ち上がるアプリの一覧が表示されます。タスクマネージャーの「スタートアップ アプリ」でも同じ設定ができます。Windows 10 では、タスクマネージャーの「スタートアップ」です。

        • 毎回すぐには使わないアプリを、オフにします。オフにしてもアプリは削除されず、自分で開けば使えます。
        • タスクマネージャーの「スタートアップへの影響」が「高」のものから見直すと、効果が出やすくなります。
        • ウイルス対策ソフトや、パソコンのメーカー名が付いたソフトは、オンのままにしておきます。

      • 重くなったら再起動する

        仕事の終わり頃に重くなる原因の一つとして、開いたままのアプリやタブが使うメモリが、時間とともに増えていくことが考えられます。重いと感じたら、作業を保存してから「再起動」します。

        Windows の初期設定では、「シャットダウン」をしても Windows の状態の一部が保存され、次の起動に引き継がれます。いったんすべてをリセットしたいときは、「再起動」を選びます。

      • Windows の更新とウイルスの検査をする

        「設定」→「Windows Update」で、更新が止まったままになっていないかを確かめます。更新には空き容量が必要なので、容量を空けたあとに行います。

        「Windows セキュリティ」を開き、「ウイルスと脅威の防止」から「クイック スキャン」を実行します。ほかのウイルス対策ソフトを使っている場合は、そのソフトで検査します。

      • 通気口のほこりを取る

        ファンの音が大きい、本体が熱い、と感じる場合に行います。

        • 電源を切り、電源ケーブルを抜いてから作業します。ノートパソコンは充電器も外します。
        • 本体の外から見える通気口のほこりを、エアダスターや柔らかいブラシで取ります。本体のねじは外しません。
        • ノートパソコンを布団やクッションの上で使うと、通気口がふさがります。机の上など、平らで硬い場所に置いて使います。

    3. 1か月の見直し

      目安：1か月後に30分ほど

      • 最初に記録した数字と比べる

        今日の行動で記録した起動までの時間とCドライブの空き容量を、同じ方法で計り直して比べます。重いと感じたときのメモリとディスクの使用率も、タスクマネージャーで見ておきます。

        空き容量は、Cドライブ全体の1〜2割ほどを空けておくのが目安としてよく挙げられます。

      • 改善が足りないときは、部品の交換や増設を検討する

        タスクマネージャーの「パフォーマンス」で「ディスク」を選ぶと、右上に SSD か HDD かが表示されます。「メモリ」を選ぶと、搭載しているメモリの量と、使っている量が分かります。

        • ディスクが HDD で、使用率が100%近くのまま続くことが多い場合は、SSD に交換（換装）すると、起動やアプリの立ち上がりが速くなる可能性があります。
        • メモリの使用率がいつも高く、80〜90%を超えることが多い場合は、メモリを増やすと改善する可能性があります。
        • SSD への交換では、Windows やデータを新しいSSDへ移す作業も必要になります。自信がない場合は、パソコンの修理店やメーカーに依頼する方法もあります。

      • 交換や増設の前に、機種と保証を確かめる

        • 自分で開けられる機種か：メーカーのサイトや取扱説明書で、メモリや保存用の部品を交換・増設できるかを調べます。ノートパソコンには、メモリが本体に固定されていて増設できない機種もあります。
        • 保証期間中か：本体を自分で開けると、保証が受けられなくなることがあります。保証期間中なら、先にメーカーに相談します。

      • 買い替えを検討する

        部品の交換や増設ができない場合や、検証の「買い替えを考えてよい場合」に当てはまる場合は、買い替えを検討します。

        新しいパソコンを選ぶときは、使いたい写真・動画編集アプリの公式サイトで「推奨環境」（必要なメモリの量など）を確かめ、それを満たすものを選びます。データの移行は、外付けのドライブにまとめてコピーする方法のほか、メーカーや販売店の移行サービスを使う方法もあります。

    1か月たって、空き容量に余裕があり、起動やアプリの立ち上がりが気にならなくなっていれば、部品の交換も買い替えもまだ必要ありません。ストレージセンサーをオンにしたまま、重いときの再起動を続けると、今の状態を保ちやすくなります。

    4注意書き

    この記事は、SNSの公開投稿をもとに合成した悩みに対する、AIによる一つの見方です。パソコンの修理や保守についての専門的な助言ではありません。

    ファイルの削除、アプリのアンインストール、設定の変更、本体を開ける作業は、ご自身の判断と責任で行ってください。削除したデータは、元に戻せないことがあります。作業の前に、必ず大事なデータのバックアップを取ってください。

    画面の名前や手順は、Windows のバージョンやパソコンの機種によって違うことがあります。自分で作業するのが不安なときや、手順どおりにいかないときは、専門の窓口に相談するのも一つの方法です。

    相談先の例

    • パソコンのメーカーのサポート窓口（保証期間中は、まずこちらに相談します）
    • パソコンを購入した販売店
    • パソコンの修理店
